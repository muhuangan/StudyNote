# 计数器

## 核心结论

计数器是对时钟脉冲进行计数的时序电路, 本质是"触发器组 + 组合反馈逻辑". 分类的三个维度是: **时钟方式**(同步/异步),**编码方式**(二进制/十进制),**计数方向**(加/减/可逆).

## 一、计数器的三个基本概念

**模(Modulus)**: 计数器循环一周所经历的状态数, 记为 $M$. 含 $n$ 个触发器的二进制计数器, 模为 $2^n$.

**计数容量**: 能计的最大数, 等于 $M - 1$. 例如模 10 计数器能计 0 至 9.

**分频**: 计数器输出端信号的频率是时钟频率的 $1 / M$, 因此计数器天然是分频器.$n$ 位二进制计数器第 $i$ 位的输出频率是时钟频率的 $1 / 2^{i + 1}$.

## 二、异步计数器(行波计数器)

**结构**: 低位触发器的输出作为高位触发器的时钟.

**翻转规则(以加法为例)**: 用 T'触发器($Q^* = \overline{Q}$), 当低位由 1 变 0(产生下降沿) 时, 高位翻转一次.

**优点**: 结构最简单, 不需要额外的组合逻辑.

**缺点**:

1. **延迟累积**: 总延迟为各级之和, 位数越多越慢. 若每级延迟 20 ns, 则 8 位计数器需要 160 ns 才能稳定.
2. **存在过渡状态**: 由于各级不是同时翻转, 输出在稳定前会出现短暂的中间值(例如从 0111 变到 1000 的过程中会瞬间出现 0110,0100,0000 等), 这些毛刺若被译码会产生错误脉冲.
3. 无法用于高速场合.

## 三、同步计数器

**结构**: 所有触发器共用同一时钟, 各触发器的输入由组合逻辑产生.

**二进制加法计数器的驱动规律**(用 T 触发器):

$$T_0 = 1$$

$$T_1 = Q_0$$

$$T_2 = Q_0 Q_1$$

$$T_i = Q_0 Q_1 \cdots Q_{i - 1} = \prod_{j = 0}^{i - 1} Q_j$$

**规律含义**: 第 $i$ 位只有在**所有低位全为 1** 时才翻转, 这正是二进制加法的进位规则.

**用 D 触发器实现**:

$$D_i = Q_i \oplus \left(\prod_{j = 0}^{i - 1} Q_j\right)$$

**优缺点**:

- 优点: 所有位同时翻转,**无过渡状态**, 速度快(延迟只有一级组合逻辑加触发器延迟).
- 缺点: 需要较多的组合逻辑(与门的输入端数随位数增大), 位数多时需要分级或用超前进位.

## 四、二进制 / 十进制 / 任意进制

| 类型        | 模    | 编码        | 说明                  |
| ----------- | ----- | ----------- | --------------------- |
| 二进制      | $2^n$ | 自然二进制  | 最基础                |
| 十进制(BCD) | 10    | 8421 BCD 码 | 便于十进制显示        |
| 任意进制    | $M$   | 自定义      | 用反馈清零/置数法实现 |

**同步十进制加法计数器**的设计要点: 在第 4 位($Q_3 Q_2 Q_1 Q_0$) 计到 1001(9) 后, 下一个时钟应回到 0000, 而不是继续到 1010. 因此驱动逻辑要按"到 9 就归零"来设计.

## 五、可逆计数器

**结构**: 在加法与减法之间切换, 用一个控制端 $U/\overline{D}$ 选择.

**驱动逻辑**(T 触发器实现):

$$T_i = \left(U \cdot \prod_{j<i} Q_j\right) + \left(\overline{U} \cdot \prod_{j<i} \overline{Q_j}\right)$$

即: 加法模式下低位全 1 时翻转, 减法模式下低位全 0 时翻转.

## 六、典型集成计数器

### 74LS161: 4 位同步二进制加法计数器

| 端口            | 名称     | 有效电平 | 说明                           |
| --------------- | -------- | -------- | ------------------------------ |
| $\overline{CR}$ | 异步清零 | 低       | 立即清零, 不受时钟控制         |
| $\overline{LD}$ | 同步置数 | 低       | 在时钟沿把 $D_0$ 至 $D_3$ 装入 |
| $EP$,$ET$       | 计数使能 | 高       | 两者同时为 1 才计数            |
| $CP$            | 时钟     | 上升沿   |                                |
| $Q_0$ 至 $Q_3$  | 输出     |          | $Q_3$ 为高位                   |
| $RCO$           | 进位输出 | 高       | 计到 1111 且 $ET = 1$ 时为 1   |

**优先顺序**:$\overline{CR}$(最高)> $\overline{LD}$ > 计数使能.

### 74LS160: 同步十进制计数器

与 74LS161 引脚兼容, 但计数循环为 0000 至 1001(模 10),$RCO$ 在计到 1001 时有效.

### 74LS191: 4 位同步二进制可逆计数器

增加 $U/\overline{D}$ 方向控制端,$U/\overline{D} = 1$ 为加法, 0 为减法; 置数为**异步**方式.

### 74LS190: 同步十进制可逆计数器

与 74LS191 对应, 模 10, 编码为 8421 BCD.

### 74LS290 / 74LS90: 异步二-五-十进制计数器

内部含一个二分频和一个五分频, 可灵活接成模 2, 模 5, 模 10 计数器, 是异步结构的代表.

## 七、级联扩展

**同步级联**(推荐):

- 低位片的 $RCO$ 接高位片的 $ET$(或 $EP$), 两片时钟共用.
- 只有低位片计满时高位片才计数, 因此两片同时更新, 无过渡状态.

**异步级联**:

- 低位片的 $RCO$(或其反相输出) 作为高位片的时钟.
- 简单但存在过渡状态, 高速场合慎用.

**级联后的模**: 两片级联后模为两片模的乘积. 例如两片 74LS160 级联得模 100 计数器.

## 八、计数器的典型应用

1. **分频**:$n$ 位二进制计数器的第 $i$ 位实现 $2^{i + 1}$ 分频.
2. **定时**: 计数到设定值产生定时中断(与比较器配合).
3. **顺序控制**: 计数器的状态作为节拍, 驱动顺序脉冲发生器.
4. **地址产生**: 为存储器提供连续地址.
5. **测量**: 配合门控信号测量频率或脉宽.

## 九、同步与异步计数器的对比

| 对比项         | 异步计数器       | 同步计数器       |
| -------------- | ---------------- | ---------------- |
| 时钟连接       | 逐级串联         | 全部并联         |
| 延迟           | $O(n)$, 逐级累积 | 一级组合逻辑延迟 |
| 过渡状态       | 有(毛刺)         | 无               |
| 最高速度       | 低               | 高               |
| 电路复杂度     | 低               | 高               |
| 译码输出安全性 | 差(需加锁存)     | 好               |

## 易错点

- 异步计数器在状态转换时存在过渡状态, 直接对其输出译码会产生毛刺, 必须加**锁存器**或改用同步计数器.
- 74LS161 的清零是**异步**的, 置数是**同步**的, 二者性质不同, 设计任意进制计数器时处理方法完全不同(见"任意进制计数器").
