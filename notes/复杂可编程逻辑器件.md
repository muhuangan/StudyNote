# 复杂可编程逻辑器件

## 核心结论

CPLD 的结构是**"多个 GAL 式的逻辑块 + 可编程互连矩阵 + I/O 控制块"**, 采用 EEPROM/Flash 工艺. 它的核心优势是**非易失(上电即工作)**与**延迟可预测(互连矩阵延迟固定)**, 适合组合逻辑密集, 时序确定性要求高的场合.

## 一、EPLD(可擦除的可编程逻辑器件)

**定位**: 介于 GAL 与 CPLD 之间的过渡产品.

**改进**:

1. 采用 EPROM 或 EEPROM 工艺, 可擦除重复编程.
2. 集成度比 GAL 显著提高(数千门).
3. 内部开始出现"逻辑块 + 互连"的分层结构.

**局限**: 结构与 GAL 类似, 资源组织仍不够灵活, 很快被 CPLD 取代.

## 二、CPLD 的三大组成

### 1. 逻辑块(Logic Block / 宏单元阵列)

每个逻辑块内部结构类似一片 GAL:

- 一个可编程的**与阵列**, 产生若干乘积项.
- 若干**宏单元(Macrocell)**, 每个宏单元含一个或门, 一个可编程触发器, 极性选择与输出使能控制.
- 乘积项可以在宏单元之间共享(乘积项分配器), 提高资源利用率.

### 2. 可编程互连矩阵(PIA / 全局布线池)

- 把各逻辑块的输入, 输出与 I/O 块连在一起.
- 采用**固定连接延迟**的布线结构: 任意两点之间的延迟基本相同且可预测.

### 3. I/O 控制块

- 每个引脚可配置为输入, 输出, 双向或专用输入.
- 提供三态控制, 上/下拉, 摆率控制与电平标准选择.

## 三、CPLD 的关键特性

| 特性       | 说明                                         |
| ---------- | -------------------------------------------- |
| 工艺       | EEPROM 或 Flash                              |
| 是否易失   | **非易失**, 上电即工作, 无需外部配置芯片     |
| 延迟特性   | **可预测**(互连延迟固定, 引脚到引脚延迟确定) |
| 逻辑实现   | 乘积项(与或式)                               |
| 触发器密度 | 较低(每个宏单元一个触发器)                   |
| 容量       | 数千门至数万门(远小于 FPGA)                  |
| 功耗       | 静态功耗相对较大                             |
| 安全性     | 可加密, 较难破解                             |

## 四、CPLD 与 FPGA 的对比

| 对比项         | CPLD                 | FPGA                     |
| -------------- | -------------------- | ------------------------ |
| 逻辑实现方式   | 乘积项(与或阵列)     | 查找表(LUT)              |
| 工艺           | EEPROM / Flash       | SRAM                     |
| 配置数据       | 片上保存, 上电即工作 | 外部保存, 上电需加载     |
| 延迟           | **固定可预测**       | 依赖布局布线, 需时序约束 |
| 集成度         | 低(数万门以下)       | 高(数千万门)             |
| 适合逻辑       | **组合逻辑密集**     | 时序逻辑, 数据通路密集   |
| 寄存器资源     | 少                   | 丰富                     |
| 内嵌 RAM / DSP | 少或无               | 丰富                     |
| 功耗           | 静态功耗较高         | 静态功耗低(但配置需外挂) |
| 启动时间       | 极短(微秒级)         | 需数十毫秒加载配置       |

## 五、为什么"延迟可预测"如此重要

CPLD 的互连矩阵是**全连通**的固定延迟结构, 因此在设计阶段就能准确知道"从某输入到某输出需要多少纳秒", 无需布局布线后的时序分析.

**适用场景**:

1. 对时序要求严格的控制逻辑(如总线仲裁, 地址译码).
2. 需要"上电立即工作"的场合(如系统上电时序控制, 配置 FPGA 的控制器).
3. 简单但要求高可靠性的胶合逻辑.

**反例**: 需要复杂算法, 大容量缓存, 高速数据通路时, CPLD 的资源远远不够, 必须用 FPGA.

## 六、典型器件系列

| 厂商             | 系列                  | 工艺           |
| ---------------- | --------------------- | -------------- |
| Altera(现 Intel) | MAX 7000, MAX II / V  | EEPROM / Flash |
| Xilinx(现 AMD)   | XC9500, CoolRunner-II | Flash          |
| Lattice          | ispMACH 4000, MachXO  | Flash          |

## 七、CPLD 的设计要点

1. **乘积项是稀缺资源**: CPLD 的与阵列乘积项数量有限, 设计时应先化简逻辑.
2. **触发器也有限**: 尽量复用寄存器, 不要无节制地插入流水级.
3. **充分利用延迟可预测性**: 可以做精确的时序预算, 无需复杂的时序约束.
4. **注意 I/O 电平标准**: 不同 bank 可能支持不同的 I/O 电平.

## 八、典型应用

1. **上电时序控制**: 系统上电时先配置 FPGA, 再释放复位.
2. **总线桥接与扩展**: 地址译码, 片选产生, 总线宽度转换.
3. **接口电平转换**: 不同电压域之间的信号桥接.
4. **简单状态机**: I/O 扩展, 键盘扫描, LED 扫描.

## 易错点

- 认为 CPLD 只是"小号 FPGA": 两者的逻辑实现方式(乘积项 vs 查找表) 根本不同, 因此适用场景也不同.
- 认为 CPLD 一定比 FPGA 慢: CPLD 的引脚到引脚延迟往往**小于**加载配置后的 FPGA 启动延迟, 在小逻辑, 要求即时响应的场合反而更快.
