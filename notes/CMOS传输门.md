# CMOS传输门

## 核心结论

CMOS 传输门由一个 NMOS 与一个 PMOS **并联**构成, 两管受互补控制信号驱动. 它的独特能力是**双向传输模拟信号**(不只是数字电平), 是构成模拟开关, 三态门, 异或门和 D 触发器的基础单元.

## 一、电路结构

- 一个 NMOS 管与一个 PMOS 管的源漏分别并联, 构成两端 $v_I$ 与 $v_O$.
- NMOS 栅极接控制端 $C$, PMOS 栅极接互补控制端 $\overline{C}$.
- 衬底连接: NMOS 衬底接地, PMOS 衬底接 $V_{DD}$(这是 MOS 管正常工作的必要条件).

## 二、工作原理

| 控制                       | NMOS 状态                               | PMOS 状态                         | 传输门状态         |
| -------------------------- | --------------------------------------- | --------------------------------- | ------------------ |
| $C = 1$,$\overline{C} = 0$ | $v_{GS} = V_{DD} - v_I > V_{thN}$, 导通 | $v_{SG} = v_I - 0 >               | V_{thP}            | $, 导通 | **导通**,$v_O = v_I$ |
| $C = 0$,$\overline{C} = 1$ | $v_{GS} = 0 - v_I < 0$, 截止            | $v_{SG} = v_I - V_{DD} < 0$, 截止 | **截止**, 输出高阻 |

**为什么必须两管并联**:

- 单独用 NMOS 传输高电平时, 输出最高只能达到 $V_{DD} - V_{thN}$, 存在**阈值损失**.
- 单独用 PMOS 传输低电平时, 输出最低只能达到 $|V_{thP}|$, 同样有损失.
- 两管并联后, 传输高电平靠 PMOS(无损失), 传输低电平靠 NMOS(无损失), 互补消除阈值损失.

## 三、导通电阻特性

导通电阻 $R_{ON}$ 随输入电压变化, 大致呈"两端低, 中间高"的曲线:

- 输入接近 0 V 时, NMOS 导通充分,$R_{ON}$ 小.
- 输入接近 $V_{DD}$ 时, PMOS 导通充分,$R_{ON}$ 小.
- 输入在中间电平时, 两管都只是部分导通,$R_{ON}$ 出现峰值.

典型 $R_{ON}$ 在几百欧量级, 与 CMOS 门的关断电阻($10^{12}\ \Omega$ 级) 相差 9 个数量级以上, 这就是它可以作为开关使用的原因.

## 四、典型应用

### 1. 模拟开关

传输 0 至 $V_{DD}$ 范围内的任意模拟电压, 用于采样保持电路, 多路模拟切换(如 CD4066).

### 2. 构成三态门

在传输门后加一级反相器(或由传输门直接输出), 当控制端无效时输出呈高阻态, 即可作为三态缓冲器使用.

### 3. 构成异或门

$$F = A \oplus B$$

用两个传输门实现: 当 $B = 0$ 时传输 $A$, 当 $B = 1$ 时传输 $\overline{A}$, 输出即为 $A \oplus B$. 仅需 4 个管子加 2 个反相器, 比用与非门搭建省得多.

### 4. 构成 D 触发器的主/从结构

主从 D 触发器中的主, 从锁存器正是用一对互补导通的传输门实现"采样—保持"切换的.

### 5. 总线隔离

多个传输门并联到同一总线, 靠互补控制信号保证任意时刻只有一个导通.

## 五、传输门与三态门的区别

| 对比项       | 传输门                 | 三态门         |
| ------------ | ---------------------- | -------------- |
| 传输方向     | 双向                   | 单向           |
| 传输内容     | 模拟信号或数字信号     | 数字信号       |
| 是否再生信号 | 否(无增益, 有电阻损耗) | 是(有缓冲放大) |
| 典型应用     | 模拟开关, 锁存器       | 总线驱动       |

## 六、使用注意

1. 传输门**没有驱动能力**, 只有导通电阻, 因此后面若接大负载必须加缓冲器.
2. 导通时存在 $R_{ON}$ 与负载电容构成的 RC 延迟, 信号带宽有限.
3. 截止时输出为**高阻**, 若后级是 CMOS 输入, 高阻节点会因漏电荷保持原电平一段时间, 但不可靠, 必须另有保持电路.

## 易错点

- 传输门可以双向传输, 不能想当然地认为"信号只能从 $v_I$ 流向 $v_O$".
- 单管(只用 NMOS 或只用 PMOS) 的开关存在阈值损失, 这是"必须用互补两管"的原因, 不是工艺习惯问题.
