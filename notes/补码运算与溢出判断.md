# 补码运算与溢出判断

## 核心结论

补码加法规则只有一句:**符号位参与运算, 最高位的进位自然丢弃**. 溢出不是"产生了进位", 而是"结果超出了补码能表示的范围", 必须用进位异或法或双符号位法专门判断.

## 一、补码加法

$$[A + B]_\text{补} = [A]_\text{补} + [B]_\text{补} \pmod{2^n}$$

即两个补码按无符号二进制相加, 超出 $n$ 位的最高进位直接舍弃.

例($n = 8$): 计算 $9 + (-5)$.

$$[9]_\text{补} = 00001001,\quad [-5]_\text{补} = 11111011$$

```
  00001001
+ 11111011
-----------
1 00000100
  最高位进位丢弃
```

结果为 $00000100 = +4$, 正确.

## 二、补码减法

$$[A - B]_\text{补} = [A]_\text{补} + [-B]_\text{补}$$

其中 $[-B]_\text{补}$ 的求法是: 把 $[B]_\text{补}$ **连同符号位一起逐位取反, 然后加 1**(称为"求补"或"变补").

例: 计算 $9 - 5 = 9 + (-5) = 4$, 与上面同一结果.

## 三、溢出的概念

$n$ 位补码的表示范围是 $-2^{n-1}$ 至 $+2^{n-1} - 1$. 两个同号数相加, 若结果的符号与加数相反, 说明结果超出范围, 称为**溢出**.

发生溢出的充分必要条件:

1. 两个正数相加得到负数(正溢, 上溢);
2. 两个负数相加得到正数(负溢, 下溢).

**异号相加不可能溢出**, 这一点可以用于快速排除.

## 四、溢出判断方法一: 进位异或法

设符号位向高位的进位为 $C_s$, 最高数值位向符号位的进位为 $C_p$, 则

$$OVR = C_s \oplus C_p$$

- 结果 0: 无溢出.
- 结果 1: 有溢出.

例($n = 8$):$70 + 80 = 150 > 127$, 应当溢出.

```
  01000110   (70)
+ 01010000   (80)
-----------
  10010110   (符号位为1, 看起来是 -106)
```

$C_s = 0$(符号位 0 + 0 无进位),$C_p = 1$(最高数值位 1 + 1 产生进位),$OVR = 0 \oplus 1 = 1$, 判定溢出, 与预期一致.

## 五、溢出判断方法二: 双符号位法(变形补码)

用两位符号位表示数: 正数符号为 `00`, 负数符号为 `11`. 运算后观察两个符号位:

| 运算后符号位 | 结论                   |
| ------------ | ---------------------- |
| 00           | 正数, 无溢出           |
| 11           | 负数, 无溢出           |
| 01           | 正溢(结果应为正却太大) |
| 10           | 负溢(结果应为负却太小) |

判据同样是 $S_1 \oplus S_2 = 1$ 时溢出. 这种方法的优点是可以由硬件直接观察, 缺点是占用一位额外的位宽.

## 六、溢出与进位的区别

| 比较项       | 进位(Carry)                      | 溢出(Overflow)            |
| ------------ | -------------------------------- | ------------------------- |
| 含义         | 最高位相加产生的进位             | 有符号数结果超出表示范围  |
| 关注对象     | 无符号数运算                     | 有符号数运算              |
| 判据         | 最高位是否有进位输出             | $C_s \oplus C_p$ 是否为 1 |
| 是否一定错误 | 不一定, 无符号数下进位是正常结果 | 一定, 结果已经错误        |

## 七、符号扩展

把 $n$ 位补码扩展为 $m$ 位($m > n$) 时, 把符号位复制到新增的所有高位. 正数补 0, 负数补 1, 数值不变.

## 易错点

- 溢出只发生在**同号相加**(或异号相减) 的情况, 见到异号相加就应判定不会溢出.
- 最高位产生进位并不等于溢出, 例如 $-5 + 3$ 会产生进位但没有溢出.
