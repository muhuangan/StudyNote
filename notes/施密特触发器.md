# 施密特触发器

## 核心结论

施密特触发器是一种**具有回差(滞回) 特性的整形电路**: 输入上升时的翻转阈值 $V_{T+}$ 高于输入下降时的翻转阈值 $V_{T-}$, 两者之差称为回差电压 $\Delta V_T$. 回差使它对叠加在信号上的噪声"迟钝", 这是它能做波形整形与按键消抖的根本原因.

## 一、回差特性

**两个阈值**:

| 参数                   | 含义                                   |
| ---------------------- | -------------------------------------- |
| $V_{T+}$(上限阈值电压) | 输入**上升**过程中使输出翻转的输入电平 |
| $V_{T-}$(下限阈值电压) | 输入**下降**过程中使输出翻转的输入电平 |
| $\Delta V_T$(回差电压) | $\Delta V_T = V_{T+} - V_{T-}$         |

**滞回的意义**: 若输入在两个阈值之间来回小幅波动, 输出**不会**反复翻转. 只有当输入明确超过 $V_{T+}$ 或明确低于 $V_{T-}$ 时, 输出才改变. 噪声幅度只要小于 $\Delta V_T$, 就不会造成误触发.

## 二、电压传输特性

**同相输出**(输出与输入同相):

| 输入变化方向          | 输出行为          |
| --------------------- | ----------------- |
| $v_I$ 上升至 $V_{T+}$ | 输出由 0 跳变为 1 |
| $v_I$ 继续上升        | 输出保持 1        |
| $v_I$ 下降至 $V_{T-}$ | 输出由 1 跳变为 0 |

**反相输出**(输出与输入反相, 更常见):

| 输入变化方向          | 输出行为          |
| --------------------- | ----------------- |
| $v_I$ 上升至 $V_{T+}$ | 输出由 1 跳变为 0 |
| $v_I$ 下降至 $V_{T-}$ | 输出由 0 跳变为 1 |

传输特性曲线是一个**滞回环**: 上升段与下降段不重合, 形成一个封闭的环.

## 三、由门电路构成施密特触发器

**结构**(以 CMOS 反相器为例): 两级反相器串联, 输出端经电阻 $R_2$ 反馈到输入端, 输入端串接电阻 $R_1$.

**阈值计算**:

$$V_{T+} = \left(1 + \frac{R_1}{R_2}\right) V_{TH}$$

$$V_{T-} = \left(1 - \frac{R_1}{R_2}\right) V_{TH}$$

$$\Delta V_T = V_{T+} - V_{T-} = 2 \cdot \frac{R_1}{R_2} \cdot V_{TH}$$

其中 $V_{TH} \approx \dfrac{V_{DD}}{2}$ 是反相器自身的阈值电压.

**约束**: 必须满足 $R_1 < R_2$, 否则 $V_{T-}$ 会变成负值, 电路失去回差特性.

## 四、由 555 定时器构成

把 555 的 2 脚(TRI) 与 6 脚(THR) 并联作为输入端, 即构成施密特触发器:

- $V_{T+} = \dfrac{2}{3}V_{CC}$(由内部上比较器决定)
- $V_{T-} = \dfrac{1}{3}V_{CC}$(由内部下比较器决定)
- $\Delta V_T = \dfrac{1}{3}V_{CC}$

若需要调整阈值, 可在 5 脚(VCO) 外接控制电压.

## 五、专用施密特触发器件

| 型号    | 特点                      |
| ------- | ------------------------- |
| 74LS14  | 六反相施密特触发器        |
| 74LS132 | 四 2 输入与非施密特触发器 |
| CD40106 | 六反相施密特触发器(CMOS)  |

**与门电路搭建的对比**: 专用器件阈值由工艺保证, 一致性好, 不占外部元件, 是工程首选.

## 六、典型应用

### 1. 波形整形

把缓慢变化或带有噪声的信号(如正弦波, 三角波, 机械触点信号) 整成边沿陡峭的方波.

$$正弦波 \xrightarrow{施密特触发器} 方波$$

**关键点**: 只有当输入信号的幅度**大于**回差电压 $\Delta V_T$ 时, 才能得到完整翻转的方波; 否则输出会一直保持一个电平.

### 2. 按键去抖(消抖)

**问题**: 机械按键闭合与断开时, 触点会在数毫秒内产生多次弹跳, 若直接接到计数器会产生多次计数.

**施密特方案**:

1. 按键与 RC 充放电网络配合, 把跳变变成一个缓慢变化的电压.
2. 该电压送施密特触发器.
3. 由于回差的存在, 抖动期间的小幅波动不会使输出翻转, 只有整体电平越过阈值才翻转一次.

**软件消抖**是另一种常见方案(延时 10 至 20 ms 后再次读取), 硬件消抖用施密特触发器, 软件消抖用定时采样, 二者可以结合.

### 3. 幅度鉴别(电平检测)

设定 $V_{T+}$ 为鉴别门限, 只有输入超过门限时才输出有效, 用于检测信号是否达到某一幅度.

### 4. 构成多谐振荡器

施密特触发器 + RC 积分回路即可构成多谐振荡器: 电容在 $V_{T+}$ 与 $V_{T-}$ 之间反复充放电, 输出自动翻转(见"多谐振荡器").

## 七、与单稳态触发器的区别

| 对比项           | 施密特触发器          | 单稳态触发器                    |
| ---------------- | --------------------- | ------------------------------- |
| 稳态个数         | 两个稳态(滞回)        | 一个稳态 + 一个暂稳态           |
| 输出是否依赖时间 | 否(只由输入电平决定)  | 是(暂稳态持续 $t_w$ 后自动返回) |
| 是否需要触发脉冲 | 不需要                | 需要                            |
| 核心参数         | 回差电压 $\Delta V_T$ | 暂稳态时间 $t_w$                |
| 主要用途         | 整形, 消抖, 鉴别      | 定时, 延时, 脉冲展宽            |

## 八、设计要点

1. **回差要足够大**: 大于噪声峰峰值, 否则无法抑制干扰.
2. **回差不能过大**: 否则输入信号幅度不足时无法触发翻转.
3. **输入信号幅度必须超过两个阈值**: 否则输出不会完整翻转.
4. 高速应用中要注意施密特触发器本身的传输延迟.

## 易错点

- 认为阈值只有一个: 施密特触发器有**两个**阈值, 这是它与普通门电路的本质区别.
- 用施密特触发器整形时输入幅度太小:$\Delta V_T$ 越大越抗干扰, 但也要求输入信号摆幅更大, 二者是矛盾的.
