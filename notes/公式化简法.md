# 公式化简法

## 核心结论

公式化简法用并项, 吸收, 消去, 配项四种操作化简与或式, 目标是"乘积项个数最少, 且每个乘积项的因子最少". 它不依赖图形, 速度取决于对公式的熟练程度, 缺点是**不能保证得到最简结果**.

## 一、化简的衡量标准

最简与或式的两个条件:

1. 乘积项(与项) 的个数最少;
2. 在满足第一条的前提下, 每个乘积项所含变量数最少.

化简的直接收益: 门的数量减少, 门的输入端数减少, 从而降低成本, 功耗和延迟.

## 二、四种基本操作

| 操作 | 依据公式                                       | 效果           |
| ---- | ---------------------------------------------- | -------------- |
| 并项 | $AB + A\overline{B} = A$                       | 消去一个变量   |
| 吸收 | $A + AB = A$                                   | 消去一个乘积项 |
| 消去 | $A + \overline{A}B = A + B$                    | 消去一个因子   |
| 配项 | $AB + \overline{A}C + BC = AB + \overline{A}C$ | 消去冗余项     |

## 三、并项法

**识别特征**: 两个乘积项中只有一个变量一正一反, 其余因子完全相同.

例:

$$F = A\overline{B}\,\overline{C} + A\overline{B}C = A\overline{B}(\overline{C} + C) = A\overline{B}$$

例:

$$F = A(B\overline{C} + \overline{B}C) + A(BC + \overline{B}\,\overline{C}) = A(B \oplus C + \overline{B \oplus C}) = A$$

## 四、吸收法

**识别特征**: 某一项是另一项的一部分(因子关系).

例:

$$F = \overline{A}\,\overline{B} + \overline{A}\,\overline{B}CD(E + F) = \overline{A}\,\overline{B}$$

例:

$$F = A + \overline{A}BCD = A + BCD \quad (\text{此处同时用了消去法})$$

注意吸收法常与消去法连续使用, 实际化简中不必严格区分步骤名称.

## 五、消去法

**识别特征**: 一项含 $A$, 另一项含 $\overline{A}$ 与其他因子的乘积.

例:

$$F = AB + \overline{A}C + \overline{B}C = AB + C(\overline{A} + \overline{B}) = AB + C \cdot \overline{AB} = AB + C$$

最后一步用的是 $A + \overline{A}B = A + B$ 的推广形式(把 $AB$ 视为一个整体变量).

## 六、配项法

**识别特征**: 两项分别含 $A$ 和 $\overline{A}$, 第三项由它们剩余因子组成, 则第三项冗余可删; 反过来也可以先添加冗余项凑出可合并的形式.

例:

$$F = A\overline{B} + \overline{A}B + AB$$

把 $AB$ 重复使用一次($A + A = A$, 重复不改变值):

$$F = A\overline{B} + \overline{A}B + AB + AB = (\overline{A}B + AB) + (A\overline{B} + AB) = B + A$$

## 七、综合示例

化简 $F = AC + \overline{A}BD + \overline{B}C\overline{D} + BC\overline{D} + \overline{A}BC$.

**第一步**: 合并含 $\overline{B}C\overline{D}$ 与 $BC\overline{D}$ 的项(只有 $B$ 相反):

$$\overline{B}C\overline{D} + BC\overline{D} = C\overline{D}$$

**第二步**: 此时 $F = AC + \overline{A}BD + C\overline{D} + \overline{A}BC$. 观察 $\overline{A}BD$ 与 $\overline{A}BC$ 无法直接合并, 但 $C\overline{D}$ 与 $\overline{A}BC$ 可用冗余律: 检查 $AC$ 与 $C\overline{D}$ 两项, 剩余因子为 $A$ 与 $\overline{D}$, 第三项为 $A\overline{D}$, 当前没有该项.

**第三步**: 改用冗余律检查 $\overline{A}BD$ 与 $C\overline{D}$, 含 $D$ 与 $\overline{D}$, 剩余因子 $\overline{A}B$ 与 $C$, 第三项应为 $\overline{A}BC$, 恰好存在, 故 $\overline{A}BC$ 为冗余项, 删去.

$$F = AC + \overline{A}BD + C\overline{D}$$

**第四步**: 再检查 $AC$ 与 $C\overline{D}$, 含 $A$ 与 $\overline{D}$, 剩余因子 $C$ 与 $C$, 第三项应为 $C$, 不存在, 无法继续.

最终 $F = AC + \overline{A}BD + C\overline{D}$.

## 八、与卡诺图法的配合

| 情况                           | 建议                               |
| ------------------------------ | ---------------------------------- |
| 3 至 4 变量                    | 直接用卡诺图, 结果可靠             |
| 5 变量以上                     | 先用公式法粗化, 再用卡诺图分块验证 |
| 表达式结构明显(含大量公共因子) | 公式法更快                         |
| 要求严谨的最简结果             | 以卡诺图为准                       |

## 易错点

- 配项法使用的"重复某项"技巧依赖 $A + A = A$, 在普通代数中不成立, 不能混用直觉.
- 公式法无法判断是否已达最简, 若题目要求"最简与或式", 建议用卡诺图验证.
