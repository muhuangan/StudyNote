# 时序逻辑电路的分析方法

## 核心结论

分析时序电路的标准流程是:**时钟方程 → 驱动方程 → 状态方程 → 输出方程 → 状态表 → 状态图 → 时序图 → 判断功能**. 核心操作只有一步: 把驱动方程代入触发器的特性方程得到状态方程.

## 一、分析步骤

1. **写时钟方程**: 各触发器时钟端的连接关系(同步电路可省略).
2. **写驱动方程**: 各触发器输入端($D$,$J$,$K$ 等) 关于输入 $X$ 和现态 $Q$ 的表达式.
3. **求状态方程**: 把驱动方程代入所用触发器的特性方程.
4. **写输出方程**: 输出关于输入和现态的表达式.
5. **列状态表**: 枚举全部现态(及输入组合), 算出次态与输出.
6. **画状态图与时序图**.
7. **判断逻辑功能**.

## 二、完整示例

**电路**: 两个上升沿 D 触发器 $FF_1$(输出 $Q_1$) 与 $FF_2$(输出 $Q_2$), 共用时钟 $CLK$, 驱动方程为

$$D_1 = \overline{Q_1}$$

$$D_2 = Q_1 \oplus Q_2$$

输出方程为

$$Y = Q_1 Q_2$$

**第一步: 时钟方程**. 两触发器共用 $CLK$, 为**同步时序电路**.

**第二步: 驱动方程**. 已给出.

**第三步: 状态方程**.D 触发器特性方程 $Q^* = D$, 直接代入:

$$Q_1^* = \overline{Q_1}$$

$$Q_2^* = Q_1 \oplus Q_2$$

**第四步: 输出方程**.$Y = Q_1 Q_2$.

**第五步: 状态表**. 设状态记作 $(Q_2 Q_1)$:

| 现态 $Q_2 Q_1$ | $Q_1^* = \overline{Q_1}$ | $Q_2^* = Q_1 \oplus Q_2$ | 次态 $Q_2^* Q_1^*$ | 输出 $Y$ |
| -------------- | ------------------------ | ------------------------ | ------------------ | -------- |
| 00             | 1                        | 0                        | 01                 | 0        |
| 01             | 0                        | 1                        | 10                 | 0        |
| 10             | 1                        | 1                        | 11                 | 0        |
| 11             | 0                        | 0                        | 00                 | 1        |

**第六步: 状态图**.

$$00 \to 01 \to 10 \to 11 \to 00$$

四个状态构成一个闭合环, 无偏离状态, 因此**电路能够自启动**.

**第七步: 判断功能**.

- 状态按 $00 \to 01 \to 10 \to 11$ 循环, 若以 $Q_1$ 为最低位,$Q_2$ 为最高位, 对应十进制数 $0 \to 1 \to 2 \to 3 \to 0$.
- $Q_1$ 每来一个时钟翻转一次($Q_1^* = \overline{Q_1}$), 符合最低位的行为.
- $Y$ 在状态 11 时为 1, 即计满时产生进位.

**结论**: 这是一个**同步四进制(2 位二进制) 加法计数器**, 输出 $Y$ 为进位信号.

## 三、异步时序电路的分析要点

若各触发器时钟不同, 分析时必须:

1. 写出每个触发器各自的时钟方程(如 $CP_1 = CLK$,$CP_2 = Q_1$).
2. 只有当该触发器的时钟**有效沿到来**时, 状态方程才生效; 否则保持原状态.
3. 状态表中需增加一列注明"该触发器是否有时钟沿".

**典型例子**: 异步二进制计数器(行波计数器)—高位触发器由低位的输出(或反相输出) 驱动, 因此翻转逐级传递, 总延迟为各级之和.

## 四、状态表的两种形式

| 形式           | 特点                               |
| -------------- | ---------------------------------- |
| 状态转换表     | 逐行列出"现态 → 次态/输出", 最常用 |
| 状态转换真值表 | 把输入也作为列, 适合 Mealy 型      |

对于有外部输入的电路(如序列检测器), 状态表必须包含输入列:

| 现态 $Q$ | 输入 $X$ | 次态 $Q^*$ | 输出 $Y$ |
| -------- | -------- | ---------- | -------- |

## 五、自启动检查(分析的重要一环)

**定义**: 若电路的**全部**状态(包括无效状态) 都能在若干时钟周期内进入有效循环, 则称电路能**自启动**(自恢复).

**检查方法**:

1. 对于 $n$ 个触发器, 共有 $2^n$ 个状态.
2. 检查那些不在主循环中的状态, 看它们的次态是否最终指向主循环.
3. 若存在孤立状态或自成小环而无法回到主循环, 则电路**不能自启动**, 上电后可能卡死在无效状态.

不能自启动的电路必须加复位电路或改造状态转换逻辑.

## 六、由状态图判断功能的经验

| 状态图特征           | 功能               |
| -------------------- | ------------------ |
| 状态成环, 环长 = $M$ | 模 $M$ 计数器      |
| 状态按二进制递增     | 加法计数器         |
| 状态按二进制递减     | 减法计数器         |
| 状态按格雷码排列     | 格雷码计数器       |
| 回到某状态时有输出   | 该状态是检测目标   |
| 有输入分支           | 序列检测器或状态机 |

## 七、常见错误

| 错误                   | 后果                         |
| ---------------------- | ---------------------------- |
| 忘记代入触发器特性方程 | 得到的是驱动方程而非状态方程 |
| 状态编码顺序写反       | 状态转换关系完全错乱         |
| 漏掉某些现态组合       | 分析结果不完整, 漏掉无效状态 |
| 未检查自启动           | 电路实际可能卡死但分析不出来 |

## 易错点

- 驱动方程与状态方程是两回事:$D_1 = \overline{Q_1}$ 是驱动方程,$Q_1^* = \overline{Q_1}$ 是状态方程; 对 D 触发器两者形式恰好相同, 但对 JK 触发器完全不同(必须代入 $Q^* = J\overline{Q} + \overline{K}Q$).
- 画时序图时, 次态是**沿之后**的值, 输出若属于 Moore 型应在状态改变的同时改变, Mealy 型则可能立即改变.
