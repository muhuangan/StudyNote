# 球面坐标系

球面坐标系适用于具有**球对称性**的问题(点电荷, 带电球壳, 球对称电流分布). 三个单位矢量 $\boldsymbol e_r,\boldsymbol e_\theta,\boldsymbol e_\phi$ **全部随位置变化**.

## 一、定义

空间中一点 $P$ 用 $(r,\theta,\phi)$ 表示:

- $r$: 点 $P$ 到原点的**距离**, $0\le r<+\infty$;
- $\theta$: 位置矢量与 $+z$ 轴的**夹角**(极角), $0\le\theta\le\pi$;
- $\phi$: 与圆柱坐标相同的**方位角**, $0\le\phi<2\pi$.

三个单位矢量指向 $r,\theta,\phi$ 增大的方向, 构成右手正交系:

$$\boldsymbol e_r\times\boldsymbol e_\theta=\boldsymbol e_\phi,\qquad \boldsymbol e_\theta\times\boldsymbol e_\phi=\boldsymbol e_r,\qquad \boldsymbol e_\phi\times\boldsymbol e_r=\boldsymbol e_\theta$$

坐标系示意见[圆柱坐标系](./圆柱坐标系.md)中的三种坐标系对比图.

## 二、与直角坐标系的互换

**坐标变换**:

$$x = r\sin\theta\cos\phi,\qquad y = r\sin\theta\sin\phi,\qquad z = r\cos\theta$$
$$r=\sqrt{x^2 + y^2 + z^2},\qquad \theta=\arccos\frac zr,\qquad \phi=\arctan\frac yx$$

**注意**: 这里的 $\theta$ 是**与 $z$ 轴的夹角**(物理与工程中的习惯), 不是数学中与 $xOy$ 平面的夹角; 二者互为余角, 做题时务必确认教材的约定.

## 三、矢量的表示

$$\boldsymbol A = A_r\boldsymbol e_r + A_\theta\boldsymbol e_\theta + A_\phi\boldsymbol e_\phi$$

$$|\boldsymbol A|=\sqrt{A_r^2 + A_\theta^2 + A_\phi^2}$$

## 四、微分元

**线元**:

$$d\boldsymbol l=\boldsymbol e_r dr+\boldsymbol e_\theta\,r\,d\theta+\boldsymbol e_\phi\,r\sin\theta\,d\phi$$

**面积元**(以 $r$ 为常数的球面为例):

$$dS_r = r^2\sin\theta\,d\theta\,d\phi$$

**体积元**:

$$dV = r^2\sin\theta\,dr\,d\theta\,d\phi$$

## 五、例题

**例 1**: 把直角坐标中的点 $(1,1,\sqrt2)$ 化为球面坐标.

解:

$$r=\sqrt{1 + 1 + 2}=\sqrt4 = 2$$
$$\theta=\arccos\frac{\sqrt2}{2} = 45^\circ,\qquad \phi=\arctan\frac11 = 45^\circ$$

即 $(r,\theta,\phi) = (2,45^\circ,45^\circ)$.

**例 2**: 求点电荷 $q$ 在距离 $r$ 处的电场(已知 $\boldsymbol E=\dfrac{q}{4\pi\varepsilon_0r^2}\boldsymbol e_r$), 并说明为何球坐标最自然.

解: 点电荷的场具有**完全的球对称性**——它只依赖于距离 $r$, 与方向 $\theta,\phi$ 无关, 因此

$$\boldsymbol E = E_r(r)\,\boldsymbol e_r,\qquad E_\theta = E_\phi = 0$$

用球坐标只需一个分量和一个变量即可描述; 若用直角坐标, 三个分量 $E_x,E_y,E_z$ 都要写成 $x,y,z$ 的函数, 形式复杂得多.

**例 3**: 求半径为 $a$ 的球体体积(用球坐标).

解:

$$V=\iiint dV=\int_0^{2\pi}\int_0^{\pi}\int_0^a r^2\sin\theta\,dr\,d\theta\,d\phi$$
$$=\left(\int_0^{2\pi}d\phi\right)\left(\int_0^\pi\sin\theta\,d\theta\right)\left(\int_0^a r^2dr\right) = 2\pi\cdot2\cdot\frac{a^3}{3}=\frac{4}{3}\pi a^3$$

**例 4**: 求半径为 $a$ 的球面面积.

解: 在 $r = a$ 的球面上

$$S=\iint dS_r=\int_0^{2\pi}\int_0^\pi a^2\sin\theta\,d\theta\,d\phi = a^2\cdot2\cdot2\pi = 4\pi a^2$$

此结果在高斯定理中反复使用.

## 六、三种坐标系对比小结

| 项目                 | 直角 $(x,y,z)$ | 圆柱 $(\rho,\phi,z)$                       | 球面 $(r,\theta,\phi)$              |
| -------------------- | -------------- | ------------------------------------------ | ----------------------------------- |
| 体积元               | $dx\,dy\,dz$   | $\rho\,d\rho\,d\phi\,dz$                   | $r^2\sin\theta\,dr\,d\theta\,d\phi$ |
| 单位矢量是否随位置变 | 否             | $\boldsymbol e_\rho,\boldsymbol e_\phi$ 变 | 三个都变                            |
| 适用场景             | 长方体, 平板   | 圆柱, 同轴线                               | 球, 点源                            |

## 七、易错点

- **漏掉 $r^2\sin\theta$**: 球坐标体积元中的两个因子都不能省.
- 把 $\theta$ 当成"与 $xOy$ 平面的夹角": 本课程约定 $\theta$ 是与 $z$ 轴的夹角.
- $\theta$ 的范围写成 $0\le\theta\le2\pi$: 正确是 $0\le\theta\le\pi$.
- 认为 $\boldsymbol e_r$ 是常矢量: 它随 $\theta,\phi$ 改变方向.
