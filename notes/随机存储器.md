# 随机存储器

## 核心结论

SRAM 用**六管触发器**存储一位, 靠正反馈自保持, 速度快但面积大; DRAM 用**一个晶体管加一个电容**存储一位, 靠电容电荷保持, 密度高但电荷会泄漏, 必须**定期刷新**.

## 一、SRAM(静态随机存储器)

**存储单元**: 由六个 MOS 管构成一个**交叉耦合的触发器**(与 SR 锁存器原理相同).

- 两个交叉耦合的反相器构成双稳电路, 保持 0 或 1.
- 两个门控管(由字线控制) 把单元与位线连通, 用于读写.

**工作原理**:

| 操作 | 过程                                                                       |
| ---- | -------------------------------------------------------------------------- |
| 读出 | 字线有效, 单元状态通过门控管驱动位线, 灵敏放大器检测位线上的微小压差并放大 |
| 写入 | 位线被强制为待写入的电平, 字线有效后强行改写触发器状态                     |

**特点**:

1. **不需要刷新**: 只要不断电, 状态由正反馈永久保持.
2. **速度快**: 存取时间在几纳秒至几十纳秒.
3. **面积大**: 每单元 6 个管子, 集成度低, 成本高.
4. **功耗较大**: 单元始终通电.

**应用**: CPU 高速缓存(L1, L2, L3), 小容量高速暂存.

## 二、DRAM(动态随机存储器)

**存储单元**: **一个 MOS 管 + 一个电容**. 信息以电容上是否存有电荷来表示.

**工作原理**:

| 操作       | 过程                                                                 |
| ---------- | -------------------------------------------------------------------- |
| 写入       | 字线有效, 位线上的电平对电容充电或放电                               |
| 读出       | 字线有效, 电容与位线共享电荷, 位线电压发生微小变化, 由灵敏放大器放大 |
| 破坏性读出 | 读出会使电容电荷改变, 因此每次读出后必须**立即重写(再生)**           |

**特点**:

1. **必须刷新**: 电容存在漏电流, 电荷会在若干毫秒内泄漏完, 因此必须定期把各单元读出再写回.
2. **集成度高**: 每单元 1 个管子加 1 个电容, 密度是 SRAM 的数倍, 成本低.
3. **速度较慢**: 受刷新与电容充放电限制.
4. **读出是破坏性的**: 必须再生.

**应用**: 计算机主存(内存条), 显卡显存.

## 三、DRAM 的刷新

**为什么要刷新**: 电容电荷只能保持很短时间, 必须周期性补充.

**刷新间隔**: 由器件手册规定. 教材中常取"两次刷新之间不超过 2 ms"; 现代器件一般规定在 64 ms 内把所有行刷新一遍.**设计时必须以手册为准**.

**刷新的三种方式**:

### 1. 集中式刷新

在一个刷新周期内, 用**一段连续时间**逐行刷新全部单元.

- 优点: 读写操作不受打扰, 效率高.
- 缺点: 这段时间内存储器不能对外服务, 产生**死时间**(约占总时间的百分之几).

### 2. 分散式刷新

把每个存取周期分为两段: 前半段读写, 后半段刷新一行.

- 优点: 没有集中的死时间, 控制简单.
- 缺点: 每个存取周期都被拉长约一倍,**系统整体效率下降**.

### 3. 异步式刷新(异步刷新, 最常用)

在一个刷新周期内, 把刷新操作**分散**安排: 每经过"刷新周期 / 行数"的时间间隔刷新一行.

- 优点: 既保证所有行都被刷新, 又把每次刷新的开销摊薄, 几乎没有明显的死时间.
- 这是现代 DRAM 控制器的普遍做法.

**示例**: 设存储器有 128 行, 刷新周期为 2 ms, 则每隔

$$\frac{2\ \text{ms}}{128} \approx 15.6\ \mu\text{s}$$

刷新一行.

## 四、SRAM 与 DRAM 的对比

| 对比项       | SRAM         | DRAM             |
| ------------ | ------------ | ---------------- |
| 单元结构     | 6 管触发器   | 1 管 + 1 电容    |
| 是否需刷新   | 否           | 是               |
| 集成度       | 低           | 高               |
| 单位成本     | 高           | 低               |
| 速度         | 快(纳秒级)   | 较慢             |
| 功耗         | 静态功耗较大 | 刷新带来额外功耗 |
| 读出是否破坏 | 否           | 是(需再生)       |
| 典型应用     | 高速缓存     | 主存             |

## 五、RAM 的时序要点

**读周期**:

1. 地址建立.
2. $\overline{CS}$ 与 $\overline{OE}$ 有效.
3. 经过读出时间后数据有效.
4. 地址与片选撤销, 输出端回到高阻.

**写周期**:

1. 地址与数据建立.
2. $\overline{CS}$ 与 $\overline{WE}$ 有效(写入脉冲宽度必须满足要求).
3. 数据在写脉冲期间被写入.
4. 撤销前必须满足数据保持时间.

**关键约束**: 写脉冲宽度不能太窄(否则写不进去), 也不能太长(可能超出手册规定).

## 六、RAM 的优缺点

**优点**: 读写速度快, 可无限次写入, 使用灵活.

**缺点**: **易失**—断电后数据全部丢失, 必须有后备电源或定期保存到非易失存储器.

## 七、新型 RAM 简介

| 类型      | 特点                                  |
| --------- | ------------------------------------- |
| SDRAM     | 与时钟同步的 DRAM, 支持突发传输       |
| DDR SDRAM | 时钟上下沿都传输数据, 带宽翻倍        |
| PSRAM     | 伪静态 RAM, 内部是 DRAM 但接口像 SRAM |
| FRAM      | 铁电存储器, 非易失且写入快            |
| MRAM      | 磁阻存储器, 非易失, 速度快, 耐写入    |

## 易错点

- 认为 DRAM 读出"只是读一下": DRAM 读出是**破坏性**的, 读后必须再生, 这一操作由芯片内部自动完成.
- 认为刷新只是"读一遍": 刷新必须包含"读出并重写"两步, 只写不读或只读不写都不能保持数据.
- 把刷新间隔背成固定值: 不同代际器件差别很大(2 ms 至 64 ms), 必须查手册.
