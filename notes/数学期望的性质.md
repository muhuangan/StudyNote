# 数学期望的性质

期望最重要的性质是**线性**: 无论是否独立, 期望都可以"逐项相加". 这一点让它成为处理复杂随机变量的有力工具.

## 一、基本性质

设 $C$ 为常数, $X,Y$ 为随机变量(期望均存在), 则:

**(1) 常数的期望**

$$E(C) = C$$

**(2) 常数可提出**

$$E(CX) = C\,E(X)$$

**(3) 期望的可加性(无需任何独立性条件)**

$$E(X + Y) = E(X) + E(Y)$$

这是期望最强大的一条: **和号的期望等于期望的和**, 与 $X,Y$ 是否独立无关.

**(4) 线性组合**

$$E(aX + bY + C) = aE(X) + bE(Y) + C$$

推广到 $n$ 个:

$$E\!\left(\sum_{i = 1}^{n}a_iX_i + C\right)=\sum_{i = 1}^{n}a_iE(X_i) + C$$

**(5) 乘积的期望(需要条件)**

若 $X,Y$ **相互独立**, 则

$$E(XY) = E(X)\,E(Y)$$

一般地, 若 $X_1,\ldots,X_n$ 相互独立, 则

$$E\!\left(\prod_{i = 1}^{n}X_i\right)=\prod_{i = 1}^{n}E(X_i)$$

**注意方向**: 独立 $\Rightarrow$ $E(XY) = E(X)E(Y)$; 但 $E(XY) = E(X)E(Y)$ **推不出**独立(这正是"不相关"的定义).

## 二、例题

**例 1**: 设 $E(X) = 2$, $E(Y)=-1$, 求 $E(3X - 2Y + 5)$.

解: 由线性性质

$$E(3X - 2Y + 5) = 3E(X) - 2E(Y) + 5 = 3\times2 - 2\times(-1) + 5 = 13$$

**例 2**(可加性用于计数, 重点技巧): 把 $n$ 个球随机放入 $N$ 个盒子, 求空盒个数的期望.

解: 定义指示变量

$$X_i=\begin{cases}1, & \text{第 }i\text{ 个盒子为空}\\ 0, & \text{否则}\end{cases},\qquad i = 1,\ldots,N$$

空盒数 $X=\sum_{i = 1}^{N}X_i$. 因为每个球都不落入第 $i$ 盒的概率为 $1-\frac1N$, 故

$$P(X_i = 1)=\left(1-\frac1N\right)^n\ \Rightarrow\ E(X_i)=\left(1-\frac1N\right)^n$$

由可加性(**无需各 $X_i$ 独立**):

$$E(X)=\sum_{i = 1}^{N}E(X_i) = N\left(1-\frac1N\right)^n$$

**这是期望可加性的经典用法**: 把复杂计数拆成若干个 0-1 变量之和, 逐个求期望再相加, 完全绕开了求联合分布.

**例 3**(独立才可拆乘积): 设 $X\sim U(0,1)$, $Y\sim U(0,1)$ 且独立, 求 $E(XY)$.

解: 由独立性

$$E(XY) = E(X)E(Y)=\frac12\times\frac12=\frac14$$

**反例**: 若 $Y = X$, 则 $E(XY) = E(X^2)=\frac13\ne\frac14$, 说明**不独立时不能拆**.

**例 4**(组合): 设 $X,Y$ 独立, $E(X) = 1$, $E(Y) = 2$, $E(X^2) = 3$, $E(Y^2) = 5$, 求 $E\bigl[(X + Y)^2\bigr]$.

解:

$$E\bigl[(X + Y)^2\bigr] = E(X^2) + 2E(XY) + E(Y^2) = 3 + 2E(X)E(Y) + 5 = 3 + 2\times1\times2 + 5 = 12$$

## 三、性质的来源(直觉)

- **可加性**来自"加权平均可以逐项分配": $\sum(x + y)p=\sum xp+\sum yp$;
- **常数提出**来自线性;
- **乘积可拆**来自独立时联合概率可分解为边缘概率之积.

## 四、易错点

- 误以为 $E(X + Y) = E(X) + E(Y)$ 需要独立性: **不需要**.
- 误以为 $E(XY) = E(X)E(Y)$ 总成立: 需要独立(或至少不相关).
- 把 $E\bigl[g(X)\bigr]$ 写成 $g\bigl(E(X)\bigr)$: 只有线性 $g$ 才成立.
- 忘记常数项也要参与: $E(aX + C) = aE(X) + C$.
