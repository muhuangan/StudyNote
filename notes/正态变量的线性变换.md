# 正态变量的线性变换

正态分布有一条极好的性质: **它的线性变换仍然是正态分布**. 这正是"任何正态都可标准化"以及"独立正态之和仍为正态"的依据.

## 一、标准化定理

设 $X\sim N(\mu,\sigma^2)$, 则

$$Z=\frac{X-\mu}{\sigma}\sim N(0,1)$$

证明见下节.

## 二、一般线性变换

设 $X\sim N(\mu,\sigma^2)$, 且 $a\ne 0$, $b$ 为常数, 则

$$Y = aX + b\sim N\bigl(a\mu + b,\ a^2\sigma^2\bigr)$$

即线性变换后**期望按同样方式变换, 方差乘以 $a^2$**(与 $b$ 无关).

**特别地**, 取 $a=-1, b = 0$ 得 $-X\sim N(-\mu,\sigma^2)$; 取 $a=\dfrac1\sigma, b=-\dfrac\mu\sigma$ 得标准化.

## 三、证明(分布函数法)

设 $Y = aX + b$, 先设 $a>0$, 则

$$F_Y(y) = P(aX + b\le y) = P\!\left(X\le\frac{y - b}{a}\right) = F_X\!\left(\frac{y - b}{a}\right)$$

两边对 $y$ 求导:

$$f_Y(y)=\frac1a f_X\!\left(\frac{y - b}{a}\right)=\frac{1}{a}\cdot\frac{1}{\sqrt{2\pi}\sigma}\exp\left[-\frac{\left(\frac{y - b}{a}-\mu\right)^2}{2\sigma^2}\right]$$

化简指数:

$$\frac{\left(\frac{y - b}{a}-\mu\right)^2}{2\sigma^2}=\frac{\bigl(y - (a\mu + b)\bigr)^2}{2a^2\sigma^2}$$

于是

$$f_Y(y)=\frac{1}{\sqrt{2\pi}\,|a|\sigma}\exp\left[-\frac{\bigl(y - (a\mu + b)\bigr)^2}{2a^2\sigma^2}\right]$$

这正是 $N(a\mu + b,\ a^2\sigma^2)$ 的密度. $a<0$ 时同样成立. 取 $a=\frac1\sigma$, $b=-\frac\mu\sigma$ 即得标准化定理.

## 四、推广: 独立正态之和

若 $X_i\sim N(\mu_i,\sigma_i^2)$ 相互独立, $c_i$ 为常数, 则

$$\sum_{i = 1}^{n}c_iX_i\sim N\!\left(\sum_{i = 1}^{n}c_i\mu_i,\ \sum_{i = 1}^{n}c_i^2\sigma_i^2\right)$$

**正态族的封闭性**: 独立正态变量的线性组合仍服从正态分布. 这一点在大数定律与中心极限定理, 以及统计推断中被大量使用.

## 五、例题

**例 1**: 设 $X\sim N(1,4)$, $Y = 2X - 3$. 求 $Y$ 的分布及 $E(Y)$, $D(Y)$.

解: $a = 2, b=-3, \mu = 1, \sigma^2 = 4$:

$$Y\sim N(2\times1 - 3,\ 2^2\times4) = N(-1,16)$$
$$E(Y)=-1,\qquad D(Y) = 16$$

**例 2**(标准化计算): 设 $X\sim N(3,4)$, 求 $P(2<X<5)$(已知 $\Phi(1) = 0.8413$, $\Phi(0.5) = 0.6915$).

解: 标准化 $Z=\dfrac{X - 3}{2}$:

$$P(2<X<5) = P\!\left(\frac{2 - 3}{2}<Z<\frac{5 - 3}{2}\right) = P(-0.5<Z<1)$$
$$=\Phi(1)-\Phi(-0.5) = 0.8413-\bigl(1 - 0.6915\bigr) = 0.5328$$

**例 3**(独立和): 设 $X\sim N(1,4)$, $Y\sim N(2,9)$ 且相互独立. 求 $Z = X + Y$ 的分布与 $P(Z<5)$(已知 $\Phi(0.53)\approx0.7019$).

解: 期望相加, 方差相加:

$$Z\sim N(1 + 2,\ 4 + 9) = N(3,13)$$

$$\sigma_Z=\sqrt{13}\approx3.606,\qquad P(Z<5) = P\!\left(Z^*<\frac{5 - 3}{3.606}\right)=\Phi(0.555)\approx0.710$$

**例 4**: 把 $X\sim N(10,25)$ 标准化为 $N(0,1)$ 并写出变换式.

解:

$$Z=\frac{X - 10}{5}\sim N(0,1)$$

## 六、易错点

- 方差变换写成 $a\sigma^2$: 正确是 $a^2\sigma^2$(注意符号无关).
- 常数 $b$ 影响期望却不影响方差: 平移只改变位置.
- 把"线性组合"与"任意函数"混淆: 只有**线性**变换(以及独立正态的线性组合)才保证仍是正态, 例如 $X^2$(即使 $X$ 正态)就不再是正态.
- 独立和时忘记方差相加要求**独立**.
