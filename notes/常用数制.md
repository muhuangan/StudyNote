# 常用数制

## 核心结论

任意进制都由**基数**和**位权**两个要素确定: 基数决定每一位可用几个数码, 位权决定该位的权重. 任意数都可以写成"数码乘以位权求和"的展开式.

## 基数与位权

**基数(radix)**: 一种数制所允许使用的数码个数, 记为 $r$. 十进制 $r = 10$, 二进制 $r = 2$, 八进制 $r = 8$, 十六进制 $r = 16$.

**位权**: 某一位上"1"所代表的数值大小. 对于整数部分从右往左第 $i$ 位(从 0 开始编号), 位权为 $r^i$; 对于小数部分从小数点往右第 $j$ 位, 位权为 $r^{-j}$.

## 按权展开式

任意一个 $r$ 进制数都可以展开为

$$N = \sum_{i=-m}^{n - 1} k_i \cdot r^i$$

其中 $k_i$ 是第 $i$ 位上的数码, 取值范围为 $0 \le k_i \le r - 1$,$n$ 是整数位数,$m$ 是小数位数.

## 四种常用数制对照

| 数制     | 基数 | 可用数码       | 进位规则   | 后缀标识 | C 语言前缀 |
| -------- | ---- | -------------- | ---------- | -------- | ---------- |
| 十进制   | 10   | 0 至 9         | 逢十进一   | D 或省略 | 无         |
| 二进制   | 2    | 0,1            | 逢二进一   | B        | `0b`       |
| 八进制   | 8    | 0 至 7         | 逢八进一   | O 或 Q   | `0`        |
| 十六进制 | 16   | 0 至 9, A 至 F | 逢十六进一 | H        | `0x`       |

十六进制中 A 至 F 分别对应十进制的 10 至 15, 大小写均可, 本书统一用大写.

## 表示方法

同一个数值有不同的书写方式, 含义相同:

- 下标法:$(1011)_2 = (11)_{10} = (13)_8 = (0\text{B})_{16}$
- 后缀法: `1011B` = `11D` = `13Q` = `0BH`

## 常用 2 的幂

$$2^{10} = 1024 \approx 10^3$$

这一近似是存储容量单位(1 KB = 1024 B) 的来源, 在做数量级估算时非常有用. 常用值:$2^4 = 16$,$2^8 = 256$,$2^{16} = 65536$.

## 易错点

- 八进制后缀在不同教材中可能是 O 也可能是 Q, 因为字母 O 容易与数字 0 混淆, 多数现代资料采用 Q.
- 十六进制数以字母开头时(如 `A3H`) 在多数汇编语法中必须补 0 写成 `0A3H`, 否则会被误认作标识符.
