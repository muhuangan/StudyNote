# 触发器动态特性

## 核心结论

触发器的动态特性就是两条时序约束: **建立时间** $t_{su}$(沿之前输入必须稳定多久) 与**保持时间** $t_h$(沿之后输入必须再保持多久). 违反任一约束, 触发器可能进入**亚稳态**, 输出在一段时间内既非 0 也非 1.

## 一、建立时间 $t_{su}$

**定义**: 在时钟有效沿到来**之前**, 输入信号必须保持稳定不变的最小时间.

**物理原因**: 输入信号需要经过内部若干级门(或传输门) 才能到达存储节点, 存储节点必须在时钟沿到来前完成充放电, 才能正确锁存.

**违反后果**: 存储节点没来得及达到正确的电平, 输出可能错误, 或进入亚稳态.

## 二、保持时间 $t_h$

**定义**: 在时钟有效沿到来**之后**, 输入信号必须继续保持稳定的最小时间.

**物理原因**: 时钟沿到来后, 输入通路需要一段时间才能被完全隔离(传输门关断, 维持阻塞线建立). 若输入在此期间就改变, 新值可能"漏"进存储节点, 覆盖刚锁存的正确值.

**违反后果**: 新数据冲掉旧数据, 输出错误.

## 三、传输延迟 $t_{pd}$

**定义**: 从时钟有效沿到达到输出完成改变所需的时间.

| 参数      | 含义                           |
| --------- | ------------------------------ |
| $t_{PHL}$ | 输出由高变低的延迟             |
| $t_{PLH}$ | 输出由低变高的延迟             |
| $t_{pd}$  | 二者的平均值, 工程上常取最大值 |

典型值: 74LS74 的 $t_{pd}$ 约 20 ns, CMOS CD4013 约 50 ns, 现代 FPGA 内触发器约 1 ns 量级.

## 四、最高时钟频率 $f_{max}$

对于最简单的情形(触发器直接驱动下一级触发器, 中间无组合逻辑), 时钟周期必须满足

$$T \ge t_{su} + t_{pd}$$

因此

$$f_{max} = \frac{1}{t_{su} + t_{pd}}$$

若两级触发器之间还存在组合逻辑(延迟为 $t_{comb}$), 则

$$T \ge t_{pd} + t_{comb} + t_{su}$$

$$f_{max} = \frac{1}{t_{pd} + t_{comb} + t_{su}}$$

这是**同步时序电路时序分析的基本不等式**, 也是"关键路径"概念的来源: 系统最高工作频率由延迟最大的那条路径决定.

**建立时间裕量(setup slack)**:

$$\text{slack} = T - (t_{pd} + t_{comb} + t_{su})$$

裕量为正则时序收敛, 为负则电路无法在该频率下工作.

## 五、亚稳态

**定义**: 当输入信号在建立/保持窗口内发生变化(即违反时序约束) 时, 触发器内部的反馈回路无法在规定时间内稳定到合法的 0 或 1, 输出可能停留在中间电平, 或在 0 与 1 之间振荡一段时间, 最终才随机稳定到某一值.

**三个特征**:

1. **不可避免**: 任何触发器都有亚稳态窗口, 无法彻底消除, 只能降低发生概率.
2. **最终会稳定**: 亚稳态不是永久的, 经过一段随机长度的时间后输出会稳定到 0 或 1, 但**稳定到哪个值不可预测**.
3. **平均无故障时间(MTBF) 随等待时间指数增长**: 多给一级触发器同步, MTBF 可以提高几个数量级.

**典型场景**: **跨时钟域(CDC) 信号传递**—外部异步信号(如按键, 串口数据) 与本系统时钟无确定相位关系, 必然有概率落在建立/保持窗口内.

**标准解决方案**: **两级触发器同步器**.

$$异步信号 \to DFF1 \to DFF2 \to 本时钟域逻辑$$

第一级可能进入亚稳态, 但只要在一个时钟周期内稳定下来, 第二级就能采到确定值, 从而把亚稳态传播概率降到可接受水平.

**其他同步手段**:

1. 多比特数据跨时钟域 → 先转**格雷码**再同步(保证每次只有一位变化).
2. 高速批量数据 → 异步 FIFO(写指针与读指针用格雷码跨时钟域传递).
3. 握手协议(请求-应答)→ 用于慢速但可靠性要求高的场合.

## 六、异步置位/复位端的时序

异步置位/复位信号虽然不受时钟控制, 但其**撤除时刻**仍有时序要求:

- **恢复时间** $t_{rec}$: 异步信号撤除后, 到下一个时钟有效沿之间必须间隔的最短时间.
- 若违反, 触发器可能在该时钟沿处无法正确采样数据.

**设计规则**: 复位信号的释放应当与时钟**同步**(即"异步复位, 同步释放"), 这是 FPGA 设计中的标准实践.

## 七、典型参数(参考量级)

| 器件         | $t_{su}$  | $t_h$     | $t_{pd}$ | $f_{max}$ |
| ------------ | --------- | --------- | -------- | --------- |
| 74LS74       | 20 ns     | 5 ns      | 约 20 ns | 约 25 MHz |
| 74HC74       | 20 ns     | 3 ns      | 约 15 ns | 约 30 MHz |
| CD4013(10 V) | 60 ns     | 20 ns     | 约 50 ns | 约 8 MHz  |
| 现代 FPGA    | 约 0.5 ns | 约 0.3 ns | 约 1 ns  | 数百 MHz  |

数值随电源电压, 温度, 工艺变化, 设计时必须以器件手册的**最坏情况值**为准.

## 八、工程检查清单

1. 时钟频率是否低于 $f_{max}$ 并留有裕量(通常留 20% 以上).
2. 所有跨时钟域信号是否做了同步处理.
3. 异步复位是否采用"同步释放".
4. 输入信号是否在建立/保持窗口内保持稳定.
5. 时钟偏移(clock skew) 是否被计入时序预算.

## 易错点

- 认为"只要满足建立时间就够了": 保持时间同样必须满足, 且保持时间与时钟频率无关, 提高频率无法修复保持时间违规.
- 认为亚稳态可以通过"选更好的触发器"消除: MTBF 只能提高, 不能归零.
