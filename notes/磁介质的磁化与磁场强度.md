# 磁介质的磁化与磁场强度

物质在磁场中会被磁化, 磁化后的介质又反过来改变原有的磁场. 直接把这种"总磁场"代入安培环路定理会遇到麻烦------环路包围的电流不止传导电流. 解决办法是引入**磁场强度** $\boldsymbol H$, 把介质的影响从方程里"挪"到本构关系中去. 这一手法与电介质中引入电位移矢量完全平行.

## 一、三类磁介质

按磁化后对外磁场的影响分三类:

| 类型       | 相对磁导率 $\mu_r$       | 磁化方向                         | 例子               |
| ---------- | ------------------------ | -------------------------------- | ------------------ |
| **顺磁质** | 略大于 1($1.0000x$)      | 与外加磁场**同向**, 使磁场略增强 | 铝、氧、铂         |
| **抗磁质** | 略小于 1($0.9999x$)      | 与外加磁场**反向**, 使磁场略减弱 | 铜、水、铋、金     |
| **铁磁质** | 远大于 1($10^2\sim10^5$) | 与外加磁场**同向**, 极大增强磁场 | 铁、钴、镍及其合金 |

**要点**: 顺磁与抗磁的效应都极微弱($|\mu_r - 1|\sim10^{-5}$), 只有铁磁质的效应显著, 因此"磁性材料"通常指铁磁质.

## 二、磁化强度

**定义**: 单位体积内分子磁矩的矢量和

$$\boldsymbol M=\frac{\sum\boldsymbol m_i}{\Delta V}$$

**物理意义**: 描述介质被磁化的程度. 未磁化时 $\boldsymbol M = 0$.

**磁化面电流**: 介质被磁化后, 内部各分子电流相互抵消, 但在**表面**上会剩下未被抵消的电流, 称为**磁化面电流**(束缚电流), 记作 $I'$. 它与磁化强度的关系为

$$\oint_L\boldsymbol M\cdot d\boldsymbol l = I'$$

即沿闭合回路的磁化强度线积分等于该回路所围的磁化面电流.

**磁化面电流的效果**: 它像螺线管中的电流一样产生磁场, 这就是介质能改变原磁场的机制.

## 三、磁介质中的安培环路定理

**问题**: 有介质时, 安培环路定理中的电流应包括传导电流 $I_0$ 与磁化电流 $I'$:

$$\oint_L\boldsymbol B\cdot d\boldsymbol l=\mu_0(I_0 + I')$$

**把 $I'$ 用 $\boldsymbol M$ 替换**($I'=\oint\boldsymbol M\cdot d\boldsymbol l$):

$$\oint_L\boldsymbol B\cdot d\boldsymbol l=\mu_0\left(I_0+\oint_L\boldsymbol M\cdot d\boldsymbol l\right)$$

移项:

$$\oint_L\left(\boldsymbol B-\mu_0\boldsymbol M\right)\cdot d\boldsymbol l=\mu_0I_0$$

**定义磁场强度**:

$$\boldsymbol H=\frac{\boldsymbol B}{\mu_0}-\boldsymbol M$$

于是得到**磁介质中的安培环路定理**:

$$\oint_L\boldsymbol H\cdot d\boldsymbol l = I_0$$

**关键优点**: 环路积分只与**传导电流**有关, 介质的影响被隔离在 $\boldsymbol H$ 与 $\boldsymbol B$ 的关系里.

## 四、本构关系与磁导率

**实验规律**: 对各向同性线性磁介质,

$$\boldsymbol M=\chi_m\boldsymbol H$$

其中 $\chi_m$ 是**磁化率**.

代入定义式 $\boldsymbol H=\dfrac{\boldsymbol B}{\mu_0}-\boldsymbol M$ 并整理:

$$\boldsymbol B=\mu_0(1+\chi_m)\boldsymbol H=\mu_0\mu_r\boldsymbol H=\mu\boldsymbol H$$

**其中**:

$$\mu_r = 1+\chi_m\ (\text{相对磁导率}),\qquad \mu=\mu_0\mu_r\ (\text{磁导率})$$

**三类介质对应的 $\chi_m$**: 顺磁质 $\chi_m>0$(很小), 抗磁质 $\chi_m<0$(很小), 铁磁质 $\chi_m\gg0$ 且**不是常数**(与 $\boldsymbol H$ 有关, 见[铁磁质与磁滞回线](./铁磁质与磁滞回线.md)).

**与静电学的平行关系**:

| 电介质                                                          | 磁介质                                                              |
| --------------------------------------------------------------- | ------------------------------------------------------------------- |
| 极化强度 $\boldsymbol P$                                        | 磁化强度 $\boldsymbol M$                                            |
| 电位移 $\boldsymbol D=\varepsilon_0\boldsymbol E+\boldsymbol P$ | 磁场强度 $\boldsymbol H=\dfrac{\boldsymbol B}{\mu_0}-\boldsymbol M$ |
| $\oint\boldsymbol D\cdot d\boldsymbol S = q_0$(自由电荷)        | $\oint\boldsymbol H\cdot d\boldsymbol l = I_0$(传导电流)            |
| $\boldsymbol D=\varepsilon_0\varepsilon_r\boldsymbol E$         | $\boldsymbol B=\mu_0\mu_r\boldsymbol H$                             |

**注意方向上的差别**: $\boldsymbol D$ 与电场的积分关系是**面积分**(与高斯定理对应), $\boldsymbol H$ 是**线积分**(与安培环路定理对应). 这是因为电场的源是电荷(点源), 磁场的源是电流(线源).

## 五、例题

**例 1**(基本换算): 某顺磁质的相对磁导率 $\mu_r = 1.0002$. 在 $H = 1.0\times10^4\ \text{A/m}$ 的磁场中, 求 $B$、$M$ 与 $\chi_m$.

解: **磁化率**:

$$\chi_m=\mu_r - 1 = 2\times10^{-4}$$

**磁感应强度**:

$$B=\mu_0\mu_rH = 4\pi\times10^{-7}\times1.0002\times1.0\times10^4\approx1.26\times10^{-2}\ \text{T}$$

**磁化强度**: 由 $\boldsymbol M=\chi_m\boldsymbol H$,

$$M = 2\times10^{-4}\times1.0\times10^4 = 2.0\ \text{A/m}$$

**量级对比**: $M = 2.0$ 远小于 $H = 10^4$, 即磁化强度对总场几乎没有贡献, 印证了顺磁效应微弱.

**例 2**(螺线管中的磁介质): 无限长直螺线管每米 $n$ 匝, 通有传导电流 $I$, 管内充满相对磁导率 $\mu_r$ 的均匀磁介质. 求管内的 $H$、$B$、$M$.

解: 取矩形回路(一边在管内沿轴线, 一边在管外), 由对称性与管外场为零:

$$\oint\boldsymbol H\cdot d\boldsymbol l = Hl = I_0 = nlI\ \Longrightarrow\ H = nI$$

**磁感应强度**:

$$B=\mu_0\mu_rH=\mu_0\mu_rnI$$

**磁化强度**:

$$M=\chi_mH = (\mu_r - 1)nI$$

**要点**: 求 $\boldsymbol H$ 时**完全不需要考虑介质**(它只依赖传导电流 $nI$); 介质的作用体现在由 $H$ 求 $B$ 时乘上 $\mu_r$. 这是用 $\boldsymbol H$ 的最大便利.

**例 3**(磁化面电流): 承上题, 求螺线管表面单位长度的磁化面电流.

解: 由 $\oint_L\boldsymbol M\cdot d\boldsymbol l = I'$, 取沿管轴、长为 $l$ 的回路, 管内 $\boldsymbol M$ 沿轴向且为常量, 管外条件使贡献为零:

$$Ml = I'\ \Longrightarrow\ \frac{I'}{l} = M = (\mu_r - 1)nI$$

**验证**: 磁化面电流产生的场为 $\mu_0\dfrac{I'}{l}=\mu_0(\mu_r - 1)nI$, 与原场 $\mu_0nI$ 叠加:

$$\mu_0nI+\mu_0(\mu_r - 1)nI=\mu_0\mu_rnI = B\quad\checkmark$$

与直接计算一致. **这说明"介质增强磁场"的物理机制就是磁化面电流的贡献.**

**例 4**(磁介质与静电学的类比): 一个同轴电缆内导体半径 $R_1$、外导体半径 $R_2$, 中间充满 $\mu_r$ 的磁介质, 内导体通电流 $I$. 求介质中的 $B$.

解: 取半径为 $r$($R_1<r<R_2$)的圆形回路, 由安培环路定理:

$$\oint\boldsymbol H\cdot d\boldsymbol l = 2\pi rH = I\ \Longrightarrow\ H=\frac{I}{2\pi r}$$

**磁感应强度**:

$$B=\mu_0\mu_rH=\frac{\mu_0\mu_rI}{2\pi r}$$

**对比真空情形**: 若中间是真空($\mu_r = 1$), 则 $B_0=\dfrac{\mu_0I}{2\pi r}$. 填介质后 $B=\mu_rB_0$, 即磁场被增强 $\mu_r$ 倍.

**注意**: 求 $H$ 的步骤与有无介质**完全无关**; 只有最后由 $H$ 求 $B$ 时才引入 $\mu_r$.

**例 5**(判断介质类型): 某材料在 $H = 2.0\times10^5\ \text{A/m}$ 时测得 $B = 0.30\ \text{T}$. 判断它属于哪类磁介质.

解: 由 $B=\mu_0\mu_rH$ 解 $\mu_r$:

$$\mu_r=\frac{B}{\mu_0H}=\frac{0.30}{4\pi\times10^{-7}\times2.0\times10^5}=\frac{0.30}{0.251}\approx1.19$$

**判断**: $\mu_r\approx1.19$, 明显大于 1 但远小于 $10^2$. 严格说这个值介于顺磁质与铁磁质之间; 但顺磁质的 $\mu_r$ 只比 1 大 $10^{-5}$ 量级, 而这里大了 19%, 因此**不是**普通顺磁质.

**结论与提醒**: 单次测量无法判定材料类型, 因为铁磁质的 $\mu_r$ 随 $H$ 变化且存在磁滞. 要判定铁磁质, 必须测出**完整的磁滞回线**(见[铁磁质与磁滞回线](./铁磁质与磁滞回线.md)). 这也说明对铁磁质不能使用常数 $\mu$ 的公式.

## 六、易错点

- 把 $\boldsymbol H$ 当成"磁场"的另一个名字. $\boldsymbol H$ 是辅助矢量, 描述磁场的物理量是 $\boldsymbol B$.
- 求 $\boldsymbol H$ 时把介质的 $\mu_r$ 也算进去. 由 $\oint\boldsymbol H\cdot d\boldsymbol l = I_0$ 知 $H$ 只依赖**传导电流**.
- 混淆 $\boldsymbol D$ 与 $\boldsymbol H$ 对应的定理: 前者对应高斯定理(面积分), 后者对应安培环路定理(线积分).
- 记错顺磁与抗磁的方向: 顺磁质磁化方向与外加场**同向**($\mu_r>1$), 抗磁质**反向**($\mu_r<1$).
- 对铁磁质套用 $\boldsymbol B=\mu_0\mu_r\boldsymbol H$ 并认为 $\mu_r$ 是常数. 铁磁质的 $\mu_r$ 依赖 $H$ 且有磁滞.
- 忽略磁化面电流这一物理机制, 只把 $\mu_r$ 当作"修正系数".
