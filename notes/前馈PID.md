# 前馈PID

1. 定义: 在 PID 反馈之外, 按给定信号或可测扰动的已知规律直接计算一部分控制量, 与反馈输出相加的复合控制
2. 反馈与前馈的分工
    1. 反馈: 等误差出现再动作, 闭环、不依赖模型、保证稳态精度, 但慢半拍
    2. 前馈: 在误差出现前按原因直接动作, 开环、快, 但依赖模型精度、不保证稳定
    3. 复合: 前馈承担可计算的主体部分, 反馈修正模型误差与未知扰动, 兼顾快速性与准确性
3. 结构: 反馈项与前馈项并联相加

$$u = u_{\mathrm{PID}} + u_{\mathrm{ff}}$$

其中 $u_{\mathrm{PID}}$ 为按误差 $e$ 计算的反馈项, $u_{\mathrm{ff}}$ 为按给定或扰动直接计算、不经过误差的前馈项.

4. 按给定前馈(跟踪前馈)
    1. 做法: 由给定值及其变化率直接估算所需控制量, 如位置给定的速度前馈、加速度前馈
    2. 效果: 目标一变提前出力, 显著减小跟踪滞后; 前馈准确时反馈项几乎不动
5. 按扰动前馈
    1. 做法: 测量或估计主要扰动(如负载力矩、坡道重力分量), 按其大小直接补偿
    2. 效果: 扰动进入回路前即被对消, 反馈只需处理未建模部分
6. 使用注意
    1. 前馈系数来自模型, 模型不准会引入新误差, 幅度需限幅并由反馈兜底
    2. 前馈不改变闭环稳定性, 增益过大易使执行器饱和
    3. 前馈通道加滤波, 避免给定突变或测量噪声直接进入执行器
7. 例: 位置控制叠加速度前馈时, 速度环给定为 $\omega_{\text{set}} = \omega_{\text{PID}} + K_v \dot{\theta}_d$, 前项是位置环 PID 输出, 后项按期望角速度 $\dot{\theta}_d$ 提前供速
