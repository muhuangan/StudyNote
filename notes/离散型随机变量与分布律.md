# 离散型随机变量与分布律

离散型随机变量的全部信息都包含在一张"取值—概率"的对应表(分布律)里. 会写分布律, 就会算它的一切.

## 一、定义

若随机变量 $X$ 只取**有限个**或**可列无穷多个**值 $x_1,x_2,\ldots,x_k,\ldots$, 则称 $X$ 为**离散型随机变量**.

称

$$P(X = x_k) = p_k,\qquad k = 1,2,\ldots$$

为 $X$ 的**概率分布律**(简称分布律, 也称概率质量).

## 二、分布律的性质

任一条分布律都必须满足:

**(1) 非负性**

$$p_k\ge 0,\qquad k = 1,2,\ldots$$

**(2) 归一性**

$$\sum_{k}p_k = 1$$

反过来, 任何满足这两条的一组数 $\{p_k\}$ 都可以充当某个离散型随机变量的分布律. 这两条是**求未知参数**与**检验答案**的通用依据.

## 三、表示方式

**表格法**(最直观):

| $X$ | $x_1$ | $x_2$ | $\cdots$ | $x_k$ | $\cdots$ |
| --- | ----- | ----- | -------- | ----- | -------- |
| $P$ | $p_1$ | $p_2$ | $\cdots$ | $p_k$ | $\cdots$ |

**公式法**(简洁):

$$P(X = k) = \text{某个关于 }k\text{ 的表达式}$$

**矩阵/列表法**: 直接写成 $\{(x_k,p_k)\}$ 的序列.

## 四、由分布律求任意事件的概率

设 $I$ 是实数轴上的任一集合(区间, 若干点等), 则

$$P(X\in I)=\sum_{x_k\in I}P(X = x_k)=\sum_{x_k\in I}p_k$$

特别地:

$$P(X\le a)=\sum_{x_k\le a}p_k,\qquad P(a<X\le b)=\sum_{a<x_k\le b}p_k$$

## 五、例题

**例 1**: 掷一颗均匀骰子, $X$ 为出现的点数, 写出 $X$ 的分布律并求 $P(X\le3)$ 与 $P(X\text{ 为偶数})$.

解: $X$ 取 $1,2,\ldots,6$, 且 $P(X = k)=\frac16$:

| $X$ | 1         | 2         | 3         | 4         | 5         | 6         |
| --- | --------- | --------- | --------- | --------- | --------- | --------- |
| $P$ | $\frac16$ | $\frac16$ | $\frac16$ | $\frac16$ | $\frac16$ | $\frac16$ |

$$P(X\le3)=\frac36=\frac12,\qquad P(X\text{ 为偶数})=\frac36=\frac12$$

**例 2**(求未知参数): 设 $X$ 的分布律为 $P(X = k)=\frac{a}{N}$, $k = 1,2,\ldots,N$, 求常数 $a$.

解: 由归一性:

$$1=\sum_{k = 1}^{N}\frac{a}{N} = N\times\frac{a}{N} = a$$

故 $a = 1$.

**例 3**(无穷情形): 设 $P(X = k)=\dfrac{c}{k!}$, $k = 0,1,2,\ldots$, 求常数 $c$.

解: 由归一性与指数函数的展开

$$1=\sum_{k = 0}^{\infty}\frac{c}{k!} = c\sum_{k = 0}^{\infty}\frac{1}{k!} = c\,e$$

故 $c = e^{-1}$.

**例 4**: 甲, 乙两人投篮, 命中率分别为 $0.6$ 与 $0.7$, 且相互独立, 各投一次的命中总数记为 $X$, 求 $X$ 的分布律.

解: $X$ 取 $0,1,2$. 记 $A,B$ 分别为甲, 乙命中:

$$P(X = 0) = P(\bar A\bar B) = 0.4\times0.3 = 0.12$$
$$P(X = 1) = P(A\bar B) + P(\bar AB) = 0.6\times0.3 + 0.4\times0.7 = 0.18 + 0.28 = 0.46$$
$$P(X = 2) = P(AB) = 0.6\times0.7 = 0.42$$

校验: $0.12 + 0.46 + 0.42 = 1$.

| $X$ | 0    | 1    | 2    |
| --- | ---- | ---- | ---- |
| $P$ | 0.12 | 0.46 | 0.42 |

注意 $X$ **不是**二项分布(两次命中率不同), 这也是判断模型时容易出错的地方.

## 六、易错点

- 写完分布律后忘记做归一性校验, 漏算或多算某个情形;
- 把 $P(X\le a)$ 中的不等号写成 $<$ 或 $>$ 导致端点丢失, 尤其连续或混合情形;
- 认为取值相同就可以合并概率: 分布律必须列出**每个**取值及其概率, 取相同值时应先合并再写表;
- 见到两次试验就默认是二项分布——两次试验的成功概率必须相同且独立才是.
