# 栈的链式结构实现

**单结点定义**

```C
typedef int ElemType;

typedef struct stack{
    ElemType data;
    struct stack * next;
}Stack;
```

**判断栈是否为空**

```C
int isEmpty(Stack *s){
    if(s -> next == NULL){
        printf("空的\n");
        return 1;
    }
    else{
        return 0;
    }
}
```

**出栈**

```C
int pop(Stack *s, ElemType *e){
    if(s -> next == NULL){
        printf("空的\n");
        return 0;
    }
    *e = s -> next -> data;
    Stack *q = s -> next;
    s -> next = q -> next;
    free(q);
    return 1;
}
```

**入栈**  
链式实现的栈的入栈与链表的头插法相同
