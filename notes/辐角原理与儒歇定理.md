# 辐角原理与儒歇定理

留数定理除了算积分, 还有一类重要应用: **数零点**. 辐角原理把"区域内零点的个数"与"沿边界的辐角变化"联系起来; 儒歇定理则给出一个实用的比较判据, 用来判断多项式在给定区域内有多少个零点. 它们也是代数基本定理的另一条证明路径.

## 一、辐角原理

**定理**: 设 $f$ 在简单闭曲线 $C$ 所围区域 $D$ 内除有限个极点外解析, 在 $C$ 上解析且无零点, 则 $f$ 在 $D$ 内的零点个数 $N$(按重数计) 与极点个数 $P$(按阶数计) 满足

$$\frac{1}{2\pi i}\oint_C\frac{f'(z)}{f(z)}dz = N - P$$

**辐角形式**(原理的名称来源):

$$\Delta_C\arg f(z) = 2\pi(N - P)$$

即 $z$ 沿 $C$ 绕行一周时, $f(z)$ 的辐角变化量等于 $2\pi(N - P)$. **直观上, $f$ 把曲线 $C$ 映成 $w$ 平面上绕原点的闭合曲线, 它绕原点转的圈数就是 $N - P$.**

**特例(无极点时)**: 若 $f$ 在 $D$ 内解析且无零点, 则

$$\frac{1}{2\pi i}\oint_C\frac{f'}{f}dz = N$$

这里 $N$ 是 $D$ 内零点的个数.

**记忆口诀**: $\dfrac{f'}{f}$ 在对数导数上有意义------$\frac{d}{dz}\ln f=\frac{f'}{f}$, 而 $\ln f$ 绕一圈的增量恰是 $2\pi i$ 乘圈数.

## 二、儒歇定理

**定理**: 设 $f$ 与 $g$ 在简单闭曲线 $C$ 所围区域 $D$ 内及 $C$ 上解析, 且

$$|g(z)|<|f(z)|\qquad(z\in C)$$

则 $f$ 与 $f + g$ 在 $D$ 内的**零点个数相同**(按重数计).

**直观**: 若 $g$ 在边界上的模严格小于 $f$, 则加上 $g$ 不会改变 $f$ 绕原点的圈数, 因此零点个数不变.

**使用要点**:

1. 把待研究的多项式拆成**主导项 $f$** 与**小项 $g$**;
2. $f$ 通常取最高次项或某个易判零点的项;
3. 在边界 $C$ 上验证 $|g|<|f|$ 是关键步骤.

## 三、例题

**例 1**(辐角原理求零点数): 设 $f(z) = z^3 - 1$, 求在 $|z|<2$ 内零点的个数.

解: $f$ 在 $|z|<2$ 内解析且无极点($P = 0$). 用儒歇定理更方便: 在 $|z|=2$ 上,

$$|g(z)|=|{-1}|=1<|f(z)|=|z^3|=8$$

故 $f + g = z^3 - 1$ 与 $f = z^3$ 在 $|z|<2$ 内零点个数相同. $z^3$ 在原点有 3 阶零点(计 3 个),

$$N = 3$$

**说明**: $z^3 - 1 = 0$ 的三个根模都为 1(即 $1,e^{\pm2\pi i / 3}$), 确实都落在 $|z|<2$ 内, 与结论一致.

**例 2**(儒歇定理的典型用法): 求 $z^4 + 6z + 3 = 0$ 在 $|z|<1$ 内有几个根.

解: 在 $|z|=1$ 上, 取 $f(z) = 6z$, $g(z) = z^4 + 3$. 则

$$|f(z)|=|6z|=6$$
$$|g(z)|\le|z|^4 + 3 = 1 + 3 = 4<6$$

故满足 $|g|<|f|$. 由儒歇定理, $f + g = z^4 + 6z + 3$ 与 $f = 6z$ 在 $|z|<1$ 内零点个数相同.

$6z$ 在原点有 1 个一阶零点, 故原方程在 $|z|<1$ 内**恰有 1 个根**.

**取 $f$ 的经验**: 选系数绝对值最大的那一项(这里是 $6z$), 它往往在边界上占优.

**例 3**(区域改为 $|z|<2$): 求 $z^4 + 6z + 3 = 0$ 在 $|z|<2$ 内有几个根.

解: 在 $|z|=2$ 上, 取 $f(z) = z^4$, $g(z) = 6z + 3$:

$$|f|=|z|^4 = 16$$
$$|g|\le6|z|+3 = 12 + 3 = 15<16$$

故由儒歇定理, $f + g$ 与 $z^4$ 在 $|z|<2$ 内零点数相同, 即 **4 个**.

**注意对比**: 同一个方程在 $|z|<1$ 内有 1 个根, 在 $|z|<2$ 内有 4 个根. **根的个数依赖于所取区域的大小**, 因此"有几根"必须指明区域.

**例 4**(代数基本定理的另一证明): 用儒歇定理证明 $n$ 次多项式 $P(z) = a_nz^n+\dots + a_0\ (a_n\neq0)$ 在 $\mathbb{C}$ 中有 $n$ 个零点.

解: 取圆 $|z|=R$, 其中 $R$ 足够大(大于一切 $\left|\frac{a_k}{a_n}\right|$ 与 1). 令

$$f(z) = a_nz^n,\qquad g(z) = a_{n - 1}z^{n - 1}+\dots + a_0$$

在 $|z|=R$ 上,

$$|g(z)|\le\sum_{k = 0}^{n - 1}|a_k|R^k\le MR^{n - 1}\qquad(M=\sum_{k = 0}^{n - 1}|a_k|)$$

而 $|f(z)|=|a_n|R^n$. 只要 $R>\frac{M}{|a_n|}$, 就有 $|g|<|f|$. 由儒歇定理, $P = f + g$ 与 $f = a_nz^n$ 在 $|z|<R$ 内零点数相同, 即 **$n$ 个**. 由于 $R$ 可任意大, 结论在全平面成立.

**例 5**(判断根的分布): 说明 $z^5 + 3z + 1 = 0$ 在 $|z|<1$ 内恰有 1 个根.

解: 在 $|z|=1$ 上取 $f(z) = 3z$, $g(z) = z^5 + 1$:

$$|f|=3,\qquad|g|\le|z|^5 + 1 = 2<3$$

满足条件. 故与 $3z$ 零点数相同, 即 **1 个根**.

**例 6**(判断零点数不变的情形): 讨论 $z^3 + z^2 + z + 1$ 在 $|z|<1$ 内与 $z^3$ 的零点数是否相同.

解: 在 $|z|=1$ 上, 取 $f = z^3$, $g = z^2 + z + 1$:

$$|f|=1,\qquad|g|\le1 + 1 + 1 = 3>1$$

**条件不满足**. 实际上 $z^3 + z^2 + z + 1 = (z + 1)(z^2 + 1)$, 在 $|z|<1$ 内**没有零点**, 而 $z^3$ 有 3 个零点(原点三阶), 两者不同.

**教训**: 儒歇定理的严格不等式 $|g|<|f|$ 是**必须验证**的, 不能只看形式就断言结论.

## 四、易错点

- 忘记验证 $|g|<|f|$, 或把它写成 $\le$.
- 忘记"按重数计": 二重零点算 2 个.
- 辐角原理中含极点时公式是 $N - P$, 不是单看 $N$.
- 不说清区域就回答"有几个根". 答案依赖区域.
- 把 $g$ 选得过大, 导致无法满足不等式(应选系数最大或次数最高的项为主导项).
