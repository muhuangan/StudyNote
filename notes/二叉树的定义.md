# 二叉树的定义

除了满二叉树和完全二叉树以外, 使用顺序结构存储都比较浪费空间, 因此首选链式存储

**单结点典型实现**

```C
typedef char ElemType;

typedef struct TreeNode{
    ElemType data;
    TreeNode* lchild;
    TreeNode* rchild;
}TreeNode;

typedef TreeNode* BiTree;
```
