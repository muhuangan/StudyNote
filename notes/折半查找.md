# 折半查找(线性表)

又叫二分查找  
折半查找的前提: 查找表必须是有序的

**算法自然语言描述**:

1. 假设查找表的起始下表为low, 结束下标为high
2. 计算中间下标: mid = (low + high) / 2 (向下取整)
    1. 如果关键字等于a\[mid\], 查找成功返回下标, 结束
    2. 如果关键字小于a\[mid\], 则在左半部分继续查找, 令high = mid - 1, 返回第二步
    3. 如果关键字大于a\[mid\], 则在右半部分继续查找, 令low = mid + 1, 返回第二步

```C
#include <stdio.h>
int binary_search(int* data, int len, int value){
    int low = 0;
    int high = len - 1;
    int mid;
    while(low <= high){
        mid = (low + high) / 2;
        if(value > data[mid]){
            low = mid + 1;
        }
        else if(value < data[mid]){
            high = mid - 1;
        }
        else{
            return mid;
        }
    }
    return -1;
}

int main(){
    int arr[] = {2, 13, 22, 38, 46, 58, 66, 77, 85, 90};
    int len = sizeof(arr) / sizeof(arr[0]);
    int pos = binary_search(arr, len, 66);
    printf("%d\n", pos);
    return 0;
}
```

顺序查找效率较低, 折半查找又依赖于有序的顺序表结构, 且插入与删除操作较为麻烦, 所以我们希望有一种查找结构可以既保持较高的查找效率, 又能在动态插入和删除时保持结构的有序性, 所以我们引入了**二叉排序树**
