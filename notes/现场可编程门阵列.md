# 现场可编程门阵列

## 核心结论

FPGA 由**可配置逻辑块(CLB) 阵列 + 输入输出块(IOB)+ 可编程布线资源 + 嵌入式硬核**构成, 逻辑功能由**查找表(LUT)**实现. 它的特点是**容量极大, 寄存器资源丰富, 适合大规模时序逻辑与数据通路**, 代价是基于 SRAM 的配置易失, 上电必须加载配置.

## 一、查找表(LUT)

**原理**: 一个 $k$ 输入的查找表是一个容量为 $2^k$ 位(常用 $k = 4$ 或 $k = 6$) 的 SRAM. 把真值表写入其中, 输入作为地址, 输出即为对应的函数值.

$$LUT(A_{k-1}, \cdots, A_0) = RAM[地址 = A_{k-1}\cdots A_0]$$

**本质**: LUT 就是"用 RAM 实现组合逻辑函数", 是第 7 章 ROM 实现逻辑函数思想的直接应用.

**关键结论**:$k$ 输入的 LUT 可以实现**任意** $k$ 输入的组合逻辑函数, 且不需要任何化简—因为它是直接查表.

**多输入函数的实现**: 超过 $k$ 个输入的函数需要用多个 LUT 级联(通过布线资源连接), 此时延迟随级数增加.

**现代 LUT 的附加能力**:

1. LUT 可配置为分布式 RAM 或移位寄存器(SLICEM).
2. 部分器件的 6 输入 LUT 可拆成两个 5 输入 LUT 使用.

## 二、可配置逻辑块(CLB)

**组成**:

| 组成        | 作用                                       |
| ----------- | ------------------------------------------ |
| 查找表(LUT) | 实现组合逻辑                               |
| 触发器(DFF) | 实现时序逻辑, 通常由 LUT 驱动              |
| 进位链      | 专用的快速进位通路, 用于实现加法器, 计数器 |
| 多路选择器  | 组合相邻 LUT 的输出                        |
| 局部布线    | CLB 内部的连接资源                         |

**Slice 结构**: 现代 FPGA 中 CLB 由 2 个或 4 个 Slice 组成, 每个 Slice 含若干 LUT 与触发器.

**关键比例**: 每个 LUT 配 1 至 2 个触发器, 因此 FPGA 的**寄存器资源非常丰富**, 这是它适合流水线与状态机设计的原因.

## 三、输入输出块(IOB)

**功能**:

1. 支持**多种电平标准**(LVTTL, LVCMOS, LVDS, SSTL 等).
2. 可选**上/下拉电阻**.
3. 可配置**驱动强度**与**摆率**(slew rate).
4. 内含输入/输出**触发器**(用于保证 I/O 时序) 与**延时单元**(IDELAY/ODELAY).
5. 支持**三态**与**双向**.
6. 部分 IOB 支持**差分信号**与**串并转换**(ISERDES/OSERDES).

**Bank 的概念**: I/O 引脚按 Bank 分组, 同一 Bank 内的引脚必须共用同一个 I/O 电压($V_{CCO}$).

## 四、布线资源

| 类型                    | 用途                           |
| ----------------------- | ------------------------------ |
| 长线(全局布线)          | 跨芯片远距离连接, 如时钟, 复位 |
| 短线(局部布线)          | 相邻 CLB 之间的连接            |
| 开关矩阵(Switch Matrix) | 实现不同方向布线的转接         |
| 专用进位链              | 相邻 CLB 之间的快速进位        |
| 时钟网络                | 低偏移的全局时钟树             |

**重要特性**: 布线延迟占 FPGA 总延迟的主要部分, 且**依赖布局布线结果**, 因此 FPGA 设计必须进行时序约束与时序分析(这与 CPLD 完全不同).

## 五、嵌入式块 RAM(Block RAM)

**特点**:

- 片内专用的同步双口 RAM, 容量通常为若干 kb 至 36 kb 一块.
- 可配置为单口 RAM, 双口 RAM(真双口/简单双口), FIFO, ROM.
- 可配置数据宽度与深度.
- 可级联成更大容量的存储器.

**与分布式 RAM 的区别**: 分布式 RAM 用 LUT 实现, 容量小但灵活; 块 RAM 是专门硬件, 容量大, 不占用逻辑资源.

## 六、DSP 单元

**组成**: 专用乘法器 + 加法器/累加器 + 流水线寄存器(如 Xilinx DSP48, Intel DSP Block).

**优势**: 用通用 LUT 实现乘法会消耗大量资源且速度慢, DSP 单元可以在一个时钟周期内完成"乘法 + 加法 + 累加", 是 FIR 滤波, FFT, 矩阵运算的核心.

## 七、其他硬核

| 硬核                           | 用途                                      |
| ------------------------------ | ----------------------------------------- |
| 时钟管理单元(DCM / PLL / MMCM) | 倍频, 分频, 相位调整, 去抖动              |
| 高速串行收发器(SerDes)         | 千兆/万兆以太网, PCIe, SATA               |
| 嵌入式处理器                   | Zynq 的 ARM Cortex, Intel 的 Nios II      |
| 模数转换器                     | 部分器件内置 ADC(如 Xilinx 7 系列的 XADC) |

## 八、FPGA 的开发流程

1. **设计输入**: Verilog / VHDL, 或图形化 IP 搭建.
2. **功能仿真**.
3. **综合**: 把 RTL 映射为 LUT, 触发器, 块 RAM 等资源.
4. **约束**: 时钟周期, I/O 引脚位置, I/O 电平标准, 时序例外.
5. **实现(布局布线)**: 确定资源位置与连线.
6. **时序分析**: 检查建立/保持时间是否满足(静态时序分析 STA).
7. **生成位流文件(.bit / .rbf / .sof)**.
8. **下载配置**(JTAG 在线调试, 或烧入外部 Flash 上电自动加载).

## 九、FPGA 与 CPLD 的选择

| 需求                           | 选择    |
| ------------------------------ | ------- |
| 逻辑简单, 上电即工作, 时序确定 | CPLD    |
| 大规模逻辑, 状态机, 流水线     | FPGA    |
| 需要大容量存储, DSP 运算       | FPGA    |
| 需要软核处理器或高速接口       | FPGA    |
| 成本极度敏感, 量很大           | 转 ASIC |

## 十、典型器件

| 厂商          | 入门系列           | 中端                         | 高端               |
| ------------- | ------------------ | ---------------------------- | ------------------ |
| Xilinx(AMD)   | Artix-7, Spartan-7 | Kintex-7 / Kintex UltraScale | Virtex UltraScale+ |
| Intel(Altera) | Cyclone 10         | Arria 10                     | Stratix 10         |
| Lattice       | iCE40, ECP5        | CrossLink                    | Certus             |

## 易错点

- 认为 FPGA 上电就能工作: 基于 SRAM 的 FPGA 上电后必须**先加载配置**, 在此之前 I/O 处于高阻或弱上拉状态, 系统设计必须考虑这一段时间.
- 认为 LUT 只能实现一个门: 一个 6 输入 LUT 可以实现任意 6 输入组合函数, 容量远大于一个门.
- 忽略时序约束: 没有约束的 FPGA 设计即使功能仿真正确, 也可能因时序违规而在实板上失效.
