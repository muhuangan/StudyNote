# 三角函数

实三角函数的定义式只用到幂与除法, 而这两者在复数域中都有意义, 因此可以把 $\sin x$, $\cos x$ 直接推广到复变量. 推广后的三角函数保住了求导公式与加法定理, 但丢掉了一个实情形中的关键性质------**有界性**: 在复数域中 $|\sin z|$ 与 $|\cos z|$ 可以任意大.

## 一、定义

由欧拉公式 $e^{iz}=\cos z + i\sin z$ 与 $e^{-iz}=\cos z - i\sin z$, 相加减得

$$\cos z=\frac{e^{iz} + e^{-iz}}{2},\qquad \sin z=\frac{e^{iz} - e^{-iz}}{2i}$$

由此定义

$$\tan z=\frac{\sin z}{\cos z},\qquad \cot z=\frac{\cos z}{\sin z},\qquad \sec z=\frac{1}{\cos z},\qquad \csc z=\frac{1}{\sin z}$$

**当 $z$ 取实数时**, 右端恰为 $\cos x$ 与 $\sin x$, 故定义是实数情形的自然推广.

## 二、性质

**(1) 解析性**: $\sin z$ 与 $\cos z$ 都是**整函数**, 且

$$(\sin z)'=\cos z,\qquad(\cos z)'=-\sin z$$

**验证 $\cos z$ 的导数**:

$$\frac{d}{dz}\cos z=\frac{d}{dz}\frac{e^{iz} + e^{-iz}}{2}=\frac{ie^{iz} - ie^{-iz}}{2} = i\cdot\frac{e^{iz} - e^{-iz}}{2}=-\frac{e^{iz} - e^{-iz}}{2i}=-\sin z$$

**(2) 周期性**: $\sin z$ 与 $\cos z$ 的实周期仍是 $2\pi$, 且它们**没有**非零的复周期(这一点与 $e^z$ 不同).

**(3) 奇偶性**: $\sin(-z)=-\sin z$, $\cos(-z)=\cos z$.

**(4) 加法定理**: 与实情形完全相同,

$$\sin(z_1\pm z_2)=\sin z_1\cos z_2\pm\cos z_1\sin z_2$$
$$\cos(z_1\pm z_2)=\cos z_1\cos z_2\mp\sin z_1\sin z_2$$

**(5) 平方关系**: $\sin^2z+\cos^2z = 1$.

**(6) 无界性**: 取 $z = iy\ (y\in\mathbb{R})$, 由定义

$$\cos iy=\frac{e^{-y} + e^{y}}{2}=\cosh y,\qquad \sin iy=\frac{e^{-y} - e^{y}}{2i} = i\sinh y$$

当 $y\to+\infty$ 时 $\cosh y\to+\infty$. 故 $\cos z$ 在复平面上**无界**, 且 $|\cos z|$ 可以任意大.

**这一点很重要**: 刘维尔定理说"有界的整函数必为常数", 而 $\cos z$ 是整函数且非常数, 因此它**必然无界**------两者的结论互相印证.

**(7) 零点**: $\sin z = 0$ 当且仅当 $z = k\pi$; $\cos z = 0$ 当且仅当 $z=\frac{\pi}{2} + k\pi$($k\in\mathbb{Z}$). 零点全在实轴上.

## 三、例题

**例 1**: 求 $\sin(2 + i)$ 的实部与虚部.

解: 用加法定理

$$\sin(2 + i)=\sin2\cos i+\cos2\sin i$$

代入 $\cos i=\cosh1$, $\sin i = i\sinh1$:

$$\sin(2 + i)=\sin2\cosh1 + i\cos2\sinh1$$

故

$$\operatorname{Re}=\sin2\cosh1,\qquad \operatorname{Im}=\cos2\sinh1$$

**取数值**: $\sin2\approx0.9093$, $\cos2\approx - 0.4161$, $\cosh1\approx1.5431$, $\sinh1\approx1.1752$. 故

$$\sin(2 + i)\approx1.4030 - 0.4891i$$

**注意**: 实部与虚部都**可以大于 1**, 这与实三角函数 $|\sin x|\le1$ 截然不同.

**例 2**: 求 $\cos i$ 与 $\sin(1 + 2i)$.

解: 由性质(6),

$$\cos i=\cosh1\approx1.5431$$

对第二个,

$$\sin(1 + 2i)=\sin1\cosh2 + i\cos1\sinh2\approx0.8415\times3.7622 + i\times0.5403\times3.6269\approx3.1658 + 1.9596i$$

**例 3**(解方程): 解方程 $\cos z = 0$.

解: 由定义 $\frac{e^{iz} + e^{-iz}}{2} = 0$, 即

$$e^{2iz}=-1$$

故 $2iz = i\pi(2k + 1)$, 即

$$z=\frac{(2k + 1)\pi}{2}=\frac{\pi}{2} + k\pi,\qquad k\in\mathbb{Z}$$

零点全落在实轴上, 与实情形一致.

**例 4**(解方程): 解方程 $\sin z = 2$.

解: 由定义

$$\frac{e^{iz} - e^{-iz}}{2i} = 2\ \Longrightarrow\ e^{iz} - e^{-iz} = 4i$$

令 $w = e^{iz}$, 则 $w-\frac1w = 4i$, 即

$$w^2 - 4iw - 1 = 0$$

解得

$$w=\frac{4i\pm\sqrt{-16 + 4}}{2}=\frac{4i\pm\sqrt{-12}}{2}=\frac{4i\pm2\sqrt3 i}{2} = i(2\pm\sqrt3)$$

两边取对数: $iz = \operatorname{Ln}\big[i(2\pm\sqrt3)\big]$, 注意 $i(2\pm\sqrt3)$ 的模为 $2\pm\sqrt3$, 辐角主值为 $\frac{\pi}{2}$. 故

$$z=\frac{\pi}{2} + 2k\pi - i\ln(2\pm\sqrt3),\qquad k\in\mathbb{Z}$$

**关键观察**: 解是**纯实部 + 纯虚部**的组合, 而实方程 $\sin x = 2$ 无解. 这说明复三角函数取遍整个复平面上的每个值(除个别例外), 而实三角函数的值域只是 $[-1,1]$.

## 四、易错点

- 认为 $|\sin z|\le1$ 或 $|\cos z|\le1$. 在复数域中这**不成立**.
- 把 $e^{iz}$ 当成实数处理.
- 解 $\sin z = a$ 时忘记化为关于 $e^{iz}$ 的二次方程, 或漏掉对数带来的 $2k\pi$.
- 记错导数符号: $(\cos z)'=-\sin z$, 与实情形相同但容易与 $\cosh$ 混淆.
