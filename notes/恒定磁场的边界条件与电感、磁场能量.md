# 恒定磁场的边界条件与电感、磁场能量

磁介质被磁化后产生附加磁场, 引入**磁场强度** $\boldsymbol H$ 可把磁化电流从方程中消去, 这与引入 $\boldsymbol D$ 的思路完全平行.

## 一、磁介质的磁化

磁介质在外磁场中呈现磁性, 称为**磁化**. 用**磁化强度**描述:

$$\boldsymbol M=\lim_{\Delta V\to0}\frac{\sum\boldsymbol m_i}{\Delta V}$$

其中 $\boldsymbol m_i$ 为每个分子磁矩(磁偶极矩), 单位为 $\text{A/m}$. 磁化产生**磁化电流**:

$$\boldsymbol J_M=\nabla\times\boldsymbol M,\qquad \boldsymbol J_{SM}=\boldsymbol M\times\boldsymbol e_n$$

## 二、磁场强度

把真空中安培环路定律的源改为"传导电流 + 磁化电流":

$$\nabla\times\boldsymbol B=\mu_0(\boldsymbol J+\boldsymbol J_M)=\mu_0(\boldsymbol J+\nabla\times\boldsymbol M)$$

整理得

$$\nabla\times\left(\frac{\boldsymbol B}{\mu_0}-\boldsymbol M\right)=\boldsymbol J$$

于是**定义磁场强度**:

$$\boldsymbol H=\frac{\boldsymbol B}{\mu_0}-\boldsymbol M$$

其意义是: **$\boldsymbol H$ 的涡旋源只有传导电流** $\boldsymbol J$.

**本构关系**(各向同性线性磁介质):

$$\boldsymbol M=\chi_m\boldsymbol H\ \Rightarrow\ \boldsymbol B=\mu_0(1+\chi_m)\boldsymbol H=\mu_0\mu_r\boldsymbol H=\mu\boldsymbol H$$

- $\chi_m$: 磁化率. $\chi_m>0$ 为**顺磁质**, $\chi_m<0$ 为**抗磁质**, $\chi_m\gg1$ 为**铁磁质**;
- $\mu_r = 1+\chi_m$: 相对磁导率; $\mu=\mu_0\mu_r$: 磁导率, $\mu_0 = 4\pi\times10^{-7}\ \text{H/m}$.

**有介质时的安培环路定律**:

$$\oint_C\boldsymbol H\cdot d\boldsymbol l=\sum I_{\text{传导}}\qquad\Longleftrightarrow\qquad\nabla\times\boldsymbol H=\boldsymbol J$$

## 三、恒定磁场的边界条件

设 $\boldsymbol e_n$ 从介质 1 指向介质 2:

**(1) 法向分量**(由磁通连续性定理):

$$B_{1n} = B_{2n}\qquad\text{或}\qquad \boldsymbol e_n\cdot(\boldsymbol B_1-\boldsymbol B_2) = 0$$

即**磁感应强度的法向分量总是连续**.

**(2) 切向分量**(由安培环路定律):

$$H_{1t} - H_{2t} = J_S\qquad\text{或}\qquad \boldsymbol e_n\times(\boldsymbol H_1-\boldsymbol H_2)=\boldsymbol J_S$$

- 分界面无面传导电流($J_S = 0$)时: $H_{1t} = H_{2t}$, **切向分量连续**;
- 若介质 2 为理想导体($\mu_r\to\infty$): 导体内部 $\boldsymbol H=\boldsymbol 0$, 磁场**只存在于导体表面外侧**.

**与静电场的对照**:

| 静电场                   | 恒定磁场                |
| ------------------------ | ----------------------- |
| $D_{1n} - D_{2n}=\rho_S$ | $B_{1n} - B_{2n} = 0$   |
| $E_{1t} = E_{2t}$        | $H_{1t} - H_{2t} = J_S$ |

**记忆技巧**: 电场是"法向跳出有源, 切向连续"; 磁场是"法向连续, 切向跳出有涡".

## 四、电感与磁场能量

**自感**:

$$L=\frac{\Psi}{I}=\frac{N\Phi}{I}$$

**互感**: $M_{12} = M_{21}=\dfrac{\Psi_{12}}{I_1}$.

**磁场能量**:

$$W_m=\frac12LI^2$$

更普遍的表达式(用场量表示, 与电场能量对称):

$$W_m=\frac12\int_V\boldsymbol B\cdot\boldsymbol H\,dV,\qquad W_e=\frac12\int_V\boldsymbol D\cdot\boldsymbol E\,dV$$

**磁场力**: 由虚功原理

$$\boldsymbol F=-\nabla W_m\big|_{I = \text{const}}\quad\text{或}\quad \boldsymbol F=\nabla W_m\big|_{\Psi = \text{const}}$$

## 五、例题

**例 1**(同轴电缆的自感): 内导体半径 $a$, 外导体内半径 $b$. 求单位长度的外电感.

解: 由安培环路定律得两导体间的磁场

$$H=\frac{I}{2\pi\rho}\ (a<\rho<b)$$

磁通交链为 $d\Psi=\frac{\mu_0I}{2\pi\rho}l\,d\rho$, 故单位长度的电感

$$L=\frac{\Psi}{Il}=\frac{\mu_0}{2\pi}\ln\frac ba$$

**例 2**(磁场能量): 承例 1, 求单位长度储存的磁场能量.

解:

$$W_m=\frac12\int\boldsymbol B\cdot\boldsymbol H\,dV=\frac12\int_a^b\left(\frac{\mu_0I}{2\pi\rho}\right)\left(\frac{I}{2\pi\rho}\right)2\pi\rho\,d\rho=\frac{\mu_0I^2}{4\pi}\ln\frac ba$$

与 $\frac12LI^2$ 对照, 结果一致, 验证了两套公式的等价性.

**例 3**(边界条件应用): 分界面无面电流, 已知介质 1 中 $\boldsymbol B_1$ 与法向夹角 $45^\circ$, $\mu_{r1} = 1$, $\mu_{r2} = 100$. 判断介质 2 中磁场方向.

解: 由切向连续与法向连续可得折射关系

$$\frac{\tan\theta_1}{\tan\theta_2}=\frac{\mu_{r1}}{\mu_{r2}}=\frac{1}{100}$$

故 $\tan\theta_2 = 100$, $\theta_2\approx89.4^\circ$, 即磁场几乎**平行于分界面**——这正是高磁导率材料"屏蔽"磁场(把磁通"拉"到材料内部)的原理.

## 六、易错点

- 把磁化电流当作传导电流代入安培环路定律右侧.
- 混淆边界条件形式: 磁场是**法向 $B$ 连续, 切向 $H$ 跳变**.
- 认为铁磁质的 $\mu_r$ 是常数: 它随工作点变化且存在磁滞与饱和.
- 把 $W_m=\frac12LI^2$ 与电场能量 $\frac12CU^2$ 的对应关系记错.
