# 希尔排序

希尔排序的灵感是, 能不能让数据先基本有序再进行排序. 它的核心思想是: 先按一定步长分组进行排序, 每个距离为步长的元素均保证相同的顺序, 逐步减小步长, 最终步长为1时完成最终的排序

希尔排序的步长的选取非常关键, 目前是一个数学难题, 没有找到一种最好的步长序列

```C
#include <stdio.h>

void shellSort(int* data, int len){
    int temp;
    // 初始化步长为数组长度的一半
    int step = len / 2;
    while(step >= 1){ //当前步长不小于1时继续排序
        // 对每个分组执行插入排序
        for(int i = step; i < len; i++){
            // 当前元素小于其步长距离前的元素 -> 需要插入排序
            if(data[i] < data[i - step]){
                temp = data[i]; // 暂存当前值
                int j = i - step

                // 向前寻找合适插入的位置,并逐步移动大于temp的元素
                while(j >= 0 && temp < data){
                    data[j + step] = data[j]; // 将较大值后移
                    j = j - step;
                }
                // 插入temp到正确的位置
                data[j + step] = temp;
            }
        }
        // 缩小步长,通常除以2
        step = step / 2;
    }
}

int main(){
    int data[] = {47, 35, 60, 95, 77, 15, 28, 52};
    int len = sizeof(data) / sizeof(data[0]);

    shellSort(data, len);

    for(int i = 0; i < len; i++){
        printf("%d ", data[i]);
    }

    return 0;
}
```

**注意: 最后一个步长必须为1**

| 维度       | 描述                                                                     |
| ---------- | ------------------------------------------------------------------------ |
| 时间复杂度 | $O(n^{1 + k})(0<k<1)$                                                    |
| 空间复杂度 | $O(1)$                                                                   |
| 算法稳定性 | 不稳定                                                                   |
| 适用场景   | 适合中等规模数据排序, 在不追求最优但希望实现简单, 高效时是一个不错的选择 |
