# 正弦电磁场的相量表示

工程中的电磁场几乎都是**时谐场**(时间上按正弦规律变化). 引入相量可以把时间导数化为代数因子 $j\omega$, 使偏微分方程降为**复数代数方程**.

## 一、时谐场的定义

若场量的每个分量都按同一角频率 $\omega$ 作正弦变化, 则称为**时谐电磁场**:

$$\boldsymbol E(\boldsymbol r,t)=\boldsymbol E_m(\boldsymbol r)\cos\bigl[\omega t+\varphi(\boldsymbol r)\bigr]$$

## 二、相量的定义

由欧拉公式 $\cos\theta=\operatorname{Re}(e^{j\theta})$, 上式可写成

$$\boldsymbol E(\boldsymbol r,t)=\operatorname{Re}\left[\dot{\boldsymbol E}(\boldsymbol r)e^{j\omega t}\right]$$

其中

$$\dot{\boldsymbol E}(\boldsymbol r)=\boldsymbol E_m(\boldsymbol r)e^{j\varphi(\boldsymbol r)}$$

称为**复振幅矢量**或**相量**. 它只含振幅与初相, **不含时间因子**.

**例**: $\boldsymbol E=\boldsymbol e_xE_0\cos(\omega t-kz)$ 的相量为 $\dot{\boldsymbol E}=\boldsymbol e_xE_0e^{-jkz}$.

## 三、时间导数化为代数因子

对时谐场, 对时间求导等价于**乘以 $j\omega$**:

$$\frac{\partial}{\partial t}\longleftrightarrow j\omega,\qquad \int dt\longleftrightarrow\frac{1}{j\omega}$$

**来源**: 因为 $\dfrac{\partial}{\partial t}\operatorname{Re}[\dot{\boldsymbol E}e^{j\omega t}]=\operatorname{Re}[j\omega\dot{\boldsymbol E}e^{j\omega t}]$, 与 $\dot{\boldsymbol E}$ 对应的时间因子被完整保留, 故可直接把算子替换掉.

**这一替换是相量法的全部价值所在**: 时域偏微分方程 $\to$ 频域代数方程.

## 四、麦克斯韦方程组的相量形式

| 时域                                                                                | 相量形式                                                                         |
| ----------------------------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| $\nabla\times\boldsymbol E=-\dfrac{\partial\boldsymbol B}{\partial t}$              | $\nabla\times\dot{\boldsymbol E}=-j\omega\dot{\boldsymbol B}$                    |
| $\nabla\times\boldsymbol H=\boldsymbol J+\dfrac{\partial\boldsymbol D}{\partial t}$ | $\nabla\times\dot{\boldsymbol H}=\dot{\boldsymbol J}+j\omega\dot{\boldsymbol D}$ |
| $\nabla\cdot\boldsymbol D=\rho$                                                     | $\nabla\cdot\dot{\boldsymbol D}=\dot\rho$                                        |
| $\nabla\cdot\boldsymbol B=0$                                                        | $\nabla\cdot\dot{\boldsymbol B}=0$                                               |

## 五、复介电常数

对导电媒质 $\dot{\boldsymbol J}=\sigma\dot{\boldsymbol E}$, $\dot{\boldsymbol D}=\varepsilon\dot{\boldsymbol E}$, 代入全电流定律:

$$\nabla\times\dot{\boldsymbol H}=\sigma\dot{\boldsymbol E}+j\omega\varepsilon\dot{\boldsymbol E}=j\omega\left(\varepsilon-j\frac{\sigma}{\omega}\right)\dot{\boldsymbol E}=j\omega\dot\varepsilon\dot{\boldsymbol E}$$

定义**复介电常数**

$$\dot\varepsilon=\varepsilon-j\frac{\sigma}{\omega}=\varepsilon\left(1-j\frac{\sigma}{\omega\varepsilon}\right)=\varepsilon(1-j\tan\delta)$$

其中 $\tan\delta=\dfrac{\sigma}{\omega\varepsilon}$ 称为**损耗角正切**, $\delta$ 称为损耗角.

**物理意义**: 复介电常数的**虚部代表损耗**(焦耳热), 实部代表储能. 这样, 导电媒质在形式上与"有损耗的电介质"统一, 无需单独处理 $\sigma$.

**两种极端**:

- $\dfrac{\sigma}{\omega\varepsilon}\ll1$: 弱导电(近理想介质), 可忽略损耗;
- $\dfrac{\sigma}{\omega\varepsilon}\gg1$: 良导体.

## 六、例题

**例 1**: 已知 $\boldsymbol H=\boldsymbol e_y10\cos(6\times10^8t-\pi z)\ \text{A/m}$, 写出其相量.

解:

$$\dot{\boldsymbol H}=\boldsymbol e_y10e^{-j\pi z}\ \text{A/m}$$

**例 2**(求时间导数): 已知相量 $\dot{\boldsymbol E}=\boldsymbol e_xE_0e^{-jkz}$, 求 $\partial\boldsymbol E/\partial t$ 的时域表达式.

解: 由替换规则, $\partial\boldsymbol E/\partial t$ 的相量为 $j\omega\dot{\boldsymbol E}=\boldsymbol e_xj\omega E_0e^{-jkz}$. 取实部:

$$\frac{\partial\boldsymbol E}{\partial t}=\operatorname{Re}\left[\boldsymbol e_xj\omega E_0e^{j(\omega t-kz)}\right]=-\boldsymbol e_x\omega E_0\sin(\omega t-kz)$$

与直接对 $\boldsymbol E=\boldsymbol e_xE_0\cos(\omega t-kz)$ 求导的结果一致.

**例 3**: 某媒质 $\varepsilon_r=2.25$, $\sigma=10^{-4}\ \text{S/m}$, 工作频率 $f=10\ \text{MHz}$. 判断其损耗程度.

解: $\omega=2\pi f=6.28\times10^7\ \text{rad/s}$, $\varepsilon=2.25\times8.854\times10^{-12}=1.99\times10^{-11}\ \text{F/m}$:

$$\frac{\sigma}{\omega\varepsilon}=\frac{10^{-4}}{6.28\times10^7\times1.99\times10^{-11}}=\frac{10^{-4}}{1.25\times10^{-3}}\approx0.08$$

比值远小于 1, 属**弱损耗媒质**, 可近似按理想介质处理. 若频率降至 $10\ \text{kHz}$, 该比值放大 1000 倍而远大于 1, 则须按良导体处理——**同一媒质的性质随频率改变**.

## 七、易错点

- 相量之间的乘除不能直接取实部: 只有对**同一频率**的相量作线性运算(加减)才可直接操作, 非线性运算需回到时域.
- 忘记取实部的约定: 用 $\cos$ 还是 $\sin$ 作时间因子须全书统一(本课程用 $\cos$).
- 混淆复介电常数虚部的符号: 取 $e^{j\omega t}$ 约定下为 $\dot\varepsilon=\varepsilon-j\sigma/\omega$.
- 把相量当作瞬时值使用.
