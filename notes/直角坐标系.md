# 直角坐标系

直角坐标系是最简单的正交坐标系, 其三个单位矢量**方向恒定**, 这是它相对于圆柱坐标与球面坐标的最大优点.

## 一、定义

在空间取一点 $O$ 为原点, 作三条互相垂直的数轴 $x,y,z$, 构成**直角坐标系**(笛卡儿坐标系). 三个坐标方向的单位矢量记为

$$\vec e_x,\ \vec e_y,\ \vec e_z$$

它们满足右手正交关系:

$$\vec e_x\times\vec e_y=\vec e_z,\qquad \vec e_y\times\vec e_z=\vec e_x,\qquad \vec e_z\times\vec e_x=\vec e_y$$

以及

$$\vec e_x\cdot\vec e_y=\vec e_y\cdot\vec e_z=\vec e_z\cdot\vec e_x = 0,\qquad \vec e_x\cdot\vec e_x=\vec e_y\cdot\vec e_y=\vec e_z\cdot\vec e_z = 1$$

## 二、位置矢量与矢量的表示

空间一点 $P(x,y,z)$ 的**位置矢量**为

$$\vec r = x\vec e_x + y\vec e_y + z\vec e_z$$

任一矢量 $\vec A$ 可分解为

$$\vec A = A_x\vec e_x + A_y\vec e_y + A_z\vec e_z$$

其模与单位矢量为

$$|\vec A|=\sqrt{A_x^2 + A_y^2 + A_z^2},\qquad \vec e_A=\frac{\vec A}{|\vec A|}$$

## 三、微分元(后面推导散度、旋度公式的基础)

**线元**(沿三个坐标方向的长度元):

$$d\vec l=\vec e_xdx+\vec e_ydy+\vec e_zdz$$

**面积元**(垂直于某一坐标轴的微小面积):

$$dS_x = dydz,\qquad dS_y = dxdz,\qquad dS_z = dxdy$$

**体积元**:

$$dV = dx\,dy\,dz$$

## 四、坐标系的核心优势

直角坐标系的三个单位矢量 $\vec e_x,\vec e_y,\vec e_z$ **不随位置变化**, 因此对矢量求导时只需对各分量分别求导:

$$\frac{\partial\vec A}{\partial x}=\frac{\partial A_x}{\partial x}\vec e_x+\frac{\partial A_y}{\partial x}\vec e_y+\frac{\partial A_z}{\partial x}\vec e_z$$

**对比**: 圆柱坐标的 $\vec e_\rho,\vec e_\phi$ 与球面坐标的 $\vec e_r,\vec e_\theta,\vec e_\phi$ 都**随位置变化**, 求导时必须额外考虑单位矢量本身的导数, 这也是这两种坐标系的散度, 旋度公式更复杂的原因.

## 五、例题

**例 1**: 已知 $\vec A = 3\vec e_x - 4\vec e_z$, 求 $\vec A$ 的模与单位矢量 $\vec e_A$.

解:

$$|\vec A|=\sqrt{3^2 + 0^2 + (-4)^2}=\sqrt{9 + 16} = 5$$
$$\vec e_A=\frac{3\vec e_x - 4\vec e_z}{5} = 0.6\vec e_x - 0.8\vec e_z$$

**例 2**: 求点 $P_1(1,2,3)$ 指向点 $P_2(4,6,3)$ 的矢量 $\vec R_{12}$ 及其单位矢量.

解:

$$\vec R_{12} = (4 - 1)\vec e_x + (6 - 2)\vec e_y + (3 - 3)\vec e_z = 3\vec e_x + 4\vec e_y$$
$$|\vec R_{12}|=\sqrt{9 + 16} = 5,\qquad \vec e_R=\frac{3\vec e_x + 4\vec e_y}{5}$$

**要点**: 在库仑定律与毕奥-萨伐尔定律中反复要用到"从源点指向场点"的矢量, 务必记住是**场点坐标减源点坐标**.

**例 3**: 求 $\vec A = 2\vec e_x + 3\vec e_y$ 与 $\vec B=\vec e_x+\vec e_y$ 之间的夹角.

解:

$$\vec A\cdot\vec B = 2\times1 + 3\times1 = 5,\qquad |\vec A|=\sqrt{13},\qquad |\vec B|=\sqrt2$$
$$\cos\theta=\frac{5}{\sqrt{13}\sqrt2}=\frac{5}{\sqrt{26}}\approx0.9806\ \Rightarrow\ \theta\approx11.3^\circ$$

**例 4**: 用体积元计算边长为 $a$ 的立方体体积.

解: 积分区域 $0\le x,y,z\le a$:

$$V=\iiint dV=\int_0^a\int_0^a\int_0^a dx\,dy\,dz = a^3$$

## 六、易错点

- 把"场点减源点"写反, 导致电场方向出错.
- 认为 $\vec e_x,\vec e_y,\vec e_z$ 会随位置变化(那是圆柱/球面坐标的事).
- 面积元 $dS$ 写错下标: 垂直于 $x$ 轴的面元是 $dydz$.
