# 逐次逼近型与并联比较型ADC

## 核心结论

**并联比较型**用 $2^n - 1$ 个比较器一次比较得出结果, 速度最快但元件数随位数指数增长.**逐次逼近型**用一个比较器加一个 D/A 转换器, 从最高位开始逐位试探, 需要 $n$ 次比较, 是速度, 精度, 成本的最佳折中, 也是最常用的 ADC 类型.

## 一、并联比较型(Flash) ADC

**结构**:

1. 用电阻分压器产生 $2^n - 1$ 个参考电平.
2. 用 $2^n - 1$ 个电压比较器, 把输入同时与全部参考电平比较.
3. 比较器的输出构成一个"温度计码", 经优先编码器转换为 $n$ 位二进制码.

**工作过程**: 所有比较器**并行**工作, 输入一加上, 全部比较器同时给出结果, 经编码后即得数字输出.**转换只需一级比较加一级编码的延迟**.

**优点**:

- 速度最快: 转换时间仅几十纳秒, 是所有 ADC 中最快的.
- 不需要采样保持电路(输入直接比较), 适合超高速场合.

**缺点**:

- 元件数随位数**指数增长**:$n$ 位需要 $2^n - 1$ 个比较器. 8 位需 255 个, 10 位需 1023 个, 12 位需 4095 个, 几乎不可实现.
- 功耗与面积大.
- 输入电容大, 对前级驱动能力要求高.

**适用**: 分辨率 6 至 8 位, 要求极高速度的场合, 如示波器, 雷达, 光通信, 磁盘读取通道.

## 二、逐次逼近型(SAR) ADC

**结构**:

| 组成                | 作用                      |
| ------------------- | ------------------------- |
| 采样保持电路        | 冻结输入电压              |
| 电压比较器          | 判断 D/A 输出与输入的大小 |
| D/A 转换器          | 把试探值变成模拟电压      |
| 逐次逼近寄存器(SAR) | 按二分搜索策略逐位确定    |
| 控制逻辑            | 协调各部分时序            |

**工作原理(二分搜索)**:

1. 先把最高位置 1, 其余位为 0, 经 D/A 得到试探电压送入比较器.
2. 若试探电压**大于**输入, 说明该位过大, 把它清 0; 否则保留 1.
3. 依次对次高位, 再下一位...... 重复上述过程.
4. 经过 $n$ 次比较,$n$ 位全部确定, 转换结束.

**示例**(4 位, 范围 0 至 8 V, 输入 5.2 V):

| 步骤 | 试探码 | D/A 输出 | 比较结果 | 决策   |
| ---- | ------ | -------- | -------- | ------ |
| 1    | 1000   | 4.0 V    | 小于输入 | 保留 1 |
| 2    | 1100   | 6.0 V    | 大于输入 | 改为 0 |
| 3    | 1010   | 5.0 V    | 小于输入 | 保留 1 |
| 4    | 1011   | 5.5 V    | 大于输入 | 改为 0 |

结果为 **1010**(对应 5.0 V), 与 5.2 V 的量化值一致($\Delta = 0.5\ \text{V}$).

**转换时间**:

$$t_{conv} = n \cdot T_{CP}$$

即 $n$ 个时钟周期(还需加上采样时间). 当时钟频率为 1 MHz 时, 8 位转换需 8 微秒.

**优点**:

1. 只需一个比较器, 元件数随位数**线性**增长, 成本低.
2. 精度较高(8 至 18 位).
3. 速度适中(微秒级).
4. 功耗低.

**缺点**: 需要 $n$ 个时钟周期, 速度不及 Flash 型; 内部 D/A 的精度直接限制整体精度.

**适用**:**应用最广**—数据采集, 工业控制, 传感器接口, 中速测量. 典型芯片: ADC0809(8 位, 8 通道), ADS7886, STM32 内部 ADC(12 位 SAR).

## 三、两种类型的对比

| 对比项         | 并联比较型         | 逐次逼近型             |
| -------------- | ------------------ | ---------------------- |
| 比较器数       | $2^n - 1$ 个       | 1 个                   |
| 转换时间       | 数十 ns(一级延迟)  | $n$ 个时钟周期         |
| 典型分辨率     | 6 至 8 位          | 8 至 18 位             |
| 是否需 D/A     | 否                 | **是**                 |
| 是否需采样保持 | 通常不需要         | 需要                   |
| 成本           | 高(位数多时不可行) | 低                     |
| 速度           | 最快               | 中                     |
| 典型应用       | 示波器, 雷达       | 数据采集, MCU 内置 ADC |

## 四、流水线型(Pipeline) ADC(拓展)

**结构**: 把转换分成若干级(每级 1 至 3 位), 每级完成"粗转换 → D/A 还原 → 求余量 → 放大 → 交给下一级", 各级**并行流水**工作.

**特点**:

1. 吞吐率高: 每级处理完就把余量交给下一级, 虽然单个样本的延迟是若干级, 但**吞吐率等于时钟频率**.
2. 分辨率可达 10 至 16 位, 速度可达数十至数百 MSPS.
3. 是 Flash 与 SAR 之间的高速高精度折中方案.

**应用**: 通信接收机, 视频采集, 医疗成像.

## 五、精度与速度的权衡

| 类型     | 速度 | 分辨率 | 说明                     |
| -------- | ---- | ------ | ------------------------ |
| Flash    | 最快 | 低     | 并行比较, 元件数指数增长 |
| Pipeline | 快   | 中     | 分级流水, 吞吐率高       |
| SAR      | 中   | 中高   | 二分搜索, 性价比最高     |
| Σ-Δ      | 慢   | 高     | 过采样, 见另一篇         |
| 双积分   | 最慢 | 高     | 两次积分, 抗干扰强       |

## 六、选型要点

1. **信号带宽决定速度需求**: 按采样定理(并留余量) 确定最低采样率.
2. **精度需求决定位数**: 注意有效位数(ENOB) 而非标称位数.
3. **MCU 内置 ADC 多为 SAR 型**: 适合一般传感器采集(温度, 电压, 电流).
4. **需要 1 MSPS 以上且 12 位以上**: 考虑外置 SAR 或 Pipeline ADC.
5. **需要纳秒级速度**: 只能选 Flash ADC.

## 七、使用要点

1. **参考电压决定精度**: 必须用高精度基准源, 并加去耦电容.
2. **输入端要加 RC 滤波**: 既抗混叠, 又为采样保持电容提供充电电流.
3. **注意采样时间配置**: MCU 的 ADC 采样时间若太短, 内部采样电容充电不足, 结果偏低(这是 STM32 ADC 最常见的误差来源).
4. **模拟与数字地要分开**: 避免数字噪声耦合到模拟部分.
5. **转换期间不要切换通道**: 切换通道后要等采样电容重新充电.

## 易错点

- 认为逐次逼近型 ADC 的转换时间与位数无关: 它需要 $n$ 个时钟周期, 位数越多越慢.
- 认为 Flash ADC 可以做到任意位数: 比较器数量随 $2^n$ 增长, 超过 8 位就不切实际.
- 忽视采样时间: SAR ADC 输入端等效为一个开关加采样电容, 采样时间不足会直接导致读数偏低.
