# 中心极限定理的应用

中心极限定理是一类"万能近似工具". 本篇按题型归纳它的用法, 并给出可直接照搬的解题模板.

## 一、三种题型与对应公式

**题型一:$n$ 个独立同分布变量之和**

设 $X_1,\ldots,X_n$ 独立同分布, $E(X_i)=\mu$, $D(X_i)=\sigma^2$, 则

$$\sum_{i = 1}^{n}X_i\ \dot\sim\ N(n\mu,\ n\sigma^2)\ \Longrightarrow\ P\left(\sum X_i\le a\right)\approx\Phi\!\left(\frac{a - n\mu}{\sqrt n\,\sigma}\right)$$

**题型二: 样本均值**

$$\overline X\ \dot\sim\ N\!\left(\mu,\ \frac{\sigma^2}{n}\right)\ \Longrightarrow\ P\bigl(\overline X\le a\bigr)\approx\Phi\!\left(\frac{a-\mu}{\sigma/\sqrt n}\right)$$

**题型三: 二项分布(棣莫弗-拉普拉斯)**

$$X\sim B(n,p)\ \dot\sim\ N\bigl(np,\ npq\bigr)\ \Longrightarrow\ P(X\le a)\approx\Phi\!\left(\frac{a - np}{\sqrt{npq}}\right)$$

## 二、标准解题步骤

1. **识别结构**: 题目是"若干个独立量之和"?"均值"? 还是"二项计数"?
2. **算期望与方差**: 和的期望是期望之和, 和的方差是方差之和(独立);
3. **标准化**: 减去期望, 除以标准差;
4. **查表**: 用 $\Phi$ 得结果; 离散情形考虑是否作连续性修正;
5. **检查条件**: $n\ge30$, 或 $np\ge5$ 且 $nq\ge5$.

## 三、例题

**例 1**(和): 某型号电池的寿命独立同分布, 期望 $100$ 小时, 标准差 $10$ 小时. 求 50 个电池的**总寿命**超过 $5200$ 小时的概率.

解: $n = 50$, $n\mu = 5000$, $n\sigma^2 = 50\times100 = 5000$, 故 $\sqrt{5000}\approx70.711$:

$$P\left(\sum X_i>5200\right) = P\left(Z>\frac{5200 - 5000}{70.711}\right) = P(Z>2.828)\approx1 - 0.9977 = 0.0023$$

**例 2**(均值): 某地成年男性身高独立同分布, 期望 $170\ \text{cm}$, 标准差 $6\ \text{cm}$. 随机抽取 64 人, 求平均身高在 $168$ 到 $172\ \text{cm}$ 之间的概率.

解: $\sigma_{\overline X}=\frac{6}{\sqrt{64}} = 0.75$:

$$P(168<\overline X<172) = P\left(\frac{-2}{0.75}<Z<\frac{2}{0.75}\right) = P(-2.667<Z<2.667)\approx0.9923$$

**例 3**(二项): 某保险公司的某种保单, 每份一年内索赔的概率为 $0.05$. 若卖出 400 份, 求索赔份数不超过 25 份的概率.

解: $X\sim B(400,0.05)$, $np = 20$, $npq = 19$, $\sqrt{npq}\approx4.359$. 用修正($b = 25$):

$$P(X\le25)\approx\Phi\!\left(\frac{25.5 - 20}{4.359}\right)=\Phi(1.262)\approx0.8965$$

**例 4**(检验样本量是否足够): 某流水线生产的产品次品率 $p = 0.01$, 检验 1000 件, 求次品数多于 20 件的概率.

解: 这里 $np = 10\ge5$, $nq = 990\ge5$, 可用正态近似. $\sqrt{npq}=\sqrt{9.9}\approx3.146$. 用修正($a = 20$):

$$P(X>20)\approx1-\Phi\!\left(\frac{20.5 - 10}{3.146}\right) = 1-\Phi(3.337)\approx1 - 0.9996 = 0.0004$$

## 四、与大数定律的分工

| 项目         | 大数定律                 | 中心极限定理             |
| ------------ | ------------------------ | ------------------------ |
| 回答的问题   | 平均**趋于**哪里         | 平均**如何波动**         |
| 结论形式     | 依概率收敛到常数         | 依分布收敛到正态         |
| 用途         | 论证估计的合理性         | 给出具体的近似数值       |
| 是否需要方差 | 切比雪夫需要, 辛钦不需要 | **需要** $\sigma^2$ 有限 |

## 五、近似选择速查

| 条件                          | 推荐近似                       |
| ----------------------------- | ------------------------------ |
| $n$ 大, $p$ 不接近 0 或 1     | 正态近似(含连续性修正)         |
| $n$ 大, $p\le0.05$, $np$ 适中 | 泊松近似                       |
| $n$ 大, $p$ 接近 1            | 转看"失败次数", 再用泊松近似   |
| 分布严重偏斜或重尾            | 需要更大的 $n$, 或直接数值计算 |

## 六、易错点

- **漏算方差**: 和的方差是 $n\sigma^2$, 均值的方差是 $\frac{\sigma^2}{n}$; 二者相差 $n^2$ 倍, 写错后果严重.
- 把 $\sqrt{n\sigma^2}$ 写成 $n\sigma$ 或 $\sqrt n\sigma^2$.
- 离散情形忘记连续性修正导致精度下降.
- 在 $n$ 太小或 $p$ 太小时强行使用正态近似.
- 把"总和的概率"与"均值的概率"混淆, 标准化时用错了分母.
