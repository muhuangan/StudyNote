# 复数的模与辐角

模与辐角是复数的**极坐标参数**: 模给出"到原点多远", 辐角给出"相对正实轴转了多少". 换成这一对参数后, 乘法、除法、乘幂、开方都有了简洁的形式, 这是复数运算比直角坐标形式更省力的地方.

## 一、模

数 $z = x + iy$ 的**模**定义为

$$|z|=\sqrt{x^2 + y^2}$$

几何上就是点 $z$ 到原点的距离.

基本性质:

- $|z|\ge0$, 且 $|z|=0$ 当且仅当 $z = 0$;
- $|\operatorname{Re}z|\le|z|$, $|\operatorname{Im}z|\le|z|$;
- $|z|^2 = z\overline{z}$;
- $|z_1z_2|=|z_1||z_2|$, $\left|\dfrac{z_1}{z_2}\right|=\dfrac{|z_1|}{|z_2|}$($z_2\neq0$).

**三角不等式**:

$$|z_1 + z_2|\le|z_1|+|z_2|$$

取等号当且仅当 $z_1$ 与 $z_2$ 的辐角相同(即同向). 对应的下界形式为

$$\big||z_1|-|z_2|\big|\le|z_1 - z_2|$$

## 二、辐角

当 $z\neq0$ 时, 满足

$$z=|z|(\cos\theta + i\sin\theta)$$

的 $\theta$ 称为 $z$ 的**辐角**, 记作 $\theta = \operatorname{Arg}z$.

**辐角是多值的**: 若 $\theta_0$ 是 $z$ 的一个辐角, 则 $\theta_0 + 2k\pi\ (k\in\mathbb{Z})$ 全都是 $z$ 的辐角. 所有辐角构成的集合记作 $\operatorname{Arg}z$, 即

$$\operatorname{Arg}z=\arg z + 2k\pi,\qquad k = 0,\pm1,\pm2,\dots$$

其中 $\arg z$ 是落在区间 $(-\pi,\pi]$ 内的那个辐角, 称为**辐角主值**.

**主值的约定**: 主值区间取 $(-\pi,\pi]$. 当 $z$ 落在负实轴上时辐角主值取 $\pi$(而不是 $-\pi$), 这一点在含 $\ln$、$\sqrt{\cdot}$ 的题目中会影响结果, 必须留意.

$z = 0$ 时辐角无意义(模为 0, 任何角度都成立).

## 三、三角形式与指数形式

由模与辐角, 复数可写成

$$z=|z|(\cos\theta + i\sin\theta)$$

称为**三角形式**. 引入欧拉公式

$$e^{i\theta}=\cos\theta + i\sin\theta$$

后, 又可写成**指数形式**

$$z=|z|e^{i\theta}$$

**欧拉公式的常用推论**:

$$e^{i\pi}=-1,\qquad e^{i\pi / 2} = i,\qquad \cos\theta=\frac{e^{i\theta} + e^{-i\theta}}{2},\qquad \sin\theta=\frac{e^{i\theta} - e^{-i\theta}}{2i}$$

最后一对式子把三角函数化为指数函数, 是后面定义**复三角函数**的依据.

## 四、辐角的计算

设 $z = x + iy\neq0$, 则

$$\arg z=\begin{cases}\arctan\dfrac{y}{x}, & x>0\\[2mm] \pi+\arctan\dfrac{y}{x}, & x<0,\ y\ge0\\[2mm] -\pi+\arctan\dfrac{y}{x}, & x<0,\ y<0\\[2mm] \dfrac{\pi}{2}, & x = 0,\ y>0\\[2mm] -\dfrac{\pi}{2}, & x = 0,\ y<0\end{cases}$$

**要点**: 不能一律用 $\arctan\frac{y}{x}$, 因为 $\arctan$ 的值域只是 $(-\frac{\pi}{2},\frac{\pi}{2})$, 会把第二、三象限的点算错. 更稳妥的办法是**先画出点所在象限, 再看几何角度**.

## 五、例题

**例 1**: 求 $z=-1+\sqrt3 i$ 的模与辐角主值.

解: 模为

$$|z|=\sqrt{(-1)^2 + (\sqrt3)^2}=\sqrt{1 + 3} = 2$$

点在第二象限, 且

$$\tan\theta=\frac{\sqrt3}{-1}=-\sqrt3$$

第二象限中符合该正切值的角为

$$\arg z=\pi-\frac{\pi}{3}=\frac{2\pi}{3}$$

于是三角形式为

$$z = 2\left(\cos\frac{2\pi}{3} + i\sin\frac{2\pi}{3}\right) = 2e^{\frac{2\pi}{3}i}$$

**若用 $\arctan$ 直接算**: $\arctan(-\sqrt3)=-\frac{\pi}{3}$, 与正确的 $\frac{2\pi}{3}$ 相差 $\pi$, 正好落在相反的方向上. 这就是必须看象限的原因.

**例 2**: 把 $z = 1 - i$ 化为指数形式, 并求 $z^2$.

解: $|z|=\sqrt2$, 点在第四象限,

$$\arg z=-\frac{\pi}{4}$$

故 $z=\sqrt2 e^{-\frac{\pi}{4}i}$. 于是

$$z^2 = (\sqrt2)^2e^{-2\cdot\frac{\pi}{4}i} = 2e^{-\frac{\pi}{2}i} = 2\left(\cos\frac{\pi}{2} - i\sin\frac{\pi}{2}\right)=-2i$$

**直接验算**: $(1 - i)^2 = 1 - 2i + i^2=-2i$, 一致.

**例 3**(用模证不等式): 证明 $|z_1 + z_2|^2+|z_1 - z_2|^2 = 2(|z_1|^2+|z_2|^2)$ 并由此说明何时 $|z_1 + z_2|=|z_1|+|z_2|$.

解: 恒等式已在[复数的几何表示](./复数的几何表示.md) 中给出证明. 把它改写为

$$|z_1 + z_2|^2 = 2(|z_1|^2+|z_2|^2)-|z_1 - z_2|^2$$

若 $|z_1 + z_2|=|z_1|+|z_2|$, 两边平方得

$$|z_1 + z_2|^2=|z_1|^2+|z_2|^2 + 2|z_1||z_2|$$

代入上式并整理得

$$|z_1 - z_2|^2 = (|z_1|-|z_2|)^2$$

**几何解释**: 平行四边形的两条对角线分别等于两邻边之和与之差, 这只有在两向量同向(退化) 时成立.

**例 4**(模的计算技巧): 求 $|(3 + 4i)(1 - i)|$ 与 $\left|\dfrac{3 + 4i}{1 - i}\right|$.

解: 用模的乘法性质比先做乘法再取模更快:

$$|3 + 4i|=5,\qquad|1 - i|=\sqrt2$$

故

$$|(3 + 4i)(1 - i)|=5\sqrt2,\qquad\left|\frac{3 + 4i}{1 - i}\right|=\frac{5}{\sqrt2}=\frac{5\sqrt2}{2}$$

**例 5**(辐角相加性的应用): 已知 $\operatorname{Arg}(z_1z_2) = \operatorname{Arg}z_1 + \operatorname{Arg}z_2$ 应理解为集合相等, 说明为什么辐角主值一般**不**满足 $\arg(z_1z_2)=\arg z_1+\arg z_2$.

解: 取 $z_1 = z_2 = e^{\frac{3\pi}{4}i}$. 两者辐角主值都是 $\frac{3\pi}{4}$, 和为 $\frac{3\pi}{2}$. 但

$$z_1z_2 = e^{\frac{3\pi}{2}i} = e^{\frac{3\pi}{2}i - 2\pi i} = e^{-\frac{\pi}{2}i}$$

其辐角主值为 $-\frac{\pi}{2}$, 并不等于 $\frac{3\pi}{2}$. 差别恰为 $2\pi$. **所以涉及辐角主值相加时, 最后常需调整 $2\pi$ 的整数倍以落回 $(-\pi,\pi]$ 区间.**

## 六、易错点

- 用 $\arctan\frac{y}{x}$ 算辐角而忽略象限.
- 把 $\operatorname{Arg}z$ 当成单值函数. 它是多值集合, 单值的是主值 $\arg z$.
- 认为 $z = 0$ 有辐角. $0$ 的辐角无定义.
- 在 $-\pi$ 与 $\pi$ 处取错: 负实轴上主值取 $\pi$.
- 指数形式中把 $e^{i\theta}$ 写成 $e^{i\theta} + 2k\pi$ 之外的形式; 正确的多值写法是 $|z|e^{i(\theta + 2k\pi)}$.
