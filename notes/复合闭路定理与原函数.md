# 复合闭路定理与原函数

柯西-古尔萨定理要求区域单连通, 但实际问题中的区域常有洞(圆环、去心圆盘). 复合闭路定理就是为这种情况准备的: 它把多连通区域上的积分拆成若干绕单个奇点的积分之和. 与它配套的"原函数存在定理", 则给出了判断能用牛顿-莱布尼茨公式的最简判据.

## 一、复合闭路定理

**定理**: 设 $C$ 是一条简单闭曲线, $C_1,C_2,\dots,C_n$ 是 $C$ 内部互不相交也互不包含的简单闭曲线. 若 $f$ 在由 $C$ 与 $C_k$ **共同围成的多连通区域** $D$ 内解析(即 $f$ 在 $D$ 及边界上解析), 则

$$\oint_Cf(z)\,dz=\sum_{k = 1}^{n}\oint_{C_k}f(z)\,dz$$

其中 $C$ 与各 $C_k$ 均取**逆时针方向**(使区域恒在曲线左侧).

**直观理解**: 把 $C$ 与各 $C_k$ 用辅助线连起来, 形成一条"外圈逆时针、内圈顺时针"的复合闭路. 辅助线往返各一次相互抵消, 复合闭路所围区域没有洞, 可用柯西-古尔萨定理得到积分为零, 整理即得结论.

**使用要点**:

1. 各 $C_k$ 必须落在 $C$ 内部且互不相交、互不包含;
2. $f$ 在"挖去洞之后"的区域内解析, 即洞内可以有不解析的点;
3. 方向统一取逆时针时, 内圈积分不加负号(因为定理的推导已含方向).

## 二、原函数存在定理

**定理**: 若 $f$ 在**单连通区域** $D$ 内解析, 则 $f$ 在 $D$ 内存在原函数 $F$, 满足 $F'=f$. 并且对 $D$ 内任意两点 $z_0,z_1$,

$$\int_{z_0}^{z_1}f(z)\,dz = F(z_1) - F(z_0)$$

**这条定理把复积分变成了"求原函数再代端点"**, 与实微积分完全平行. 但前提是**单连通**.

**在多连通区域上**: 原函数未必存在(可能多值). 典型例子是 $f(z)=\frac1z$ 在圆环 $0<|z|<2$ 内, 形式上原函数是 $\ln z$, 但 $\ln z$ 不是单值函数.

## 三、例题

**例 1**: 计算 $\oint_{|z|=2}\dfrac{dz}{z^2 - 1}$.

解: 奇点为 $z=\pm1$, 都满足 $|z|=1<2$, 落在圆内. 先把被积函数拆开:

$$\frac{1}{z^2 - 1}=\frac{1}{(z - 1)(z + 1)}=\frac12\left(\frac{1}{z - 1}-\frac{1}{z + 1}\right)$$

由复合闭路定理, 用两个小圆分别围住 $z = 1$ 与 $z=-1$:

$$\oint_{|z|=2}\frac{dz}{z^2 - 1}=\frac12\left(\oint_{|z - 1|=\varepsilon}\frac{dz}{z - 1}-\oint_{|z + 1|=\varepsilon}\frac{dz}{z + 1}\right)$$

两个积分分别为 $2\pi i$ 与 $2\pi i$, 故

$$=\frac12(2\pi i - 2\pi i) = 0$$

**要点**: 用**部分分式**把被积函数拆成"每个分母只含一个奇点"的形式, 再逐项用 $\oint\frac{dz}{z - z_0} = 2\pi i$.

**例 2**: 计算 $\oint_{|z|=3}\dfrac{z}{z^2 - 1}dz$.

解: 同样两个奇点 $\pm1$ 都在圆内. 部分分式:

$$\frac{z}{z^2 - 1}=\frac12\left(\frac{1}{z - 1}+\frac{1}{z + 1}\right)$$

(可用待定系数法或观察得到.) 于是

$$\oint_{|z|=3}\frac{z\,dz}{z^2 - 1}=\frac12(2\pi i + 2\pi i) = 2\pi i$$

**对比例 1**: 分子由 $1$ 换成 $z$ 后, 两个部分分式的系数由 $+1,-1$ 变成 $+1,+1$, 结果由 0 变为 $2\pi i$. **分子的取值直接决定各奇点贡献的正负.**

**例 3**(原函数的用法): 计算 $\int_{0}^{2\pi i}e^z\,dz$.

解: $e^z$ 是整函数, 可直接用原函数:

$$\int_0^{2\pi i}e^z\,dz=\left[e^z\right]_0^{2\pi i} = e^{2\pi i} - e^0 = 1 - 1 = 0$$

**注意**: 若沿路径从 $0$ 到 $2\pi i$ 是任意曲线均可, 结果相同(解析函数的积分只依赖端点).

**例 4**(多连通区域不能求原函数): 说明在圆环 $D=\{1<|z|<2\}$ 内不存在单值的 $\ln z$.

解: 取 $D$ 内的闭路 $|z|=\frac32$. 若存在单值解析的 $F$ 使 $F'=\frac1z$, 则由柯西-古尔萨定理(可先把圆环挖洞或用路径变形论证) 应有 $\oint_{|z|=3 / 2}F'\,dz = 0$. 但已知

$$\oint_{|z|=3 / 2}\frac{dz}{z} = 2\pi i\neq0$$

矛盾. 故不存在.

**解释**: 绕原点一周后辐角增加 $2\pi$, $\ln z$ 的虚部不能回到原值. 根源是圆环**含一个洞**, 不是单连通.

**例 5**(用复合闭路定理处理多个奇点): 计算 $\oint_{|z|=2}\dfrac{dz}{z(z - 1)^2}$.

解: 奇点为 $z = 0$(一阶) 与 $z = 1$(二阶), 都在圆内. 部分分式:

$$\frac{1}{z(z - 1)^2}=\frac{1}{z}-\frac{1}{z - 1}+\frac{1}{(z - 1)^2}$$

(可自行验算: 右端通分后与左端相同.) 逐项积分:

- $\oint\dfrac{dz}{z} = 2\pi i$;
- $\oint\dfrac{dz}{z - 1} = 2\pi i$;
- $\oint\dfrac{dz}{(z - 1)^2} = 0$(因为 $\frac{d}{dz}\left(-\frac{1}{z - 1}\right)=\frac{1}{(z - 1)^2}$, 有单值原函数).

故

$$\oint_{|z|=2}\frac{dz}{z(z - 1)^2} = 2\pi i - 2\pi i + 0 = 0$$

**要点**: 形如 $\dfrac{1}{(z - z_0)^n}\ (n\ge2)$ 沿绕 $z_0$ 的闭路积分为 0, 只有 $n = 1$ 才有贡献.

## 四、易错点

- 复合闭路定理中各内圈的方向取错, 导致符号错误.
- 内圈没有落在外圈内部, 或相互相交、包含, 不满足定理前提.
- 忘记 $f$ 必须在"挖洞后"的区域解析. 若洞内还有别的奇点, 需继续细拆.
- 在多连通区域上用牛顿-莱布尼茨公式, 而原函数并不单值.
- 把 $\oint\frac{dz}{(z - z_0)^n}$ 在 $n\ge2$ 时也算成 $2\pi i$.
