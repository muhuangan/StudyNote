# 队列的链式结构

**初始化**  
典型实现

```C
Queue* initQueue(){
    Queue *q = (Queue*)malloc(sizeof(Queue));
    QueueNode *node = (QueueNode*)malloc(sizeof(QueueNode));
    node -> data = 0;
    node -> next = NULL;
    q -> front = node;
    q -> rear = node;
    return q;
}

typedef struct QueueNode{
    ElemType data;
    struct QueueNode * next;
}QueueNode;

typedef struct{
    QueueNode* front;
    QueueNode* rear;
}Queue;
```

**判断队列是否为空**  
典型实现

```C
int isEmpty(Queue *q){
    if(q -> front == q -> rear){
        return 1;
    }
    else{
        return 0;
    }
}
```

**入队(尾插法)**  
典型实现

```C
void equeue(Queue *q, ElemType e){
    QueueNode *node = (QueueNode*)malloc(sizeof(QueueNode));
    node -> data = e;
    node -> next = NULL;
    q -> rear -> next = node;
    q -> rear = node;
}
```

**出队(释放首结点)**  
典型实现

```C
int dequeue(Queue *q, ElemType *e){
    QueueNode *node = q -> front -> next;
    *e = node -> data;
    q -> front -> next = node -> next;
    if(q -> rear == node){
        q -> rear = q -> front;
    }
    free(node);
    return 1;
}
```
