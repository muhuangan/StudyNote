# 切比雪夫不等式

切比雪夫不等式用**只知道期望和方差**这一有限信息, 对"偏离中心"的概率给出上界. 它本身很粗糙, 却是大数定律的核心工具.

## 一、定理

设随机变量 $X$ 的期望 $E(X)=\mu$, 方差 $D(X)=\sigma^2$ 均存在, 则对任意常数 $\varepsilon>0$ 有

$$P\bigl(|X-\mu|\ge\varepsilon\bigr)\le\frac{\sigma^2}{\varepsilon^2}$$

等价形式(更常用于"保证落在中心附近"的估计):

$$P\bigl(|X-\mu|<\varepsilon\bigr)\ge1-\frac{\sigma^2}{\varepsilon^2}$$

**要点**: 这两个不等式**对任意分布**都成立, 不需要知道 $X$ 服从什么分布, 只需要 $\mu$ 与 $\sigma^2$.

## 二、证明(连续情形)

设 $X$ 的密度为 $f(x)$, 则

$$\sigma^2=\int_{-\infty}^{+\infty}(x-\mu)^2f(x)dx\ge\int_{|x-\mu|\ge\varepsilon}(x-\mu)^2f(x)dx$$

在积分区域 $|x-\mu|\ge\varepsilon$ 上有 $(x-\mu)^2\ge\varepsilon^2$, 故

$$\sigma^2\ge\varepsilon^2\int_{|x-\mu|\ge\varepsilon}f(x)dx=\varepsilon^2P\bigl(|X-\mu|\ge\varepsilon\bigr)$$

两边同除 $\varepsilon^2$ 即得结论. 离散情形把积分换成求和即可.

## 三、例题

**例 1**: 设 $X$ 的期望为 $\mu$, 方差为 $\sigma^2$. 分别取 $\varepsilon = 2\sigma$ 与 $\varepsilon = 3\sigma$, 估计 $X$ 落在中心附近的概率下界.

解: 由切比雪夫不等式:

$$P(|X-\mu|<2\sigma)\ge1-\frac{\sigma^2}{4\sigma^2} = 1-\frac14 = 0.75$$
$$P(|X-\mu|<3\sigma)\ge1-\frac{\sigma^2}{9\sigma^2} = 1-\frac19\approx0.889$$

**对比**: 若已知 $X$ 服从正态分布, 相应的概率是 $0.954$ 与 $0.997$, 远高于切比雪夫给出的下界. 这说明切比雪夫不等式的估计**很保守**, 但它的优势是**无需分布信息**.

**例 2**(与二项分布结合): 设 $X\sim B(100,0.5)$, 用切比雪夫不等式估计 $P(30<X<70)$ 的下界.

解: $E(X) = 50$, $D(X) = 25$. 事件 $30<X<70$ 即 $|X - 50|<20$, 取 $\varepsilon = 20$:

$$P(30<X<70)\ge1-\frac{25}{400} = 1 - 0.0625 = 0.9375$$

真实值约为 $0.99996$, 再次说明上界的保守性.

**例 3**(大数定律的雏形): 设 $X_1,\ldots,X_n$ 相互独立同分布, $E(X_i)=\mu$, $D(X_i)=\sigma^2$, 记样本均值 $\overline X=\frac1n\sum X_i$. 用切比雪夫不等式估计 $P\bigl(|\overline X-\mu|\ge\varepsilon\bigr)$ 的上界.

解: 由[方差的性质](./方差的性质.md),

$$E(\overline X)=\mu,\qquad D(\overline X)=\frac{\sigma^2}{n}$$

代入切比雪夫不等式:

$$P\bigl(|\overline X-\mu|\ge\varepsilon\bigr)\le\frac{\sigma^2}{n\varepsilon^2}\xrightarrow{\ n\to\infty\ }0$$

**这正是大数定律的证明主线**: 样本量越大, 均值偏离真值的概率越趋于 0.

## 四、适用场景与局限

| 情形                | 说明                                       |
| ------------------- | ------------------------------------------ |
| 已知分布            | 直接用分布函数算, 结果精确, 不要用切比雪夫 |
| 只知 $\mu,\sigma^2$ | 用切比雪夫给出保守界                       |
| 理论证明            | 证明大数定律等极限定理                     |
| 数值                | 一般**偏松**, 仅作粗估                     |

## 五、易错点

- 把不等式方向写反: 是 $P(|X-\mu|\ge\varepsilon)\le\frac{\sigma^2}{\varepsilon^2}$, 注意**分母是 $\varepsilon^2$**.
- 忘记 $\varepsilon>0$ 的要求.
- 用切比雪夫去求精确概率: 它只给界.
- 忘记 $\mu$ 与 $\sigma^2$ 必须存在(柯西分布就无法使用).
