# 二维随机变量与联合分布函数

从本章起同时考察两个(或多个)随机变量. 描述它们**联合行为**的工具是联合分布函数, 它比两个一维分布合起来包含更多信息.

## 一、二维随机变量

设 $E$ 的样本空间为 $\Omega=\{\omega\}$, $X = X(\omega)$, $Y = Y(\omega)$ 是定义在 $\Omega$ 上的两个随机变量, 则称有序对

$$(X,Y)$$

为**二维随机变量**(二维随机向量).

**关键理解**: $(X,Y)$ 不是两个独立的问题, 而是一个整体的随机对象. 它同时包含"各自的取值规律"与"彼此的联系"两方面的信息.

## 二、联合分布函数

对任意实数 $x,y$, 称二元函数

$$F(x,y) = P\bigl(\{X\le x\}\cap\{Y\le y\}\bigr) = P(X\le x,\ Y\le y)$$

为二维随机变量 $(X,Y)$ 的**联合分布函数**(简称分布函数).

**几何意义**: $F(x,y)$ 是随机点 $(X,Y)$ 落在以 $(x,y)$ 为右上角顶点的**无限矩形** $(-\infty,x]\times(-\infty,y]$ 内的概率.

## 三、联合分布函数的性质

**(1) 对每个变量单调不减**

$$x_1<x_2\Rightarrow F(x_1,y)\le F(x_2,y);\qquad y_1<y_2\Rightarrow F(x,y_1)\le F(x,y_2)$$

**(2) 有界性与极限**

$$0\le F(x,y)\le1$$
$$F(-\infty,y) = F(x,-\infty) = F(-\infty,-\infty) = 0,\qquad F(+\infty,+\infty) = 1$$

**(3) 右连续**: 对每个变量都是右连续的.

**(4) 矩形公式**(二维最重要的性质): 对任意 $x_1<x_2$, $y_1<y_2$, 有

$$P(x_1<X\le x_2,\ y_1<Y\le y_2) = F(x_2,y_2) - F(x_1,y_2) - F(x_2,y_1) + F(x_1,y_1)\ge0$$

这个"两加两减"的形式是求矩形区域概率的标准算式, 值得单独记忆.

## 四、边缘分布函数

由联合分布函数可以"取极限"得到各自的分布函数:

$$F_X(x) = P(X\le x) = F(x,+\infty)$$
$$F_Y(y) = P(Y\le y) = F(+\infty,y)$$

分别称为 $(X,Y)$ 关于 $X$ 与关于 $Y$ 的**边缘分布函数**.

**注意**: 由联合分布可以推出边缘分布, 但**由两个边缘分布不能还原联合分布**——后者还包含"$X$ 与 $Y$ 如何关联"的信息.

## 五、例题

**例 1**: 设 $(X,Y)$ 的联合分布函数为

$$
F(x,y)=\begin{cases}
(1 - e^{-x})(1 - e^{-y}), & x>0,\ y>0\\
0, & \text{其他}
\end{cases}
$$

求 $F_X(x)$ 与 $F_Y(y)$, 并求 $P(1<X\le2,\ 1<Y\le2)$.

解: 取 $y\to+\infty$:

$$F_X(x) = F(x,+\infty)=\begin{cases}1 - e^{-x}, & x>0\\ 0, & x\le0\end{cases}$$

同理 $F_Y(y) = 1 - e^{-y}\ (y>0)$. 可见 $X,Y$ 都服从参数为 1 的指数分布.

由矩形公式:

$$P(1<X\le2,\ 1<Y\le2) = F(2,2) - F(1,2) - F(2,1) + F(1,1)$$
$$=(1 - e^{-2})^2 - 2(1 - e^{-1})(1 - e^{-2}) + (1 - e^{-1})^2$$
$$=\bigl[(1 - e^{-2}) - (1 - e^{-1})\bigr]^2 = (e^{-1} - e^{-2})^2\approx0.1002$$

**例 2**(不独立的情形): 设 $(X,Y)$ 只在单位正方形中取值, 且

$$F(x,y) = xy+\frac{x(1 - x)y(1 - y)}{4},\qquad 0\le x,y\le1$$

(其余位置按 0 或 1 补齐). 求边缘分布 $F_X(x)$.

解:

$$F_X(x) = F(x,1) = x+\frac{x(1 - x)\cdot1\cdot0}{4} = x,\qquad 0\le x\le1$$

即 $X\sim U(0,1)$. 同理 $Y\sim U(0,1)$. 两个边缘都是均匀分布, 但联合分布并不是"$xy$"(那才是独立的情形), 说明**边缘相同不代表联合相同**.

## 六、易错点

- 混淆 $P(X\le x, Y\le y)$ 与 $P(X\le x)P(Y\le y)$: 后者只在独立时成立.
- 求矩形概率时漏掉第四项 $+F(x_1,y_1)$.
- 认为两个边缘分布能唯一确定联合分布: 不能.
- 把 $F(x,y)$ 的定义区间端点忽略: 分段函数的定义域外必须显式给出 0.
