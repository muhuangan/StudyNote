# 麦克斯韦方程组

麦克斯韦方程组是电磁场理论的最高成就: 四个方程统一了电与磁, 并预言了电磁波的存在.

## 一、法拉第电磁感应定律

**积分形式**:

$$\oint_C\vec E\cdot d\vec l=-\frac{d\Phi}{dt}=-\frac{d}{dt}\int_S\vec B\cdot d\vec S$$

**微分形式**:

$$\nabla\times\vec E=-\frac{\partial\vec B}{\partial t}$$

**物理意义**: 变化的磁场产生电场(感生电场). 注意感生电场是**有旋场**($\nabla\times\vec E\ne\vec 0$), 因此此时不能引入电位.

## 二、位移电流

对恒定情形有 $\nabla\times\vec H=\vec J$. 但对时变场, 两边取散度会导致矛盾:

$$\nabla\cdot(\nabla\times\vec H) = 0\quad\text{但}\quad\nabla\cdot\vec J=-\frac{\partial\rho}{\partial t}\ne0$$

麦克斯韦引入**位移电流密度**修补:

$$\vec J_d=\frac{\partial\vec D}{\partial t}$$

于是

$$\nabla\times\vec H=\vec J+\frac{\partial\vec D}{\partial t}$$

**意义**: 位移电流**不是电荷的运动**, 而是变化电场的等效电流. 它保证了电流连续性, 并使"电场变化产生磁场"成为可能, 从而预言了电磁波.

## 三、麦克斯韦方程组

| 名称         | 微分形式                                                       | 积分形式                                                                                               |
| ------------ | -------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| 高斯定律(电) | $\nabla\cdot\vec D=\rho$                                       | $\oint_S\vec D\cdot d\vec S=\int_V\rho\,dV$                                                            |
| 磁通连续性   | $\nabla\cdot\vec B = 0$                                        | $\oint_S\vec B\cdot d\vec S = 0$                                                                       |
| 法拉第定律   | $\nabla\times\vec E=-\dfrac{\partial\vec B}{\partial t}$       | $\oint_C\vec E\cdot d\vec l=-\dfrac{d}{dt}\int_S\vec B\cdot d\vec S$                                   |
| 全电流定律   | $\nabla\times\vec H=\vec J+\dfrac{\partial\vec D}{\partial t}$ | $\oint_C\vec H\cdot d\vec l=\int_S\left(\vec J+\dfrac{\partial\vec D}{\partial t}\right)\cdot d\vec S$ |

**辅助关系**(媒质本构方程):

$$\vec D=\varepsilon\vec E,\qquad \vec B=\mu\vec H,\qquad \vec J=\sigma\vec E$$

## 四、时变电磁场的边界条件

| 分量 | 条件                                        |
| ---- | ------------------------------------------- |
| 法向 | $D_{1n} - D_{2n}=\rho_S$; $B_{1n} = B_{2n}$ |
| 切向 | $E_{1t} = E_{2t}$; $H_{1t} - H_{2t} = J_S$  |

**理想导体表面**($\sigma\to\infty$)的特殊结论:

$$E_t = 0,\qquad B_n = 0,\qquad \vec H_t=\vec J_S\times\vec e_n,\qquad D_n=\rho_S$$

即理想导体表面**电场切向为零、磁场法向为零**, 电磁波无法进入导体内部.

## 五、坡印廷定理与坡印廷矢量

由麦克斯韦方程组可推出**能流密度矢量**:

$$\vec S=\vec E\times\vec H$$

方向为电磁能量流动方向, 大小为**单位时间穿过单位垂直面积的能量**(单位 $\text{W/m}^2$).

**坡印廷定理**(能量守恒的数学表述):

$$-\frac{\partial}{\partial t}\int_V\left(\frac12\vec D\cdot\vec E+\frac12\vec B\cdot\vec H\right)dV=\oint_S\vec S\cdot d\vec S+\int_V\vec J\cdot\vec E\,dV$$

**各项含义**: 体积内电磁能量的减少 = 向外辐射的功率 + 媒质中的焦耳损耗.

## 六、波动方程

在无源($\rho = 0,\vec J=\vec 0$)的理想介质中, 方程组化为

$$\nabla^2\vec E-\mu\varepsilon\frac{\partial^2\vec E}{\partial t^2}=\vec 0,\qquad \nabla^2\vec H-\mu\varepsilon\frac{\partial^2\vec H}{\partial t^2}=\vec 0$$

即标准的**齐次波动方程**, 波速为

$$v=\frac{1}{\sqrt{\mu\varepsilon}}$$

**真空中** $v=\dfrac{1}{\sqrt{\mu_0\varepsilon_0}} = c\approx3\times10^8\ \text{m/s}$——这正是光速, 由此**预言光是电磁波**.

## 七、例题

**例 1**(位移电流计算): 平行板电容器极板面积 $S$, 极板间电压 $u = U_m\sin\omega t$. 求极板间的位移电流.

解: 忽略边缘效应, 极板间电场 $E=\dfrac u d$, 故

$$J_d=\frac{\partial D}{\partial t}=\varepsilon_0\frac{\partial E}{\partial t}=\frac{\varepsilon_0}{d}\omega U_m\cos\omega t$$

$$i_d = J_dS=\frac{\varepsilon_0S}{d}\omega U_m\cos\omega t = C\frac{du}{dt}$$

**结论**: 位移电流恰好等于导线中的**传导电流** $C\dfrac{du}{dt}$, 说明电容器电路中电流得以"连续". 这就是引入位移电流的直接理由.

**例 2**(坡印廷矢量方向): 同轴电缆中电场沿径向、磁场沿角向, 求能流方向.

解: 在内外导体之间 $\vec E\parallel\vec e_\rho$, $\vec H\parallel\vec e_\phi$, 故

$$\vec S=\vec E\times\vec H\parallel\vec e_\rho\times\vec e_\phi=\vec e_z$$

即能量沿**电缆轴向**在介质中传输, 而不是在导体内部——这是一个常被忽视但重要的结论.

## 八、易错点

- 把位移电流理解为"电荷的移动": 它是变化电场的等效量.
- 忘记法拉第定律中的**负号**(楞次定律的体现).
- 在时变情形仍使用静电场结论(如 $\vec E=-\nabla\varphi$): 感生电场是有旋场, **不能**引入标量电位.
- 混淆坡印廷矢量的方向与电场、磁场方向: 遵循右手法则 $\vec E\times\vec H$.
