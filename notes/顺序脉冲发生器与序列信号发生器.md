# 顺序脉冲发生器与序列信号发生器

## 核心结论

**顺序脉冲发生器**输出一组**依次出现, 互不重叠**的节拍脉冲, 典型结构是"计数器 + 译码器".**序列信号发生器**输出一个**按指定周期重复的串行码流**, 典型结构是"移位寄存器 + 反馈组合逻辑"或"计数器 + ROM/数据选择器".

## 一、顺序脉冲发生器

### 基本结构

$$计数器 \to 译码器 \to 节拍输出$$

计数器产生 $0$ 至 $M-1$ 的循环状态, 译码器把每个状态译成一个输出端的有效电平, 于是 $Y_0$ 至 $Y_{M-1}$ 依次输出宽度为 1 个时钟周期的脉冲.

**典型应用**: 为多步操作提供节拍(如 CPU 的指令周期节拍, AD 转换的分时控制, 动态显示的位选信号).

### 关键问题: 译码毛刺

**问题根源**: 若计数器是异步的, 各位翻转有先后, 状态转换过程中会出现短暂的中间状态, 被译码器译出后在非预期的输出端产生**窄毛刺**.

**三种解决方案**:

| 方案           | 做法                         | 效果                                   |
| -------------- | ---------------------------- | -------------------------------------- |
| 用同步计数器   | 所有位同时翻转               | 消除过渡状态, 最常用                   |
| 用扭环形计数器 | 相邻状态只有一位不同         | 天然无译码竞争, 不需译码器即可得到节拍 |
| 加选通脉冲     | 只在状态稳定后才允许译码输出 | 通用, 但需额外时序控制                 |

### 用扭环形计数器(Johnson 计数器) 产生节拍

$n$ 位移位寄存器把末级的反相输出反馈到首级, 状态数为 $2n$, 且相邻状态只有一位不同. 因为每次只有一位变化,**不存在译码竞争**, 可以直接用"相邻两位译码"得到 $2n$ 个节拍脉冲, 无需额外措施.

## 二、序列信号发生器

### 方法一: 计数器 + 组合逻辑(或 ROM / 数据选择器)

**结构**:

- 计数器产生地址(周期 = 序列长度 $L$).
- ROM(或数据选择器) 中存放序列的每一位.

**优点**: 可以产生**任意**序列, 周期和内容的自由度最高; 改变序列只需改写 ROM 内容或数据选择器输入端电平.

**示例**: 产生序列 101100(周期 6). 用一个模 6 计数器, 把 6 个状态(000 至 101) 作为地址, ROM 中依次存放 1,0,1,1,0,0.

**用数据选择器实现**: 把计数器的输出接到 MUX 的地址端, 序列各位依次接到 $D_0$ 至 $D_{L-1}$.

### 方法二: 移位寄存器 + 反馈逻辑

**结构**:$n$ 级移位寄存器, 把各级输出经组合逻辑反馈到第一级的串行输入端 $D_{in}$.

$$D_{in} = f(Q_0, Q_1, \cdots, Q_{n-1})$$

**设计步骤**:

1. 根据要求的序列, 确定移位寄存器的级数 $n$($n$ 级最多产生周期 $2^n - 1$ 的序列, 全 0 状态要排除).
2. 列出状态转换表: 把序列按 $n$ 位一组滑动截取, 得到每一拍的状态与下一拍应移入的位.
3. 由状态表求出 $D_{in}$ 的逻辑表达式(用卡诺图化简).
4. 检查自启动(全 0 状态必须能跳出).

**示例**: 用 3 级移位寄存器产生序列 101(周期 3).

取 $n = 3$, 输出从 $Q_0$ 取出. 列出状态($Q_2 Q_1 Q_0$ 为移位寄存器内容,$Q_0$ 为输出):

| 现态 $Q_2 Q_1 Q_0$ | 输出($Q_0$) | 序列的下一拍应移入 | 次态 |
| ------------------ | ----------- | ------------------ | ---- |
| 101                | 1           | 0                  | 010  |
| 010                | 0           | 1                  | 101  |

(序列 101 循环, 只需两个状态)

由表得 $D_{in}$: 现态 101 时 $D_{in} = 0$, 现态 010 时 $D_{in} = 1$, 其余状态为无关项. 经卡诺图化简可得 $D_{in}$ 的表达式, 并把无关项用于保证自启动(例如让全 000 状态转移到 101).

### 方法三: 最长线性反馈移位寄存器(m 序列发生器)

**性质**:$n$ 级线性反馈移位寄存器(LFSR) 若反馈多项式为本原多项式, 则可产生周期为

$$L = 2^n - 1$$

的最长序列(m 序列).

**典型反馈连接**:

| 级数 $n$ | 反馈抽头(异或)                         |
| -------- | -------------------------------------- |
| 3        | $Q_2 \oplus Q_1$(或 $Q_2 \oplus Q_0$)  |
| 4        | $Q_3 \oplus Q_2$                       |
| 5        | $Q_4 \oplus Q_2$                       |
| 6        | $Q_5 \oplus Q_4$                       |
| 7        | $Q_6 \oplus Q_5$                       |
| 8        | $Q_7 \oplus Q_5 \oplus Q_4 \oplus Q_3$ |

**特点**:

1. 序列周期最长, 状态利用率最高($2^n - 1$ 个非零状态全用).
2. 序列具有**伪随机性**: 0 与 1 的个数接近相等, 游程分布符合随机序列的统计特性.
3. **全 0 状态是死循环**(线性反馈下 0 异或 0 仍为 0), 必须加自启动电路或用异步置位端装入非零初值.

**应用**: 伪随机数产生, 扩频通信, CRC 校验, 内置自测试(BIST) 激励.

## 三、两种发生器的对比

| 对比项   | 顺序脉冲发生器     | 序列信号发生器                   |
| -------- | ------------------ | -------------------------------- |
| 输出形式 | 多路, 依次有效     | 单路, 串行码流                   |
| 典型结构 | 计数器 + 译码器    | 移位寄存器 + 反馈 / 计数器 + ROM |
| 关键问题 | 译码毛刺           | 自启动(避开死循环)               |
| 应用     | 节拍控制, 分时复用 | 通信码型, 测试激励               |

## 四、设计要点

1. **自启动必须检查**: 序列信号发生器(尤其是 LFSR) 的无效状态(如全 0) 必须能进入有效循环, 否则上电后输出恒为 0.
2. **输出取自哪一级要明确**: 移位寄存器各级都是有效输出, 只是相位不同.
3. **周期与级数的匹配**:$n$ 级移位寄存器最多产生 $2^n - 1$ 周期; 若要求的周期更长, 应改用计数器 + ROM 方案.

## 易错点

- 顺序脉冲发生器直接用异步计数器加译码器, 输出必然有毛刺; 考试中若要求"无毛刺", 必须答"改用同步计数器"或"用扭环形计数器"或"加选通脉冲".
- LFSR 的全 0 状态无法自行跳出, 这是它唯一的死循环状态, 必须专门处理.
