# 逻辑代数常用公式

## 核心结论

常用公式是基本公式的推论, 直接服务于化简: **并项, 吸收, 消去, 配项**四类操作, 分别对应"消变量, 消乘积项, 消因子, 造项再消". 熟练后化简速度远超卡诺图, 且不依赖图形.

## 一、并项公式(消变量)

$$AB + A\overline{B} = A$$

$$(A + B)(A + \overline{B}) = A$$

**适用场景**: 两个乘积项只有一个变量相反, 其余完全相同, 可以合并, 消去这个相反的变量.

例:$AB\overline{C} + AB C = AB(\overline{C} + C) = AB$.

## 二、吸收公式(消乘积项)

$$A + AB = A$$

$$A(A + B) = A$$

**适用场景**: 一个乘积项是另一个乘积项的"子集"(因子), 则被包含的那一项可以整体删去.

例:$\overline{A}B + \overline{A}BCD(E + F) = \overline{A}B$, 因为 $\overline{A}B$ 是 $\overline{A}BCD(E + F)$ 的因子.

## 三、消去公式(消因子)

$$A + \overline{A}B = A + B$$

$$A(\overline{A} + B) = AB$$

**适用场景**: 一个项含有某变量的原变量 $A$, 另一个项含有其反变量 $\overline{A}$ 与其他因子的乘积, 则可以消去 $\overline{A}$ 这个因子.

例:$A + \overline{A}BC = A + BC$; 再进一步若还有 $A$ 与 $BC$ 的关系, 可继续用其他公式简化.

## 四、配项公式(造项再消)

$$AB + \overline{A}C + BC = AB + \overline{A}C$$

$$AB + \overline{A}C + BCD = AB + \overline{A}C$$

**适用场景**: 两个主要项分别含 $A$ 与 $\overline{A}$, 此时任何由它们剩余因子组成的第三项都是冗余项, 可以直接删除; 反过来, 为了凑出可合并的形式, 也可以**主动添加**冗余项再消去.

例:$AB + \overline{A}C + BCD = AB + \overline{A}C$, 因为 $BC$ 的冗余性可推广到 $BCD$.

## 五、交叉互换公式

$$AB + \overline{A}C = (A + C)(\overline{A} + B)$$

这是与或式和或与式互转的一条捷径, 由分配律第二式结合互补律推出.

## 六、常用公式速查表

| 编号 | 公式                                            | 名称         | 化简效果      |
| ---- | ----------------------------------------------- | ------------ | ------------- |
| 1    | $AB + A\overline{B} = A$                        | 并项         | 消 1 个变量   |
| 2    | $A + AB = A$                                    | 吸收         | 消 1 个乘积项 |
| 3    | $A + \overline{A}B = A + B$                     | 消去         | 消 1 个因子   |
| 4    | $AB + \overline{A}C + BC = AB + \overline{A}C$  | 冗余/配项    | 消 1 个冗余项 |
| 5    | $A(A + B) = A$                                  | 吸收(或对偶) | 消 1 个或项   |
| 6    | $A(\overline{A} + B) = AB$                      | 消去(或对偶) | 消 1 个因子   |
| 7    | $\overline{A + B} = \overline{A}\,\overline{B}$ | 德摩根       | 形式变换      |

## 七、化简示例

化简 $F = A\overline{B} + \overline{A}B + AB$.

**第一步(配项)**: 把 $AB$ 复制一份(因为 $A + A = A$, 添加重复项不改变函数值).

$$F = A\overline{B} + \overline{A}B + AB + AB$$

**第二步(分组并项)**:

$$F = (\overline{A}B + AB) + (A\overline{B} + AB) = B(\overline{A} + A) + A(\overline{B} + B) = B + A$$

结果为 $F = A + B$.

## 八、与卡诺图化简的关系

| 对比项       | 公式法                     | 卡诺图法               |
| ------------ | -------------------------- | ---------------------- |
| 依赖         | 对公式的熟练度             | 图形观察               |
| 变量数限制   | 无严格限制, 但变量越多越难 | 5 变量以内最实用       |
| 是否保证最简 | 不保证, 依赖经验           | 按规则圈组可保证最简   |
| 速度         | 熟练后极快                 | 稳定但不适合变量很多时 |

工程实践通常是: 先用公式法粗化, 再用卡诺图验证.

## 易错点

- 配项法中添加的冗余项必须是**逻辑上的重复或已证明冗余的项**, 不能凭空添加改变函数值的项.
- $A + \overline{A}B = A + B$ 只对"另一项恰好是 $\overline{A}$ 与某因子的乘积"成立, 若为 $A + \overline{A}\,\overline{B}$ 则结果为 $A + \overline{B}$, 注意反变量的位置.
