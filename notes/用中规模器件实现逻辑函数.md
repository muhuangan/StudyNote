# 用中规模器件实现逻辑函数

## 核心结论

用 MSI 器件实现逻辑函数有三条路线: **译码器(配与非门), 数据选择器(配数据端电平), ROM/PLD(直接存真值表)**. 选择依据是函数的变量数, 输出个数和是否要求最简.

## 一、三条路线的对比

| 路线            | 适用变量数        | 输出个数 | 所需外接器件       | 是否需要化简 |
| --------------- | ----------------- | -------- | ------------------ | ------------ |
| 译码器 + 与非门 | $n$(等于地址位数) | 可多路   | 每组输出一个与非门 | 不需要       |
| 数据选择器      | $n$ 至 $n + 1$    | 一路     | 通常不需要         | 需要(降维法) |
| ROM / PLD       | 任意              | 多路     | 无                 | 完全不需要   |

## 二、路线一: 译码器

**原理**:$n$ 位地址译码器的 $2^n$ 个输出恰好就是全部 $n$ 变量最小项(输出低有效时为最小项之非).

**步骤**:

1. 把函数写成 $F = \sum m(\cdots)$.
2. 函数变量按约定顺序接译码器地址端(**最高位对应 $A_{n - 1}$**).
3. 输出低电平有效时, 把函数包含的最小项对应的输出端接**与非门**; 输出高电平有效时用**或门**.
4. 接好使能端.

**示例**: 用 74LS138 实现 $F_1(A,B,C) = \sum m(1, 3, 5)$ 与 $F_2 = \sum m(2, 4, 6)$.

- $A$,$B$,$C$ 分别接 $A_2$,$A_1$,$A_0$; 使能端接有效电平.
- $\overline{Y_1}$,$\overline{Y_3}$,$\overline{Y_5}$ 接一个 3 输入与非门, 输出 $F_1$.
- $\overline{Y_2}$,$\overline{Y_4}$,$\overline{Y_6}$ 接另一个 3 输入与非门, 输出 $F_2$.

**优势**: 一片译码器可以同时产生多个函数, 只要多接几组门.

**局限**: 变量数严格等于地址位数; 变量更多时需要先用门做预处理或扩展译码器.

## 三、路线二: 数据选择器

**原理**: MUX 的输出为 $Y = \sum m_i D_i$, 把函数值"配置"到数据端即可.

### 变量数等于地址位数

直接把真值表的输出列依次接到 $D_0$ 至 $D_{2^n - 1}$.

### 变量数比地址位数多 1(降维法)

**步骤**:

1. 选定一个变量作为"数据端变量"(一般选最高位或最低位, 选使结果最简的那个).
2. 其余变量作地址, 画卡诺图并按地址分组.
3. 对每组观察两个方格的函数值, 按下表确定数据端:

| 组内两格的取值        | 数据端接法        |
| --------------------- | ----------------- |
| 0 与 0                | 接 0              |
| 1 与 1                | 接 1              |
| $\overline{X}$ 与 $X$ | 接 $X$            |
| $X$ 与 $\overline{X}$ | 接 $\overline{X}$ |

**示例**: 用 8 选 1 MUX(地址 $A_2 A_1 A_0$) 实现 4 变量函数 $F(A,B,C,D) = \sum m(0, 1, 3, 5, 6, 8, 9, 12, 13)$.

令 $A_2 A_1 A_0 = A B C$,$D$ 作数据端变量, 按 $ABC$ 分组:

| $ABC$ | $D = 0$ 对应最小项 | $F$ 值 | $D = 1$ 对应最小项 | $F$ 值 | $D_i$ 接法     |
| ----- | ------------------ | ------ | ------------------ | ------ | -------------- |
| 000   | $m_0$              | 1      | $m_1$              | 1      | 1              |
| 001   | $m_2$              | 0      | $m_3$              | 1      | $D$            |
| 010   | $m_4$              | 0      | $m_5$              | 1      | $D$            |
| 011   | $m_6$              | 1      | $m_7$              | 0      | $\overline{D}$ |
| 100   | $m_8$              | 1      | $m_9$              | 1      | 1              |
| 101   | $m_{10}$           | 0      | $m_{11}$           | 0      | 0              |
| 110   | $m_{12}$           | 1      | $m_{13}$           | 1      | 1              |
| 111   | $m_{14}$           | 0      | $m_{15}$           | 0      | 0              |

即 $D_0 = 1$,$D_1 = D$,$D_2 = D$,$D_3 = \overline{D}$,$D_4 = 1$,$D_5 = 0$,$D_6 = 1$,$D_7 = 0$.

### 变量数比地址位数多 2 及以上

需先扩展 MUX(级联), 或先用少量门处理掉多余变量.

## 四、路线三: ROM 与 PLD

**原理**: 把真值表直接"烧"进存储器.

- 用 $n$ 位地址线接 $n$ 个输入变量.
- 存储器的每个存储单元存放该输入组合下的输出值.
- 输出端即为函数值.

**优点**: 完全不需要化简, 任意复杂函数都一样处理, 修改只需重新烧录.

**缺点**: 对于简单函数, 存储器的资源利用率极低($2^n$ 个单元往往只用到很少一部分).

详见"用存储器实现组合逻辑函数".

## 五、选择决策树

1. 输出只有一路, 变量数不超过"地址位数 + 1"→ **数据选择器**(器件最省).
2. 需要多路输出, 变量数等于地址位数 → **译码器 + 与非门**.
3. 函数极其复杂, 变量很多, 或需要经常修改 → **ROM / PLD / FPGA**.
4. 函数本质是算术运算 → **加法器**.
5. 函数本质是大小判断 → **数值比较器**.

## 六、实现后的检查

1. 变量与地址位的对应关系是否正确(最高位对最高位).
2. 使能端是否全部接好.
3. 未使用的数据输入端是否接了确定电平(0 或 1),**不能悬空**.
4. 是否检查了竞争-冒险(MSI 器件内部同样存在).

## 易错点

- 变量与地址端的对应关系写反($A_2$ 接了最低位变量), 这是最常见的错误.
- 数据选择器的未用数据端悬空, 导致输出不确定.
- 用译码器实现函数时把与非门误接成或门(输出低有效器件必须用与非门).
