# 译码器

## 核心结论

译码器把 $n$ 位二进制码变换成 $2^n$ 个输出状态,**任意时刻只有一个输出有效**. 因为它的每个输出恰好对应一个最小项, 所以译码器本质上是"最小项发生器", 这是它能实现任意逻辑函数的根本原因.

## 一、二进制译码器

**3 线 - 8 线译码器**(高电平输出有效):

| $A_2$ | $A_1$ | $A_0$ | 有效输出            |
| ----- | ----- | ----- | ------------------- |
| 0     | 0     | 0     | $Y_0 = 1$, 其余为 0 |
| 0     | 0     | 1     | $Y_1 = 1$           |
| 0     | 1     | 0     | $Y_2 = 1$           |
| 0     | 1     | 1     | $Y_3 = 1$           |
| 1     | 0     | 0     | $Y_4 = 1$           |
| 1     | 0     | 1     | $Y_5 = 1$           |
| 1     | 1     | 0     | $Y_6 = 1$           |
| 1     | 1     | 1     | $Y_7 = 1$           |

**核心关系**:

$$Y_i = m_i$$

即第 $i$ 个输出正好就是第 $i$ 个最小项. 若输出为低电平有效(记作 $\overline{Y_i}$), 则

$$\overline{Y_i} = \overline{m_i}$$

## 二、74LS138: 3 线 - 8 线译码器

**引脚**:

| 信号                                          | 说明                   |
| --------------------------------------------- | ---------------------- |
| $A_2$,$A_1$,$A_0$                             | 地址输入($A_2$ 为高位) |
| $\overline{Y_0}$ 至 $\overline{Y_7}$          | 输出,**低电平有效**    |
| $G_1$,$\overline{G_{2A}}$,$\overline{G_{2B}}$ | 三个使能端             |

**使能条件**: 必须同时满足

$$G_1 = 1,\quad \overline{G_{2A}} = 0,\quad \overline{G_{2B}} = 0$$

三个使能端的设计是为了方便级联扩展: 用高位地址控制使能, 即可把多片 138 拼成更大的译码器.

**工作时**: 满足使能条件时, 与输入码对应的那个输出为 0, 其余全为 1; 不满足使能条件时, 全部输出为 1(无效).

## 三、级联扩展

**用两片 74LS138 构成 4 线 - 16 线译码器**:

1. 4 位地址的低 3 位 $A_2 A_1 A_0$ 同时接到两片的地址端.
2. 最高位 $A_3$ 控制使能:$A_3$ 直接接片 1 的 $G_1$, 经反相后接片 2 的 $G_1$; 两片的 $\overline{G_{2A}}$,$\overline{G_{2B}}$ 接译码总使能.
3. 当 $A_3 = 0$ 时片 1 工作, 输出 $\overline{Y_0}$ 至 $\overline{Y_7}$; 当 $A_3 = 1$ 时片 2 工作, 输出 $\overline{Y_8}$ 至 $\overline{Y_{15}}$.

同理可用 4 片 138 加 1 片 139(2 线 - 4 线译码器) 构成 5 线 - 32 线译码器, 原理是**用高位地址译码产生片选信号**.

## 四、二-十进制译码器(BCD 译码器)

**功能**: 输入 4 位 8421 BCD 码, 输出 10 个(或 4 个十位数) 中的对应一个有效.

**关键区别**: 输入只使用 0000 至 1001 十个码, 1010 至 1111 是**伪码**. 处理方式有两种:

1. **完全译码**: 伪码输入时全部输出无效(常见的 74LS42 即如此).
2. **部分译码**: 把伪码当作无关项, 输出可能有效(芯片内部简化所致).

## 五、用译码器实现逻辑函数(重点)

**原理**: 译码器的每个输出就是一个最小项, 把函数包含的最小项对应的输出用**或门(输出高有效) 或与非门(输出低有效)**收集起来即可.

**步骤**:

1. 把函数写成最小项之和 $F = \sum m(\cdots)$.
2. 令译码器的地址输入 $A_{n - 1} \cdots A_0$ 等于函数的输入变量.
3. 若译码器输出低电平有效(如 74LS138), 把函数包含的最小项对应的输出端接到一个**与非门**:

$$F = \overline{\overline{m_i} \cdot \overline{m_j} \cdot \overline{m_k}} = m_i + m_j + m_k$$

4. 若输出高电平有效, 则用**或门**.

**示例**: 用 74LS138 实现三变量多数表决函数 $F = \sum m(3, 5, 6, 7)$.

- 把 $A$,$B$,$C$ 接到 $A_2$,$A_1$,$A_0$.
- 把 $\overline{Y_3}$,$\overline{Y_5}$,$\overline{Y_6}$,$\overline{Y_7}$ 接到一个 4 输入与非门.
- 与非门输出即为 $F$.

**优点**: 一个译码器加一个门可以实现**多个**函数(只要多用几组门), 因为所有最小项都同时可用.

## 六、译码器的其他应用

1. **地址译码**: CPU 的地址总线译码产生各外设的片选信号, 这是译码器最重要的系统级应用.
2. **片选扩展**: 与使能端配合构成更大的译码网络.
3. **数据分配器**: 把使能端当作数据输入端使用, 即可实现"把一路数据分配到 $2^n$ 路中的一路".
4. **最小项发生器**: 作为组合逻辑函数发生器使用.

## 七、译码器与数据选择器的对比

| 对比项       | 译码器               | 数据选择器                       |
| ------------ | -------------------- | -------------------------------- |
| 数据流向     | 1 路码 → 多路选择    | 多路 → 1 路                      |
| 输出/输入    | $n$ 入 $2^n$ 出      | $2^n$ 数据入 + $n$ 地址入 → 1 出 |
| 实现函数方式 | 最小项之或(配与非门) | 用地址选通(配数据端电平)         |
| 典型芯片     | 74LS138              | 74LS151                          |

## 易错点

- 74LS138 的输出是**低电平有效**, 用与非门收集; 若误用或门, 得到的是反函数.
- 使能端必须全部满足才工作, 漏接 $\overline{G_{2B}}$ 是硬件调试中最常见的故障.
