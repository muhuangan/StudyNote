# 铁磁质与磁滞回线

铁磁质是唯一能显著改变磁场的磁介质. 它的 $\mu_r$ 可达 $10^2\sim10^5$, 但代价是**不再线性**: $\mu_r$ 随磁场变化, 而且磁化过程不可逆------这就是磁滞. 磁滞回线的形状直接决定材料用途: 回线窄的做变压器铁芯, 回线宽的做永磁体.

## 一、铁磁质的四个特征

**(1) 相对磁导率极大**: $\mu_r$ 可达 $10^2\sim10^5$, 比顺磁质大 5 到 10 个数量级.

**(2) 非线性**: $\mu_r$ 不是常数, 随 $\boldsymbol H$ 变化. 因此**不能**简单套用 $\boldsymbol B=\mu_0\mu_r\boldsymbol H$ 做常系数计算.

**(3) 磁滞现象**: 磁化过程不可逆------$\boldsymbol H$ 减小到零后 $\boldsymbol B$ 不回到零. 这是"记忆"效应.

**(4) 存在居里温度**: 超过某一温度 $T_C$(铁的 $T_C\approx1043\ \text{K}$)后, 铁磁性消失, 变为顺磁质. 原因是热运动破坏了磁畴的有序排列.

## 二、磁化曲线

从完全退磁状态出发, 逐渐增大 $\boldsymbol H$, 测得 $B$ 随 $H$ 的变化曲线, 称为**起始磁化曲线**.

**曲线的三个阶段**:

| 阶段   | 特征             | 原因                                   |
| ------ | ---------------- | -------------------------------------- |
| 起始段 | $B$ 增长较慢     | 磁畴取向的"可逆"阶段                   |
| 陡增段 | $B$ 急剧增大     | 磁畴壁大量移动, 有利取向的磁畴迅速长大 |
| 饱和段 | $B$ 几乎不再增大 | 全部磁畴已转向外场方向                 |

**饱和**: 达到饱和后 $B$ 不再随 $H$ 明显增大. 此时再加磁场只是真空贡献的 $\mu_0H$.

**由曲线求 $\mu_r$**: 对每个 $H$, 取对应点的

$$\mu_r=\frac{B}{\mu_0H}$$

由于曲线非线性, 各点算出的 $\mu_r$ 不同, 通常提到"某工作点处的 $\mu_r$".

## 三、磁滞回线

**形成过程**: 磁化到饱和后, 令 $H$ 逐渐减小并反向, 再回到原方向, 得一条**闭合曲线**, 称为**磁滞回线**.

**两个关键点**:

**(1) 剩磁 $B_r$**: 当 $H$ 减到零时, 磁感应强度并不为零, 而保持数值 $B_r$, 称为**剩余磁感应强度**(剩磁).

$$H = 0\ \Longrightarrow\ B = B_r\neq0$$

**(2) 矫顽力 $H_c$**: 要使 $B$ 减到零, 必须加一个反向磁场, 其大小 $H_c$ 称为**矫顽力**.

$$B = 0\ \Longrightarrow\ H=-H_c$$

**这两个量决定材料的用途**, 是磁滞回线最重要的两个读数.

## 四、软磁材料与硬磁材料

|              | 软磁材料                       | 硬磁材料(永磁材料)           |
| ------------ | ------------------------------ | ---------------------------- |
| 磁滞回线     | **窄**(面积小)                 | **宽**(面积大)               |
| 矫顽力 $H_c$ | 小                             | 大                           |
| 剩磁 $B_r$   | 视用途, 一般较小               | 大                           |
| 磁滞损耗     | 小                             | 大                           |
| 典型材料     | 软铁、硅钢、坡莫合金、铁氧体   | 碳钢、铝镍钴、钕铁硼         |
| 用途         | 变压器铁芯、电机铁芯、电感磁芯 | 永磁体、扬声器磁铁、电机定子 |

**判据逻辑**:

- **变压器铁芯**要求反复磁化而损耗小 → 回线**窄**、$H_c$ 小;
- **永磁体**要求撤去外场后仍保留强磁性 → 回线**宽**、$H_c$ 大、$B_r$ 大.

**磁滞损耗**: 每磁化一个循环, 单位体积介质耗散的能量等于磁滞回线所围的面积

$$w=\oint H\,dB$$

这就是变压器发热的原因之一, 也是选用软磁材料的直接理由.

## 五、磁畴

**磁畴**: 铁磁质内部存在许多微小的自发磁化区域, 每个区域内的原子磁矩已经整齐排列, 称为**磁畴**. 磁畴线度为 $10^{-4}\sim10^{-2}\ \text{cm}$.

**用磁畴解释铁磁性的三个特征**:

**(1) 为什么 $\mu_r$ 极大**: 磁畴内已有大量整齐排列的磁矩, 外场只需使其转向, 就能获得远大于顺磁质的磁化.

**(2) 为什么有饱和**: 当所有磁畴都转向外场方向后, 无法再进一步磁化.

**(3) 为什么有磁滞**: 磁畴壁的移动与磁畴的转动存在**摩擦**, 撤去外场后不能完全回到原状态, 于是留下剩磁.

**为什么超过居里温度铁磁性消失**: 热运动能量超过磁畴内交换作用的束缚能, 磁畴结构被破坏, 各原子磁矩变为无规取向, 材料退化为顺磁质.

## 六、例题

**例 1**(读图求参数): 某铁磁材料的磁滞回线上读到: 饱和磁感应强度 $B_s = 1.5\ \text{T}$, 剩磁 $B_r = 1.2\ \text{T}$, 矫顽力 $H_c = 4.0\times10^4\ \text{A/m}$. 判断它适合作变压器铁芯还是永磁体.

解: **判断依据是回线的宽窄**.

**先看 $H_c$**: $4.0\times10^4\ \text{A/m}$ 是较大的矫顽力------软磁材料的 $H_c$ 通常只有几十到几百 A/m(如硅钢约 $40\ \text{A/m}$).

**再看剩磁**: $B_r = 1.2\ \text{T}$ 也很高.

**结论**: $H_c$ 大且 $B_r$ 大 → 回线**宽** → 属于**硬磁材料**, 适合作**永磁体**, **不适合作变压器铁芯**(磁滞损耗过大, 会严重发热).

**例 2**(磁滞损耗的估计): 承上题, 若回线所围面积约 $8.0\times10^3\ \text{J/m}^3$, 铁芯体积 $V = 2.0\times10^{-3}\ \text{m}^3$, 工作频率 $f = 50\ \text{Hz}$. 估算每秒的磁滞损耗功率.

解: **每循环每单位体积损耗** $w = 8.0\times10^3\ \text{J/m}^3$.

**每循环总损耗**:

$$W_1 = wV = 8.0\times10^3\times2.0\times10^{-3} = 16\ \text{J}$$

**功率**(每秒 $f$ 个循环):

$$P = fW_1 = 50\times16 = 800\ \text{W}$$

**结论**: 单是磁滞损耗就有 800 W, 一块小体积铁芯会迅速升温. 这清楚说明为什么变压器必须用**回线极窄**的硅钢片------换成软磁材料后回线面积可小两三个数量级, 损耗降到瓦级.

**例 3**(居里温度的应用): 说明为什么可以用加热的方法给铁磁体退磁.

解: 加热到**超过居里温度** $T_C$ 后, 热运动破坏了磁畴的有序排列, 铁磁性消失, 材料变为顺磁质. 此时原有的剩磁(磁畴取向)随之瓦解.

**冷却后**: 若在**无外磁场**的环境中冷却, 磁畴重新形成时取向是随机分布的, 宏观磁矩为零, 即达到**完全退磁**状态.

**要点**: 这与"用交变磁场逐渐退磁"是两种不同的退磁方法, 但原理都是打乱磁畴的定向排列.

**例 4**(为什么 $\mu_r$ 不能当常数用): 某铁磁材料在工作点 $H_1 = 100\ \text{A/m}$ 处 $B_1 = 1.0\ \text{T}$, 在 $H_2 = 1.0\times10^4\ \text{A/m}$ 处 $B_2 = 1.5\ \text{T}$. 分别求两点的 $\mu_r$, 并说明能否用 $\mu_r = 100$ 统一计算 $H = 1000\ \text{A/m}$ 时的 $B$.

解: **点 1**:

$$\mu_r=\frac{B_1}{\mu_0H_1}=\frac{1.0}{4\pi\times10^{-7}\times100}=\frac{1.0}{1.257\times10^{-4}}\approx8.0\times10^3$$

**点 2**:

$$\mu_r=\frac{1.5}{4\pi\times10^{-7}\times1.0\times10^4}=\frac{1.5}{1.257\times10^{-2}}\approx1.2\times10^2$$

**对比**: 两点 $\mu_r$ 相差近 70 倍!

**结论**: **不能**用任一点算出的 $\mu_r$ 去计算其他工作点的 $B$. 铁磁质的 $\boldsymbol B$ 与 $\boldsymbol H$ 的关系必须查**磁化曲线**或**磁滞回线**, 这正是铁磁材料手册给出曲线的而非常数的原因.

**提醒**: 只有当题目给出"工作点处的 $\mu_r$"或明确说明用某段近似线性区域时, 才能按常数处理.

## 七、易错点

- 把 $\mu_r$ 当常数用于铁磁质. 它随 $H$ 变化, 且存在磁滞.
- 混淆剩磁 $B_r$ 与矫顽力 $H_c$: 前者是 $H = 0$ 时的 $B$, 后者是使 $B = 0$ 所需的反向 $H$.
- 认为剩磁越大越好. 对永磁体是优点, 对变压器铁芯则是缺点(需要更大的反向磁场去磁).
- 认为超过居里温度后材料"没有磁性". 实际是变为**顺磁质**, 仍有极弱的磁性.
- 把磁滞回线面积与"饱和磁感应强度"混为一谈. 面积代表每循环的**能量损耗**.
- 用"磁畴"解释一切而不理解其物理本质: 磁畴是自发磁化区域, 其存在源于量子交换作用.
