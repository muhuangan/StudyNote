# 寄存器与移位寄存器

## 核心结论

**寄存器**用 $n$ 个 D 触发器并联, 在一个时钟沿同时存入 $n$ 位数据; **移位寄存器**用 D 触发器串联, 每来一个时钟沿数据整体右移(或左移) 一位. 后者是串并转换, 延时和序列产生的通用工具.

## 一、数码寄存器

**结构**:$n$ 个 D 触发器的时钟端并联, 数据端各自独立.

**工作过程**: 在时钟沿到来的瞬间, 把 $D_0$ 至 $D_{n - 1}$ 上的 $n$ 位数据同时存入, 之后一直保持到下一个时钟沿.

**关键要求**: 寄存器的触发器必须是**边沿触发**的. 若用电平触发锁存器, 则在有效电平期间输出会跟随输入变化, 起不到"寄存"的作用.

**典型芯片**:

| 型号    | 功能                            |
| ------- | ------------------------------- |
| 74LS175 | 四 D 触发器(带公共清零)         |
| 74LS273 | 八 D 触发器(带公共清零)         |
| 74LS373 | 八 D 锁存器(三态输出, 电平敏感) |
| 74LS374 | 八 D 触发器(三态输出, 边沿触发) |

**三态输出的意义**: 带三态输出的寄存器可以直接挂在数据总线上, 靠输出使能端控制是否占用总线.

## 二、移位寄存器

**结构**: 把 D 触发器串成链,$Q_i$ 接 $D_{i + 1}$, 所有触发器共用时钟.

$$Q_0^* = D_{in},\quad Q_1^* = Q_0,\quad Q_2^* = Q_1,\quad \cdots$$

**移位的本质**: 每个时钟沿把前一级的当前状态搬到后一级. 因为所有触发器**同时**动作, 所以不会出现"一级追一级"的直通现象—这正是必须用边沿触发器的原因.

**四种工作方式**:

| 类型            | 输入方式     | 输出方式     | 典型用途         |
| --------------- | ------------ | ------------ | ---------------- |
| 串入-串出(SISO) | 逐位串行     | 逐位串行     | 数据延时线       |
| 串入-并出(SIPO) | 逐位串行     | 一次并行读出 | 串口接收, 串转并 |
| 并入-串出(PISO) | 一次并行装入 | 逐位串行     | 串口发送, 并转串 |
| 并入-并出(PIPO) | 一次并行装入 | 一次并行读出 | 普通寄存器       |

## 三、74LS194: 4 位双向通用移位寄存器

**功能**: 兼具并行置数, 左移, 右移, 保持四种功能, 由两个模式控制端 $S_1$,$S_0$ 选择.

| $S_1$ | $S_0$ | 功能                                  |
| ----- | ----- | ------------------------------------- |
| 0     | 0     | 保持                                  |
| 0     | 1     | **右移**($D_{SR}$ 端的数据移入最高位) |
| 1     | 0     | **左移**($D_{SL}$ 端的数据移入最低位) |
| 1     | 1     | **并行置数**($D_0$ 至 $D_3$ 装入)     |

其他端口:

- $\overline{CR}$: 异步清零(低电平有效, 优先级最高).
- $D_{SR}$: 右移串行输入端.
- $D_{SL}$: 左移串行输入端.
- $Q_0$ 至 $Q_3$: 并行输出端.

**级联扩展**: 把低位片的右移串行输入端与高位片的 $Q_0$ 相连(或反之), 即可扩展为 8 位, 12 位移位寄存器, 两片的 $S_1 S_0$,$CLK$,$\overline{CR}$ 并联.

## 四、移位寄存器的典型应用

### 1. 串并转换与并串转换

- **接收**: 串行数据从 $D_{SR}$ 逐位移入,$n$ 个时钟后从 $Q_0$ 至 $Q_{n - 1}$ 并行读出(串转并).
- **发送**: 先并行置数, 再逐拍右移, 从 $Q_{n - 1}$ 逐位输出(并转串).

UART, SPI 等串行接口的硬件实现本质上都是移位寄存器.

### 2. 数据延时线

每经过一级移位寄存器, 数据延迟一个时钟周期.$n$ 级移位寄存器可实现 $n$ 个时钟周期的精确延时, 常用于流水线同步.

### 3. 环形计数器与扭环形计数器

- **环形计数器**: 把末级输出反馈到首级输入($D_{in} = Q_{n - 1}$),$n$ 位移位寄存器构成**模 $n$** 计数器, 状态为循环移位的一个 1. 优点是不需要译码即可直接得到节拍信号; 缺点是不能自启动, 需预置初值.
- **扭环形计数器(Johnson 计数器)**: 把末级的反相输出反馈到首级($D_{in} = \overline{Q_{n - 1}}$),$n$ 位移位寄存器构成**模 $2n$** 计数器, 状态数是环形计数器的两倍, 且相邻状态只有一位不同(无译码毛刺).

### 4. 序列信号发生器

把移位寄存器的输出经组合逻辑反馈到串行输入端, 即可产生任意周期序列(见"顺序脉冲发生器与序列信号发生器").

### 5. 乘法与除法运算

配合加法器, 用"移位-相加"实现乘法, 用"移位-相减"实现除法.

## 五、移位寄存器的时序特点

1. **同步移位**: 所有位在同一时钟沿同时移动, 因此不存在逐级传递的延迟累积.
2. **必须满足建立/保持时间**: 因为前一级的输出是后一级的输入, 级间延迟必须小于时钟周期减去建立时间.
3. **高速时需注意时钟偏移**: 时钟到达各级触发器的时间差(clock skew) 过大会导致移位错误.

## 六、与计数器的对比

| 对比项     | 移位寄存器                      | 计数器               |
| ---------- | ------------------------------- | -------------------- |
| 状态变化   | 循环移位                        | 按编码递增/递减      |
| 用途       | 串并转换, 延时, 序列产生        | 计数, 分频, 定时     |
| 状态利用率 | 低(环形计数器只用了 $n$ 个状态) | 高($2^n$ 个状态全用) |

## 易错点

- 用**电平触发**锁存器做移位寄存器会导致数据在一个时钟周期内"直通"到底, 移位功能完全失效. 这是移位寄存器必须使用边沿触发器的根本原因.
- 环形计数器**不能自启动**, 上电后必须先用并行置数端装入有效初值(如 0001), 否则会停在无效状态.
