# 磁场对载流导线和线圈的作用

把洛伦兹力 $q\boldsymbol v\times\boldsymbol B$ 用于导体中的自由电子, 宏观上就表现为**载流导线在磁场中受力**(安培力). 进一步把导线弯成线圈, 就得到**磁力矩**------这是电动机与磁电式仪表的工作原理.

## 一、安培力公式

**电流元** $I\,d\boldsymbol l$ 在磁场中受的力:

$$d\boldsymbol F = I\,d\boldsymbol l\times\boldsymbol B$$

**有限长导线**的受力为各电流元受力的矢量和:

$$\boldsymbol F=\int_L I\,d\boldsymbol l\times\boldsymbol B$$

**推导要点**: 设导线截面积 $S$、载流子浓度 $n$、电荷量 $q$、定向速度 $\boldsymbol v$, 则 $I = nqvS$. 一段长 $dl$ 内的载流子数为 $nSdl$, 每个受洛伦兹力 $q\boldsymbol v\times\boldsymbol B$, 故

$$d\boldsymbol F = nSdl\cdot q\boldsymbol v\times\boldsymbol B = (nqvS)\,dl\,\boldsymbol v\times\boldsymbol B$$

由于 $nqvS\boldsymbol v = I\boldsymbol v$, 而 $\boldsymbol v\parallel d\boldsymbol l$(定向速度方向即电流方向), 故 $\boldsymbol v\,dl = d\boldsymbol l\,v$, 整理得 $d\boldsymbol F = I\,d\boldsymbol l\times\boldsymbol B$.

**方向判定**: 与洛伦兹力一致------右手四指指向电流方向, 弯向磁场方向, 拇指指向受力方向.

## 二、均匀磁场中的几种常用结果

**(1) 直线导线**: 长为 $L$ 的直导线, 与 $\boldsymbol B$ 夹角为 $\theta$:

$$F = BIL\sin\theta$$

**方向**: 垂直于导线与磁场所决定的平面.

**(2) 当导线与磁场平行**($\theta = 0$): $F = 0$.

**(3) 任意形状的闭合载流回路**: 在**均匀**磁场中受到的总力为零.

$$\oint_L I\,d\boldsymbol l\times\boldsymbol B = I\left(\oint d\boldsymbol l\right)\times\boldsymbol B = 0$$

因为闭合回路的矢量和 $\oint d\boldsymbol l = 0$.

**重要区分**: 总力为零, 但**力矩不一定为零**. 这正是下一节的内容.

## 三、平行载流导线间的相互作用

两根平行长直导线, 相距 $a$, 电流分别为 $I_1$、$I_2$.

**导线 1 在导线 2 处产生的磁场**(见[安培环路定理](./安培环路定律.md)):

$$B_1=\frac{\mu_0I_1}{2\pi a}$$

方向垂直于两导线所在平面.

**导线 2 单位长度受力**:

$$\frac{dF}{dl} = I_2B_1=\frac{\mu_0I_1I_2}{2\pi a}$$

**电流方向与力的关系**:

| 电流方向 | 相互作用 |
| -------- | -------- |
| 同向     | **相吸** |
| 反向     | **相斥** |

**记忆法**: 同向电流"像绑在一起"一样相互吸引.

**安培的定义**: 这一结果是国际单位制中安培定义的原始依据------两根相距 $1\ \text{m}$ 的无限长平行细导线, 通以等量恒定电流, 若每米长度受力为 $2\times10^{-7}\ \text{N}$, 则导线中的电流为 $1\ \text{A}$. 由此 $\mu_0 = 4\pi\times10^{-7}\ \text{N/A}^2$.

## 四、磁矩与磁力矩

**磁矩(磁偶极矩)**: 对面积 $S$、匝数 $N$、电流 $I$ 的平面载流线圈,

$$m = NIS$$

**方向**: 由右手螺旋定则确定------四指沿电流方向环绕, 拇指指向 $m$ 的方向, 即线圈平面的**法线**方向.

**磁力矩**: 在均匀磁场中, 线圈受到的力矩为

$$\boldsymbol M=\boldsymbol m\times\boldsymbol B$$

**大小**:

$$M = mB\sin\theta = NISB\sin\theta$$

其中 $\theta$ 是 $\boldsymbol m$ 与 $\boldsymbol B$ 的夹角(即线圈法线与磁场的夹角).

**方向**: 使线圈的磁矩转向与 $\boldsymbol B$ 同向------**磁场总是"把线圈扳正"**.

**四个特殊位置**:

| $\theta$                                         | 力矩             | 说明       |
| ------------------------------------------------ | ---------------- | ---------- |
| $0^\circ$($\boldsymbol m\parallel\boldsymbol B$) | $0$              | 稳定平衡   |
| $90^\circ$                                       | 最大($M = NISB$) | 力矩最大   |
| $180^\circ$                                      | $0$              | 不稳定平衡 |
| 一般 $\theta$                                    | $NISB\sin\theta$ | 中间值     |

**注意区分**: 均匀磁场中线圈受力**为零**、力矩**不为零**. 这一组合正是电动机能持续转动的关键------不需净力, 只需力矩.

## 五、磁电式仪表原理

磁电式电流计(电流表、电压表的核心)利用的就是磁力矩:

- 线圈(磁矩 $\boldsymbol m$)放在永磁铁产生的径向磁场中;
- 通电后受磁力矩 $\boldsymbol M=\boldsymbol m\times\boldsymbol B$, 使指针转动;
- 由**游丝提供反力矩**, 反力矩与转角成正比;
- 平衡时 $\boldsymbol M$ 与游丝反力矩相等, 故**转角与电流成正比**------这就是刻度均匀的原因.

$$\theta\propto NISB\ \Longrightarrow\ \theta\propto I$$

**读数要点**: 由于转角正比于电流, 表盘刻度可以做成线性的.

## 六、例题

**例 1**: 一根长 $L = 0.20\ \text{m}$ 的直导线通有 $I = 5.0\ \text{A}$ 电流, 放在 $B = 0.40\ \text{T}$ 的均匀磁场中, 两者夹角 $30^\circ$. 求安培力大小.

解:

$$F = BIL\sin\theta = 0.40\times5.0\times0.20\times\sin30^\circ = 0.40\times5.0\times0.20\times0.5 = 0.20\ \text{N}$$

**方向**: 垂直于导线与磁场所决定的平面, 由右手法则判定.

**例 2**(闭合回路的受力): 说明为什么在均匀磁场中任意形状的闭合载流回路受的总力为零, 并指出在什么情形下总力不为零.

解: **总力公式**:

$$\boldsymbol F=\oint_L I\,d\boldsymbol l\times\boldsymbol B = I\left(\oint_Ld\boldsymbol l\right)\times\boldsymbol B$$

闭合回路上 $\oint_Ld\boldsymbol l = 0$(从起点回到起点的位移为零), 故 $\boldsymbol F = 0$.

**总力不为零的情形**:

- 磁场**不均匀**时, 各电流元处的 $\boldsymbol B$ 不同, 不能提到积分号外, 总力一般不为零.
- 例如磁铁靠近线圈时吸力、磁场梯度对线圈的推动, 都属于这种情形.

**要点**:"闭合回路在均匀磁场中受力为零"的关键是**均匀**二字.

**例 3**(平行导线): 两根相距 $a = 2.0\ \text{cm}$ 的平行长直导线, 各通 $I = 10\ \text{A}$ 的同向电流. 求每米长度上的作用力大小与性质.

解:

$$\frac{F}{l}=\frac{\mu_0I_1I_2}{2\pi a}=\frac{4\pi\times10^{-7}\times10\times10}{2\pi\times0.020}$$

计算: $4\pi\times10^{-7}\times100 = 4\pi\times10^{-5}$; 分母 $2\pi\times0.020 = 0.04\pi$.

$$\frac{F}{l}=\frac{4\pi\times10^{-5}}{0.04\pi} = 1.0\times10^{-3}\ \text{N/m}$$

**性质**: 电流**同向**, 故相互**吸引**, 每米长吸力 $1.0\ \text{mN}$.

**例 4**(磁力矩与平衡位置): 一个 $N = 100$ 匝、面积 $S = 2.0\times10^{-3}\ \text{m}^2$ 的矩形线圈通有 $I = 0.50\ \text{A}$ 电流, 放在 $B = 0.30\ \text{T}$ 的均匀磁场中. 求线圈所受最大力矩, 以及磁矩在什么方向时力矩为零.

解: **磁矩大小**:

$$m = NIS = 100\times0.50\times2.0\times10^{-3} = 0.10\ \text{A·m}^2$$

**最大力矩**($\theta = 90^\circ$):

$$M_{\max} = mB = 0.10\times0.30 = 3.0\times10^{-2}\ \text{N·m}$$

**力矩为零的方向**: $\boldsymbol m\times\boldsymbol B = 0$, 即 $\boldsymbol m\parallel\boldsymbol B$ 或 $\boldsymbol m\parallel-\boldsymbol B$, 对应 $\theta = 0^\circ$ 与 $\theta = 180^\circ$.

**稳定性判断**: $\theta = 0^\circ$ 是**稳定平衡**(受扰动后磁场会把它扳回), $\theta = 180^\circ$ 是**不稳定平衡**(受扰动后会翻转到 $0^\circ$).

**例 5**(磁电式仪表的刻度线性): 某磁电式电流计线圈 $N = 200$ 匝、$S = 1.5\times10^{-4}\ \text{m}^2$, 游丝的反力矩系数 $k = 2.0\times10^{-6}\ \text{N·m/rad}$, 磁感应强度 $B = 0.20\ \text{T}$(径向磁场, 线圈受力始终垂直于线框平面). 求通以 $I = 100\ \mu\text{A}$ 时的偏转角.

解: 由力矩平衡 $NISB = k\theta$:

$$\theta=\frac{NISB}{k}=\frac{200\times100\times10^{-6}\times1.5\times10^{-4}\times0.20}{2.0\times10^{-6}}$$

分子: $200\times1.0\times10^{-4}\times1.5\times10^{-4}\times0.20 = 200\times3.0\times10^{-9} = 6.0\times10^{-7}$.

$$\theta=\frac{6.0\times10^{-7}}{2.0\times10^{-6}} = 0.30\ \text{rad}\approx17.2^\circ$$

**要点**: 转角与电流成正比($\theta\propto I$), 因此刻度均匀. **径向磁场的作用**是使线圈在任何转角下 $B$ 都垂直于线框平面, 从而 $M = NISB$ 与转角无关, 保证了线性关系.

**例 6**(磁矩方向的判断): 半径 $R$ 的圆形线圈通有逆时针电流 $I$(从 $+z$ 方向俯视). 求磁矩方向.

解: 由右手螺旋定则: 四指沿逆时针方向环绕, 拇指指向 $+z$ 方向. 故

$$\boldsymbol m = NIS\boldsymbol e_z = I\pi R^2\boldsymbol e_z$$

**口诀**: 逆时针看电流时, 磁矩垂直纸面向外.

## 七、易错点

- 把安培力公式写成 $d\boldsymbol F = I\boldsymbol B\times d\boldsymbol l$(差一个负号). 正确顺序是 $d\boldsymbol l\times\boldsymbol B$.
- 认为闭合回路在均匀磁场中"受力与力矩都为零". 受力为零, 力矩一般不为零.
- 混淆磁矩方向与线圈平面方向: $\boldsymbol m$ 沿**法线**, 不是沿平面.
- 磁力矩公式中把 $\theta$ 误认为线圈平面与磁场的夹角. 实际是**法线与磁场**的夹角.
- 判断平行导线相互作用方向时记反口诀. 记住"**同向相吸**".
- 计算有限长导线的安培力时直接套 $F = BIL$ 而忘记 $\sin\theta$ 因子.
