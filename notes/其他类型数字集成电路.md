# 其他类型数字集成电路

## 核心结论

除 CMOS 与 TTL 两大主流外, 历史上还出现过 **PMOS, NMOS, ECL, I²L** 四类电路. 它们的兴衰说明了一个规律: **速度, 功耗, 集成度三者不可兼得**, 每种电路都在其中一维做到极致, 代价是另外两维.

## 一、PMOS 电路

**特点**:

- 全部使用 P 沟道 MOS 管, 工艺最简单, 成本最低, 是最早实现商品化的 MOS 集成电路.
- 电源电压较高(如 -12 V 至 -24 V), 与 TTL 电平不兼容.
- 空穴迁移率约为电子迁移率的 1 / 2 至 1 / 3, 因此**速度慢**.

**现状**: 已被 NMOS 与 CMOS 完全淘汰, 仅存于历史文献和少数特殊高压接口电路中.

## 二、NMOS 电路

**特点**:

- 全部使用 N 沟道 MOS 管, 电子迁移率高,**速度约为 PMOS 的 2 至 3 倍**.
- 是 20 世纪 70 至 80 年代 LSI(大规模集成电路) 的主力技术, 早期微处理器(如 Intel 8080,8086) 多采用 NMOS 工艺.

**负载管的演化**:

| 类型       | 负载器件           | 缺点                                 |
| ---------- | ------------------ | ------------------------------------ |
| E/E MOS    | 增强型 NMOS 作负载 | 输出高电平有阈值损失, 且需要额外电源 |
| E/D MOS    | 耗尽型 NMOS 作负载 | 输出高电平可达到 $V_{DD}$, 速度较快  |
| 后来的改进 | 用 PMOS 作负载     | 实际上已经演化为 CMOS                |

**静态功耗问题**: NMOS 门的输出为低电平时, 负载管始终导通, 存在直流通路, 静态功耗不为零. 这是它被 CMOS 取代的根本原因.

## 三、ECL 电路(发射极耦合逻辑)

**结构核心**: 由差分放大器构成的**电流开关**, 三极管工作在**非饱和区**(放大区或截止区).

**优点**:

1. **速度最快**: 因为三极管从不进入饱和, 没有存储时间, 传输延迟可达 1 ns 以下, 是双极型电路中最快的.
2. 输出为**互补输出**(同时提供 $F$ 与 $\overline{F}$), 使用方便.
3. 逻辑摆幅小(约 0.8 V), 充放电时间短.

**缺点**:

1. **功耗大**: 电流开关中始终有恒定电流流过, 每门功耗可达数十毫瓦.
2. **噪声容限小**: 逻辑摆幅只有 0.8 V, 噪声容限仅约 0.2 V.
3. **使用负电源**(典型 $V_{EE} = -5.2\ \text{V}$), 与 TTL/CMOS 电平不兼容, 需要专门的接口电路.
4. 输出电平随温度和电源电压漂移较大.

**应用**: 高速通信, 超高速计数, 雷达信号处理等不计功耗只求速度的场合.

## 四、I²L 电路(集成注入逻辑)

**结构核心**:

- 由一个横向 PNP 管(作为恒流源) 和一个纵向 NPN 管(作为反相器) 构成.
- **没有电阻**, 全部用晶体管实现, 这是它集成度极高的原因.
- 采用**合并晶体管**技术, 多个门共用注入极.

**优点**:

1. **集成度极高**: 单元面积小, 无电阻, 适合做 LSI 和 VLSI.
2. **功耗极低**: 工作电流可低至纳安级, 可在很低电压下工作.
3. 工艺简单, 与双极型工艺兼容.

**缺点**:

1. **速度较低**: 受电流驱动能力限制, 延迟在几十纳秒量级.
2. 逻辑摆幅小(约 0.6 V), 噪声容限小.
3. 驱动能力弱.

**应用**: 低速大规模数字集成电路, 如早期的电子表芯片, 计算器芯片; 后被 CMOS 取代.

## 五、五类电路横向对比

| 电路类型 | 速度   | 静态功耗 | 集成度 | 噪声容限 | 现状              |
| -------- | ------ | -------- | ------ | -------- | ----------------- |
| PMOS     | 慢     | 较大     | 高     | 较大     | 淘汰              |
| NMOS     | 中     | 较大     | 高     | 中       | 淘汰(演进为 CMOS) |
| CMOS     | 中至快 | 极小     | 极高   | 大       | **主流**          |
| TTL      | 快     | 大       | 中     | 小       | 仍广泛使用        |
| ECL      | 极快   | 极大     | 低     | 很小     | 特殊高速场合      |
| I²L      | 慢     | 极小     | 极高   | 小       | 淘汰              |

## 六、演进的规律

1. **功耗驱动了 CMOS 的胜利**: 任何存在静态直流通路的电路, 随着集成度提高, 总功耗会线性增长到不可接受, 因此"互补"结构成为必然.
2. **速度需求保留了双极型**: 双极型管跨导大, 驱动能力强, 因此 ECL 在极限速度领域仍有位置.
3. **工艺融合**: 现代 BiCMOS 工艺把双极型管的高驱动能力与 CMOS 的低功耗结合在同一芯片上, 用于高速模拟数字混合电路.

## 易错点

- ECL 的"快"来自**避免饱和**, 而不是来自使用了更好的材料, 理解这一点才能明白为什么它的功耗降不下来.
- I²L 的"集成度高"与"速度慢"是同一枚硬币的两面: 恒流源电流小省电, 但充放电慢.
