# 基数排序

基数排序是一种分配式的排序方法, 适用于整数排序, 尤其在处理大批量数据时表现亮眼. 它的核心思想是: 把整数按"位"分配到不同的"桶"(按某一位的数进行分类) 中, 再按位合并, 通过多轮这样的分配与合并, 最终完成排序

```C
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

#define MAX 100
#define RADIX 10 //10进制,桶的数量为10

// 获取某个数在某一位上的数字
int getDigit(int num, int pos){
    int radix = 1;
    for(int i = 1; i < pos; i++){
        radix *= 10;
    }
    return (num / radix) % 10;
}

// 获取数组中最大数的位数
int getMaxDigit(int* data, int len){
    int max = data[0];
    for(int i = 1; i < len; i++){
        if(data[i] > max){
            max = data[i];
        }
    }

    int digit = 0;
    while(max != 0){
        digit++;
        max /= 10;
    }

    return digit;
}

void radixSort(int* data, int len){
    int maxDigit = getMaxDigit(data, len); //获取最大位数,决定排序轮数
    int bucket[RADIX][MAX]; //定义10个桶,每个桶最多装MAX个元素
    int count[RADIX]; // 每个桶中的元素数量

    for(int pos = 1; pos <= maxDigit; pos++){ // 从个位开始,依次对每一位进行排序
        memset(count, 0, sizeof(count)); // 清空计数器,准备新一轮

        //分配阶段:将每个元素放入对应的桶中
        for(int i = 0; i < len; i++){
            int digit = getDigit(data[i], pos);
            bucket[digit][count[digit]++] = data[i]; // 放入对应的桶中
        }

        // 收集阶段:按桶的顺序重新收集数据
        int index = 0;
        for(int i = 0; i < RADIX; i++){
            //依次从0到9号桶中取出数据
            for(int j = 0; j < count[i]; i++){
                data[index++] = bucket[i][j];
            }
        }
    }
}

int main(){
    int data[] = {170, 201, 321, 95, 843, 996, 57, 8, 241, 30};
    int len = sizeof(data) / sizeof(data[0]);

    radixSort(data, len);

    for(int i = 0; i < len; i++){
        printf("%d ", data[i]);
    }
    return 0;
}
```

**基数排序完全不需要进行比较**

| 维度       | 描述                                                               |
| ---------- | ------------------------------------------------------------------ |
| 时间复杂度 | $O(d\times n)$ 其中d是最大数的位数, n为数据量                      |
| 空间复杂度 | $O(n + RADIX)$ 需要额外的输出数组和计数桶(RADIX为桶的数量)         |
| 算法稳定性 | 稳定                                                               |
| 适用场景   | 适合整数, 定长字符串, 尤其是大数据量, 数据分布均匀且位数不高的场景 |
