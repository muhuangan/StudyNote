# 标准正态分布

标准正态分布 $N(0,1)$ 是正态分布的"母版": 一切正态计算最终都化归为它, 所以必须熟练掌握它的分布函数 $\Phi(x)$ 与查表方法.

## 一、定义

当 $\mu=0$, $\sigma=1$ 时, 称 $X$ 服从**标准正态分布**, 记为 $X\sim N(0,1)$. 其密度与分布函数习惯用专用记号:

$$\varphi(x)=\frac{1}{\sqrt{2\pi}}e^{-x^2/2}$$
$$\Phi(x)=\int_{-\infty}^{x}\frac{1}{\sqrt{2\pi}}e^{-t^2/2}\,dt$$

## 二、基本性质

**(1) 密度为偶函数**

$$\varphi(-x)=\varphi(x)$$

曲线关于 $y$ 轴对称, 在 $x=0$ 处取最大值 $\frac{1}{\sqrt{2\pi}}\approx0.3989$.

**(2) 对称公式**(最常用)

$$\Phi(-x)=1-\Phi(x)$$

**(3) 中点值**

$$\Phi(0)=0.5,\qquad \Phi(-\infty)=0,\qquad \Phi(+\infty)=1$$

**(4) 区间概率**

$$P(a<X\le b)=\Phi(b)-\Phi(a)$$

## 三、查表方法

通常的 $\Phi(x)$ 表只给出 $x\ge0$ 的值, 遇到负数用对称公式转换:

$$\Phi(-1.5)=1-\Phi(1.5)=1-0.9332=0.0668$$

**常用数值**(建议熟记):

| $x$   | $\Phi(x)$ | 含义                 |
| ----- | --------- | -------------------- |
| 0     | 0.5000    | 中位数               |
| 1     | 0.8413    | 一 $\sigma$ 右边界   |
| 1.645 | 0.9500    | 单侧 $95\%$ 分位点   |
| 1.96  | 0.9750    | 双侧 $95\%$ 的关键值 |
| 2     | 0.9772    | 两 $\sigma$          |
| 2.58  | 0.9951    | 双侧 $99\%$ 的关键值 |
| 3     | 0.9987    | 三 $\sigma$          |

## 四、例题

**例 1**: 设 $X\sim N(0,1)$, 求 $P(X<1.96)$, $P(X>-1)$, $P(|X|<1.96)$ 与 $P(0.5<X<1.5)$(已知 $\Phi(1)=0.8413$, $\Phi(1.5)=0.9332$, $\Phi(0.5)=0.6915$, $\Phi(1.96)=0.9750$).

解:

$$P(X<1.96)=\Phi(1.96)=0.9750$$
$$P(X>-1)=1-\Phi(-1)=1-\bigl(1-\Phi(1)\bigr)=\Phi(1)=0.8413$$
$$P(|X|<1.96)=P(-1.96<X<1.96)=\Phi(1.96)-\Phi(-1.96)=0.9750-0.0250=0.9500$$
$$P(0.5<X<1.5)=\Phi(1.5)-\Phi(0.5)=0.9332-0.6915=0.2417$$

**例 2**: 设 $X\sim N(0,1)$, 求常数 $c$, 使 $P(X>c)=0.025$(已知 $\Phi(1.96)=0.9750$).

解: $P(X>c)=1-\Phi(c)=0.025$, 即 $\Phi(c)=0.975$, 查表得

$$c=1.96$$

这个 $1.96$ 在后面的区间估计中会反复出现.

**例 3**: 设 $X\sim N(0,1)$, 求 $P(-2<X<-1)$.

解:

$$P(-2<X<-1)=\Phi(-1)-\Phi(-2)=\bigl(1-\Phi(1)\bigr)-\bigl(1-\Phi(2)\bigr)=\Phi(2)-\Phi(1)$$
$$=0.9772-0.8413=0.1359$$

**要点**: 两端都为负时, 用对称公式化简为两个正数之差, 可减少查表次数.

## 五、易错点

- 忘记 $\Phi(-x)=1-\Phi(x)$, 直接查表中不存在的负数行.
- 把 $\Phi(x)$ 当作 $1-\Phi(-x)$ 的反面: 实际二者相等, 方向不要绕混.
- 求 $P(a<X<b)$ 时写成 $\Phi(b)+\Phi(a)$ 或 $\Phi(b-a)$.
- 把 $1.645$ 与 $1.96$ 记错用途: 前者对应单侧 $5\%$, 后者对应双侧 $5\%$(即单侧 $2.5\%$).
