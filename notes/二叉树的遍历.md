# 二叉树的遍历

1. **前序遍历**  
   **根左右**  
   递归典型实现

```C
void preOrder(BiTree T){
    if(T == NULL){
        return;
    }
    printf("%c ", T -> data);
    preOrder(T -> lchild);
    preOrder(T -> rchild);
}
```

非递归典型实现

```C
void iterPreOrder(Stack *s, BiTree T){
    while(T != NULL || !isEmpty(s)){
        while(T != NULL){
            printf("%c ", T -> data);
            push(s, T);
            T = T -> lchild;
        }
        pop(s, &T);
        T = T -> rchild;
    }
}
```

2. **中序遍历**  
   **左根右**  
   典型实现

```C
void inOrder(BiTree T){
    if(T == NULL){
        return;
    }
    inOrder(T -> lchild);
    printf("%c ", T -> data);
    inOrder(T -> rchild);
}
```

3. **后序遍历**  
   **左右根**  
   典型实现

```C
void postOrder(BiTree T){
    if(T == NULL){
        return;
    }
    postOrder(T -> lchild);
    postOrder(T -> rchild);
    printf("%c ", T -> data);
}
```

**根据遍历结果推导二叉树**:  
已知前序遍历和中序遍历, 可以唯一确定一棵二叉树  
已知中序遍历和后序遍历, 可以唯一确定一颗二叉树  
已知前序遍历和后序遍历, 不能唯一确定一颗二叉树
