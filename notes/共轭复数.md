# 共轭复数

共轭运算 $z\mapsto\overline z$ 是"关于实轴作镜像". 它把复数与实数联系起来: 凡是含 $\overline z$ 的表达式, 结果往往可以直接读出实部、虚部或模. 在解析函数那一章, 判断函数"是否只含 $z$ 而不含 $\overline z$"是识别解析性的一个快捷手段.

## 一、定义

设 $z=x+iy$. 称

$$\overline z=x-iy$$

为 $z$ 的**共轭复数**. 几何上, $\overline z$ 是 $z$ 关于实轴的对称点: 实部不变, 虚部取相反数.

## 二、基本性质

设 $z,z_1,z_2\in\mathbb{C}$, 则

**(1) 二次共轭还原**

$$\overline{\overline{z}}=z$$

**(2) 四则运算的"可交换性"**

$$\overline{z_1\pm z_2}=\overline{z_1}\pm\overline{z_2},\qquad \overline{z_1z_2}=\overline{z_1}\cdot\overline{z_2},\qquad \overline{\left(\frac{z_1}{z_2}\right)}=\frac{\overline{z_1}}{\overline{z_2}}\quad(z_2\neq0)$$

**含义**: 求共轭与做四则运算可以交换次序. 遇到复杂表达式时, 可以先把括号里的共轭求出, 再算运算.

**(3) 与实部、虚部的关系**

$$\operatorname{Re}z=\frac{z+\overline z}{2},\qquad \operatorname{Im}z=\frac{z-\overline z}{2i}$$

**这是"由 $z$ 反解实虚部"的标准公式**, 在把复变函数方程化为实变量方程组时非常实用.

**(4) 与模的关系**

$$z\overline z=|z|^2$$

**(5) 实数的判别**

$z$ 为实数当且仅当 $z=\overline z$; $z$ 为纯虚数当且仅当 $z=-\overline z$ 且 $z\neq0$.

**(6) 求和、求积的共轭**

$$\overline{\sum_{k=1}^n z_k}=\sum_{k=1}^n\overline{z_k},\qquad \overline{\prod_{k=1}^n z_k}=\prod_{k=1}^n\overline{z_k}$$

## 三、例题

**例 1**(化简): 设 $z=3-4i$, 求 $\overline z$, $\operatorname{Re}z$, $\operatorname{Im}z$, $|z|$ 与 $z\overline z$.

解:

$$\overline z=3+4i,\qquad \operatorname{Re}z=3,\qquad \operatorname{Im}z=-4$$
$$|z|=\sqrt{3^2+(-4)^2}=5,\qquad z\overline z=25=|z|^2$$

**例 2**(用共轭求实虚部): 已知 $z+\overline z=6$ 且 $z-\overline z=8i$, 求 $z$.

解: 用性质(3) 的方向反推:

$$\operatorname{Re}z=\frac{z+\overline z}{2}=\frac{6}{2}=3,\qquad \operatorname{Im}z=\frac{z-\overline z}{2i}=\frac{8i}{2i}=4$$

故 $z=3+4i$.

**例 3**(验证性质(2)): 设 $z_1=1+i$, $z_2=2-i$, 验证 $\overline{z_1z_2}=\overline{z_1}\cdot\overline{z_2}$.

解: 先算乘积再取共轭:

$$z_1z_2=(1+i)(2-i)=2-i+2i-i^2=3+i\ \Longrightarrow\ \overline{z_1z_2}=3-i$$

先取共轭再算乘积:

$$\overline{z_1}\cdot\overline{z_2}=(1-i)(2+i)=2+i-2i-i^2=3-i$$

两者相等, 性质成立.

**例 4**(证明恒等式): 证明对任意 $z_1,z_2$ 有 $|z_1+z_2|^2+|z_1-z_2|^2=2|z_1|^2+2|z_2|^2$.

解: 用 $|w|^2=w\overline w$ 展开:

$$|z_1+z_2|^2=(z_1+z_2)(\overline{z_1}+\overline{z_2})=|z_1|^2+|z_2|^2+z_1\overline{z_2}+\overline{z_1}z_2$$

注意 $z_1\overline{z_2}$ 与 $\overline{z_1}z_2$ 互为共轭, 其和为 $2\operatorname{Re}(z_1\overline{z_2})$. 于是

$$|z_1+z_2|^2=|z_1|^2+|z_2|^2+2\operatorname{Re}(z_1\overline{z_2})$$
$$|z_1-z_2|^2=|z_1|^2+|z_2|^2-2\operatorname{Re}(z_1\overline{z_2})$$

两式相加得 $2|z_1|^2+2|z_2|^2$, 结论成立.

**技巧小结**: 凡是涉及模的平方的恒等式, 一律用 $|w|^2=w\overline w$ 展开, 再把成对的共轭项合并为 $2\operatorname{Re}(\cdot)$.

**例 5**(判断函数形式): 判断 $f(z)=z^2+\overline z$ 能否写成只含 $z$ 的表达式.

解: 把 $z=x+iy$, $\overline z=x-iy$ 代入:

$$f(z)=(x+iy)^2+(x-iy)=x^2+2xyi-y^2+x-iy$$

分离:

$$\operatorname{Re}f=x^2-y^2+x,\qquad \operatorname{Im}f=2xy-y$$

其中 $\operatorname{Im}f$ 中出现 $y$ 的一次项与 $x,y$ 的耦合, 无法消去. 因此 $f$ 依赖 $\overline z$, 不能写成仅含 $z$ 的表达式.

**这一点为什么重要**: 解析函数的充要条件之一是函数**只依赖于 $z$**, 与 $\overline z$ 无关. 上述判断给出了一个快速的"筛查"手段(严格的判定仍要用柯西-黎曼方程).

## 四、易错点

- 把 $\overline{z_1z_2}$ 写成 $\overline{z_1}\overline{z_2}$ 时漏掉乘积号, 或误写成 $\overline{z_1}\cdot z_2$.
- 记错 $\operatorname{Im}z=\dfrac{z-\overline z}{2i}$ 的分母: 是 $2i$, 不是 $2$. 用 $z=i$ 代入检验最方便: $\dfrac{i-(-i)}{2i}=\dfrac{2i}{2i}=1=\operatorname{Im}i$.
- 认为 $\operatorname{Re}(z_1z_2)=\operatorname{Re}z_1\cdot\operatorname{Re}z_2$. 实部对乘法**不**满足分配性, 必须展开计算.
- 用 $\overline z$ 求模时忘记开方: $z\overline z=|z|^2$, 再开方才是 $|z|$.
