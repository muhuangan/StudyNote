# 复变函数的概念

复变函数把复平面的一部分映射到复平面, 因此它最自然的图示是**两个复平面之间的对应**, 而不是实函数那样的"曲线". 这种"看成映射"的观点在后面研究共形映射时会被推到前台, 但它的基础在这里就已经奠定.

## 一、定义

设 $G$ 是一个复数集合. 若对 $G$ 中每个 $z$, 按某个法则 $f$ 有唯一确定的复数 $w$ 与之对应, 则称 $f$ 是定义在 $G$ 上的**复变函数**, 记作

$$w = f(z),\qquad z\in G$$

$z$ 称为**自变量**, $w$ 称为**因变量**, $G$ 称为**定义域**, 全体函数值构成的集合称为**值域**.

## 二、实虚部分解

这是把复变函数与已有实函数知识连接起来的关键一步. 设 $z = x + iy$, 则 $w = f(z)$ 也是一个复数, 把它写成

$$w = f(z) = u(x,y) + iv(x,y)$$

其中 $u,v$ 都是**二元实值函数**:

$$u = \operatorname{Re}f(z),\qquad v = \operatorname{Im}f(z)$$

**要点**: 一个复变函数等价于**一对二元实函数** $u(x,y)$ 与 $v(x,y)$. 这个分解有两个用途:

1. **判断极限与连续**可以转化为对 $u,v$ 分别判断;
2. **解析性条件**(柯西-黎曼方程) 正是加在 $u,v$ 上的一对偏微分方程.

**例**: $f(z) = z^2$. 由

$$(x + iy)^2 = (x^2 - y^2) + 2xyi$$

得 $u = x^2 - y^2$, $v = 2xy$.

## 三、映射的观点

把自变量所在的复平面称为 **$z$ 平面**, 函数值所在的复平面称为 **$w$ 平面**. 于是 $w = f(z)$ 可以理解为: 把 $z$ 平面上的点(或图形) 变换到 $w$ 平面上.

这种理解方式的价值在于:

- $z$ 平面上的一条曲线, 经 $f$ 后变成 $w$ 平面上的一条曲线;
- $z$ 平面上的一个区域, 经 $f$ 后变成 $w$ 平面上的一个区域(**像区域**);
- 当 $f$ 解析且导数不为零时, 这种变换在局部表现为**旋转加伸缩**, 这就是后面"保角映射"的来源.

**常用初等映射的直观效果**:

| 函数                   | 效果                       |
| ---------------------- | -------------------------- |
| $w = z + a$            | 平移                       |
| $w = kz$($k>0$ 为实数) | 按比例伸缩                 |
| $w = e^{i\alpha}z$     | 逆时针旋转 $\alpha$        |
| $w=\dfrac1z$           | 关于单位圆的"反演"并作对称 |
| $w = z^2$              | 把上半平面张开的角"折半"   |
| $w = e^z$              | 把带形区域映为角形区域     |

## 四、单值函数与多值函数

若对每个 $z\in G$ 只对应**一个** $w$, 则 $f$ 为**单值函数**; 若对应多个 $w$, 则为**多值函数**.

前面已经遇到过典型例子:

- $w = z^2$, $w = z^3$ 等乘幂是**单值**的;
- $w=\sqrt[n]{z}$ 是**$n$ 值**的;
- $w = \operatorname{Arg}z$ 是**无穷多值**的.

**处理多值函数的办法**: 通过限制辐角的取值范围, 把多值函数"切"成若干单值分支. 例如约定 $\arg z\in(-\pi,\pi]$, 就得到 $\sqrt[n]{z}$ 的**主值分支**. 这一技巧在[对数函数](./对数函数.md) 与[幂函数](./幂函数.md) 中会正式使用.

**注意**: 多值性是复变函数特有的现象, 它导致了"分支点""割线""黎曼面"等概念. 初学阶段只需掌握"通过限定辐角范围取单值分支"这一条实用原则.

## 五、例题

**例 1**: 设 $f(z) = z^2 - 2z$, 求其对应的 $u(x,y)$ 与 $v(x,y)$, 并求 $f(1 + i)$.

解: 先求函数值:

$$f(1 + i) = (1 + i)^2 - 2(1 + i) = (1 + 2i + i^2) - 2 - 2i = (2i) - 2 - 2i=-2$$

分离实虚部: 设 $z = x + iy$,

$$z^2 - 2z = (x^2 - y^2 + 2xyi) - 2x - 2yi$$

故

$$u = x^2 - y^2 - 2x,\qquad v = 2xy - 2y = 2y(x - 1)$$

**检验**: 把 $x = 1,y = 1$ 代入, 得 $u = 1 - 1 - 2=-2$, $v = 0$, 与 $-2$ 一致.

**例 2**: 设 $f(z)=|z|^2$, 写出 $u,v$, 并说明它只依赖 $|z|$.

解: 由 $|z|^2 = x^2 + y^2$ 得

$$u = x^2 + y^2,\qquad v = 0$$

**说明**: 函数值恒为实数, 且只与半径有关, 与方向无关. 这类函数在复平面上呈"径向对称". 值得注意的是, 它虽然处处连续, 但**只在 $z = 0$ 处可导**, 处处不解析(详见[解析函数的概念](./解析函数的概念.md)).

**例 3**: 设 $f(z)=\dfrac{1}{z}$, 求 $u,v$ 与定义域.

解: 定义域为 $z\neq0$. 有理化:

$$\frac{1}{z}=\frac{1}{x + iy}=\frac{x - iy}{x^2 + y^2}$$

故

$$u=\frac{x}{x^2 + y^2},\qquad v=\frac{-y}{x^2 + y^2}$$

**例 4**(映射效果): 说明 $w = z^2$ 把两块区域分别映到哪里.

解: 用指数形式最清楚: 设 $z = re^{i\theta}$, 则

$$w = z^2 = r^2e^{2i\theta}$$

于是**模变为平方, 辐角加倍**.

(1) 第一象限 $0<\theta<\frac{\pi}{2}$ 的像为上半平面 $0<2\theta<\pi$, 即 $\operatorname{Im}w>0$;

(2) 上半平面 $0<\theta<\pi$ 的像为 $0<2\theta<2\pi$, 即**整个 $w$ 平面去掉正实轴**.

**这说明 $w = z^2$ 在 $z$ 平面到 $w$ 平面的映射中不是一对一的**: 上半平面与下半平面都被映到"去掉正实轴"的同一区域. 要得到一一对应, 必须把 $z$ 平面上的角形域限制在张角不超过 $\pi$ 的范围内.

**例 5**(多值性): 说明 $w=\sqrt z$ 在 $z = 1$ 附近为何不能只用一个值来讨论.

解: $z = 1$ 的一个辐角为 0, 于是 $\sqrt z$ 有两个值

$$w_0 = e^{i\cdot0} = 1,\qquad w_1 = e^{i\pi}=-1$$

若让 $z$ 沿单位圆绕原点一周回到 $1$(辐角由 0 增到 $2\pi$), 则 $\sqrt z$ 的值由 $1$ 连续变到 $e^{i\pi}=-1$, **并未回到出发点**. 这说明 $\sqrt z$ 在绕原点一周后从一个分支"接到"了另一个分支, 根因是原点成为**分支点**. 处理办法是取定辐角范围(如 $-\pi<\arg z\le\pi$) 并在负实轴上"割开", 从而得到单值分支.

## 六、易错点

- 认为复变函数可以像实函数那样画成一条曲线. 它需要"两个复平面"来描述.
- 把 $w = f(z)$ 与 $u(x,y)$, $v(x,y)$ 混为一谈: 后者只是前者的分解, 用于分析.
- 忽略定义域: 例如 $f(z)=\frac1z$ 在 $z = 0$ 处无定义, 讨论它的性质必须把 $0$ 排除.
- 把多值函数当成单值函数直接代入相消, 例如写成 $\sqrt{z^2} = z$. 在复数域内这不恒成立.
