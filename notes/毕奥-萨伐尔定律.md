# 毕奥-萨伐尔定律

毕奥-萨伐尔定律是计算恒定磁场最通用的工具: 它给出任意形状载流回路产生的磁场, 是安培环路定律的"积分前身".

## 一、定律内容

电流元 $Id\boldsymbol l$ 在距离 $R$ 处产生的磁感应强度为

$$d\boldsymbol B=\frac{\mu_0}{4\pi}\cdot\frac{Id\boldsymbol l\times\boldsymbol e_R}{R^2}$$

整段回路的贡献由叠加原理积分:

$$\boldsymbol B=\frac{\mu_0}{4\pi}\int_l\frac{Id\boldsymbol l\times\boldsymbol e_R}{R^2}$$

对体分布电流($\boldsymbol J$)与面电流($\boldsymbol J_S$)则改为

$$\boldsymbol B=\frac{\mu_0}{4\pi}\int_V\frac{\boldsymbol J\times\boldsymbol e_R}{R^2}dV,\qquad \boldsymbol B=\frac{\mu_0}{4\pi}\int_S\frac{\boldsymbol J_S\times\boldsymbol e_R}{R^2}dS$$

**来源**见[磁感应强度与安培力定律](./磁感应强度与安培力定律.md): 把安培力定律按"电流元 × 场"拆分即得.

## 二、三个标准结果(可直接引用)

**(1) 无限长直导线**(距离 $a$):

$$\boldsymbol B=\frac{\mu_0I}{2\pi a}\boldsymbol e_\phi$$

**(2) 有限长直导线**: 设场点到导线的垂足为原点, 导线沿 $z$ 轴从 $z_1$ 到 $z_2$, 垂距为 $a$. 定义 $\theta$ 为连线与垂线之间的夹角($\sin\theta = z/\sqrt{a^2 + z^2}$), 则

$$\boldsymbol B=\frac{\mu_0I}{4\pi a}(\sin\theta_2-\sin\theta_1)\boldsymbol e_\phi$$

**对称情形**(导线从 $-L / 2$ 到 $L / 2$, 半张角为 $\theta$):

$$\boldsymbol B=\frac{\mu_0I}{2\pi a}\sin\theta\,\boldsymbol e_\phi$$

**检验**: 当 $L\to\infty$ 时 $\theta\to90^\circ$, $\sin\theta = 1$, 退化为无限长结果.

**(3) 圆环轴线上**: 半径 $a$ 的圆环通电流 $I$, 轴线上距圆心 $z$ 处:

$$\boldsymbol B=\frac{\mu_0Ia^2}{2(a^2 + z^2)^{3 / 2}}\boldsymbol e_z$$

**圆心处**($z = 0$):

$$\boldsymbol B=\frac{\mu_0I}{2a}\boldsymbol e_z$$

## 三、有限长直线的推导(示范积分过程)

场点在 $(a,0,0)$, 电流元 $Id\boldsymbol l = Idz\,\boldsymbol e_z$, 源点 $(0,0,z)$:

$$\boldsymbol R = a\boldsymbol e_\rho - z\boldsymbol e_z,\qquad R=\sqrt{a^2 + z^2},\qquad \boldsymbol e_R=\frac{a\boldsymbol e_\rho - z\boldsymbol e_z}{R}$$

叉乘:

$$d\boldsymbol l\times\boldsymbol e_R = dz\,\boldsymbol e_z\times\frac{a\boldsymbol e_\rho - z\boldsymbol e_z}{R}=\frac{a\,dz}{R}\,\boldsymbol e_\phi$$

**注意**: 各电流元贡献的方向都是 $\boldsymbol e_\phi$, 因此可按**标量**积分:

$$B=\frac{\mu_0I}{4\pi}\int_{z_1}^{z_2}\frac{a\,dz}{(a^2 + z^2)^{3 / 2}}=\frac{\mu_0I}{4\pi a}\left[\frac{z}{\sqrt{a^2 + z^2}}\right]_{z_1}^{z_2}=\frac{\mu_0I}{4\pi a}(\sin\theta_2-\sin\theta_1)$$

**通用经验**: 只有当各电流元的 $d\boldsymbol B$ **方向一致**时才能标量积分; 否则必须先分解分量、利用对称性消去某些分量.

## 四、例题

**例 1**: 长 $L = 1\ \text{m}$ 的直导线通电流 $I = 10\ \text{A}$, 求其中垂线上 $a = 0.1\ \text{m}$ 处的磁场.

解: 半张角满足 $\sin\theta=\dfrac{L / 2}{\sqrt{a^2 + (L / 2)^2}}=\dfrac{0.5}{\sqrt{0.01 + 0.25}}=\dfrac{0.5}{0.5099}\approx0.9806$:

$$B=\frac{\mu_0I}{2\pi a}\sin\theta=\frac{4\pi\times10^{-7}\times10}{2\pi\times0.1}\times0.9806 = 2\times10^{-5}\times0.9806\approx1.96\times10^{-5}\ \text{T}$$

若为无限长导线, 则 $B = 2\times10^{-5}\ \text{T}$; 有限长的结果略小, 符合预期.

**例 2**: 半径 $a = 0.05\ \text{m}$ 的圆环, 通电流 $I = 5\ \text{A}$. 求圆心处与轴线上 $z = 0.12\ \text{m}$ 处的磁场.

解: 圆心处

$$B_0=\frac{\mu_0I}{2a}=\frac{4\pi\times10^{-7}\times5}{2\times0.05}=\frac{2\pi\times10^{-6}}{0.1} = 2\pi\times10^{-5}\approx6.28\times10^{-5}\ \text{T}$$

轴线上 $z = 0.12\ \text{m}$, $a^2 + z^2 = 0.0025 + 0.0144 = 0.0169$, $(a^2 + z^2)^{3 / 2} = 0.0169^{1.5} = 0.002197$:

$$B=\frac{\mu_0Ia^2}{2(a^2 + z^2)^{3 / 2}}=\frac{4\pi\times10^{-7}\times5\times0.0025}{2\times0.002197}=\frac{1.571\times10^{-8}}{0.004394}\approx3.58\times10^{-6}\ \text{T}$$

**结论**: 离圆心越远场越弱, 且轴线上的场沿轴向.

**例 3**: 两根平行无限长导线, 电流均为 $I$ 但**方向相反**, 相距 $d = 0.2\ \text{m}$. 求两导线中点处的磁场.

解: 在中点, 距每根导线 $d / 2 = 0.1\ \text{m}$. 由右手定则, 两电流方向相反时, 在**两线之间**产生的磁场**同向**, 故

$$B = 2\times\frac{\mu_0I}{2\pi(d / 2)}=\frac{2\mu_0I}{\pi d}$$

若 $I = 10\ \text{A}$: $B=\dfrac{2\times4\pi\times10^{-7}\times10}{\pi\times0.2} = 4\times10^{-5}\ \text{T}$.

## 五、易错点

- 叉乘次序与 $\boldsymbol e_R$ 方向写错, 导致磁场方向相反.
- 在方向不一致时直接标量积分(应分解分量).
- 有限长与无限长公式混用.
- 圆环轴线公式漏掉 $a^2$ 因子或把分母的 $3 / 2$ 次方写成平方.
