# 字符编码与奇偶校验码

## 核心结论

ASCII 码解决"字符如何用二进制表示", 奇偶校验码解决"传输过程中出错如何被发现".**奇偶校验只能检错, 不能纠错, 且只能发现奇数个位错误**.

## 一、ASCII 码

ASCII(American Standard Code for Information Interchange) 是 7 位二进制编码, 共 $2^7 = 128$ 个码字. 计算机中通常用一个字节(8 位) 存储, 最高位补 0 或用作扩展.

| 字符类别        | 十六进制范围 | 说明                                     |
| --------------- | ------------ | ---------------------------------------- |
| 控制字符        | 00H 至 1FH   | 不可打印, 如换行 LF = 0AH, 回车 CR = 0DH |
| 空格            | 20H          | 可打印字符的起点                         |
| 数字 0 至 9     | 30H 至 39H   | 低位正好是数字本身, 便于与数值互换       |
| 大写字母 A 至 Z | 41H 至 5AH   | 连续排列                                 |
| 小写字母 a 至 z | 61H 至 7AH   | 连续排列                                 |

**大小写转换技巧**: 同一个字母的大小写只在第 5 位(从 0 起编号) 上差 1, 因此

$$\text{小写} = \text{大写} + 20\text{H},\quad \text{大写} = \text{小写} - 20\text{H}$$

等效的位运算是: `小写 = 大写 | 0x20`,`大写 = 小写 & 0xDF`.

**数字字符转数值**: `数值 = 字符 - 0x30`, 或 `数值 = 字符 & 0x0F`.

## 二、奇偶校验码

**构成**: 在 $n$ 位信息位之外附加 1 位校验位, 使整个码字中 1 的个数满足奇偶性要求.

| 类型   | 规则                  | 校验位取值                                  |
| ------ | --------------------- | ------------------------------------------- |
| 奇校验 | 码字中 1 的个数为奇数 | 信息位中 1 的个数为偶数时补 1, 为奇数时补 0 |
| 偶校验 | 码字中 1 的个数为偶数 | 校验位等于信息位各位的异或和                |

偶校验位的生成逻辑最简单:

$$P = D_{n - 1} \oplus D_{n - 2} \oplus \cdots \oplus D_0$$

**接收端检错**: 对收到的全部 $n + 1$ 位重新做异或(偶校验时), 结果为 0 认为无错, 为 1 认为有错.

## 三、奇偶校验的能力边界

| 错误情况       | 能否发现 |
| -------------- | -------- |
| 1 位出错       | 能       |
| 奇数个位出错   | 能       |
| 偶数个位出错   | 不能     |
| 定位哪一位出错 | 不能     |
| 自动纠正错误   | 不能     |

**码距(汉明距离)**是衡量检错纠错能力的核心指标: 两个合法码字之间不同的位数称为码距, 一种编码中任意两个合法码字的最小码距称为最小码距 $d_{\min}$.

- 检测 $e$ 位错误要求 $d_{\min} \ge e + 1$.
- 纠正 $t$ 位错误要求 $d_{\min} \ge 2t + 1$.

奇偶校验码的最小码距为 2, 因此只能检测 1 位错误. 要纠错至少需要 $d_{\min} = 3$, 典型方案是汉明码.

## 四、检错与纠错的工程选择

| 方案             | 冗余位          | 能力             | 典型应用                     |
| ---------------- | --------------- | ---------------- | ---------------------------- |
| 奇偶校验         | 1 位            | 检 1 位错        | 串口异步通信, 内存条早期方案 |
| 汉明码           | $\log_2 n$ 量级 | 纠 1 位, 检 2 位 | ECC 内存                     |
| CRC 循环冗余校验 | 16 或 32 位     | 检多位突发错     | 以太网, 磁盘, USB            |
| 重复发送         | 2 倍以上        | 三取二表决       | 高可靠控制                   |

## 五、示例

信息位为 `1011001`(4 个 1, 偶数):

- 偶校验位 $P = 1 \oplus 0 \oplus 1 \oplus 1 \oplus 0 \oplus 0 \oplus 1 = 0$, 发送 `10110010`.
- 奇校验位 $P = 1$, 发送 `10110011`.

## 易错点

- 校验位是"附加"的, 不计入信息位本身; 计算 1 的个数时一定要把校验位算进去.
- 奇偶校验无法发现"两位同时反转"的错误, 这是它在高可靠场景中必须被 CRC 替代的根本原因.
