# 散度定理

散度定理把**闭合面上的面积分**与**所围体积上的体积分**联系起来, 是电磁场由积分形式过渡到微分形式的数学桥梁.

## 一、定理

设矢量场 $\boldsymbol A$ 在闭合面 $S$ 所围区域 $V$ 内具有连续的一阶偏导数, 则

$$\oint_S\boldsymbol A\cdot d\boldsymbol S=\int_V\nabla\cdot\boldsymbol A\,dV$$

其中 $S$ 取**外法向**. 该定理又称**高斯定理**(数学上的高斯-奥斯特洛格拉德斯基定理).

## 二、证明思路

把区域 $V$ 分割成 $N$ 个微小体积元 $\Delta V_i$. 对每个小体积元, 由散度的定义有

$$\oint_{S_i}\boldsymbol A\cdot d\boldsymbol S\approx\nabla\cdot\boldsymbol A\,\Delta V_i$$

**关键**: 相邻体积元的公共面上的通量**方向相反, 恰好抵消**. 把所有小体积的等式相加后, 内部界面上的积分两两相消, 只剩下最外层闭合面 $S$ 上的积分:

$$\oint_S\boldsymbol A\cdot d\boldsymbol S=\sum_i\nabla\cdot\boldsymbol A\,\Delta V_i\ \xrightarrow{\ \Delta V_i\to0\ }\ \int_V\nabla\cdot\boldsymbol A\,dV$$

## 三、意义与用途

**(1) 建立电磁场微分方程**: 把麦克斯韦方程组的积分形式(如 $\oint_S\boldsymbol D\cdot d\boldsymbol S = q$)化为微分形式(如 $\nabla\cdot\boldsymbol D=\rho$);

**(2) 简化运算**: 当面积分困难而体积分容易(或反之)时互相转化;

**(3) 数学上等价于"通量的体密度等于散度"** 这一物理图像.

**相关的两个平行结论**(应一并记住):

$$\oint_S\boldsymbol A\cdot d\boldsymbol S=\int_V\nabla\cdot\boldsymbol A\,dV\quad\text{(散度定理)}$$
$$\oint_C\boldsymbol A\cdot d\boldsymbol l=\int_S(\nabla\times\boldsymbol A)\cdot d\boldsymbol S\quad\text{(斯托克斯定理)}$$

## 四、例题

**例 1**(验证定理): 设 $\boldsymbol A = x\boldsymbol e_x + y\boldsymbol e_y + z\boldsymbol e_z$, $S$ 为半径 $a$ 的球面. 验证散度定理.

解: **左端**: 球面上 $\boldsymbol A = a\boldsymbol e_r$, $d\boldsymbol S=\boldsymbol e_r dS$:

$$\oint_S\boldsymbol A\cdot d\boldsymbol S=\oint_S a\,dS = a\cdot4\pi a^2 = 4\pi a^3$$

**右端**: 已求得 $\nabla\cdot\boldsymbol A = 3$:

$$\int_V\nabla\cdot\boldsymbol A\,dV = 3\cdot\frac43\pi a^3 = 4\pi a^3$$

两端相等, 定理成立.

**例 2**(利用定理简化计算): 设 $\boldsymbol A = 2x\boldsymbol e_x + 3y\boldsymbol e_y$, $S$ 是边长为 1 的立方体($0\le x,y,z\le1$)的表面, 求 $\oint_S\boldsymbol A\cdot d\boldsymbol S$.

解: 用散度定理最省力:

$$\nabla\cdot\boldsymbol A = 2 + 3 + 0 = 5$$
$$\oint_S\boldsymbol A\cdot d\boldsymbol S=\int_V5\,dV = 5\times1 = 5$$

若直接算六个面的面积分, 工作量显著更大.

**例 3**(推证连续性方程): 已知电荷守恒要求"从闭合面流出的电流等于面内电荷的减少率":

$$\oint_S\boldsymbol J\cdot d\boldsymbol S=-\frac{\partial}{\partial t}\int_V\rho\,dV$$

用散度定理把左端化为体积分:

$$\int_V\nabla\cdot\boldsymbol J\,dV=-\int_V\frac{\partial\rho}{\partial t}dV$$

由于体积 $V$ 任意, 得到**连续性方程的微分形式**:

$$\nabla\cdot\boldsymbol J=-\frac{\partial\rho}{\partial t}$$

**这正是"由积分形式得微分形式"的典型操作**.

## 五、易错点

- 忘记 $S$ 必须是**闭合面**, $V$ 是它所围的区域.
- 法向取内法向: 通量的正负号会整体相反.
- 把散度定理与斯托克斯定理用错场景: 前者联系"面积分 ⇄ 体积分", 后者联系"线积分 ⇄ 面积分".
- 在场有奇点(如原点)的区域盲目使用: 需把奇点用小面挖去后再用.
