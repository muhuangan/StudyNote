# 条件分布

条件分布把一维条件概率的思想推广到随机变量: **固定其中一个变量的取值, 另一个变量的分布会变成什么样**.

## 一、离散型条件分布律

设 $(X,Y)$ 的联合分布律为 $p_{ij}$. 当 $P(Y = y_j) = p_{\cdot j}>0$ 时, 称

$$P(X = x_i\mid Y = y_j)=\frac{p_{ij}}{p_{\cdot j}},\qquad i = 1,2,\ldots$$

为在 $Y = y_j$ 条件下 $X$ 的**条件分布律**.

对照定义: 这就是把分母换成"$Y = y_j$ 的边缘概率"的条件概率. 注意它对 $i$ 求和必须为 1.

## 二、连续型条件概率密度

设联合密度为 $f(x,y)$, 边缘密度 $f_Y(y)$. 对使 $f_Y(y)>0$ 的 $y$, 称

$$f_{X\mid Y}(x\mid y)=\frac{f(x,y)}{f_Y(y)}$$

为在 $Y = y$ 条件下 $X$ 的**条件概率密度**. 对称地

$$f_{Y\mid X}(y\mid x)=\frac{f(x,y)}{f_X(x)},\qquad f_X(x)>0$$

**要点**:

- 条件密度对 $x$ 的积分必须为 1, 可作校验;
- $f_{X\mid Y}(x\mid y)$ 中对 $x$ 而言, $y$ 是**常数**(可以代入具体数值);
- 条件概率同样满足一切概率性质(非负, 规范, 可加).

## 三、例题

**例 1**(离散): 承[二维离散型随机变量的联合分布律](./二维离散型随机变量的联合分布律.md)例 1(2 红 3 白, 不放回取两球):

| $X\backslash Y$ | 0              | 1              | $p_{i\cdot}$   |
| --------------- | -------------- | -------------- | -------------- |
| 0               | $\frac{3}{10}$ | $\frac{3}{10}$ | $\frac{6}{10}$ |
| 1               | $\frac{3}{10}$ | $\frac{1}{10}$ | $\frac{4}{10}$ |
| $p_{\cdot j}$   | $\frac{6}{10}$ | $\frac{4}{10}$ | 1              |

求在 $X = 1$(第一次取到红球)条件下 $Y$ 的条件分布律.

解: $p_{1\cdot} = P(X = 1) = 0.4$:

$$P(Y = 0\mid X = 1)=\frac{p_{10}}{p_{1\cdot}}=\frac{0.3}{0.4}=\frac34$$
$$P(Y = 1\mid X = 1)=\frac{p_{11}}{p_{1\cdot}}=\frac{0.1}{0.4}=\frac14$$

这与"第一次取到红球后, 袋中剩 1 红 3 白, 第二次取到红球的概率为 $\frac14$"完全一致, 验证了条件分布的实际含义.

**例 2**(连续, 重点): 承[边缘分布](./边缘分布.md)例 2, $(X,Y)$ 在三角形 $D=\{0<y<x<1\}$ 上均匀分布, 联合密度 $f(x,y) = 2$, 边缘密度 $f_Y(y) = 2(1 - y)$, $0<y<1$. 求 $f_{X\mid Y}(x\mid y)$.

解: 对 $0<y<1$:

$$f_{X\mid Y}(x\mid y)=\frac{f(x,y)}{f_Y(y)}=\frac{2}{2(1 - y)}=\frac{1}{1 - y},\qquad y<x<1$$

即在 $Y = y$ 条件下, $X$ 在区间 $(y,1)$ 上服从**均匀分布**. 校验:

$$\int_y^1\frac{1}{1 - y}dx=\frac{1 - y}{1 - y} = 1$$

**直观**: 三角形区域的竖截线在 $x$ 方向上是固定长度 $1 - y$, 所以给定 $y$ 后 $X$ 在 $(y,1)$ 内是均匀的.

**例 3**(条件密度的应用): 承例 2, 求 $P\!\left(X>\frac34\mid Y=\frac12\right)$.

解: 条件密度为 $\dfrac{1}{1 - 1 / 2} = 2$, 定义域 $x\in(1 / 2,1)$:

$$P\!\left(X>\frac34\mid Y=\frac12\right)=\int_{3 / 4}^{1}2\,dx = 2\times\frac14=\frac12$$

## 四、条件分布与独立性

$X$ 与 $Y$ 独立 $\iff$ 条件分布与条件本身无关, 即

$$f_{X\mid Y}(x\mid y) = f_X(x)\ (\text{对一切 }y)\qquad\text{或}\qquad P(X = x_i\mid Y = y_j) = P(X = x_i)$$

即"知道 $Y$ 的取值不会改变 $X$ 的分布".

## 五、易错点

- 分母用错: 条件分布的分母是**边缘**概率/密度, 不是联合的.
- 确定条件密度的**定义域**: $f_{X\mid Y}(x\mid y)$ 的 $x$ 范围随 $y$ 变化(例 2 中是 $y<x<1$).
- 把 $f_{X\mid Y}(x\mid y)$ 里的 $y$ 仍当变量处理: 代入具体数值后它应是常数.
- 忘记校验条件密度的积分为 1.
