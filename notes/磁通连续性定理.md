# 磁通连续性定理

磁通连续性定理是恒定磁场两大基本方程之一, 它表明磁场**无源**: 不存在孤立的磁荷.

## 一、定理内容

**积分形式**: 穿过任意闭合面的磁通量恒为零:

$$\oint_S\boldsymbol B\cdot d\boldsymbol S = 0$$

**微分形式**(由散度定理):

$$\nabla\cdot\boldsymbol B = 0$$

单位: 磁通 $\Phi$ 的单位为 $\text{Wb}$, $\boldsymbol B$ 的单位为 $\text{T}$($=\text{Wb/m}^2$).

## 二、来源与物理意义

**来源一(实验)**: 至今未发现磁单极子. 把磁棒无论切分得多小, 每一段总是同时具有 N 极与 S 极, 不存在"只有 N 极"的磁荷. 因此磁感线既无起点也无终点.

**来源二(数学)**: 由[毕奥-萨伐尔定律](./毕奥-萨伐尔定律.md)可以证明 $\boldsymbol B$ 恒等于某个矢量场的旋度(即 $\boldsymbol B=\nabla\times\boldsymbol A$), 而恒等式 $\nabla\cdot(\nabla\times\boldsymbol A) = 0$ 立即给出 $\nabla\cdot\boldsymbol B = 0$.

**物理图像**: 磁感线是**闭合曲线**(或伸至无穷远再回来), 穿过任一闭合面的"进入"与"穿出"必然相等, 代数和为零.

**对比电场的高斯定理**:

|          | 电场                                           | 磁场                                           |
| -------- | ---------------------------------------------- | ---------------------------------------------- |
| 通量方程 | $\oint_S\boldsymbol D\cdot d\boldsymbol S = q$ | $\oint_S\boldsymbol B\cdot d\boldsymbol S = 0$ |
| 微分形式 | $\nabla\cdot\boldsymbol D=\rho$                | $\nabla\cdot\boldsymbol B = 0$                 |
| 场线     | 起于正电荷、止于负电荷                         | **处处闭合**                                   |
| 源       | 有(电荷)                                       | 无(无磁荷)                                     |

## 三、重要推论

**(1) 磁场是无散场**, 因此可以引入**矢量磁位** $\boldsymbol A$:

$$\boldsymbol B=\nabla\times\boldsymbol A$$

(依据是"无散场必可表为某矢量场的旋度", 见[无旋场、无散场与亥姆霍兹定理](./无旋场、无散场与亥姆霍兹定理.md))

**(2) 磁通只与回路交链有关**: 在确定的回路下, 磁通与所取曲面无关(只要曲面以该回路为边界).

**(3) 磁路中的磁通守恒**: 铁芯中任意截面的磁通相同(忽略漏磁).

## 四、例题

**例 1**: 已知 $\boldsymbol B=\dfrac{\mu_0I}{2\pi\rho}\boldsymbol e_\phi$(无限长直导线的场), 验证 $\nabla\cdot\boldsymbol B = 0$.

解: 用圆柱坐标的散度公式:

$$\nabla\cdot\boldsymbol B=\frac1\rho\frac{\partial(\rho B_\rho)}{\partial\rho}+\frac1\rho\frac{\partial B_\phi}{\partial\phi}+\frac{\partial B_z}{\partial z}$$

此处 $B_\rho = B_z = 0$, $B_\phi=\dfrac{\mu_0I}{2\pi\rho}$ 与 $\phi$ 无关, 故

$$\nabla\cdot\boldsymbol B = 0+\frac1\rho\cdot0 + 0 = 0$$

**注意**: $B_\phi$ 随 $\rho$ 变化, 但散度公式中 $\phi$ 分量的导数是对 $\phi$ 求导, 因此不产生贡献. 这说明"场的大小随 $\rho$ 变化"与"无散"并不矛盾.

**例 2**: 说明为什么不能像电场那样定义"磁荷密度".

解: 若存在磁荷密度 $\rho_m$, 则应有 $\nabla\cdot\boldsymbol B=\rho_m$. 但实验表明 $\nabla\cdot\boldsymbol B\equiv0$ 处处成立, 故 $\rho_m\equiv0$, 磁荷不存在.

**例 3**: 长直螺线管内部磁场近似均匀为 $B$, 截面积为 $S$. 求穿过管口端面的磁通, 并说明该磁通"从哪里出去、又从哪里回来".

解: 穿过管口端面的磁通 $\Phi = BS$. 由磁通连续性, 这些磁感线不会终止, 而是从 N 端出发、经外部空间回到 S 端, 在管内闭合. 因此**穿过管内任一截面的磁通都相同**(这正是磁路计算的基础).

## 五、易错点

- 认为"磁场有源": 磁场的涡旋源是电流, 但**散度源(磁荷)不存在**.
- 把 $\oint_S\boldsymbol B\cdot d\boldsymbol S = 0$ 误解为"磁场为零": 它只说明净通量为零.
- 把散度公式中"对哪个变量求导"记错: $\boldsymbol e_\phi$ 分量的贡献是对 $\phi$ 求导, 不是对 $\rho$ 求导.
- 认为铁磁体表面"磁荷"是真实存在的: 那是等效磁荷模型, 并非真实磁单极子.
