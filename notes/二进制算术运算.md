# 二进制算术运算

## 核心结论

二进制算术的规则与十进制完全相同, 只是**进位基数为 2**: 加法逢二进一, 减法借一当二. 在数字电路中, 减法, 乘法, 除法最终都可以归结为加法和移位操作.

## 一、无符号二进制加法

基本规则:

$$0 + 0 = 0,\quad 0 + 1 = 1,\quad 1 + 0 = 1,\quad 1 + 1 = 10$$

最后一条表示本位得 0, 向高位进 1. 多位相加时逐位相加并把进位传到高位.

例:$1011 + 0111 = 10010$(即十进制 $11 + 7 = 18$).

## 二、无符号二进制减法

基本规则:

$$0 - 0 = 0,\quad 1 - 0 = 1,\quad 1 - 1 = 0,\quad 10 - 1 = 1$$

最后一条表示本位不够减时向高位借 1, 借来的 1 在本位当 2 用.

## 三、乘法

二进制乘法由"移位 + 相加"两步组成: 乘数某位为 1 就把被乘数左移相应位数得到一个部分积, 为 0 则部分积为 0, 最后把所有部分积相加.

例:$1011 \times 1101$

```
     1011
   x 1101
   ------
     1011        (乘数第0位为1)
    0000         (乘数第1位为0, 左移1位)
   1011          (乘数第2位为1, 左移2位)
  1011           (乘数第3位为1, 左移3位)
  --------
 10001111
```

结果为 $(10001111)_2 = 143$, 与十进制 $11 \times 13 = 143$ 一致.

## 四、除法

二进制除法与十进制长除法同构: 从被除数高位开始逐位与除数比较, 够减则商 1 并做减法, 不够减则商 0, 然后把下一位移下来继续. 硬件实现上通常转化为"移位 + 减法"的循环.

## 五、移位与乘除 2 的关系

- 左移 1 位等价于乘以 2, 左移 $n$ 位等价于乘以 $2^n$.
- 右移 1 位等价于除以 2(整数除法向下取整), 右移 $n$ 位等价于除以 $2^n$.

这是移位寄存器和乘法器设计的理论基础.

## 六、定点数与浮点数

**定点数**: 小数点在数中的位置固定不变.

1. 定点整数: 小数点固定在最低位右侧.
2. 定点小数: 小数点固定在最高位左侧, 常用于表示绝对值小于 1 的数.

定点数表示范围小, 精度固定, 但运算电路简单.

**浮点数**: 一个数 $N$ 表示为

$$N = M \cdot R^{E}$$

其中 $M$ 是尾数(决定精度),$E$ 是阶码(决定范围),$R$ 是阶的基数(通常为 2). 小数点位置随阶码浮动, 因此可以在不增加位数的前提下大幅扩展表示范围. IEEE 754 标准是浮点数最通行的编码规范.

| 对比项   | 定点数                 | 浮点数               |
| -------- | ---------------------- | -------------------- |
| 表示范围 | 小                     | 大                   |
| 精度     | 全程一致               | 随数量级变化         |
| 运算电路 | 简单                   | 复杂(需对阶, 规格化) |
| 典型应用 | 嵌入式定点 DSP, 计数器 | 通用处理器, 科学计算 |

## 易错点

- 二进制乘法中部分积的**对齐方向**容易写错: 第 $i$ 位对应的部分积要左移 $i$ 位.
- 移位运算要注意位宽: 在固定位宽下左移会丢失高位, 这正是溢出产生的根源之一.
