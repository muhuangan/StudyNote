# 典型共形映射

求区域间的共形映射没有通用公式, 但有一组**标准映射**可以把常见区域依次化简: 角形域用幂函数, 带形域与半带形域用指数函数, 一般区域用分式线性映射化到上半平面. 掌握这几个映射的"作用方向", 大多数题目都能拆成几步来做.

## 一、幂函数与根式函数

**映射**:

$$w = z^n\qquad(n\text{ 为正整数})$$

**作用**: 把角形域 $0<\arg z<\frac{\pi}{n}$ 映为上半平面, 更一般地把张角为 $\frac{\pi}{n}$ 的角形域映为张角为 $\pi$ 的角形域(**张角放大 $n$ 倍**).

**逆映射** $w = z^{1 / n}$(取单值分支) 把张角缩小为 $\frac1n$.

**典型用法**: 把张角为 $\frac{\pi}{n}$ 的角形域化为上半平面, 再接分式线性映射化为单位圆.

**例**: $w = z^2$ 把第一象限 $0<\arg z<\frac\pi2$ 映为上半平面.

**一般情形**: 把顶点在 $z_0$、张角为 $\alpha$ 的角形域映为上半平面, 用

$$w = (z - z_0)^{\pi/\alpha}$$

## 二、指数函数与对数函数

**映射**:

$$w = e^z$$

**作用**: 把**水平带形域** $0<\operatorname{Im}z<\pi$ 映为**上半平面**, 把宽度为 $\alpha$ 的水平带形域 $0<\operatorname{Im}z<\alpha$ 映为张角为 $\alpha$ 的角形域.

**原理**: 设 $z = x + iy$, 则 $w = e^xe^{iy}$. 竖直线 $x = c$ 映为圆 $|w|=e^c$, 水平线 $y = c$ 映为射线 $\arg w = c$. 因此**带形域被"卷"成角形域**.

**逆映射** $w=\ln z$ 把角形域化为带形域.

**典型用法**: 处理**半带形域**(如 $x<0,\ 0<y<\pi$) 时, 先用 $e^z$ 化为半圆域, 再用分式线性映射化为单位圆.

## 三、分式线性映射

**作用**: 把**广义圆**映为**广义圆**, 因此可以把圆、半平面互相转化.

**最常用的三个**:

| 目标区域                      | 映射                       |
| ----------------------------- | -------------------------- |
| 上半平面 $\to$ 单位圆         | $w=\dfrac{z - i}{z + i}$   |
| 单位圆 $\to$ 上半平面         | $w=-i\dfrac{z - 1}{z + 1}$ |
| 单位圆 $\to$ 单位圆(保持原点) | $w = e^{i\theta}z$         |
| 右半平面 $\to$ 单位圆         | $w=\dfrac{1 - z}{1 + z}$   |

**一般形式**(把单位圆映为单位圆):

$$w = e^{i\theta}\frac{z - a}{1-\overline az},\qquad |a|<1$$

**一般形式**(把上半平面映为单位圆, 指定 $z_0$ 映为原点):

$$w = e^{i\theta}\frac{z - z_0}{z-\overline{z_0}},\qquad \operatorname{Im}z_0>0$$

## 四、组合使用的策略

**核心思路**: 把复杂区域经**几步**标准映射逐步化为标准区域.

**示例: 把半带形域 $D=\{z:\operatorname{Re}z<0,\ 0<\operatorname{Im}z<\pi\}$ 映为单位圆**

- **第一步**: $w_1 = e^z$. 检验: $z$ 在 $D$ 中时 $w_1 = e^xe^{iy}$, 其中 $x<0$ 给出 $|w_1|<1$, $0<y<\pi$ 给出 $0<\arg w_1<\pi$. 故 $D$ 映为**上半单位圆**.
- **第二步**: 用分式线性映射把上半单位圆映为上半平面或直接化为单位圆.

**要点**: 每一步都先问"这一步把边界的哪部分映到哪里", 用边界对应关系确认方向是否正确.

## 五、例题

**例 1**: 求把角形域 $0<\arg z<\frac\pi4$ 映为上半平面的映射.

解: 张角为 $\frac\pi4$, 需要放大 4 倍到 $\pi$, 故取 $n=\frac{\pi}{\pi / 4} = 4$:

$$w = z^4$$

**验算**: 取 $z = e^{i\pi / 8}$(在角内), $w = e^{i\pi / 2} = i$, 落在上半平面 ✓.

**例 2**: 求把带形域 $0<\operatorname{Im}z<\pi$ 映为单位圆的映射.

解: **第一步** 用 $w_1 = e^z$ 化为上半平面: 当 $0<\operatorname{Im}z<\pi$ 时 $0<\arg w_1<\pi$, 即 $\operatorname{Im}w_1>0$.

**第二步** 用 $w=\dfrac{w_1 - i}{w_1 + i}$ 把上半平面映为单位圆.

**合成**:

$$w=\frac{e^z - i}{e^z + i}$$

**验算**: 取 $z = i\frac\pi2$($\operatorname{Im}z=\frac\pi2$, 在带内), $e^z = e^{i\pi / 2} = i$, 代入得 $w=\frac{i - i}{i + i} = 0$, 落在单位圆内 ✓.

**例 3**: 求把右半平面 $\operatorname{Re}z>0$ 映为上半平面的映射.

解: 右半平面的边界是虚轴, 应映为实轴.

**方法一(旋转)**: 乘 $i$ 可使虚轴变为实轴: $w = iz$. 检验: $z = 1$ 在右半平面, $w = i$ 在上半平面 ✓.

**方法二(分式线性)**: 也可用 $w=\dfrac{z - 0}{z + 0}\cdot k$ 型.

**方法一最简**:

$$w = iz$$

**例 4**: 求把圆环 $1<|z|<2$ 映为圆环的映射(说明不可能映为单位圆).

解: 分式线性映射把广义圆映为广义圆, 因此圆环的两个边界(两个同心圆) 会映为两条不相交的广义圆. 要保持"同心"这一结构, 只有在特定条件下才可能.

**若要求把圆环映为圆环**且保持原点对应原点, 可取 $w = kz$. 此时两个圆周映为半径 $k$ 与 $2k$ 的圆周, 仍是圆环.

**结论**: $w = kz\ (k\neq0)$ 把 $1<|z|<2$ 映为 $|k|<|w|<2|k|$.

**要点**: **圆环不能映为单连通的单位圆**------因为共形映射保持连通数(洞的个数), 单连通区域与二连通区域不可能共形等价. 这是拓扑上的限制.

**例 5**(综合): 求把上半平面去掉上半单位圆后的区域 $\{z:\operatorname{Im}z>0,\ |z|>1\}$ 映为上半个带形域的思路.

解: 这类区域用**分式线性映射**先把两个边界圆(实轴与单位圆) 化成两条平行直线或两条相交直线.

关键在于: 两个边界圆都经过点 $z=\pm1$. 取把 $z = 1$ 映为 $0$、$z=-1$ 映为 $\infty$ 的分式线性映射(例如 $w=\frac{z - 1}{z + 1}$), 则两个圆都过 $z=-1$(映为 $\infty$), 故两个圆都映为**过原点的直线**(两条射线), 于是区域被映为**角形域**. 再用幂函数把角形域变为上半平面.

**这一步的道理**: 两个边界圆在 $z=-1$ 处相交成某个夹角; 映射把交点送到 $\infty$, 使两圆变成两条直线, 而夹角保持不变------角形域的张角就等于原两圆在交点处的夹角.

## 六、易错点

- 把幂函数的张角关系记反: $w = z^n$ 把张角**放大 $n$ 倍**, 不是缩小.
- 指数函数的带形宽度与角形张角对应关系弄错: 宽度 $\alpha$ 的带形映为张角 $\alpha$ 的角形.
- 忘记每一步都要检查"区域内点映到区域内".
- 试图把圆环共形映为单位圆(违反拓扑限制).
- 组合映射时把顺序弄反: **应当按作用顺序依次复合**, 后作用的写在左边(作为外层函数).
