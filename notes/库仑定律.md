# 库仑定律

库仑定律是静电场理论的实验基础, 它给出真空中两个静止点电荷之间的相互作用力.

## 一、定律内容

真空中两个静止点电荷 $q_1$ 与 $q_2$ 之间的作用力:

**大小**: 与两电荷量的乘积成正比, 与它们之间距离的平方成反比;

**方向**: 沿两电荷的连线; 同号相斥, 异号相吸.

**矢量表达式**:

$$\boldsymbol F_{12}=\frac{q_1q_2}{4\pi\varepsilon_0R^2}\boldsymbol e_R$$

其中:

- $\boldsymbol F_{12}$ 是 $q_2$ 对 $q_1$ 的作用力(作用在被施力者上);
- $\boldsymbol R$ 是从 $q_2$ 指向 $q_1$ 的矢量, $R=|\boldsymbol R|$, $\boldsymbol e_R=\boldsymbol R / R$;
- $\varepsilon_0$ 是**真空介电常数**:
  $$\varepsilon_0=\frac{1}{36\pi}\times10^{-9}\ \text{F/m}\approx8.854\times10^{-12}\ \text{F/m}$$

**注意符号**: 公式中的 $q_1q_2$ 保留正负号. 若 $q_1q_2>0$ 则 $\boldsymbol F_{12}$ 与 $\boldsymbol e_R$ 同向(斥力); 若 $q_1q_2<0$ 则反向(引力).

## 二、叠加原理

点电荷系对某点电荷的作用力等于**各点电荷单独作用力的矢量和**:

$$\boldsymbol F=\sum_{i = 1}^{n}\boldsymbol F_i=\frac{q}{4\pi\varepsilon_0}\sum_{i = 1}^{n}\frac{q_i}{R_i^2}\boldsymbol e_{Ri}$$

叠加原理是静电场可以线性叠加的根源, 也是引入"电场强度"概念的动机.

## 三、例题

**例 1**: 在真空中, 点电荷 $q_1 = 2\times10^{-6}\ \text{C}$ 位于原点, $q_2=-3\times10^{-6}\ \text{C}$ 位于 $(0,3,0)\ \text{m}$. 求 $q_2$ 对 $q_1$ 的作用力.

解: 从 $q_2$ 指向 $q_1$ 的矢量 $\boldsymbol R = (0,-3,0)$, $R = 3$, $\boldsymbol e_R=-\boldsymbol e_y$:

$$\boldsymbol F_{12}=\frac{(2\times10^{-6})(-3\times10^{-6})}{4\pi\varepsilon_0\times3^2}(-\boldsymbol e_y)$$

代入 $\dfrac{1}{4\pi\varepsilon_0}\approx9\times10^9$:

$$\boldsymbol F_{12}=\frac{9\times10^9\times(-6\times10^{-12})}{9}(-\boldsymbol e_y) = (-6\times10^{-3})(-\boldsymbol e_y) = 6\times10^{-3}\boldsymbol e_y\ \text{N}$$

**方向判读**: 结果沿 $+\boldsymbol e_y$, 即从 $q_1$(原点)指向 $q_2$, 表现为**吸引**(两电荷异号), 与物理直觉一致.

**例 2**: 三个等量同号点电荷 $q$ 位于边长 $a$ 的等边三角形顶点, 求每个电荷所受的合力.

解: 任取一个电荷, 它受另外两个电荷的斥力, 大小均为

$$F_1=\frac{q^2}{4\pi\varepsilon_0a^2}$$

两力夹角为 $60^\circ$, 合力大小为

$$F = 2F_1\cos30^\circ=\sqrt3\,F_1=\frac{\sqrt3\,q^2}{4\pi\varepsilon_0a^2}$$

方向沿三角形角的**外角平分线**(背离重心).

**例 3**: 说明为什么库仑定律以 $1 / R^2$ 出现而非其他幂次.

解: $1 / R^2$ 的规律使穿过任意半径球面的通量恒为 $\dfrac{q}{\varepsilon_0}$, 与半径无关; 这正是高斯定理得以成立的关键. 实验上, 库仑定律的幂次偏差小于 $10^{-16}$ 量级.

## 四、易错点

- 把"从谁指向谁"写反: 公式中 $\boldsymbol e_R$ 的方向是**从施力电荷指向受力电荷**.
- 忘记保留电荷的正负号, 导致力的方向判断错误.
- 只在"**静止, 点电荷, 真空**"三个前提下严格成立; 带电体须用积分或高斯定理.
- 把 $1 / (4\pi\varepsilon_0)$ 的数值记错: 约为 $9\times10^9$.
