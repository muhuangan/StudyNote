# 常见分布的期望与方差

把各个标准分布的期望与方差整理成一张表, 做题时直接查用; 表中的每个结论都可以由前面各篇的推导得到.

## 一、离散型分布

| 分布       | 记号                  | 分布律                                  | 期望 $E(X)$     | 方差 $D(X)$                                                 |
| ---------- | --------------------- | --------------------------------------- | --------------- | ----------------------------------------------------------- |
| 0-1 分布   | $\text{Bernoulli}(p)$ | $p^k(1 - p)^{1 - k},\ k = 0,1$          | $p$             | $p(1 - p)$                                                  |
| 二项分布   | $B(n,p)$              | $C_n^kp^k(1 - p)^{n - k}$               | $np$            | $np(1 - p)$                                                 |
| 泊松分布   | $P(\lambda)$          | $\dfrac{\lambda^k}{k!}e^{-\lambda}$     | $\lambda$       | $\lambda$                                                   |
| 几何分布   | $Ge(p)$               | $q^{k - 1}p,\ k\ge1$                    | $\dfrac1p$      | $\dfrac{1 - p}{p^2}$                                        |
| 超几何分布 | $H(N,M,n)$            | $\dfrac{C_M^kC_{N - M}^{n - k}}{C_N^n}$ | $\dfrac{nM}{N}$ | $\dfrac{nM}{N}\left(1-\dfrac MN\right)\dfrac{N - n}{N - 1}$ |

## 二、连续型分布

| 分布     | 记号              | 密度                                                           | 期望 $E(X)$        | 方差 $D(X)$             |
| -------- | ----------------- | -------------------------------------------------------------- | ------------------ | ----------------------- |
| 均匀分布 | $U(a,b)$          | $\dfrac{1}{b - a},\ a<x<b$                                     | $\dfrac{a + b}{2}$ | $\dfrac{(b - a)^2}{12}$ |
| 指数分布 | $E(\theta)$       | $\dfrac1\theta e^{-x/\theta},\ x>0$                            | $\theta$           | $\theta^2$              |
| 正态分布 | $N(\mu,\sigma^2)$ | $\dfrac{1}{\sqrt{2\pi}\sigma}e^{-\frac{(x-\mu)^2}{2\sigma^2}}$ | $\mu$              | $\sigma^2$              |

(指数分布若写成 $\lambda e^{-\lambda x}$ 的形式, 则 $E(X)=\frac1\lambda$, $D(X)=\frac{1}{\lambda^2}$.)

## 三、记忆要点

- **泊松分布**: 期望与方差**相等**, 都是 $\lambda$——这是它最显眼的特征;
- **二项分布**: 相当于 $n$ 个独立 0-1 变量之和, 期望与方差都是 0-1 分布的 $n$ 倍;
- **正态分布**: 两个参数直接就是期望与方差;
- **指数分布**: 标准差等于均值, 变异系数恒为 1;
- **均匀分布**: 方差只依赖区间长度;
- **几何分布**: 期望 $\frac1p$ 很直观(每次成功概率 $p$, 平均 $\frac1p$ 次成功一次).

## 四、例题

**例 1**: 设 $X\sim B(20,0.4)$. 求 $E(X)$, $D(X)$, $E(3X - 2)$ 与 $D(3X - 2)$.

解: $E(X) = 20\times0.4 = 8$, $D(X) = 20\times0.4\times0.6 = 4.8$:

$$E(3X - 2) = 3\times8 - 2 = 22,\qquad D(3X - 2) = 9\times4.8 = 43.2$$

**例 2**: 设 $X\sim P(3)$, 求 $E(X^2)$.

解: 由 $D(X) = E(X^2) - [E(X)]^2$ 及 $E(X) = D(X) = 3$:

$$E(X^2) = D(X) + [E(X)]^2 = 3 + 9 = 12$$

**例 3**: 设 $X\sim U(2,8)$, 求 $E(X)$, $D(X)$ 与标准差.

解:

$$E(X)=\frac{2 + 8}{2} = 5,\qquad D(X)=\frac{(8 - 2)^2}{12}=\frac{36}{12} = 3,\qquad \sigma_X=\sqrt3\approx1.732$$

**例 4**: 某元件的寿命 $X\sim E(\theta)$, 已知 $E(X) = 2000$ 小时. 求其标准差, 以及寿命超过 3000 小时的概率.

解: $\theta = 2000$, 故 $\sigma_X=\theta = 2000$ 小时;

$$P(X>3000) = e^{-3000 / 2000} = e^{-1.5}\approx0.2231$$

**例 5**(反向求参数): 设 $X\sim B(n,p)$, 已知 $E(X) = 6$, $D(X) = 2.4$, 求 $n$ 与 $p$.

解: 由 $np = 6$ 与 $np(1 - p) = 2.4$:

$$1 - p=\frac{2.4}{6} = 0.4\ \Rightarrow\ p = 0.6,\qquad n=\frac{6}{0.6} = 10$$

## 五、易错点

- 把 $N(\mu,\sigma^2)$ 的方差写成 $\sigma$: 第二个参数本身已是方差.
- 二项分布的方差写成 $np$: 正确是 $np(1 - p)$.
- 指数分布 $\theta$ 与 $\lambda$ 两种参数混用, 导致期望倒置.
- 几何分布的方差写成 $\frac{1 - p}{p}$: 分母应平方.
- 超几何分布与二项分布混用: 不放回抽样要用超几何的方差.
