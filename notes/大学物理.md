# 大学物理

大学物理的电磁学部分从**实验定律**出发, 用积分形式的方程刻画场的规律, 强调物理图像与量级估算; 后续的《电磁场与波》则进一步引入矢量微积分, 把同一套规律改写成微分形式并推广到时变场.

这套笔记先建立**静电学**与**静磁学**两部分, 覆盖电荷与库仑定律、电场与高斯定理、电位、导体与电介质、电容与电场能量, 以及磁场与毕奥-萨伐尔定律、安培环路定理、洛伦兹力、磁介质与磁场能量.

## 主线与要点

**静电学**的逻辑链是: 电荷守恒与库仑定律确立实验基础 → 引入电场强度(矢量)与电位(标量)两种描述 → 用高斯定理处理对称分布、用环路定理处理电位 → 讨论导体(电荷全在表面、内部无场)与电介质(极化、电位移矢量)这两类特殊介质 → 最后落到电容与电场能量.

**静磁学**的逻辑链是: 由电流的磁效应引入磁感应强度 → 毕奥-萨伐尔定律给出任意电流分布的场 → 用安培环路定理处理对称分布 → 讨论磁场对运动电荷(洛伦兹力)与载流导线(安培力、磁力矩)的作用 → 引入磁介质与铁磁质 → 最后落到自感、互感与磁场能量.

**贯穿两部分的对应关系**:

| 电场                                                                 | 磁场                                                        |
| -------------------------------------------------------------------- | ----------------------------------------------------------- |
| 库仑定律                                                             | 毕奥-萨伐尔定律                                             |
| 高斯定理 $\oint\boldsymbol D\cdot d\boldsymbol S = q_0$              | 磁通连续性 $\oint\boldsymbol B\cdot d\boldsymbol S = 0$     |
| 环路定理 $\oint\boldsymbol E\cdot d\boldsymbol l = 0$                | 安培环路定理 $\oint\boldsymbol H\cdot d\boldsymbol l = I_0$ |
| 电位 $V=\displaystyle\int_a^\infty\boldsymbol E\cdot d\boldsymbol l$ | (无对应标量, 磁场非保守场)                                  |
| 电介质极化 → 电位移矢量                                              | 磁介质磁化 → 磁场强度                                       |
| 电场能量密度 $\dfrac12\varepsilon E^2$                               | 磁场能量密度 $\dfrac{B^2}{2\mu}$                            |

**最值得留意的一处不对称**: 静电场有电位(因为它是保守场), 而恒定磁场没有对应的标量势(因为电场力做功为零、磁场力做功恒为零但磁感线是闭合的). 因此电学中"由电位求场强"的便利在磁学中要用"由 $\boldsymbol H$ 求 $\boldsymbol B$"来部分替代.
