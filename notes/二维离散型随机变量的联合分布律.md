# 二维离散型随机变量的联合分布律

二维离散型随机变量的全部信息都写在一张**联合分布表**里, 行和列的和分别给出两个边缘分布.

## 一、定义

若 $(X,Y)$ 的所有可能取值只有有限对或可列无穷多对, 则称 $(X,Y)$ 为**二维离散型随机变量**. 称

$$P(X=x_i,\ Y=y_j)=p_{ij},\qquad i,j=1,2,\ldots$$

为它的**联合分布律**.

## 二、性质

**(1) 非负性**: $p_{ij}\ge0$;

**(2) 归一性**:

$$\sum_{i}\sum_{j}p_{ij}=1$$

**(3) 任意事件的概率**:

$$P\bigl((X,Y)\in D\bigr)=\sum_{(x_i,y_j)\in D}p_{ij}$$

## 三、表格表示

把 $p_{ij}$ 排成表格, 行对应 $X$, 列对应 $Y$, **右侧列出各行之和** $p_{i\cdot}=P(X=x_i)$(边缘分布律), **最下行列出各列之和** $p_{\cdot j}=P(Y=y_j)$:

| $X\backslash Y$ | $y_1$        | $y_2$        | $\cdots$ | $p_{i\cdot}$ |
| --------------- | ------------ | ------------ | -------- | ------------ |
| $x_1$           | $p_{11}$     | $p_{12}$     | $\cdots$ | $p_{1\cdot}$ |
| $x_2$           | $p_{21}$     | $p_{22}$     | $\cdots$ | $p_{2\cdot}$ |
| $\vdots$        | $\vdots$     | $\vdots$     |          | $\vdots$     |
| $p_{\cdot j}$   | $p_{\cdot1}$ | $p_{\cdot2}$ | $\cdots$ | 1            |

**边缘分布律由联合分布律"行和 / 列和"得到**:

$$p_{i\cdot}=\sum_jp_{ij}=P(X=x_i),\qquad p_{\cdot j}=\sum_ip_{ij}=P(Y=y_j)$$

## 四、独立性的判据

$X$ 与 $Y$ **独立** $\iff$ 对所有 $i,j$ 都有

$$p_{ij}=p_{i\cdot}\,p_{\cdot j}$$

即"**每个格子都等于其所在行和与列和的乘积**". 只要有一个格子不满足, 就不独立.

## 五、例题

**例 1**: 袋中有 2 个红球, 3 个白球, 不放回地依次取两球. 令 $X=1$ 表示第一次取到红球, $Y=1$ 表示第二次取到红球($0$ 表示取到白球). 求 $(X,Y)$ 的联合分布律, 两个边缘分布律, 并判断独立性.

解: 逐个计算:

$$p_{11}=P(X=1,Y=1)=\frac25\times\frac14=\frac{1}{10}$$
$$p_{10}=P(X=1,Y=0)=\frac25\times\frac34=\frac{3}{10}$$
$$p_{01}=P(X=0,Y=1)=\frac35\times\frac24=\frac{3}{10}$$
$$p_{00}=P(X=0,Y=0)=\frac35\times\frac24=\frac{3}{10}$$

校验: $\frac{1+3+3+3}{10}=1$.

| $X\backslash Y$ | $0$            | $1$            | $p_{i\cdot}$   |
| --------------- | -------------- | -------------- | -------------- |
| $0$             | $\frac{3}{10}$ | $\frac{3}{10}$ | $\frac{6}{10}$ |
| $1$             | $\frac{3}{10}$ | $\frac{1}{10}$ | $\frac{4}{10}$ |
| $p_{\cdot j}$   | $\frac{6}{10}$ | $\frac{4}{10}$ | 1              |

边缘分布: $P(X=1)=\frac25$, $P(Y=1)=\frac25$, 都服从参数为 $\frac25$ 的 0-1 分布.

**独立性检验**: $p_{11}=\frac{1}{10}$, 而 $p_{1\cdot}p_{\cdot1}=\frac{4}{10}\times\frac{4}{10}=\frac{4}{25}=0.16$. 因 $\frac{1}{10}=0.1\ne0.16$, 故 $X$ 与 $Y$ **不独立**(不放回抽样导致的依赖).

**例 2**: 把两枚硬币各掷一次, 令 $X$ 为第一枚的正面次数, $Y$ 为两枚的正面总数. 求联合分布律.

解: $(X,Y)$ 的可能取值: $(0,0),(0,1),(1,1),(1,2)$(注意 $X\le Y$ 恒成立).

$$P(X=0,Y=0)=P(TT)=\frac14$$
$$P(X=0,Y=1)=P(TH)=\frac14$$
$$P(X=1,Y=1)=P(HT)=\frac14$$
$$P(X=1,Y=2)=P(HH)=\frac14$$

| $X\backslash Y$ | 0         | 1         | 2         | $p_{i\cdot}$ |
| --------------- | --------- | --------- | --------- | ------------ |
| 0               | $\frac14$ | $\frac14$ | 0         | $\frac12$    |
| 1               | 0         | $\frac14$ | $\frac14$ | $\frac12$    |
| $p_{\cdot j}$   | $\frac14$ | $\frac12$ | $\frac14$ | 1            |

注意表中出现了 0 元素, 表示 $(0,2)$ 与 $(1,0)$ 不可能发生. 由 $p_{11}=\frac14\ne p_{1\cdot}p_{\cdot1}=\frac12\times\frac12$, 得 $X,Y$ 不独立.

## 六、易错点

- 遗漏不可能的取值组合(如例 2 中的 $(0,2)$): 表格必须覆盖全部组合, 不可能的组合写 0.
- 求边缘分布时漏加或多加某一行(列).
- 判断独立性时只检查一个格子就下结论 "独立": 必须**所有**格子都验证; 但发现**一个**格子不满足即可断定**不独立**.
- 把"不放回"误当作独立: 不放回抽样一般导致不独立.
