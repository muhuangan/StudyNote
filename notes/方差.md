# 方差

期望刻画"中心在哪", 方差刻画"离散到什么程度". 两者合起来才能大致描述一个分布的面貌.

## 一、定义

设 $X$ 是一个随机变量, 若 $E\bigl\{[X - E(X)]^2\bigr\}$ 存在, 则称它为 $X$ 的**方差**, 记作 $D(X)$ 或 $\operatorname{Var}(X)$:

$$D(X) = E\bigl\{\bigl[X - E(X)\bigr]^2\bigr\}$$

称 $\sqrt{D(X)}$ 为 $X$ 的**标准差**(均方差), 记作 $\sigma_X$.

**直观含义**: $X - E(X)$ 是"偏离中心的量", 平方后消去符号, 再取期望就是"平均平方偏离". 开方得到标准差, 使单位与 $X$ 一致.

## 二、计算方差的简公式

$$D(X) = E(X^2)-\bigl[E(X)\bigr]^2$$

**证明**: 记 $\mu = E(X)$, 展开平方:

$$D(X) = E\bigl[(X-\mu)^2\bigr] = E\bigl(X^2 - 2\mu X+\mu^2\bigr) = E(X^2) - 2\mu E(X)+\mu^2 = E(X^2)-\mu^2$$

**用法**: 只要分别求出 $E(X)$ 与 $E(X^2)$ 即可, 不必先算 $X - E(X)$ 的分布.

## 三、离散与连续情形的算法

**离散**: $D(X)=\displaystyle\sum_k x_k^2p_k-\left(\sum_kx_kp_k\right)^2$;

**连续**: $D(X)=\displaystyle\int_{-\infty}^{+\infty}x^2f(x)dx-\left(\int_{-\infty}^{+\infty}xf(x)dx\right)^2$.

## 四、例题

**例 1**: 掷一颗均匀骰子, 求 $D(X)$.

解: 已知 $E(X) = 3.5$. 再求

$$E(X^2)=\sum_{k = 1}^{6}k^2\cdot\frac16=\frac{1 + 4 + 9 + 16 + 25 + 36}{6}=\frac{91}{6}\approx15.1667$$

故

$$D(X)=\frac{91}{6}-\left(\frac72\right)^2=\frac{91}{6}-\frac{49}{4}=\frac{182 - 147}{12}=\frac{35}{12}\approx2.9167$$

**例 2**: 设 $X\sim U(0,1)$, 求 $D(X)$.

解:

$$E(X)=\frac12,\qquad E(X^2)=\int_0^1x^2dx=\frac13$$
$$D(X)=\frac13-\frac14=\frac{1}{12}\approx0.0833$$

**例 3**: 设 $X\sim\text{Bernoulli}(p)$, 求 $D(X)$.

解: $E(X) = p$, $E(X^2) = p$(因为 $X^2 = X$), 故

$$D(X) = p - p^2 = p(1 - p)$$

**例 4**(由方差反求参数): 设 $X\sim N(\mu,\sigma^2)$ 且 $E(X) = 1$, $D(X) = 4$, 写出 $X$ 的分布.

解: $\mu = E(X) = 1$, $\sigma^2 = D(X) = 4$, 故

$$X\sim N(1,4)$$

**注意** $N(\mu,\sigma^2)$ 中第二个参数是**方差**, 所以这里不能写 $N(1,2)$.

## 五、方差为 0 的含义

$$D(X) = 0\iff P\bigl(X = E(X)\bigr) = 1$$

即方差为 0 当且仅当 $X$ 几乎处处取常数. 因此"$D(X) = 0$"是判断退化分布的依据.

## 六、易错点

- 把方差写成 $E\bigl[(X - E(X))\bigr]$: 少了平方, 结果恒为 0, 毫无意义.
- 忘记 $[E(X)]^2$ 那一项: 简公式是 $E(X^2) - [E(X)]^2$, 不是 $E(X^2) - E(X)$.
- 把 $D(X)$ 与 $D(X^2)$ 混淆.
- 忘记方差量纲是 $X$ 的平方, 比较离散程度时应看标准差.
- 认为 $D(X)\ge0$ 是"显然的"而忽略: 它正是简公式的必然推论, 也用于校验计算.
