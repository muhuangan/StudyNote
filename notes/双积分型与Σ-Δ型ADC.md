# 双积分型与Σ-Δ型ADC

## 核心结论

**双积分型**用"两次积分的时间比"求电压, 结果与 R, C 的绝对值无关, 精度高, 抗工频干扰强, 但速度慢, 是数字万用表的标准方案.**Σ-Δ 型**用"过采样 + 噪声整形 + 数字滤波"换取极高的分辨率(16 至 24 位), 速度低, 是高精密测量与音频的主流.

## 一、双积分型(双斜率) ADC

**结构**: 积分器 + 比较器 + 计数器 + 控制逻辑 + 两个极性相反的参考电压.

**工作过程(两个阶段)**:

**第一阶段—对输入电压定时积分($T_1$ 固定)**:

闭合开关把被测电压 $v_I$ 接入积分器, 积分时间固定为 $T_1$(由计数器计满确定). 积分器输出为

$$v_{O1} = -\frac{1}{RC}\int_0^{T_1} v_I\, dt = -\frac{T_1}{RC} \cdot \overline{v_I}$$

**第二阶段—对参考电压反向积分($T_2$ 测量)**:

切换到与 $v_I$ 极性相反的参考电压 $-V_{REF}$, 积分器输出从 $v_{O1}$ 向 0 回扫, 同时计数器开始计数, 直到输出过零:

$$0 = v_{O1} + \frac{1}{RC}\int_{T_1}^{T_1 + T_2} V_{REF}\, dt = v_{O1} + \frac{T_2}{RC} V_{REF}$$

**求解得**:

$$T_2 = \frac{T_1}{V_{REF}} \cdot \overline{v_I}$$

$$\overline{v_I} = \frac{T_2}{T_1} \cdot V_{REF}$$

**关键结论**:

1. 结果只取决于 $T_2 / T_1$ 与 $V_{REF}$,**与 R, C 的具体数值无关**, 因此对元件精度要求低.
2. 结果是对输入在 $T_1$ 内的**平均值**, 因此叠加在输入上的周期性干扰(尤其是工频 50 Hz) 若其周期为 $T_1$ 的整数倍, 会被**完全平均掉**—这是双积分型抗工频干扰的根本原因.
3. 若取 $T_1$ 为 20 ms(50 Hz 的一个周期), 可极大抑制工频串模干扰.

**优点**: 精度高, 成本低, 抗干扰能力强.

**缺点**: **速度慢**(转换时间为 $T_1 + T_2$, 通常毫秒至百毫秒量级), 不适合高速采集.

**典型应用**: 数字万用表, 精密直流电压表, 温度/压力等慢变信号测量. 典型芯片: ICL7106/7107(3 位半数字表专用).

## 二、Σ-Δ(Sigma-Delta) 型 ADC

**核心思想三要素**: **过采样(Oversampling)+ 噪声整形(Noise Shaping)+ 数字抽取滤波**.

### 1. 过采样

以远高于奈奎斯特频率的速率采样, 设过采样比为

$$OSR = \frac{f_s}{2 f_m}$$

过采样把量化噪声的功率摊薄到更宽的频带上, 使**信号频带内**的噪声功率下降. 仅靠过采样, 信噪比改善为

$$\Delta \text{SNR} = 10 \log_{10}(OSR)\ \text{dB}$$

即 OSR 每提高 4 倍, SNR 提高 6 dB(相当于 1 位).

### 2. 噪声整形

Σ-Δ 调制器的结构:

```
输入 → Σ(求和) → ∫(积分器) → 量化器(1位或多位) → 数字输出
                    ↑                    │
                    └──── D/A 反馈 ──────┘
```

- 积分器对"输入与反馈之差"进行累积.
- 量化器通常是**1 位**的(只输出 0 或 1), 线性度天然完美.
- 反馈环使量化噪声被**高通整形**: 低频段的量化噪声被大幅压低, 噪声被推到高频段.

**噪声整形的效果**: 一阶 Σ-Δ 调制器的带内噪声随频率升高而增大, SNR 改善为

$$\Delta \text{SNR} = 30 \log_{10}(OSR)\ \text{dB}$$

即 OSR 每提高 2 倍, SNR 提高 9 dB(相当于 1.5 位). 高阶调制器(二阶, 三阶) 效果更强.

### 3. 数字抽取滤波

用一个数字低通滤波器滤掉被推到高频的量化噪声, 再按抽取比降低数据率, 得到高分辨率的低速输出.

**最终效果**: 用极高的采样率(MHz 级) 换取极高的分辨率(16 至 24 位) 和较低的输出速率(Hz 至 kHz 级).

**优点**:

1. 分辨率极高(16 至 24 位).
2. 内部量化器位數少, 线性度好, 成本低.
3. 对前端抗混叠滤波器要求低(因为过采样使过渡带很宽).

**缺点**:

1. **速度低**: 输出速率通常只有几 Hz 到几百 kSPS.
2. 存在**建立时间**(数字滤波器的群延迟), 不适合需要快速响应的多路切换采集.
3. 对时钟抖动敏感.

**典型应用**:

- 音频 ADC/DAC(24 位, 48 kHz 是标准配置).
- 精密测量(电子秤, 压力传感器, 温度传感器).
- 地震勘探, 医疗仪器.

典型芯片: ADS1232(24 位, 电子秤), ADS1256(24 位, 8 通道), CS5343(音频 ADC).

## 三、两类 ADC 的对比

| 对比项         | 双积分型             | Σ-Δ 型                       |
| -------------- | -------------------- | ---------------------------- |
| 原理           | 两次积分的时间比     | 过采样 + 噪声整形            |
| 分辨率         | 12 至 20 位          | **16 至 24 位**              |
| 转换速度       | 毫秒至百毫秒         | 输出速率低(但内部采样率极高) |
| 抗工频干扰     | **极强**(平均值原理) | 取决于数字滤波器配置         |
| 对元件精度要求 | 低(R, C 抵消)        | 低                           |
| 成本           | 低                   | 中                           |
| 典型应用       | 数字万用表           | 电子秤, 音频, 精密测量       |

## 四、五类 ADC 的横向对比

| 类型       | 速度 | 分辨率           | 抗干扰   | 成本 | 典型应用           |
| ---------- | ---- | ---------------- | -------- | ---- | ------------------ |
| 并联比较型 | 最快 | 低(6 至 8 位)    | 弱       | 高   | 示波器, 雷达       |
| 流水线型   | 快   | 中(10 至 16 位)  | 中       | 中高 | 通信, 视频         |
| 逐次逼近型 | 中   | 中高(8 至 18 位) | 中       | 低   | 通用采集, MCU 内置 |
| Σ-Δ 型     | 慢   | 高(16 至 24 位)  | 强       | 中   | 音频, 精密测量     |
| 双积分型   | 最慢 | 高(12 至 20 位)  | **极强** | 低   | 数字万用表         |

## 五、选型决策

1. 测**慢变直流**, 要求抗工频干扰, 成本敏感 → **双积分型**
2. 测**慢变信号**, 要求极高精度(如称重, 应变) → **Σ-Δ 型**
3. 测**音频** → **Σ-Δ 型**
4. 通用多路采集, 中等速度与精度 → **逐次逼近型**
5. 高速波形采集 → **并联比较型 / 流水线型**

## 六、使用要点

### 双积分型

1. 积分电容要选用**低漏电, 低介质吸收**的型号(聚丙烯, 聚苯乙烯), 普通电解电容不可用.
2. 积分电阻与电容的温度系数会影响精度(虽然结果与 R, C 绝对值无关, 但温漂会引入时变误差).
3. 自动校零是双积分型仪表的标准功能, 用于消除运放失调.

### Σ-Δ 型

1. 注意**输出速率与分辨率的权衡**: 多数芯片允许配置过采样比, 速率越高分辨率越低.
2. 注意数字滤波器的**建立时间**: 切换通道后要等待若干转换周期, 前面的数据无效.
3. 参考电压的稳定性直接决定精度, 高精度应用必须使用外部基准.
4. 时钟抖动会直接劣化 SNR.

## 易错点

- 认为双积分型"慢所以精度低": 恰恰相反, 它的精度很高, 慢是速度的代价而非精度的代价.
- 认为 Σ-Δ 的"1 位量化"意味着只有 1 位分辨率: 分辨率来自过采样与噪声整形后的数字滤波, 1 位只是调制器内部的量化器位數.
- 忽略 Σ-Δ 的建立时间: 切换输入通道后立刻读取, 会得到上一个通道的残留值.
