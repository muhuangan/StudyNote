# PLD的编程

## 核心结论

PLD 编程的实质是**把配置信息写入器件内部的编程单元**(熔丝, 浮栅或 SRAM 单元).**在系统可编程(ISP)**技术让器件焊接在电路板上后仍能直接编程, 是现代 PLD 的标准能力.

## 一、编程的三种物理机制

| 机制          | 原理                                               | 是否可重复 | 是否易失 |
| ------------- | -------------------------------------------------- | ---------- | -------- |
| 熔丝 / 反熔丝 | 大电流熔断(或击穿) 连接点                          | 否         | 否       |
| 浮栅注入      | 电子注入浮栅改变晶体管阈值(EPROM / EEPROM / Flash) | 是         | 否       |
| SRAM 单元     | 配置数据保存在静态存储单元中                       | 是         | **是**   |

**熔丝型**: 编程时给需要断开的连接点通以大电流, 使其熔断. 一旦熔断无法恢复, 因此是**一次性编程(OTP)**. 反熔丝相反—出厂时断开, 编程时在高电压下击穿形成连接, 同样是 OTP, 但可靠性更高(常用于航天抗辐射器件).

**浮栅型**: 利用浮栅 MOS 管保存电荷. 注入电荷使管子截止(或导通), 从而实现连接或不连接. 擦除时让电荷泄放. EEPROM 与 Flash 采用电擦除(隧道效应), 可在系统中直接操作.

**SRAM 型**: 配置数据控制着每一个可编程开关(传输门或多路选择器) 的通断. 掉电后 SRAM 内容丢失, 器件功能消失, 必须重新加载.

## 二、在系统可编程(ISP)

**定义**: 器件已经焊接在目标电路板上之后, 仍能通过简单的接口(无需专用编程器, 无需取下芯片) 完成编程与再编程.

**实现条件**:

1. 器件内部集成编程电压产生电路(电荷泵), 无需外部高压.
2. 有一个标准的串行接口用于传送配置数据(最常见的是 **JTAG**).
3. 器件内部有编程状态机控制擦除, 写入, 校验全过程.

**带来的好处**:

| 好处         | 说明                           |
| ------------ | ------------------------------ |
| 简化生产     | 可以先焊接再编程, 不必预先烧录 |
| 现场升级     | 产品出厂后仍可通过接口更新逻辑 |
| 缩短开发周期 | 反复擦写, 快速迭代             |
| 降低库存     | 同一种器件可按需配置成不同功能 |

**典型器件**: ispGAL22V10, Lattice ispMACH 系列, 各类 CPLD 与 FPGA.

## 三、JTAG(IEEE 1149.1) 接口

**四根基本信号**:

| 信号       | 名称         | 作用           |
| ---------- | ------------ | -------------- |
| TCK        | 测试时钟     | 提供移位时钟   |
| TMS        | 测试模式选择 | 控制内部状态机 |
| TDI        | 测试数据输入 | 串行输入       |
| TDO        | 测试数据输出 | 串行输出       |
| TRST(可选) | 测试复位     | 复位状态机     |

**工作原理**: 器件内部有一个 **TAP 控制器**(16 状态的状态机) 和若干**数据寄存器**与**指令寄存器**. 外部通过 TMS 序列把状态机引到相应状态, 再通过 TDI/TDO 移位读写寄存器.

**在 PLD 中的用途**:

1. **编程与配置**: 把配置数据串行移入器件.
2. **边界扫描测试**: 检测 PCB 上引脚的焊接短路/开路(这是 JTAG 最初的目的).
3. **在线调试**: 读取内部寄存器, 设置断点(如 FPGA 的 ILA, ARM 的调试接口).

**菊花链**: 多个器件的 TDI/TDO 首尾串接, TCK, TMS 并联, 可用一个接口同时配置多片.

## 四、编程文件格式

| 格式             | 适用           | 说明                                 |
| ---------------- | -------------- | ------------------------------------ |
| `.jed`(JEDEC)    | PAL, GAL, CPLD | 标准 PLD 烧录文件                    |
| `.pof`           | Altera CPLD    | 编程器目标文件                       |
| `.sof` / `.jic`  | Altera FPGA    | SRAM 目标文件 / 间接配置(烧入 Flash) |
| `.bit` / `.bin`  | Xilinx FPGA    | 位流文件                             |
| `.mcs`           | 通用           | 用于烧写外部配置 Flash               |
| `.svf` / `.xsvf` | 通用           | JTAG 操作序列, 可用于第三方编程器    |

## 五、编程的完整流程

1. **设计输入与仿真**(确认功能正确).
2. **综合与实现**(生成针对具体器件的网表与布局布线结果).
3. **生成编程文件**.
4. **连接下载电缆**(USB-Blaster, Platform Cable, FTDI 等).
5. **执行编程**: 擦除 → 写入 → 校验(CPLD/Flash 工艺); 或直接配置(SRAM 型 FPGA).
6. **验证**: 实测功能是否符合预期.

**注意**: SRAM 型 FPGA 的"编程"是**易失配置**, 若要产品化必须把位流烧入外部 Flash, 并在上电时自动加载.

## 六、加密与安全

1. **加密位**: GAL/CPLD 可设置加密位, 防止读出内部阵列(注意: 加密后无法再读出校验, 但可整体擦除后重新编程).
2. **位流加密**: FPGA 支持 AES 加密位流, 配置时在片内解密, 防止被复制.
3. **认证**: 高端器件支持 HMAC 认证, 防止加载未授权的位流.

## 七、常见故障

| 现象           | 原因                                        |
| -------------- | ------------------------------------------- |
| 无法识别器件   | JTAG 链断开, 电缆接触不良, 器件未上电       |
| 编程校验失败   | 器件已加密, 编程电压不足, 芯片损坏          |
| 配置后功能不对 | 位流文件版本与器件型号不匹配                |
| 上电后不工作   | SRAM 型 FPGA 未连接配置 Flash, 或加载未完成 |

## 八、安全操作要点

1. **禁止热插拔 JTAG 电缆**(可能损坏接口).
2. 编程前确认目标器件型号与封装.
3. 对已加密器件编程前必须先整体擦除.
4. 编程电压与时序必须按器件手册执行.

## 易错点

- 认为"编程"与"配置"是同一回事: 对 CPLD/Flash 工艺器件, 编程是**永久写入**; 对 SRAM 型 FPGA, 配置是**易失加载**, 掉电即失效.
- 认为 JTAG 只能编程: JTAG 的核心设计目的是**边界扫描测试**, 编程只是它的扩展应用之一.
