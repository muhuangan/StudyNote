# 数模与模数转换概述

## 核心结论

D/A 转换器把数字量变成模拟电压(电流), A/D 转换器把模拟电压变成数字量. 评价两者的三个通用指标是: **分辨率(能分辨多细), 转换精度(误差多大), 转换速度(多快)**, 三者相互制约.

## 一、为什么需要转换

现实世界的物理量(温度, 压力, 声音, 光强) 都是**模拟量**, 而数字系统只能处理数字量, 因此任何"数字系统 + 真实世界"的接口都需要转换:

```
物理量 → 传感器 → 信号调理 → 采样保持 → A/D → 数字系统(处理/存储)
                                                      ↓
物理量 ← 执行机构 ← 功率驱动 ← 滤波 ← D/A ←──────────┘
```

**典型应用**: 音频采集与回放, 数据采集系统, 数字电源, 电机控制, 仪器仪表.

## 二、D/A 与 A/D 的基本关系

**D/A 转换**: 输入 $n$ 位数字量 $D$, 输出与之成正比的模拟量 $v_O$.

$$v_O = K \cdot D$$

其中 $K$ 是转换比例系数.

**A/D 转换**: 输入模拟量 $v_I$, 输出 $n$ 位数字量 $D$.

$$D = \left\lfloor \frac{v_I}{K} \right\rfloor$$

**注意**: A/D 的结果必然是**量化**的(取整), 因此存在固有的量化误差; D/A 的输出是连续的.

## 三、分辨率

**定义**: 转换器能分辨的最小输入变化量, 通常用**位数**或 **1 LSB 对应的模拟量**表示.

**LSB(最低有效位) 的含义**:$n$ 位转换器的输出有 $2^n$ 个可能值, 最低位变化 1 所对应的模拟量变化量就是 1 LSB.

$$1\ \text{LSB} = \frac{V_{REF}}{2^n}$$

**相对分辨率**:

$$\text{分辨率} = \frac{1}{2^n}$$

| 位数 | 级数       | 相对分辨率   |
| ---- | ---------- | ------------ |
| 8    | 256        | 约 0.39%     |
| 10   | 1024       | 约 0.098%    |
| 12   | 4096       | 约 0.024%    |
| 16   | 65536      | 约 0.0015%   |
| 24   | 约 1677 万 | 约 0.000006% |

**注意**: 分辨率只说明"能分辨多细", 不说明"有多准". 一个 12 位转换器若误差达 10 LSB, 其有效精度远低于 12 位.

## 四、转换精度

**转换误差的主要来源**:

| 误差类型               | 含义                                        |
| ---------------------- | ------------------------------------------- |
| 失调误差(零点误差)     | 输入为 0 时输出不为 0, 可校准               |
| 增益误差(比例系数误差) | 实际转换曲线的斜率偏离理想值, 可校准        |
| 非线性误差(INL)        | 实际转换曲线偏离直线的最大偏差,**不可校准** |
| 微分非线性(DNL)        | 相邻码的步距偏离 1 LSB 的程度               |
| 量化误差               | A/D 固有的取整误差,**不可消除**             |
| 温度漂移               | 参数随温度变化                              |

**有效位数(ENOB)**: 考虑噪声与非线性后的实际可用位数, 是比"标称位数"更真实的指标.

$$\text{ENOB} = \frac{\text{SINAD} - 1.76}{6.02}$$

(SINAD 为信号与噪声加失真比, 单位 dB)

## 五、转换速度

| 指标               | 适用 | 含义                                             |
| ------------------ | ---- | ------------------------------------------------ |
| 建立时间 $t_{set}$ | D/A  | 输出达到并保持在终值 ±1 / 2 LSB 范围内所需的时间 |
| 转换时间           | A/D  | 从启动转换到得到稳定数字输出所需的时间           |
| 采样率(SPS)        | A/D  | 每秒可完成的转换次数                             |

**各类转换器的速度量级**:

| 类型               | 转换时间        | 典型分辨率  |
| ------------------ | --------------- | ----------- |
| 并联比较型(Flash)  | 纳秒级(数十 ns) | 6 至 8 位   |
| 逐次逼近型(SAR)    | 微秒级          | 8 至 18 位  |
| 流水线型(Pipeline) | 数十纳秒至微秒  | 10 至 16 位 |
| Σ-Δ 型             | 毫秒级          | 16 至 24 位 |
| 双积分型           | 毫秒至百毫秒    | 12 至 20 位 |

**速度与精度成反比**是转换器选型的基本规律.

## 六、系统层面的关键概念

| 概念               | 含义                                        |
| ------------------ | ------------------------------------------- |
| 参考电压 $V_{REF}$ | 决定转换的基准, 其精度直接决定转换精度      |
| 满量程范围(FSR)    | 输入(或输出) 的允许范围                     |
| 单调性             | 输入增大时输出数字量不减小(D/A 需要)        |
| 缺失码             | A/D 中某些数字码永远不出现(由 DNL 过大导致) |

## 七、选型要点

1. **先定分辨率**: 由被测信号的最小变化量与量程决定.
2. **再定速度**: 由信号带宽与采样定理决定.
3. **参考电压要稳**: 用高精度基准源(如 TL431, REF 系列), 不要用电源直接分压.
4. **注意接口类型**: 并行, SPI, I2C 的选择影响 MCU 资源占用与速度.
5. **模拟前端要匹配**: 信号调理(放大/衰减/滤波) 决定能否充分利用 ADC 的量程与精度.

## 易错点

- 混淆分辨率与精度: 位数多只说明"分得细", 若参考电压不准或噪声大, 实际精度远低于位数.
- 认为提高采样率就能提高精度: 分辨率由位数决定, 提高采样率只在配合平均/过采样技术时才可能改善有效位数.
