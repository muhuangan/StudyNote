# 矢量磁位与磁偶极子

矢量磁位 $\vec A$ 是求解磁场的"势函数"方法: 因为磁场无散, 必可写成某个矢量的旋度. 磁偶极子则是电流环在远区的等效模型, 与电偶极子完全对偶.

## 一、矢量磁位的引入

由[磁通连续性定理](./磁通连续性定理.md), $\nabla\cdot\vec B = 0$, 即磁场是**无散场**. 而无散场必可表示为某矢量场的旋度(见亥姆霍兹定理的推论), 故定义**矢量磁位**:

$$\vec B=\nabla\times\vec A$$

**合法性验证**: $\nabla\cdot\vec B=\nabla\cdot(\nabla\times\vec A) = 0$, 自动满足磁通连续性.

**规范问题**: 由 $\vec A$ 求 $\vec B$ 时, $\vec A$ 并不唯一——若 $\vec A'=\vec A+\nabla\psi$, 则

$$\nabla\times\vec A'=\nabla\times\vec A+\nabla\times(\nabla\psi)=\nabla\times\vec A=\vec B$$

(因为 $\nabla\times\nabla\psi=\vec 0$). 因此必须附加条件(称为**规范**), 恒定磁场通常取**库仑规范**:

$$\nabla\cdot\vec A = 0$$

## 二、矢量磁位的积分表达式

在库仑规范下, 由毕奥-萨伐尔定律可推出

$$\vec A=\frac{\mu_0}{4\pi}\int_V\frac{\vec J}{R}dV$$

**对比电位的表达式** $\varphi=\dfrac{1}{4\pi\varepsilon_0}\int\dfrac{\rho}{R}dV$: 二者结构完全平行, 只是"源"由电荷密度 $\rho$ 换成电流密度 $\vec J$, 标量换成矢量.

**要点**: 这是**矢量积分**, 需按分量计算; 但比直接算 $\vec B$ 简单, 因为分母只有 $R$ 而毕奥-萨伐尔定律的分母是 $R^2$ 且含叉乘.

## 三、磁偶极子

**定义**: 一个面积很小的平面载流回路(电流 $I$, 面积 $S$)称为**磁偶极子**, 其**磁偶极矩**为

$$\vec m = IS\,\vec e_n$$

其中 $\vec e_n$ 由电流按右手螺旋法则确定. 多匝线圈则 $\vec m = NIS\,\vec e_n$.

**远区矢量磁位**($r\gg$ 回路尺寸):

$$\vec A=\frac{\mu_0}{4\pi}\frac{\vec m\times\vec e_r}{r^2}$$

**远区磁场**与电偶极子的场**形式相同**:

$$\vec B=\frac{\mu_0}{4\pi r^3}\left[3(\vec m\cdot\vec e_r)\vec e_r-\vec m\right]$$

**与电偶极子的对偶对照**:

|        | 电偶极子                                                    | 磁偶极子                                             |
| ------ | ----------------------------------------------------------- | ---------------------------------------------------- |
| 矩     | $\vec p = q\vec d$                                          | $\vec m = IS\vec e_n$                                |
| 远区势 | $\varphi=\dfrac{\vec p\cdot\vec e_r}{4\pi\varepsilon_0r^2}$ | $\vec A=\dfrac{\mu_0\vec m\times\vec e_r}{4\pi r^2}$ |
| 场衰减 | $\propto 1 / r^3$                                           | $\propto 1 / r^3$                                    |

**意义**: 一切闭合电流回路在远区都等效为一个磁偶极子; 这也是**磁介质磁化**的微观模型(分子电流视为磁偶极子).

## 四、例题

**例 1**: 无限长直导线(沿 $z$ 轴, 电流 $I$), 求其矢量磁位.

解: 由对称性 $\vec A = A_z(\rho)\vec e_z$. 由 $\vec B=\nabla\times\vec A$:

$$B_\phi=\left(\nabla\times\vec A\right)_\phi=-\frac{\partial A_z}{\partial\rho}$$

已知 $B_\phi=\dfrac{\mu_0I}{2\pi\rho}$, 故

$$\frac{\partial A_z}{\partial\rho}=-\frac{\mu_0I}{2\pi\rho}\ \Rightarrow\ A_z=-\frac{\mu_0I}{2\pi}\ln\rho + C$$

**注意**: $\vec A$ 含任意常数(规范自由度), 且随 $\rho\to\infty$ 发散——这是因为无限长导线的理想化模型, 实际有限长度时不会出现.

**例 2**: 半径 $a = 0.01\ \text{m}$ 的单匝圆环, 电流 $I = 1\ \text{A}$, 求磁偶极矩, 并求轴线上 $r = 0.5\ \text{m}$ 处的远区磁场大小.

解:

$$m = IS = 1\times\pi a^2=\pi\times10^{-4}\approx3.14\times10^{-4}\ \text{A}\cdot\text{m}^2$$

轴线上 $\vec m\parallel\vec e_r$, 故 $(\vec m\cdot\vec e_r)\vec e_r=\vec m$:

$$B=\frac{\mu_0}{4\pi r^3}\bigl[3\vec m-\vec m\bigr]\ \Rightarrow\ B=\frac{\mu_0\,2m}{4\pi r^3}=\frac{\mu_0m}{2\pi r^3}$$

$$B=\frac{4\pi\times10^{-7}\times3.14\times10^{-4}}{2\pi\times0.125}=\frac{3.95\times10^{-10}}{0.785}\approx5.0\times10^{-10}\ \text{T}$$

**例 3**: 说明为何磁偶极子的场按 $1 / r^3$ 衰减, 而点电荷按 $1 / r^2$.

解: 电偶极子的两个电荷相距极近, 其 $1 / r^2$ 的"单极项"相互抵消, 剩下 $1 / r^3$ 的偶极项. 磁偶极子因**无磁荷**, 连单极项都不存在, 最低阶就是 $1 / r^3$ 的偶极项.

## 五、易错点

- 认为 $\vec A$ 唯一: 它有规范自由度, 必须附加 $\nabla\cdot\vec A = 0$ 之类的条件.
- 把 $\vec B=\nabla\times\vec A$ 记成 $\vec A=\nabla\times\vec B$.
- 磁偶极矩方向判错: 由电流按**右手螺旋**确定, 不是由面积法向任意选取.
- 忘记多匝线圈要乘匝数 $N$.
