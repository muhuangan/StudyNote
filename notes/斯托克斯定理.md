# 斯托克斯定理

斯托克斯定理把**沿闭合曲线的线积分**与**以该曲线为边界的曲面上的面积分**联系起来, 是麦克斯韦方程组由积分形式化为微分形式的另一条桥梁.

## 一、定理

设 $S$ 是以闭合曲线 $C$ 为边界的有向曲面, 矢量场 $\boldsymbol A$ 在含 $S$ 的区域内具有连续的一阶偏导数, 则

$$\oint_C\boldsymbol A\cdot d\boldsymbol l=\int_S(\nabla\times\boldsymbol A)\cdot d\boldsymbol S$$

## 二、方向约定(最容易出错之处)

曲线 $C$ 的**环绕方向**与曲面 $S$ 的**法向**必须满足**右手螺旋关系**:

右手四指沿 $C$ 的绕行方向弯曲, 拇指所指即 $d\boldsymbol S$ 的方向.

一旦方向约定反了, 结果会整体差一个负号.

## 三、证明思路

把曲面 $S$ 分割成 $N$ 个微小面元 $\Delta S_i$. 对每个面元用旋度的定义:

$$\oint_{C_i}\boldsymbol A\cdot d\boldsymbol l\approx(\nabla\times\boldsymbol A)\cdot\Delta\boldsymbol S_i$$

**关键**: 相邻面元的**公共边界方向相反, 线积分恰好抵消**. 加起来后只剩最外层边界 $C$ 上的积分:

$$\oint_C\boldsymbol A\cdot d\boldsymbol l=\sum_i(\nabla\times\boldsymbol A)\cdot\Delta\boldsymbol S_i\ \xrightarrow{\ \Delta S_i\to0\ }\ \int_S(\nabla\times\boldsymbol A)\cdot d\boldsymbol S$$

## 四、意义与用途

**(1) 建立电磁场方程的微分形式**: 例如把安培环路定律 $\oint_C\boldsymbol H\cdot d\boldsymbol l=\int_S\boldsymbol J\cdot d\boldsymbol S$ 化为 $\nabla\times\boldsymbol H=\boldsymbol J$;

**(2) 判断"是否有旋"**: 若 $\nabla\times\boldsymbol A=\boldsymbol 0$, 则沿任意闭合路径环量为 0, 场为保守场;

**(3) 位置无关性**: 当 $\nabla\times\boldsymbol A=\boldsymbol 0$ 时, 线积分只依赖端点, 与路径无关.

## 五、例题

**例 1**(验证): 设 $\boldsymbol A=-y\boldsymbol e_x + x\boldsymbol e_y$, $C$ 为 $xOy$ 平面内半径 $a$ 的圆(逆时针), $S$ 为该圆面. 验证斯托克斯定理.

解: 由[矢量场的环量与旋度](./矢量场的环量与旋度.md)已得 $\nabla\times\boldsymbol A = 2\boldsymbol e_z$, 与 $d\boldsymbol S=\boldsymbol e_z dS$ 同向:

$$\int_S(\nabla\times\boldsymbol A)\cdot d\boldsymbol S=\int_S2\,dS = 2\pi a^2$$

**线积分验证**: 在圆上 $\boldsymbol A = a\boldsymbol e_\phi$, $d\boldsymbol l = a\,d\phi\,\boldsymbol e_\phi$:

$$\oint_C\boldsymbol A\cdot d\boldsymbol l=\int_0^{2\pi}a\cdot a\,d\phi = 2\pi a^2$$

两端相等, 定理成立.

**例 2**(逆用定理): 若 $\nabla\times\boldsymbol A=\boldsymbol 0$ 在区域内处处成立, 说明 $\boldsymbol A$ 沿任意闭合路径的环量.

解: 由斯托克斯定理

$$\oint_C\boldsymbol A\cdot d\boldsymbol l=\int_S(\nabla\times\boldsymbol A)\cdot d\boldsymbol S = 0$$

即环量恒为 0, 场是**保守场**(无旋场). 这正是静电场可以引入电位的数学依据.

**例 3**(结合散度定理的对照记忆):

| 定理         | 联系                | 方向约定                 |
| ------------ | ------------------- | ------------------------ |
| 散度定理     | 闭合面积分 ⇄ 体积分 | 闭合面取**外法向**       |
| 斯托克斯定理 | 闭合线积分 ⇄ 面积分 | 曲线与法向取**右手螺旋** |

## 六、易错点

- 方向约定反了(曲线与法向不成右手螺旋), 结果差负号.
- 把斯托克斯定理与散度定理混用: 前者用于"线积分", 后者用于"面积分".
- 在曲面与曲线不匹配(曲线不是曲面边界)时使用.
- 场在 $S$ 上有奇点时直接套用.
