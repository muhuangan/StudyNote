# 条件概率

条件概率回答的是: **在已知某事件发生的条件下, 另一事件发生的概率是多少**. 它是全概率公式, 贝叶斯公式与独立性这三个核心概念的公共起点.

## 一、定义

设 $A,B$ 为两个事件, 且 $P(B)>0$, 则称

$$P(A\mid B)=\frac{P(AB)}{P(B)}$$

为在事件 $B$ 发生的条件下事件 $A$ 发生的**条件概率**.

对称地, 若 $P(A)>0$:

$$P(B\mid A)=\frac{P(AB)}{P(A)}$$

**几何解释**: 把样本空间从 $\Omega$ 缩小到 $B$, 然后在 $B$ 内部度量 $A$ 占的比例, 即 $A\cap B$ 在 $B$ 中的占比. 条件概率本质上是"换了分母".

## 二、条件概率仍然是概率

对固定的 $B\ (P(B)>0)$, 映射 $A\mapsto P(A\mid B)$ 满足三条公理:

1. 非负性: $P(A\mid B)\ge 0$;
2. 规范性: $P(\Omega\mid B) = 1$;
3. 可列可加性: 互斥事件的条件下概率可加.

因此, **一切概率的性质都可以搬到条件概率上**, 只需把每个 $P(\cdot)$ 替换成 $P(\cdot\mid B)$:

$$P(\bar A\mid B) = 1 - P(A\mid B)$$
$$P(A\cup C\mid B) = P(A\mid B) + P(C\mid B) - P(AC\mid B)$$

这个"整体替换"的技巧在解题中非常好用.

## 三、两种算法

**算法一(用定义式)**: 先求 $P(AB)$ 与 $P(B)$, 再相除. 适用于给了联合概率或分布律的情形.

**算法二(缩小的样本空间)**: 在 $B$ 这个新样本空间里直接按古典概型重新数数. 适用于抽球, 掷骰等古典概型题.

## 四、例题

**例 1**: 掷一枚均匀骰子, 已知出现的点数是偶数, 求点数大于 4 的概率.

解: 记 $A=\{\text{点数大于 4}\}=\{5,6\}$, $B=\{\text{点数为偶数}\}=\{2,4,6\}$.

**算法一**:

$$P(A\mid B)=\frac{P(AB)}{P(B)}=\frac{1 / 6}{1 / 2}=\frac13$$

**算法二**: 已知 $B$ 发生后样本空间缩小为 $\{2,4,6\}$, 其中满足 $A$ 的只有 $\{6\}$, 故 $P(A\mid B)=\frac13$.

**例 2**: 袋中有 3 个白球, 2 个黑球, 不放回地依次取两次. 已知第一次取到白球, 求第二次也取到白球的概率.

解: 设 $A_i=\{\text{第 }i\text{ 次取到白球}\}$. 第一次取到白球后, 袋中还剩 2 白 2 黑:

$$P(A_2\mid A_1)=\frac{2}{4}=\frac12$$

用定义式验证:

$$P(A_1A_2)=\frac{3}{5}\times\frac{2}{4}=\frac{3}{10},\qquad P(A_1)=\frac35$$
$$P(A_2\mid A_1)=\frac{3 / 10}{3 / 5}=\frac12$$

**例 3**: 某工厂有甲, 乙两条生产线, 产量分别占 $60\%$ 与 $40\%$, 次品率分别为 $1\%$ 与 $2\%$. 求随机取一件产品是次品的概率, 以及已知是次品时它来自甲线的概率.

解: 记 $A_1=\{\text{来自甲线}\}$, $A_2=\{\text{来自乙线}\}$, $B=\{\text{次品}\}$. 已知

$$P(A_1) = 0.6,\quad P(A_2) = 0.4,\quad P(B\mid A_1) = 0.01,\quad P(B\mid A_2) = 0.02$$

先求次品概率(全概率公式的原型, 下一篇系统处理):

$$P(B) = P(A_1)P(B\mid A_1) + P(A_2)P(B\mid A_2) = 0.6\times0.01 + 0.4\times0.02 = 0.014$$

再由条件概率定义:

$$P(A_1\mid B)=\frac{P(A_1B)}{P(B)}=\frac{P(A_1)P(B\mid A_1)}{P(B)}=\frac{0.6\times0.01}{0.014}\approx0.429$$

**这个例子非常重要**: 它展示了"由结果反推原因"的典型套路, 这正是**贝叶斯公式**要解决的问题.

## 五、易错点

- **混淆 $P(A\mid B)$ 与 $P(B\mid A)$**: 二者完全不同,"已知是女性时患病的概率"与"已知患病时是女性的概率"不是一回事.
- 忘记条件 $P(B)>0$: 分母为 0 时条件概率无定义.
- 把 $P(A\mid B)$ 直接当成 $P(AB)$: 条件概率是"比例", 联合概率是"占比", 相差一个因子 $P(B)$.
- 误以为 $P(A\mid B) + P(A\mid \bar B) = 1$: 一般不成立, 正确的只有 $P(A\mid B) + P(\bar A\mid B) = 1$.
