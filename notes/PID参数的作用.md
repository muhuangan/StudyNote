# PID参数的作用

1. 比例 P: 输出与当前误差成正比
    1. 作用: 误差一出现立即产生相应控制量, 决定响应快慢
    2. Kp 过小: 响应迟缓, 误差收敛慢
    3. Kp 过大: 超调增大、来回振荡, 严重时系统失稳
    4. 局限: 对恒值目标, 纯 P 控制稳态时必须靠误差维持输出, 存在稳态误差
2. 积分 I: 输出与误差的累积成正比
    1. 作用: 只要误差不为 0 就持续调整, 把稳态误差压到 0
    2. Ki 过小: 消除稳态误差太慢
    3. Ki 过大: 累积过快, 超调大且回落过程振荡时间长
    4. 副作用: 大误差期间或输出受限时误差被持续累加, 形成积分饱和; 饱和解除后要先消化累加量, 造成大超调与长时间回落, 对策见 [PID的优化方案](./PID的优化方案.md)
3. 微分 D: 输出与误差的变化速率成正比
    1. 作用: 按误差走势提前动作, 误差快速增大时提前加强输出, 误差快速减小时提前减速, 提供阻尼、抑制超调
    2. Kd 过小: 阻尼不足, 超调不易压住
    3. Kd 过大: 放大测量噪声, 控制量抖动, 执行器磨损发热
    4. 问题: 给定值阶跃瞬间误差突变, 微分项产生尖峰(微分冲击), 需限幅或改用微分先行, 见 [PID的优化方案](./PID的优化方案.md)
4. 整定方法
    1. 常规顺序: 先加 P 至响应够快且不持续振荡, 再加 I 消除稳态误差, 最后加 D 抑制超调
    2. 经验法则: 齐格勒-尼科尔斯临界比例度法由临界增益与振荡周期算出初值, 再按实际响应微调
    3. 三个参数相互牵制, 最终以超调量、调节时间与稳态精度验收
