# 双曲函数

双曲函数与三角函数在复数域中通过"乘以 $i$"互相转化. 明确这层关系后, 只需记住一套公式, 另一套可以现场推出. 双曲函数也是解含指数方程的常用工具.

## 一、定义

$$\cosh z=\frac{e^{z} + e^{-z}}{2},\qquad \sinh z=\frac{e^{z} - e^{-z}}{2}$$
$$\tanh z=\frac{\sinh z}{\cosh z}=\frac{e^{z} - e^{-z}}{e^{z} + e^{-z}},\qquad \coth z=\frac{1}{\tanh z}$$

## 二、与三角函数的关系

由定义直接比较可得

$$\cosh(iz)=\cos z,\qquad \cos(iz)=\cosh z$$
$$\sinh(iz) = i\sin z,\qquad \sin(iz) = i\sinh z$$

**记法**: 把 $z$ 换成 $iz$ 时, $\sin$ 与 $\sinh$ 互换并可能产生 $i$; $\cos$ 与 $\cosh$ 互换且不带 $i$.

## 三、性质

**(1) 解析性**: $\cosh z$ 与 $\sinh z$ 都是整函数, 且

$$(\sinh z)'=\cosh z,\qquad(\cosh z)'=\sinh z$$

**注意符号**: 双曲函数求导**不带负号**, 这是与三角函数的唯一差别.

**(2) 奇偶性**: $\sinh(-z)=-\sinh z$, $\cosh(-z)=\cosh z$.

**(3) 平方关系**:

$$\cosh^2z-\sinh^2z = 1$$

**注意是减号**, 与三角函数的 $\sin^2+\cos^2 = 1$ 相反.

**(4) 加法定理**:

$$\sinh(z_1\pm z_2)=\sinh z_1\cosh z_2\pm\cosh z_1\sinh z_2$$
$$\cosh(z_1\pm z_2)=\cosh z_1\cosh z_2\pm\sinh z_1\sinh z_2$$

**(5) 周期性**: 以 $2\pi i$ 为周期, 因为 $e^z$ 以 $2\pi i$ 为周期. 这与 $\sin z$、$\cos z$ 以 $2\pi$ 为实周期形成对照.

**(6) 与三角函数的数值联系**: 当 $z = x$ 为实数时, $\cosh x$、$\sinh x$ 就是实双曲函数, 且 $\cosh x\ge1$、$\sinh x$ 取遍 $\mathbb{R}$.

## 四、例题

**例 1**: 求 $\sinh(1 + i)$ 的实虚部.

解: 用加法定理

$$\sinh(1 + i)=\sinh1\cosh i+\cosh1\sinh i$$

由关系式 $\cosh i=\cos1$, $\sinh i = i\sin1$, 得

$$\sinh(1 + i)=\sinh1\cos1 + i\cosh1\sin1$$

取数值: $\sinh1\approx1.1752$, $\cos1\approx0.5403$, $\cosh1\approx1.5431$, $\sin1\approx0.8415$:

$$\sinh(1 + i)\approx0.6350 + 1.2985i$$

**例 2**(解方程): 解方程 $\cosh z = 0$.

解: 由定义 $\frac{e^z + e^{-z}}{2} = 0$, 即 $e^{2z}=-1$. 故

$$2z = i\pi(2k + 1)\ \Longrightarrow\ z = i\frac{(2k + 1)\pi}{2},\qquad k\in\mathbb{Z}$$

**零点全在虚轴上**; 对比 $\cos z$ 的零点全在实轴上, 这正是 $\cosh(iz)=\cos z$ 的体现(实轴与虚轴互换).

**例 3**(导数验证): 验证 $(\cosh z)'=\sinh z$ 并说明为何没有负号.

解:

$$\frac{d}{dz}\cosh z=\frac{d}{dz}\frac{e^z + e^{-z}}{2}=\frac{e^z - e^{-z}}{2}=\sinh z$$

**与 $\cos z$ 的对比**: $\frac{d}{dz}\cos z=\frac{ie^{iz} - ie^{-iz}}{2} = i\cdot\frac{e^{iz} - e^{-iz}}{2}$; 注意分母缺 $i$, 所以结果带上 $i$, 化简后得 $-\sin z$. 双曲函数的定义式中分母是 $2$ 而不是 $2i$, 因此求导后不带负号.

**例 4**(用双曲函数表示三角函数的实虚部): 把 $\cos(x + iy)$ 用实双曲函数表示.

解: 由加法定理

$$\cos(x + iy)=\cos x\cos iy-\sin x\sin iy$$

代入 $\cos iy=\cosh y$, $\sin iy = i\sinh y$:

$$\cos(x + iy)=\cos x\cosh y - i\sin x\sinh y$$

于是

$$\operatorname{Re}\cos(x + iy)=\cos x\cosh y,\qquad \operatorname{Im}\cos(x + iy)=-\sin x\sinh y$$

**推论**: 由于 $\cosh y\to\infty\ (y\to\infty)$, 函数值可以任意大, 这不违背刘维尔定理------该定理只对有界整函数成立.

## 五、易错点

- 把 $\cosh^2z-\sinh^2z = 1$ 写成加号.
- 求导时给 $(\cosh z)'$ 加上负号.
- 混淆 $\sin(iz) = i\sinh z$ 与 $\sinh(iz) = i\sin z$ 的方向.
- 忘记双曲函数的周期是 $2\pi i$ 而不是 $2\pi$.
