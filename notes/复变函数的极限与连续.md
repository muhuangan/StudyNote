# 复变函数的极限与连续

复变函数的极限在形式上和实函数几乎一样, 但含义严格得多: $z\to z_0$ 是**在平面上以任意方式**趋于 $z_0$, 而不是只从左、右两个方向逼近. 这个"任意方式"的要求使得复极限比实极限更难满足------也正因如此, 复可导(解析) 的条件比实可导强得多.

## 一、极限的定义

设 $f$ 在 $z_0$ 的某去心邻域内有定义, $A$ 为复常数. 若对任意 $\varepsilon>0$, 存在 $\delta>0$, 使得当

$$0<|z - z_0|<\delta$$

时恒有

$$|f(z) - A|<\varepsilon$$

则称 $z\to z_0$ 时 $f(z)$ 的**极限**为 $A$, 记作

$$\lim_{z\to z_0}f(z) = A$$

**与实极限的关键差别**: 在实数情形, $x\to x_0$ 只有左右两个方向; 而在复平面, $z\to z_0$ 可以沿**任意方向、任意路径**趋近. 因此复极限存在的要求更强: 只要存在两条路径给出不同的极限值, 极限就不存在.

## 二、极限与实虚部的关系

**定理**: 设 $f(z) = u(x,y) + iv(x,y)$, $A = a + ib$, $z_0 = x_0 + iy_0$. 则

$$\lim_{z\to z_0}f(z) = A$$

当且仅当

$$\lim_{(x,y)\to(x_0,y_0)}u(x,y) = a,\qquad\lim_{(x,y)\to(x_0,y_0)}v(x,y) = b$$

**用途**: 把复极限问题一分为二地化为两个二元实极限问题. 判断"极限不存在"时也常用这条: 只要 $u$ 或 $v$ 的二元极限不存在, 复极限就不存在.

## 三、极限的运算法则

若 $\lim f(z) = A$, $\lim g(z) = B$, 则

$$\lim[f(z)\pm g(z)] = A\pm B,\qquad\lim[f(z)g(z)] = AB$$
$$\lim\frac{f(z)}{g(z)}=\frac AB\qquad(B\neq0)$$

这与实极限的法则完全一致, 证明方式也一样.

## 四、连续

**定义**: 若 $f$ 在 $z_0$ 的某邻域内有定义, 且

$$\lim_{z\to z_0}f(z) = f(z_0)$$

则称 $f$ 在 $z_0$ **连续**. 若 $f$ 在区域 $D$ 内处处连续, 则称 $f$ 在 $D$ 内连续.

**定理**: $f(z) = u + iv$ 在 $z_0$ **连续**, 当且仅当 $u$ 与 $v$ 都在 $(x_0,y_0)$ 连续.

**连续函数的性质**(与实情形平行):

- 连续函数的和、差、积、商(分母不为 0) 仍连续;
- 连续函数的复合仍连续;
- **在有界闭区域上连续的函数有界, 且能取到最大模与最小模**.

**多项式与有理函数的连续性**: 由 $|z|^2 = z\overline z$ 可知 $|z|$ 连续, 从而多项式处处连续; 有理函数在分母不为零的点处连续.

## 五、例题

**例 1**: 求 $\lim_{z\to i}(z^2 + 2z - 1)$.

解: 多项式处处连续, 直接代入:

$$i^2 + 2i - 1=-1 + 2i - 1=-2 + 2i$$

**例 2**: 求 $\lim_{z\to1}\dfrac{z^2 - 1}{z - 1}$.

解: 分子分解并约去 $z - 1$(在去心邻域内 $z\neq1$, 约去合法):

$$\frac{z^2 - 1}{z - 1} = z + 1\qquad(z\neq1)$$

故极限为 $1 + 1 = 2$.

**注意**: 这里用到了与实情形相同的"约去零因子"技巧. 复数的因式分解同样成立, 因为复数域是代数封闭的.

**例 3**(证明极限不存在): 讨论 $\lim_{z\to0}\dfrac{\overline z}{z}$.

解: 让 $z$ 沿**正实轴**趋于 0, 即 $z = x>0$, 则

$$\frac{\overline z}{z}=\frac xx = 1$$

让 $z$ 沿**虚轴**趋于 0, 即 $z = iy\ (y>0)$, 则

$$\frac{\overline z}{z}=\frac{-iy}{iy}=-1$$

两条路径给出不同极限, 故 $\lim_{z\to0}\dfrac{\overline z}{z}$ **不存在**.

**这条题目是复极限"路径无关性"的经典反例**, 应记住它的思路: 取两条特殊路径作比较.

**例 4**: 求 $\lim_{z\to0}\dfrac{|z|^2}{z}$.

解: 由 $|z|^2 = z\overline z$ 得

$$\frac{|z|^2}{z}=\overline z\qquad(z\neq0)$$

而 $z\to0$ 时 $\overline z\to0$, 与路径无关. 故极限存在且为 $0$.

**对比例 3**: 分子从 $\overline z$ 换成 $|z|^2$ 后极限就存在了. 差别在于 $\dfrac{\overline z}{z}$ 的模恒为 1 而辐角随路径变化, 而 $|z|^2 / z=\overline z$ 的模趋于 0. **判断这类极限时, 先看表达式的模是否趋于 0 是最有效的入手点.**

**例 5**(连续性的判断): 设

$$f(z)=\begin{cases}\dfrac{z^2}{|z|}, & z\neq0\\[2mm]0, & z = 0\end{cases}$$

判断 $f$ 在 $z = 0$ 处是否连续.

解: 计算

$$\left|\frac{z^2}{|z|} - 0\right|=\frac{|z|^2}{|z|}=|z|\ \xrightarrow{\ z\to0\ }\ 0$$

由于与路径无关且趋于 0, 故

$$\lim_{z\to0}f(z) = 0 = f(0)$$

函数在 $z = 0$ 处**连续**.

**例 6**(用实虚部判断): 设 $f(z)=\dfrac{z}{\overline z}\ (z\neq0)$, 判断 $z\to0$ 时极限是否存在.

解: 写成 $z = re^{i\theta}$, 则

$$\frac{z}{\overline z}=\frac{re^{i\theta}}{re^{-i\theta}} = e^{2i\theta}$$

极限值随 $\theta$ 变化, 故**不存在**. (这与例 3 同源: 只含"方向信息"的表达式在 $z\to0$ 时通常无极限.)

## 六、易错点

- 只沿一两条路径验证极限就断言存在. 必须证明与路径无关, 或者用实虚部分解 + 二元极限的理论.
- 混淆 $\overline z$ 的连续性与 $\dfrac{\overline z}{z}$ 的极限存在性: 前者连续, 后者的极限不存在.
- 认为"在 $z_0$ 有极限"与"在 $z_0$ 连续"是一回事: 还需要 $f(z_0)$ 有定义且等于该极限.
- 忘记复数域的因式分解同样可以做, 遇到 $\frac00$ 型却不敢约分.
