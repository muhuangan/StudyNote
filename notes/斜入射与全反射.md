# 斜入射与全反射

斜入射引入了一个新的几何自由度(入射角), 由此派生出反射定律、折射定律、全反射与布儒斯特角四个重要结论.

## 一、相位匹配条件(三个定律的统一来源)

设分界面为 $z = 0$. 入射、反射、透射波的波矢量分别为

$$\boldsymbol k_i = k_1(\sin\theta_i\boldsymbol e_x+\cos\theta_i\boldsymbol e_z)$$
$$\boldsymbol k_r = k_1(\sin\theta_r\boldsymbol e_x-\cos\theta_r\boldsymbol e_z)$$
$$\boldsymbol k_t = k_2(\sin\theta_t\boldsymbol e_x+\cos\theta_t\boldsymbol e_z)$$

**关键要求**: 在分界面($z = 0$)上, 三列波的相位必须处处相等, 否则边界条件无法对所有 $x$ 成立. 即**切向波数必须相等**:

$$k_1\sin\theta_i = k_1\sin\theta_r = k_2\sin\theta_t$$

由前一个等号得**反射定律**:

$$\theta_r=\theta_i$$

由后一个等号得**折射定律**(斯涅尔定律):

$$\frac{\sin\theta_t}{\sin\theta_i}=\frac{k_1}{k_2}=\frac{n_1}{n_2}$$

其中 $n=\sqrt{\varepsilon_r\mu_r}$ 为折射率.

**要点**: 两条定律同出一源——**边界上的相位匹配**. 这也是为什么斯涅尔定律具有普适性, 与波的偏振状态无关.

## 二、全反射与临界角

由斯涅尔定律, 若 $n_1>n_2$(由光密进入光疏), 则 $\sin\theta_t=\dfrac{n_1}{n_2}\sin\theta_i>\sin\theta_i$, 即**折射角大于入射角**.

当 $\sin\theta_t = 1$ 时的入射角称为**临界角**:

$$\sin\theta_c=\frac{n_2}{n_1}$$

**当 $\theta_i>\theta_c$ 时, 无实数解, 发生全反射**.

**全反射的两个特征**:

1. **能量完全反射**, 反射系数 $|\Gamma|=1$;
2. 媒质 2 中仍存在**表面波(衰逝波)**, 其振幅沿法向按指数衰减, 不传输能量.

**应用**: 光纤通信(光在纤芯内反复全反射而几乎无损耗)、介质波导、全反射棱镜.

## 三、全透射与布儒斯特角

对**平行极化**(磁场垂直于入射面, 即电场平行于入射面)的波, 存在一个使反射系数为零的入射角:

$$\tan\theta_B=\frac{n_2}{n_1}=\sqrt{\frac{\varepsilon_{r2}}{\varepsilon_{r1}}}$$

称为**布儒斯特角**(起偏角). 此时入射功率**全部透射**.

**注意区分**:

| 现象   | 条件                             | 结果     |
| ------ | -------------------------------- | -------- |
| 全反射 | $n_1>n_2$ 且 $\theta_i>\theta_c$ | 全部反射 |
| 全透射 | 平行极化且 $\theta_i=\theta_B$   | 反射为零 |

二者条件与结果都不同, 不可混淆.

**应用**: 偏振眼镜利用布儒斯特角消除水面反射的眩光(反射光中垂直极化分量仍存在, 水平分量被消除).

## 四、例题

**例 1**: 光从玻璃($n_1 = 1.5$)射向空气($n_2 = 1$). 求临界角; 若入射角为 $60^\circ$, 判断是否全反射.

解:

$$\sin\theta_c=\frac{1}{1.5} = 0.6667\ \Rightarrow\ \theta_c\approx41.8^\circ$$

因 $60^\circ>41.8^\circ$, **发生全反射**.

**例 2**(斯涅尔定律): 光从空气以 $30^\circ$ 入射到 $\varepsilon_r = 2.25$ 的玻璃上, 求折射角.

解: $n_1 = 1$, $n_2 = 1.5$:

$$\sin\theta_t=\frac{n_1}{n_2}\sin30^\circ=\frac{1}{1.5}\times0.5 = 0.3333\ \Rightarrow\ \theta_t\approx19.5^\circ$$

**例 3**(布儒斯特角): 求空气–水($\varepsilon_r\approx1.77$, $n\approx1.33$)界面的布儒斯特角.

解:

$$\tan\theta_B=\frac{1.33}{1} = 1.33\ \Rightarrow\ \theta_B\approx53.1^\circ$$

在实际拍摄中, 以约 $53^\circ$ 的俯角拍摄水面时, 反射眩光中的水平偏振分量被最大限度抑制.

**例 4**(垂直极化与平行极化的差异): 说明为什么只有平行极化存在布儒斯特角.

解: 在布儒斯特角下, 透射波中的电场方向恰好与反射波的传播方向平行, 而**电磁波是横波**(电场垂直于传播方向), 因此该方向不可能存在反射波, 反射必然为零. 垂直极化不满足这一几何关系, 故其反射系数永不为零. 物理上, 反射光在布儒斯特角下是**完全线极化**的(只含垂直极化分量).

## 五、易错点

- 把临界角与布儒斯特角混淆: 前者对应"折射角 $90^\circ$"(全反射), 后者对应"反射为零"(全透射).
- 忘记全反射的前提是**由光密进入光疏**($n_1>n_2$).
- 认为折射定律与极化状态有关: 斯涅尔定律对两种极化都成立.
- 认为布儒斯特角下"什么都不反射": 对**平行极化**才完全无反射, 垂直极化仍有反射.
- 认为全反射时媒质 2 中"什么都没有": 存在指数衰减的表面波(衰逝波), 这是光纤耦合、全反射荧光显微镜等技术的物理基础.
