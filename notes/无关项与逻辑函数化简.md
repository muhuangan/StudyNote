# 无关项与逻辑函数化简

## 核心结论

**无关项**(Don't Care) 是函数取值可以为 0 也可以为 1 的输入组合, 记作 $\times$,$\phi$ 或 $d$. 化简时可以**按需把它当作 1 或 0**, 目的是把圈画得更大, 从而得到更简的表达式.

## 一、无关项的两类来源

**约束项(受约束项)**: 在某些实际系统中, 某些输入组合**根本不会出现**. 例如用 4 位 BCD 码表示 1 位十进制数时, 1010 至 1111 这 6 个状态不会出现, 对应的输出取 0 还是 1 无所谓.

**任意项(随意项)**: 某些输入组合下输出为 1 或 0 **都不影响系统功能**. 例如某个指示灯在某种特定状态下亮灭均可接受.

两类统称无关项, 逻辑上完全等价地处理.

## 二、无关项的表示

$$F = \sum m(\text{必然为 1 的最小项}) + \sum d(\text{无关项})$$

例:$F(A,B,C,D) = \sum m(1, 3, 5, 7, 9) + \sum d(10, 11, 12, 13, 14, 15)$.

## 三、卡诺图中的处理规则

1. 无关项方格填入 $\times$.
2. 若某无关项**有助于扩大圈**(使圈包含 $2^k$ 个方格且能多消变量), 就把它当作 1 圈进去.
3. 若某无关项对化简无帮助, 就当作 0 忽略.
4. **绝对不能出现"只有无关项, 没有 1"的圈**, 这样的圈没有意义, 且会引入错误输出.

## 四、化简示例

化简 $F(A,B,C,D) = \sum m(1, 3, 5, 7, 9) + \sum d(10, 11, 12, 13, 14, 15)$.

填图(AB 为行, CD 为列):

| AB \ CD | 00       | 01       | 11       | 10       |
| ------- | -------- | -------- | -------- | -------- |
| 00      | 0        | 1        | 1        | 0        |
| 01      | 0        | 1        | 1        | 0        |
| 11      | $\times$ | $\times$ | $\times$ | $\times$ |
| 10      | 0        | 1        | $\times$ | $\times$ |

**圈组**:

- 组一: 列 CD = 01 中 $m_1, m_5$ 为 1,$m_{13}, m_9$ 中 $m_9$ 为 1,$m_{13}$ 为无关项, 把 $m_{13}$ 当作 1 后整列为 4 个 1, 得 $\overline{C}D$.
- 组二: 列 CD = 11 中 $m_3, m_7$ 为 1,$m_{15}, m_{11}$ 为无关项, 同样整列并入, 得 $CD$.

两组合并:$\overline{C}D + CD = D$.

$$F = D$$

若不利用无关项, 原函数需写成 $F = \overline{A}\,\overline{B}D + \overline{A}BD + A\overline{B}D$, 远比 $D$ 复杂.

## 五、公式法中的处理

用公式法处理无关项时, 把无关项视为"可自由添加的项": 先按普通与或式化简, 再检查添加某些无关项能否触发吸收律或冗余律.

## 六、需要注意的代价

把无关项当作 1 圈入, 等价于**规定了这些输入组合下的输出值为 1**. 若系统在运行中真的出现了本应"不会出现"的输入组合(例如受干扰后 BCD 码落入伪码区), 输出将按化简后的函数给出确定值. 多数情况下这可以接受, 但对于安全关键系统, 需要额外检测非法输入.

## 七、典型应用: BCD 码检测电路

设计一个判断 4 位输入是否为合法 8421 BCD 码的电路.

- 输入 0000 至 1001(0 至 9): 输出 1.
- 输入 1010 至 1111(10 至 15): 无关项(若约定不会出现, 则填 $\times$).

利用无关项后, 最简结果为

$$F = \overline{A} + \overline{B}\,\overline{C}$$

(其中 A 为最高位). 若不利用无关项, 结果会包含更多项.

## 易错点

- 圈中必须至少含有一个真正的 1, 全由无关项组成的圈是无效圈.
- 无关项在真值表中填 $\times$, 但在最终实现的电路里仍会有确定输出, 不要误以为它"真的不确定".
