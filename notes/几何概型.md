# 几何概型

当样本空间包含**无限多个**样本点且"等可能"体现为在某个区域上均匀时, 古典概型的"数个数"失效, 改用"度量之比", 这就是几何概型.

## 一、定义

若随机试验满足:

1. 样本空间 $\Omega$ 可以对应到直线上的区间, 平面上的区域或空间中的立体(具有有限的几何度量);
2. 样本点落在 $\Omega$ 中任意两个"大小相同"的子区域上的可能性相同;

则称它为**几何概型**. 此时事件 $A$ 的概率为

$$P(A)=\frac{\mu(A)}{\mu(\Omega)}$$

其中 $\mu$ 是相应的几何度量: 一维是**长度**, 二维是**面积**, 三维是**体积**.

## 二、例题

**例 1**(一维, 长度比): 一根长为 $l$ 的细棒随机折成三段(随机独立地选两个断点), 求三段能构成三角形的概率.

分析: 这是经典题, 结论为 $\frac14$. 关键在于把两个断点坐标记为 $x,y$ 后化为二维面积问题, 并处理三角形不等式. 结论记住即可, 考试中常被用作"退化一维→二维"的范例.

**例 2**(二维, 会面问题): 甲, 乙两人约定在 $[0,T]$ 时间内在某地见面, 先到者等待 $t\ (t<T)$ 后离开. 设两人到达的时刻相互独立且都在 $[0,T]$ 上均匀分布, 求两人能会面的概率.

解: 设 $X,Y$ 分别为两人到达时刻, 样本空间是边长为 $T$ 的正方形, 面积为 $T^2$:

$$\Omega=\{(x,y)\mid 0\le x\le T,\ 0\le y\le T\}$$

能会面的条件是 $|X - Y|\le t$, 对应正方形内夹在两条直线之间的带状区域. 不好直接算面积, 改用对立事件: 不能会面对应两个直角三角形, 每个的直角边长为 $T - t$, 合计面积 $(T - t)^2$. 因此

$$P = 1-\frac{(T - t)^2}{T^2} = 1-\left(1-\frac{t}{T}\right)^2$$

**例 3**(二维, 区域面积比): 向半径为 $r$ 的圆盘 $\Omega$ 内随机投一点, 求该点落在半径为 $\frac r2$ 的同心圆内的概率.

解:

$$P=\frac{\pi\left(\frac r2\right)^2}{\pi r^2}=\frac14$$

注意结果是半径比的**平方**, 这是几何概型常见的陷阱.

**例 4**(蒲丰投针): 平面上画有间距为 $d$ 的平行线, 向平面随机投一根长为 $l\ (l<d)$ 的针, 求针与任一平行线相交的概率.

解: 设 $X$ 为针的中点到最近一条平行线的距离 $(0\le X\le \frac d2)$, $\varphi$ 为针与平行线的夹角 $(0\le\varphi\le\frac\pi2)$. 样本空间为矩形, 面积为 $\frac d2\cdot\frac\pi2=\frac{\pi d}{4}$. 相交的充要条件是 $X\le\frac l2\sin\varphi$, 对应面积

$$\int_0^{\pi / 2}\frac l2\sin\varphi\,d\varphi=\frac l2$$

故

$$P=\frac{l / 2}{\pi d / 4}=\frac{2l}{\pi d}$$

这个结果的妙处在于可以用频率估计 $\pi$: 大量投针后用 $\pi\approx\dfrac{2l}{d\,f}$.

## 三、伯特兰悖论: 为什么必须说清"怎样随机"

**例 5**: 在半径为 $r$ 的圆内任作一条弦, 求弦长大于该圆内接正三角形边长(即 $\sqrt3\,r$)的概率.

同一个问题, 因为对"任作一条弦"的随机方式规定不同, 会得出三种答案:

| 随机化的含义                        | 答案      |
| ----------------------------------- | --------- |
| 弦的两个端点在圆周上均匀选取        | $\frac13$ |
| 弦到圆心的距离在 $[0,r]$ 上均匀分布 | $\frac12$ |
| 弦的中点在圆盘内均匀分布            | $\frac14$ |

三者都对, 因为三者对应的**试验并不相同**.

**启示**: 几何概型中"等可能"必须明确是对**什么量**等可能, 否则题目本身是不完全的. 这也是 Probability 必须由样本空间 + 概率测度共同定义的直观理由.

## 四、与古典概型的关系

- 古典概型数的是**个数**, 几何概型量的是**测度**;
- 两者本质上都是"有利部分占全体的比例", 几何概型可看作古典概型在无限不可数样本空间上的推广;
- 几何概型的例子在引入连续型随机变量后几乎全部等价于**均匀分布**(区间 $[a,b]$ 上的均匀分布即一维几何概型).

## 五、易错点

- 把长度比误当面积比, 或反之. 判据: 随机点数由几个独立参数决定, 就是几维度量.
- 二维问题中忘记"面积比等于线性比的平方".
- 认为"概率为 0 就是不可能事件": 几何概型中"恰好投到某一点"的概率为 0, 但它并非不可能发生. 概率为 0 的事件不一定是不可能事件.
