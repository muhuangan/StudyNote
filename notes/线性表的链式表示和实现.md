# 线性表的链式表示和实现(链表)

**一个结点包含数据和下一个节点的地址**

单链表的结点的典型实现:

```C
typedef int ElemType;
typedef struct node{
    ElemType data;
    struct node* next;
}Node;
```

**单链表的插入**:  
把s插到p的后面为例  
s->next = p->next;  
p->next = s;

**单链表的删除**:  
以删除p后面的结点为例  
s = p -> next;  
p->next = p -> next -> next;

**单链表的插入**

1. 头插法: 每一次数据都插在头结点的后面  
   典型实现:

```C
int insertHead(Node* L, ElemType e){
    Node* p = (Node*)malloc(sizeof(Node));
    p -> data = e;
    p -> next = L -> next;
    L -> next = p;
}
```

2. 尾插法: 每一次数据都插在尾结点的后面  
   典型实现:

```C
Node* get_tail(Node *L){
    Node* p = L;
    while(p -> next != NULL){
        p = p -> next;
    }
    return p;
}

Node* insertTail(Node *tail, ElemType e){
    Node* p = (Node*)malloc(sizeof(Node));
    p -> data = e;
    tail -> next = p;
    p -> next = NULL;
    return p;
}
```

3. 在指定位置插入数据  
   典型实现:

```C
int insertNode(Node*L, int pos, ElemType e){
    Node*p = L;
    int i = 0;
    //找到插入位置的前驱结点
    while(i < pos - 1){
        p = p -> next;
        i++;
        if(p == NULL){
            return 0;
        }
    }

    //要插入的新节点
    Node *q = (Node*)malloc(sizeof(Node));
    q -> data = e;
    q -> next = p -> next;
    p -> next = q;
    return 1;
}
```

**单链表结点的删除**:  
典型实现:

```C
int deleteNode(Node*L, int pos){
    Node *p = L;
    int i = 0;
    //找到要删除结点的前驱结点
    while(i < pos - 1){
        p = p -> next;
        i++;
        if(p == NULL){
            return 0;
        }
    }

    //鲁棒性
    if(p -> next == NULL){
        printf("要删除的位置错误\n");
        return 0;
    }

    //q指向要删除的结点
    Node *q = p -> next;
    p -> next = q -> next;
    free(q);
    return 1;
}
```

**释放链表**  
自然语言描述:

1. 指针p指向头节点后的第一个结点
2. 判断p是否指向空结点
3. 如果p不为空, 用指针q记录指针p的后继结点
4. 释放p指向的结点
5. 把q赋值给p
6. 循环操作

典型实现:

```C
void freeList(Node* L){
    Node * p = L -> next;
    Node * q;

    while(p != NULL){
        q = p -> next;
        free(p);
        p = q;
    }
    L -> next = NULL;
}
```

小总结: 读取数据顺序表强于链表, 修改数据链表强于顺序表

**链表典型运用与套路**:

1.  双指针(快慢指针):
    1. 找到倒数第n个结点:
        1. 快指针先走n步
        2. 慢指针开始走
        3. 两者同步更新
        4. 快指针指向NULL时, 慢指针走到倒数第n个结点
    2. 找到中间结点
        1. 快指针初始指向head->next, 慢指针初始指向head
        2. 快指针一次走两步, 慢指针一次走一步
        3. 直到快指针或快指针所指向的结点指针域所指向的结点为空
        4. 此时慢结点所指向的结点为中间结点
    3. 判断链表中是否有环
        1. 快指针走两步, 慢指针走一步
        2. 两个能指向同一个结点说明有环

        ```C
        int isCycle(Node *head){
            Node* fast = head;
            Node* slow = head;

            while(fast != NULL && fast -> next != NULL){
                fast = fast -> next -> next;
                slow = slow -> next;
                if(fast == slow){
                    return 1;
                }
            }
            return 0;
        }
        ```

        3. 此时开始计数, 记录多少步后(记作count) 快慢指针再一次重合, 即为环的周长有多少个结点
        4. 然后让快慢指针同时指向头指针, 快指针比慢指针先走count步, 然后同步走, 等两个指针再次相遇时就是环的入口

        ```C
        Node* findBegin(Node* head){
            Node* fast = head;
            Node* slow = head;

            while(fast != NULL && fast -> next != NULL){
                fast = fast -> next -> next;
                slow = slow -> next;
                if(fast == slow){
                    Node* p = fast;
                    int count = 1;
                    while(p -> next != slow){
                        count++;
                        p = p -> next;
                    }
                    fast = head;
                    slow = head;

                    for(int i = 0; i < count; i++){
                        fast = fast -> next;
                    }
                    while(fast != slow){
                        fast = fast -> next;
                        slow = slow -> next;
                    }
                    return slow;
                }
            }
            return NULL;
        }
        ```

2.  反转单链表
    1.  三个指针(first, second, third)
    2.  first初始指向空值, second初始指向首结点, third指向second指向的结点的下一个结点
    3.  second所指向的结点的指针域指向first所指向的结点
    4.  first指向second指向的结点, second指向third指向的结点, third指向third所指向的结点的指针域所指向的结点(即全体往后挪)
    5.  重复以上过程, 直到second为空值
    6.  头指针指向first  
        典型应用

    ```C
    void reverseList(Node* head){
    Node* first = NULL;
    Node* second = head -> next;
    Node* third;

            while(second != NULL){
                third = second -> next;
                second -> next = first;
                first = second;
                second = third;
            }
            head->next = first;
        }
    ```

    **单链表的局限性: 不能回头!!**

**双向链表: **  
两个指针: 一个指向直接后继, 一个指向直接前驱  
数据域

典型的双向链表结点实现:

```C
typedef int ElemType;

typedef struct node{
    ElemType data;
    struct node *prev, *next;
}Node;
```

**双向链表头插法**:  
典型实现:

```C
int insertHead(Node* L, ElemType e){
    Node *p = (Node*)malloc(sizeof(Node));
    p -> data = e;
    p -> prev = L;
    p -> next = L -> next;
    if(L -> next != NULL){
        L -> next -> prev = p;
    }
    L -> next = p;
    return 1;
}
```

**双向链表尾插法**:  
典型实现:

```C
Node * insertTail(Node *tail, ElemType e){
    Node *p = (Node*)malloc(sizeof(Node));
    p -> data = e;
    p -> prev = tail;
    tail -> next = p;
    p -> next = NULL;
    return p;
}
```

**双向链表指定位置插入数据**:  
典型实现:

```C
int insertNode(Node *L, int pos, ElemType e){
    Node *p = L;
    int i = 0;
    while(i < pos - 1){
        p = p -> next;
        i++;
        if(p == NULL){
            return 0;
        }
    }

    Node *q = (Node*)malloc(sizeof(Node));
    q -> data = e;
    q -> prev = p;
    q -> next = p -> next;
    if(p->next != NULL)
        p -> next -> prev = q;
    p -> next = q;
    return 1;
}
```

**双向链表指定位置删除结点**:  
典型实现:

```C
int deleteNode(Node *L, int pos){
    Node *p = L;
    int i = 0;
    while(i < pos - 1){
        p = p -> next;
        i++;
        if(p == NULL){
            return 0;
        }
    }

    if(p -> next == NULL){
        printf("要删除的位置错误\n");
        return 0;
    }

    Node *q = p -> next;
    p -> next = q -> next;
    if(q->next!=NULL)
        q -> next -> prev = p;
    free(q);
    return 1;
}
```
