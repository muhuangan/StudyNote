# 伯努利概型

伯努利概型是"重复抛一枚不均匀硬币"这一情景的抽象, 它直接导出后面最重要的离散分布——**二项分布**.

## 一、$n$ 重伯努利试验

若 $n$ 次试验满足:

1. 每次试验只有两个结果: $A$ 与 $\bar A$(称 $A$ 为"成功");
2. 各次试验中 $P(A) = p$ 保持不变, $P(\bar A) = 1 - p = q$;
3. 各次试验**相互独立**;

则称这 $n$ 次试验为 **$n$ 重伯努利试验**(伯努利概型).

## 二、恰好成功 $k$ 次的概率

在 $n$ 重伯努利试验中, 事件 $A$ 恰好发生 $k$ 次的概率为

$$P_n(k) = C_n^k\,p^k\,q^{\,n - k}=\binom{n}{k}p^k(1 - p)^{n - k},\qquad k = 0,1,\ldots,n$$

**推导**: 指定的一种"前 $k$ 次成功, 后 $n - k$ 次失败"的排列方式, 由独立性其概率为 $p^kq^{n - k}$; 而 $k$ 次成功可以分布在 $n$ 个位置中的任意 $C_n^k$ 种位置组合上, 这些组合两两互斥, 故乘 $C_n^k$.

**校验**:

$$\sum_{k = 0}^{n}C_n^kp^kq^{\,n - k} = (p + q)^n = 1$$

正好是二项式展开, 这也是"**二项分布**"名称的由来.

## 三、常见的变形与推广

| 问题                    | 概率                                             |
| ----------------------- | ------------------------------------------------ |
| 恰好成功 $k$ 次         | $C_n^kp^kq^{n - k}$                              |
| 至少成功 $k$ 次         | $\displaystyle\sum_{i = k}^{n}C_n^ip^iq^{n - i}$ |
| 至多成功 $k$ 次         | $\displaystyle\sum_{i = 0}^{k}C_n^ip^iq^{n - i}$ |
| 全失败                  | $q^n$                                            |
| 首次成功出现在第 $k$ 次 | $q^{k - 1}p$                                     |

最后一行即**几何分布**, 后面单独讨论.

## 四、例题

**例 1**: 掷一枚均匀硬币 5 次, 求恰有 3 次正面的概率, 以及至少有 3 次正面的概率.

解: $n = 5$, $p=\frac12$.

$$P(\text{恰有 3 次}) = C_5^3\left(\frac12\right)^3\left(\frac12\right)^2 = 10\times\frac{1}{32}=\frac{5}{16}$$

$$P(\text{至少 3 次})=\sum_{k = 3}^{5}C_5^k\left(\frac12\right)^5=\frac{10 + 5 + 1}{32}=\frac{16}{32}=\frac12$$

**例 2**: 某批产品的次品率为 $0.05$, 有放回地抽取 20 件, 求恰有 2 件次品的概率.

解: 有放回保证了独立性与概率恒定, 是标准的伯努利试验:

$$P = C_{20}^{2}(0.05)^2(0.95)^{18} = 190\times0.0025\times0.95^{18}\approx190\times0.0025\times0.397\approx0.189$$

**例 3**: 甲投篮命中率为 $0.6$, 独立投篮 4 次, 求至少命中 3 次的概率.

解:

$$P = C_4^3(0.6)^3(0.4) + C_4^4(0.6)^4 = 4\times0.216\times0.4 + 0.1296$$
$$=0.3456 + 0.1296 = 0.4752$$

**例 4**(独立性的实用检验): 一批产品共 100 件含 5 件次品, **不放回**抽取 10 件, 恰有 2 件次品的概率.

解: 不放回时各次抽取**不独立**, 不是伯努利概型, 应当直接用古典概型(超几何):

$$P=\frac{C_5^2C_{95}^{8}}{C_{100}^{10}}$$

**注意**: 当总体很大而抽样比例很小时, 不放回可用伯努利近似. 例如把本题改成"无限大批量, 次品率 $5\%$", 则近似为

$$P\approx C_{10}^2(0.05)^2(0.95)^8\approx45\times0.0025\times0.663\approx0.0746$$

## 五、易错点

- 把不放回抽样当作伯努利概型使用 $(1 - p)^{n - k}p^k$: **不放回不独立**, 必须用超几何(或在大总体下明确指出是近似).
- 忘记乘组合数 $C_n^k$: 只对"指定某几次成功"才不用乘.
- 混淆"至少 $k$ 次"与"恰好 $k$ 次", 前者要逐项求和或改用对立事件.
- 把 $p$ 与 $k$ 的个数关系写错指数: $p$ 的指数是**成功次数** $k$, $q$ 的指数是**失败次数** $n - k$, 二者之和必须为 $n$.
