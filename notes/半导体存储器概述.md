# 半导体存储器概述

## 核心结论

半导体存储器是"用电路存储大量二值数据"的器件. 它的通用结构是**地址译码器 + 存储矩阵 + 读写控制电路**; 核心指标是**存储容量, 存取时间, 功耗**与**是否易失**.

## 一、存储器的分类

**按读写功能**:

| 类别 | 全称       | 特点                                         |
| ---- | ---------- | -------------------------------------------- |
| ROM  | 只读存储器 | 断电后数据不丢失(非易失), 正常工作时只能读出 |
| RAM  | 随机存储器 | 可读可写, 断电后数据丢失(易失)               |

**ROM 的细分**:

| 类型     | 写入方式         | 擦除方式         | 可重复写入 |
| -------- | ---------------- | ---------------- | ---------- |
| 掩模 ROM | 制造时由掩模决定 | 不可             | 否         |
| PROM     | 用户烧断熔丝     | 不可             | 一次       |
| EPROM    | 编程器写入       | 紫外线照射(整片) | 多次       |
| EEPROM   | 电信号写入       | 电信号(按字节)   | 多次       |
| Flash    | 电信号写入       | 电信号(按块)     | 多次       |

**RAM 的细分**:

| 类型 | 存储单元    | 是否需刷新 | 速度 | 集成度 |
| ---- | ----------- | ---------- | ---- | ------ |
| SRAM | 六管触发器  | 否         | 快   | 低     |
| DRAM | 单管 + 电容 | **是**     | 较慢 | 高     |

## 二、存储容量

**定义**: 存储容量 = 字数 × 位数, 单位用位(bit) 或字节(B) 表示.

$$容量 = 2^n \times m$$

其中 $n$ 是地址线根数(决定字数),$m$ 是每个字的位数.

**示例**: 一片存储器有 10 根地址线, 8 根数据线, 则容量为

$$2^{10} \times 8 = 8192\ \text{位} = 1\ \text{K} \times 8\ \text{位} = 1\ \text{KB}$$

**单位约定**:

| 单位 | 数值                 |
| ---- | -------------------- |
| 1 KB | $2^{10} = 1024$ 字节 |
| 1 MB | $2^{20}$ 字节        |
| 1 GB | $2^{30}$ 字节        |

## 三、存取时间

**定义**: 从启动一次读/写操作到完成该操作所需的时间.

- **读出时间**: 从地址有效到数据出现在数据线上所需的时间.
- **写入时间**: 从地址与数据都有效到数据被可靠写入所需的时间.
- **存储周期**: 连续两次独立的访问操作之间所需的最小时间间隔, 通常**大于**存取时间(因为需要恢复时间).

**典型量级**: SRAM 约几纳秒至几十纳秒, DRAM 约几十纳秒, Flash 读出约几十纳秒, 写入约微秒至毫秒级.

## 四、功耗

| 类型  | 功耗特点                           |
| ----- | ---------------------------------- |
| SRAM  | 静态功耗较大(单元始终通电)         |
| DRAM  | 静态功耗小, 但刷新操作带来额外功耗 |
| Flash | 读功耗低, 写/擦除功耗较高          |

## 五、通用结构

```
地址输入 A0..A(n-1) ──> 地址译码器 ──> 字线(选择某一行)
                                          │
                                      存储矩阵 ──> 位线 ──> 读/写控制与 I/O ──> 数据 D0..D(m-1)
                                          │
                              片选 CS, 读写控制 R/W
```

四个组成部分:

1. **地址译码器**: 把 $n$ 位地址译成 $2^n$ 条字线中的一条有效.
2. **存储矩阵**: 由存储单元按行列排成的阵列, 是数据的实际存放处.
3. **读/写控制电路**: 控制数据的流向(读出还是写入) 与三态输出.
4. **片选端 $\overline{CS}$ 与输出使能 $\overline{OE}$**: 用于多片级联和总线隔离.

## 六、易失性对比

| 特性       | ROM 类              | RAM 类           |
| ---------- | ------------------- | ---------------- |
| 断电后数据 | 保留                | 丢失             |
| 写入速度   | 慢(尤其 Flash 擦写) | 快               |
| 典型用途   | 固件, 程序, 查找表  | 变量, 堆栈, 缓存 |

## 七、存储器的层次化应用

在计算机系统中, 存储器按"速度—容量—成本"的折中组成层次结构:

| 层次     | 器件         | 速度 | 容量 | 成本/位 |
| -------- | ------------ | ---- | ---- | ------- |
| 寄存器   | 触发器       | 最快 | 极小 | 最高    |
| 高速缓存 | SRAM         | 快   | 小   | 高      |
| 主存     | DRAM         | 中   | 大   | 中      |
| 外存     | Flash / 硬盘 | 慢   | 极大 | 低      |

层次化的依据是**程序访问的局部性**: 时间局部性(刚访问的很可能再访问) 与空间局部性(相邻的很可能被访问).

## 八、选型要点

1. 需要断电保存, 只读取 → ROM / Flash.
2. 需要高速读写, 容量不大 → SRAM.
3. 需要大容量, 可接受刷新开销 → DRAM.
4. 需要频繁改写且断电保存 → EEPROM / Flash.

## 易错点

- 存储容量的单位是"位"还是"字节": 容量 $= 2^n \times m$ 算出来的是**位**, 除以 8 才是字节.
- "存取时间"与"存储周期"不是一回事, 后者包含恢复时间, 系统设计必须按存储周期计算.
