# 磁场能量

建立电流的过程就是建立磁场的过程. 由于自感电动势阻碍电流增大, 电源必须额外做功才能把电流建立起来, 这部分功就以**磁场能量**的形式储存在磁场中. 由此还能得到磁能密度的表达式------它与电场能量密度形式高度平行, 是理解电磁场能量的基础.

## 一、自感磁能

**结论**: 自感为 $L$ 的回路通有电流 $I$ 时, 储存的磁场能量为

$$W_m=\frac12LI^2$$

**推导**: 在建立电流的过程中, 某时刻电流为 $i$, 自感电动势

$$\varepsilon_L=-L\frac{di}{dt}$$

电源为克服它而多做的功等于

$$dW=-\varepsilon_L\cdot i\,dt=L\frac{di}{dt}\cdot i\,dt=Li\,di$$

从 $0$ 积分到 $I$:

$$W_m=\int_0^{I}Li\,di=\frac12LI^2$$

**类比记忆**:

| 力学                | 电路                    |
| ------------------- | ----------------------- |
| 动能 $\dfrac12mv^2$ | 磁场能量 $\dfrac12LI^2$ |
| 质量 $m$(惯性)      | 自感 $L$(电感惯性)      |
| 速度 $v$            | 电流 $I$                |

**这说明"自感是电路的惯性"是有量化的对应的**.

## 二、磁能密度

上面的公式把能量归给了回路, 但能量实际储存在**磁场**里. 用螺线管来定位:

**螺线管的磁场**:

$$B=\mu_0\mu_rnI\ \Longrightarrow\ I=\frac{B}{\mu_0\mu_rn}$$

**自感**:

$$L=\mu_0\mu_rn^2V$$

**代入能量公式**:

$$W_m=\frac12LI^2=\frac12\mu_0\mu_rn^2V\cdot\left(\frac{B}{\mu_0\mu_rn}\right)^2$$

化简: $n^2$ 与 $\dfrac{1}{n^2}$ 相消,

$$W_m=\frac12\mu_0\mu_rn^2V\cdot\frac{B^2}{\mu_0^2\mu_r^2n^2}=\frac{B^2}{2\mu_0\mu_r}V$$

**磁能密度**(单位体积的磁场能量):

$$w_m=\frac{W_m}{V}=\frac{B^2}{2\mu_0\mu_r}=\frac{B^2}{2\mu}=\frac12BH$$

最后一个等号用了 $B=\mu H$.

**结论**: 磁能密度只由该点的 $\boldsymbol B$ 与 $\boldsymbol H$ 决定, 与产生磁场的方式无关. **这是一个普适结论**, 对任意磁场都成立(可用于非均匀场, 只需逐点积分):

$$W_m=\int_V\frac{B^2}{2\mu}dV$$

## 三、与电场能量密度的对照

|          | 电场                                                   | 磁场                                      |
| -------- | ------------------------------------------------------ | ----------------------------------------- |
| 能量密度 | $w_e=\dfrac12\varepsilon_0\varepsilon_rE^2=\dfrac12DE$ | $w_m=\dfrac{B^2}{2\mu_0\mu_r}=\dfrac12BH$ |
| 场量     | 与 $\boldsymbol E$、$\boldsymbol D$ 有关               | 与 $\boldsymbol B$、$\boldsymbol H$ 有关  |
| 储存方式 | 电容器的电场                                           | 电感线圈的磁场                            |
| 总能量   | $W_e=\dfrac12CU^2$                                     | $W_m=\dfrac12LI^2$                        |

**形式上的完全平行**值得记住: 把 $\varepsilon\rightarrow\mu$, $E\rightarrow B$, $D\rightarrow H$, $C\rightarrow L$, $U\rightarrow I$ 即可互换两套公式.

**注意**: 两者的差别在于"源"------电场由电荷(与电压 $U$ 对应)建立, 磁场由电流(与 $I$ 对应)建立.

## 四、例题

**例 1**(基本计算): 一个 $L=0.50\ \text{H}$ 的电感线圈通有 $I=2.0\ \text{A}$ 的电流. 求储存的磁场能量.

解:

$$W_m=\frac12LI^2=\frac12\times0.50\times(2.0)^2=1.0\ \text{J}$$

**量级感受**: 1 J 的能量相当于把 100 g 物体举高约 1 m. 电感储能量级通常不大, 但瞬时释放时功率可以很高.

**例 2**(与电容的对比): 已知某 LC 回路中 $L=1.0\times10^{-3}\ \text{H}$, $C=1.0\times10^{-6}\ \text{F}$. 若电容充电到 $U=100\ \text{V}$ 后对电感放电, 求振荡过程中磁场能量的最大值.

解: 若忽略电阻, 能量在电容与电感之间往复转换, 总量守恒.

**电容初始储能**:

$$W_e=\frac12CU^2=\frac12\times1.0\times10^{-6}\times(100)^2=5.0\times10^{-3}\ \text{J}$$

**磁场能量最大值**: 当电容完全放电(电压为零)时, 全部能量转入磁场:

$$W_{m,\max}=W_e=5.0\times10^{-3}\ \text{J}=5.0\ \text{mJ}$$

**对应的最大电流**:

$$\frac12LI_{\max}^2=5.0\times10^{-3}\ \Longrightarrow\ I_{\max}=\sqrt{\frac{2\times5.0\times10^{-3}}{1.0\times10^{-3}}}=\sqrt{10}\approx3.2\ \text{A}$$

**要点**: LC 回路中电场能与磁场能相互转换, 总能量守恒. **这一点与力学中的简谐振动完全平行**(动能与势能互换).

**例 3**(螺线管的储能): 长 $l=0.50\ \text{m}$、横截面积 $S=4.0\times10^{-4}\ \text{m}^2$、匝数 $N=1000$ 的螺线管, 通有 $I=2.0\ \text{A}$ 电流, 内部为真空. 用两种方法求储能并验证一致.

解: **方法一(用自感)**: 由[自感与互感](./自感与互感.md)例 1,

$$L=\mu_0n^2lS\approx1.0\times10^{-3}\ \text{H}$$

$$W_m=\frac12LI^2=\frac12\times1.0\times10^{-3}\times(2.0)^2=2.0\times10^{-3}\ \text{J}$$

**方法二(用磁能密度)**: 管内磁场

$$B=\mu_0nI=4\pi\times10^{-7}\times2000\times2.0\approx5.03\times10^{-3}\ \text{T}$$

**磁能密度**:

$$w_m=\frac{B^2}{2\mu_0}=\frac{(5.03\times10^{-3})^2}{2\times4\pi\times10^{-7}}=\frac{2.53\times10^{-5}}{2.513\times10^{-6}}\approx1.01\times10^1\ \text{J/m}^3$$

**体积**:

$$V=lS=0.50\times4.0\times10^{-4}=2.0\times10^{-4}\ \text{m}^3$$

$$W_m=w_mV=10.1\times2.0\times10^{-4}\approx2.0\times10^{-3}\ \text{J}$$

**两法一致** ✓. 这验证了 $\dfrac12LI^2$ 与 $\displaystyle\int\dfrac{B^2}{2\mu}dV$ 的等价性.

**例 4**(非均匀场的能量): 同轴电缆内导体半径 $R_1$, 外导体内半径 $R_2$, 中间为真空, 内导体通电流 $I$(外层回流). 求单位长度储存的磁场能量.

解: 介质中($R_1<r<R_2$)磁场为

$$B=\frac{\mu_0I}{2\pi r}$$

**磁能密度**:

$$w_m=\frac{B^2}{2\mu_0}=\frac{1}{2\mu_0}\cdot\frac{\mu_0^2I^2}{4\pi^2r^2}=\frac{\mu_0I^2}{8\pi^2r^2}$$

**单位长度能量**(对半径从 $R_1$ 到 $R_2$ 积分, 体积元 $dV=2\pi r\,dr\cdot1$):

$$\frac{W_m}{l}=\int_{R_1}^{R_2}\frac{\mu_0I^2}{8\pi^2r^2}\cdot2\pi r\,dr=\frac{\mu_0I^2}{4\pi}\int_{R_1}^{R_2}\frac{dr}{r}=\frac{\mu_0I^2}{4\pi}\ln\frac{R_2}{R_1}$$

**由能量求自感**: 由 $W_m=\dfrac12LI^2$ 得单位长度的自感

$$\frac{L}{l}=\frac{\mu_0}{2\pi}\ln\frac{R_2}{R_1}$$

**要点**: **"用能量法求自感"是一个重要技巧**------当直接求磁通链不方便(磁场非均匀、形状复杂)时, 可以先算磁能密度并积分, 再由 $L=2W_m/I^2$ 反求自感. 同轴电缆就是典型例子, 它的场随 $1/r$ 变化, 直接在几何上求磁通链比较麻烦.

**例 5**(能量的应用: 判断能否忽略): 某电感线圈 $L=0.10\ \text{H}$, 通过 $I=5.0\ \text{A}$ 的电流. 若在 $1.0\ \text{ms}$ 内把电路断开, 估算自感电动势并判断其危害.

解: **电流变化率**:

$$\left|\frac{dI}{dt}\right|=\frac{5.0}{1.0\times10^{-3}}=5.0\times10^3\ \text{A/s}$$

**自感电动势**:

$$|\varepsilon_L|=L\left|\frac{dI}{dt}\right|=0.10\times5.0\times10^3=500\ \text{V}$$

**危害判断**: 500 V 虽不算极高, 但若断开时间更短(如 $1\ \mu\text{s}$), 电动势会达到 $5\times10^5\ \text{V}$, 足以击穿空气并损坏开关触点或电子元件.

**工程对策**: 在电感旁并联**续流二极管**或 RC 吸收回路, 给电流提供一条缓慢衰减的通路. 这也从能量角度说明------磁场储能在 $W_m=\dfrac12LI^2$ 必须先被消耗掉, 强行瞬间断流等价于要求它瞬间释放, 必然产生高电压.

## 五、易错点

- 忘记 $\dfrac12$ 系数. 与电场能量 $\dfrac12CU^2$、电场密度 $\dfrac12\varepsilon E^2$ 一样都带 $\dfrac12$.
- 把磁场能量归于"电流"而非"磁场". 能量实际储存在磁场所在的空间里.
- 用 $w_m=\dfrac{B^2}{2\mu_0}$ 时忘了介质的情形应为 $\mu=\mu_0\mu_r$.
- 对非均匀场直接套 $W_m=\dfrac12LI^2$ 而不知道 $L$, 却忘了可以用能量密度积分再反求.
- 混淆磁能密度与磁滞损耗(后者是铁磁质反复磁化的耗散, 单位是 J/m³ 每循环).
- 认为断开电感电路"不会有事". 大电感瞬时断流会产生危险的高电压.
