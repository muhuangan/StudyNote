# 复数及其代数运算

复变函数论的研究对象是**自变量取复值的函数**, 所以起点是把复数及其运算讲清楚. 引入复数最直接的动机是让 $x^2=-1$ 这类方程有解, 但真正让它成为有力工具的原因在于: 复数可以看成平面上的点或向量, 加法与乘法因此获得了明确的几何意义.

## 一、定义

形如

$$z = x + iy\qquad(x,y\in\mathbb{R})$$

的数称为**复数**, 其中 $i$ 是**虚数单位**, 规定

$$i^2=-1$$

$x$ 称为 $z$ 的**实部**, 记作 $x = \operatorname{Re}z$; $y$ 称为 $z$ 的**虚部**, 记作 $y = \operatorname{Im}z$.

当 $y = 0$ 时 $z = x$ 为实数; 当 $x = 0$ 且 $y\neq0$ 时 $z = iy$ 为**纯虚数**. 全体复数构成的集合记作 $\mathbb{C}$.

**注意**: 虚部 $\operatorname{Im}z$ 是**实数** $y$, 而不是 $iy$. 这是最常见的笔误来源.

## 二、相等与四则运算

设 $z_1 = x_1 + iy_1$, $z_2 = x_2 + iy_2$.

**相等**: $z_1 = z_2$ 当且仅当 $x_1 = x_2$ **且** $y_1 = y_2$. 也就是说, 一个复数等式等价于两个实数等式, 这一点在后面分离实虚部时反复用到.

**加法和减法**: 实部与虚部分别相加减,

$$z_1\pm z_2 = (x_1\pm x_2) + i(y_1\pm y_2)$$

**乘法**: 按多项式展开并利用 $i^2=-1$,

$$z_1z_2 = (x_1x_2 - y_1y_2) + i(x_1y_2 + x_2y_1)$$

**除法**: 当 $z_2\neq0$ 时, 分子分母同乘分母的共轭,

$$\frac{z_1}{z_2}=\frac{z_1\overline{z_2}}{z_2\overline{z_2}}=\frac{x_1x_2 + y_1y_2}{x_2^2 + y_2^2} + i\frac{x_2y_1 - x_1y_2}{x_2^2 + y_2^2}$$

**除法要点**: 分母的共轭 $x_2 - iy_2$ 是"有理化"的钥匙, 它把分母变成实数 $x_2^2 + y_2^2$. 无需背公式, 按此步骤做即可.

## 三、运算律

复数的加法与乘法满足:

- **交换律**: $z_1 + z_2 = z_2 + z_1$, $z_1z_2 = z_2z_1$;
- **结合律**: $(z_1 + z_2) + z_3 = z_1 + (z_2 + z_3)$, $(z_1z_2)z_3 = z_1(z_2z_3)$;
- **分配律**: $z_1(z_2 + z_3) = z_1z_2 + z_1z_3$.

因此 $\mathbb{C}$ 构成一个**域**. 与实数域的关键差别在于: **$\mathbb{C}$ 不是有序域**, 即复数之间不能比较大小. 说"$z_1>z_2$"是没有意义的, 只能说它们的**模**谁大谁小.

## 四、例题

**例 1**: 设 $z_1 = 2 - 3i$, $z_2=-1 + 4i$, 求 $z_1 + z_2$, $z_1 - z_2$, $z_1z_2$ 与 $z_1 / z_2$.

解: 加、减按分量进行:

$$z_1 + z_2 = (2 - 1) + (-3 + 4)i = 1 + i$$
$$z_1 - z_2 = (2 + 1) + (-3 - 4)i = 3 - 7i$$

乘法展开:

$$z_1z_2 = (2 - 3i)(-1 + 4i) = 2(-1) + 2(4i) + (-3i)(-1) + (-3i)(4i)$$

$$=-2 + 8i + 3i - 12i^2=-2 + 11i + 12 = 10 + 11i$$

除法先有理化:

$$\frac{z_1}{z_2}=\frac{(2 - 3i)(-1 - 4i)}{(-1)^2 + 4^2}=\frac{-2 - 8i + 3i + 12i^2}{17}=\frac{-14 - 5i}{17}=-\frac{14}{17}-\frac{5}{17}i$$

**例 2**: 求 $\dfrac{1}{i}$ 与 $\dfrac{1 + i}{1 - i}$.

解:

$$\frac{1}{i}=\frac{1\cdot(-i)}{i\cdot(-i)}=\frac{-i}{1}=-i$$

$$\frac{1 + i}{1 - i}=\frac{(1 + i)^2}{(1 - i)(1 + i)}=\frac{1 + 2i + i^2}{1^2 + 1^2}=\frac{2i}{2} = i$$

后一题的技巧: 分母为 $1 - i$ 时, 直接同乘 $1 + i$ 即可; 也可以先看出 $(1 + i)^2 = 2i$, 运算更快.

**例 3**(虚数单位的周期性): 计算 $i^{2026}$.

解: 由 $i^1 = i$, $i^2=-1$, $i^3=-i$, $i^4 = 1$ 可知 $i$ 的幂以 4 为周期. 由 $2026 = 4\times506 + 2$, 得

$$i^{2026} = i^{4\times506 + 2} = (i^4)^{506}\cdot i^2 = 1\cdot(-1)=-1$$

**例 4**(实虚部待定): 设 $(1 + 2i)x + (3 - 5i)y = 2 + i$, 其中 $x,y$ 为实数, 求 $x$ 与 $y$.

解: 整理左端, 分离实虚部:

$$(x + 3y) + (2x - 5y)i = 2 + i$$

由复数相等等价于实虚部分别相等:

$$\begin{cases}x + 3y = 2\\ 2x - 5y = 1\end{cases}$$

解得 $x=\dfrac{13}{11}$, $y=\dfrac{3}{11}$.

**要点**: 凡是"求实数 $x,y$"的题, 手法都是分离实虚部, 化为二元一次方程组.

## 五、易错点

- 把 $\operatorname{Im}z$ 误写成含 $i$ 的表达式. $\operatorname{Im}(3 + 4i) = 4$, 不是 $4i$.
- 认为复数可以比较大小. 只有模、实部、虚部(都是实数) 才能比较.
- 除法时忘记同乘共轭、把分母留成复数.
- 计算 $i$ 的高次幂时忘记周期为 4.
