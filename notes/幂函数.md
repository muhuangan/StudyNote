# 幂函数

幂函数 $w = z^\alpha$ 在复数域中不是"乘若干次"那么简单: 由于要用对数来定义, 它一般**是多值的**. 复数的幂函数统一了实数域的整数次幂、根式与无理次幂, 也统一了 $n$ 次方根的多值性.

## 一、定义

设 $\alpha$ 为复常数, $z\neq0$, 定义

$$w = z^\alpha = e^{\alpha\operatorname{Ln}z} = e^{\alpha(\ln z + 2k\pi i)},\qquad k\in\mathbb{Z}$$

**为什么必须这样定义**: 对一般的 $\alpha$, 反复相乘的定义方式无法解释(例如 $\alpha=\sqrt2$ 时"乘 $\sqrt2$ 次"没有意义). 唯一的推广办法是借助指数与对数:

$$z^\alpha = e^{\alpha\ln z}$$

而 $\ln z$ 多值, 于是 $z^\alpha$ 一般也**多值**.

**取值讨论**:

- 若 $\alpha = n$ 为整数: $e^{n(\ln z + 2k\pi i)} = e^{n\ln z}e^{2kn\pi i} = e^{n\ln z}$, 与 $k$ 无关, 故**单值**; 且 $z^n$ 就是通常的整数次幂(在 $z = 0$ 处补充定义 $0^n = 0$).
- 若 $\alpha=\dfrac1n$($n$ 为正整数): $e^{2k\pi i / n}$ 取 $n$ 个不同值, 故为 **$n$ 值**, 恰与 $\sqrt[n]{z}$ 的 $n$ 个根一致.
- 若 $\alpha=\dfrac pq$ 为**既约有理数**($q>0$): 取值个数为 $q$, 即 **$q$ 值**.
- 若 $\alpha$ 为**无理数或虚数**: $e^{2k\pi\alpha i}$ 随 $k$ 取无穷多个不同值, 故为**无穷多值**.

## 二、主值分支与解析性

取定对数主值 $\ln z$, 得到**主值** $z^\alpha = e^{\alpha\ln z}$, 它在区域 $D=\mathbb{C}\setminus\{(-\infty,0]\cup\{0\}\}$ 内单值解析, 且

$$\frac{d}{dz}z^\alpha=\alpha z^{\alpha - 1}$$

**注意**: $z = 0$ 与 $z=\infty$ 是分支点(当 $\alpha$ 不是整数时).

## 三、例题

**例 1**: 求 $1^{\sqrt2}$ 的全部值.

解: $\operatorname{Ln}1 = 2k\pi i$, 故

$$1^{\sqrt2} = e^{\sqrt2\cdot2k\pi i} = e^{2\sqrt2k\pi i},\qquad k\in\mathbb{Z}$$

由于 $\sqrt2$ 是无理数, 这些值互不相同且模都是 1, 均匀但稠密地分布在单位圆上(不闭合). 共有**无穷多个**值.

**对比**: $1^3 = 1$(单值), $1^{1 / 2}=\pm1$(两值). 可见取值个数取决于指数.

**例 2**: 求 $i^i$ 的值.

解: $\operatorname{Ln}i = i\left(\frac{\pi}{2} + 2k\pi\right)$, 故

$$i^i = e^{i\cdot i(\frac{\pi}{2} + 2k\pi)} = e^{-(\frac{\pi}{2} + 2k\pi)},\qquad k\in\mathbb{Z}$$

**要点**: $i^i$ 的结果是**实数**, 而且有无穷多个值. 主值为 $e^{-\pi / 2}\approx0.2079$.

**例 3**(多值性): 求 $(-1)^{1 / 3}$.

解: $-1 = e^{i(\pi + 2k\pi)}$, 故

$$(-1)^{1 / 3} = e^{i\frac{\pi + 2k\pi}{3}},\qquad k = 0,1,2$$

三个值为

$$e^{\frac{\pi}{3}i}=\frac12+\frac{\sqrt3}{2}i,\qquad e^{\pi i}=-1,\qquad e^{\frac{5\pi}{3}i}=\frac12-\frac{\sqrt3}{2}i$$

与[复数的乘幂与方根](./复数的乘幂与方根.md) 的 $\sqrt[3]{-1}$ 完全一致.

**例 4**(求导): 求 $\dfrac{d}{dz}z^{1 + i}$.

解: 由公式

$$\frac{d}{dz}z^{1 + i} = (1 + i)z^{(1 + i) - 1} = (1 + i)z^{i}$$

原函数与导函数都在 $D=\mathbb{C}\setminus\{(-\infty,0]\cup\{0\}\}$ 内解析.

**例 5**(判断多值性): 判断 $z^{\frac23}$ 的取值个数.

解: $\alpha=\frac23$ 是既约有理数, 分母 $q = 3$. 故有 **3 个值**, 一般**不是** $z^2$ 的立方根集合(虽有关联, 但 $z^{2 / 3}$ 的三个值对应 $z^2$ 的立方根). 写成

$$z^{2 / 3} = e^{\frac23(\ln z + 2k\pi i)},\qquad k = 0,1,2$$

## 四、易错点

- 把 $z^\alpha$ 当成单值函数, 尤其当 $\alpha=\frac pq$ 时漏掉 $q$ 个值.
- 认为 $(z^{\alpha})^{\beta} = z^{\alpha\beta}$. 多值函数下这不成立.
- 忘记 $\alpha$ 为无理数或虚数时有无穷多值.
- 在含负实轴的区域上不加说明地使用主值分支.
- 把 $i^i$ 误认作虚数. 它是实数(主值为 $e^{-\pi / 2}$).
