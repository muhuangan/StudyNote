# 欧姆定律与焦耳定律

欧姆定律描述导电媒质中"电场驱动电流"的关系, 焦耳定律描述电流通过导体时的能量损耗. 二者都由实验定律提升为**点的(微分)形式**.

## 一、欧姆定律的两种形式

**积分形式**(电路中的熟悉写法):

$$U = IR$$

**微分形式**(场论中的写法):

$$\boldsymbol J=\sigma\boldsymbol E$$

其中 $\sigma$ 为**电导率**, 单位 $\text{S/m}$; 其倒数 $\rho_c = 1/\sigma$ 为**电阻率**.

## 二、微分形式的来源推导

取导体内一小段: 长度 $\Delta l$, 截面积 $\Delta S$, 沿电流方向.

- 该段的电位差: $\Delta U = E\,\Delta l$(电场均匀);
- 通过的电流: $\Delta I = J\,\Delta S$;
- 该段电阻: $\Delta R=\dfrac{\Delta l}{\sigma\Delta S}$(由电阻公式, 见下).

代入积分形式的欧姆定律 $\Delta U=\Delta I\cdot\Delta R$:

$$E\,\Delta l = J\,\Delta S\cdot\frac{\Delta l}{\sigma\Delta S}=\frac{J\,\Delta l}{\sigma}$$

消去 $\Delta l$ 得

$$E=\frac{J}{\sigma}\quad\Longrightarrow\quad \boldsymbol J=\sigma\boldsymbol E$$

**要点**: 微分形式不依赖导体形状, 是**点的关系**, 适用于任意非均匀媒质.

## 三、电阻公式的来源

对均匀导体(长 $l$, 截面积 $S$, 电导率 $\sigma$), 由 $U = El$, $I = JS=\sigma ES$:

$$R=\frac{U}{I}=\frac{El}{\sigma ES}=\frac{l}{\sigma S}=\rho_c\frac{l}{S}$$

**结论**: 电阻与长度成正比, 与截面积成反比, 比例系数为电阻率.

## 四、焦耳定律

**积分形式**(电路):

$$P = UI = I^2R=\frac{U^2}{R}$$

**微分形式**(场论): 单位体积内消耗的功率(功率密度)为

$$p=\boldsymbol J\cdot\boldsymbol E=\sigma E^2$$

**来源推导**: 对体积元 $\Delta V=\Delta l\,\Delta S$, 消耗功率

$$\Delta P=\Delta U\cdot\Delta I = (E\,\Delta l)(J\,\Delta S) = EJ\,(\Delta l\,\Delta S) = EJ\,\Delta V$$

除以 $\Delta V$ 得 $p = EJ$; 再用 $\boldsymbol J=\sigma\boldsymbol E$ 得 $p=\sigma E^2$.

**物理意义**: 电场对载流子做功, 载流子通过与晶格碰撞把能量转化为**热**, 这就是电阻发热的微观机制.

## 五、例题

**例 1**: 铜的 $\sigma = 5.8\times10^7\ \text{S/m}$, 求通过 $I = 10\ \text{A}$ 电流、截面积 $1\ \text{mm}^2$ 的铜线中的电场强度与漂移速度.

解:

$$J=\frac{I}{S}=\frac{10}{1\times10^{-6}} = 1\times10^7\ \text{A/m}^2$$
$$E=\frac{J}{\sigma}=\frac{1\times10^7}{5.8\times10^7}\approx0.172\ \text{V/m}$$

**结论**: 铜线中维持 10 A 电流只需极小的电场(每米约 0.17 V), 这正是良导体的特征.

**例 2**(电阻计算): 长 $l = 100\ \text{m}$, 截面积 $S = 2.5\ \text{mm}^2$ 的铜线, 求电阻.

解: $\rho_c = 1/\sigma = 1.72\times10^{-8}\ \Omega\cdot\text{m}$:

$$R=\rho_c\frac{l}{S} = 1.72\times10^{-8}\times\frac{100}{2.5\times10^{-6}} = 1.72\times10^{-8}\times4\times10^7\approx0.69\ \Omega$$

**例 3**(功率密度): 承例 1, 求铜线单位体积的发热功率.

解:

$$p=\boldsymbol J\cdot\boldsymbol E = 1\times10^7\times0.172\approx1.72\times10^6\ \text{W/m}^3$$

再乘铜线体积 $S\times l$ 即总发热功率. 注意: 虽然 $E$ 很小, 但 $J$ 很大, 功率密度仍然可观.

## 六、欧姆定律的适用范围

| 媒质                               | 是否满足 $\boldsymbol J=\sigma\boldsymbol E$                           |
| ---------------------------------- | ---------------------------------------------------------------------- |
| 各向同性线性导电媒质(金属, 电解液) | 满足                                                                   |
| 各向异性媒质(晶体, 等离子体)       | 需写成**张量**形式 $\boldsymbol J=\boldsymbol\sigma\cdot\boldsymbol E$ |
| 半导体, 气体放电                   | 非线性, $\sigma$ 随场强变化                                            |
| 超导体                             | 不适用(电阻为零, $E$ 可为 0 而 $J\ne0$)                                |

## 七、易错点

- 把电阻率 $\rho_c$ 与电荷密度 $\rho$ 混为一谈: 二者符号相近但含义完全不同.
- 把 $p=\boldsymbol J\cdot\boldsymbol E$ 写成 $JE^2$ 或 $J^2E$.
- 认为"电阻是材料的属性": 电阻与**几何尺寸**有关, 电阻率才是材料属性.
- 用 $P = I^2R$ 计算**媒质内部发热**时误用: 场论中应改用 $\int_V\sigma E^2\,dV$.
