# OC门与三态门

## 核心结论

**OC 门**解决"多个输出直接并联实现线与",**三态门**解决"多个输出通过高阻态共享总线". 两者的共同点是都破坏了普通推挽输出的结构, 因此都需要额外处理(上拉电阻或使能控制).

## 一、为什么普通门不能线与

推挽输出结构的门, 输出高电平时上拉管导通, 输出低电平时下拉管导通. 若把两个普通门的输出直接并联:

- 一个输出 1, 另一个输出 0 时, 电源经上拉管与下拉管形成**低阻直流通路**, 产生数十毫安的大电流.
- 结果是输出电平不确定(约 1.4 V, 落在禁止区), 且器件可能过热损坏.

因此**普通推挽输出门严禁并联**.

## 二、OC 门(集电极开路门)

**结构**: 把输出级的上拉部分(T4, D2, R4) 全部去掉, 只保留下拉管 T5, T5 的集电极**悬空**引出作为输出端.

**工作条件**: 必须**外接上拉电阻** $R_L$ 到电源 $V_{CC}'$, 否则无法输出高电平.

| 状态   | T5       | 输出                                       |
| ------ | -------- | ------------------------------------------ |
| 逻辑 0 | 饱和导通 | 输出被拉到 $V_{CES} \approx 0.2\ \text{V}$ |
| 逻辑 1 | 截止     | 输出被 $R_L$ 上拉到 $V_{CC}'$              |

### 线与功能

多个 OC 门的输出并联到同一上拉电阻时, 只要有任意一个门输出低电平, 总线就被拉低:

$$F = \overline{A_1 B_1} \cdot \overline{A_2 B_2} \cdot \cdots = \overline{A_1 B_1 + A_2 B_2 + \cdots}$$

这就是**线与(Wired-AND)**—在输出端直接完成与运算, 无需额外门电路.

### 上拉电阻的计算

设参与线与的 OC 门数为 $n$, 后级负载门的输入端数为 $m$.

**上限(保证输出高电平)**: 所有 OC 门都截止时, 流过 $R_L$ 的电流包括 $n$ 个门的输出漏电流 $I_{OH}$ 和 $m$ 个负载输入的高电平电流 $I_{IH}$:

$$R_{L(max)} = \frac{V_{CC} - V_{OH(min)}}{n \cdot I_{OH} + m \cdot I_{IH}}$$

若 $R_L$ 大于此值, 输出高电平将低于 $V_{OH(min)}$.

**下限(保证输出低电平且不过流)**: 只有一个 OC 门导通时, 流过 $R_L$ 的电流加上 $m$ 个负载注入的电流, 全部灌入该导通管, 不得超过其最大灌电流 $I_{OL(max)}$:

$$R_{L(min)} = \frac{V_{CC} - V_{OL(max)}}{I_{OL(max)} - m \cdot |I_{IL}|}$$

若 $R_L$ 小于此值, 导通管会过流.

**取值**:$R_{L(min)} \le R_L \le R_{L(max)}$, 通常取中间偏小的值以兼顾速度($R_L$ 越小, 对负载电容充电越快, 上升沿越陡).

### OC 门的其他用途

1. **电平转换**: 上拉电阻接到与 $V_{CC}$ 不同的电源 $V_{CC}'$, 即可把 TTL 电平转换为更高电压(如 12 V, 15 V) 的电平.
2. **驱动大电流负载**: 直接驱动继电器, LED, 指示灯等, 只要不超过 $I_{OL(max)}$.
3. **总线连接**: 多个设备通过 OC 输出挂在同一条线上, 实现"任一设备拉低即有效"的中断请求线.

**CMOS 的对应结构**是 OD 门(漏极开路门), 原理完全相同.

## 三、三态门(TSL 门)

**三种输出状态**:

| 状态      | 含义       | 输出阻抗       |
| --------- | ---------- | -------------- |
| 高电平    | 逻辑 1     | 低阻, 主动上拉 |
| 低电平    | 逻辑 0     | 低阻, 主动下拉 |
| 高阻态(Z) | 输出被断开 | 极高阻(兆欧级) |

**结构**: 在普通推挽输出门的基础上增加一个**使能控制端** $EN$. 当 $EN$ 无效时, 控制电路使上拉管和下拉管**同时截止**, 输出呈现高阻态.

**使能方式**:

- 高电平有效:$EN = 1$ 时正常工作,$EN = 0$ 时高阻.
- 低电平有效:$\overline{EN} = 0$ 时正常工作,$\overline{EN} = 1$ 时高阻(符号上用小圆圈表示).

### 总线应用

$$原则:任意时刻只允许一个三态门处于工作状态,其余必须为高阻态.$$

典型应用是**数据总线**: CPU, 存储器, 外设都挂在同一组数据线上, 靠地址译码产生的片选信号控制各设备的三态缓冲器, 实现分时复用.

**控制信号的设计要点**:

1. 切换时必须保证"先断后通", 即先让原驱动门进入高阻, 再让新驱动门开始驱动. 若两者同时驱动, 会形成与"线与冲突"类似的短路电流.
2. 实际系统中常插入一个短暂的"死区时间"(总线空闲期) 来规避冲突.

### 三态门与 OC 门的对比

| 对比项         | OC 门               | 三态门               |
| -------------- | ------------------- | -------------------- |
| 需要外接电阻   | 是(上拉电阻)        | 否                   |
| 输出高电平方式 | 靠电阻上拉, 速度慢  | 主动上拉, 速度快     |
| 能否线与       | 能                  | 不能(同时导通会冲突) |
| 总线应用       | 可以(但速度受限)    | 首选方案             |
| 驱动能力       | 弱(受上拉电阻限制)  | 强                   |
| 高阻态         | 输出 1 时即等于断开 | 显式的高阻态         |

## 四、工程选型

| 需求                         | 选择                       |
| ---------------------------- | -------------------------- |
| 多个输出"与"在一起(如中断线) | OC 门                      |
| 需要电平转换                 | OC 门(或专用电平转换芯片)  |
| 驱动 LED, 继电器             | OC 门                      |
| 双向数据总线                 | 三态门(双向缓冲器 74LS245) |
| 高速单向总线                 | 三态门(74LS244)            |

## 易错点

- OC 门不加外接上拉电阻就完全没有高电平输出能力, 这是最常见的原理性错误.
- 三态门的高阻态**不等于**逻辑 0, 测量高阻节点电压会得到不确定的浮动值, 必须靠总线上的其他驱动或上/下拉电阻确定电平.
- 上拉电阻的两个极值公式容易记反: 分子都是 $V_{CC} - V_{O}$, 但**上限**除以的是"截止时的总漏电流",**下限**除以的是"导通时的允许灌电流减去负载注入电流".
