# 复数的乘幂与方根

用指数形式做乘幂与开方, 是复数运算中效率最高的一步: 乘幂把"乘 $n$ 次"变成"辐角乘 $n$", 开方则把"根号"变成"辐角除以 $n$ 再加上 $\frac{2k\pi}{n}$". 后者引出复数与实数的一个根本差别------**在复数域内, $n$ 次方程一定有 $n$ 个根**.

## 一、乘幂

设 $z=|z|e^{i\theta}$, $n$ 为正整数. 反复用"模相乘、辐角相加"得

$$z^n=|z|^ne^{in\theta}=|z|^n(\cos n\theta + i\sin n\theta)$$

这就是**棣莫弗(De Moivre) 公式**:

$$(\cos\theta + i\sin\theta)^n=\cos n\theta + i\sin n\theta$$

对负整数 $n$, 由 $z^{-n}=\dfrac{1}{z^n}$ 与 $\left|\dfrac1z\right|=\dfrac{1}{|z|}$ 同样成立.

**要点**: 乘幂只改变模和辐角, **并不产生多值性**------$z^n$ 仍是单值的.

## 二、方根

求满足 $w^n = z$ 的 $w$(记作 $w=\sqrt[n]{z}$). 设 $z=|z|e^{i\theta}$, $w=|w|e^{i\varphi}$, 则

$$|w|^ne^{in\varphi}=|z|e^{i\theta}$$

比较模与辐角(注意辐角的多值性):

$$|w|^n=|z|\ \Longrightarrow\ |w|=\sqrt[n]{|z|}$$
$$n\varphi=\theta + 2k\pi\ \Longrightarrow\ \varphi=\frac{\theta + 2k\pi}{n}$$

于是

$$w_k=\sqrt[n]{|z|}\,e^{i\frac{\theta + 2k\pi}{n}},\qquad k = 0,1,2,\dots,n - 1$$

**关键结论**:

- $n$ 次方根共有 **$n$ 个互不相同的值**, 对应 $k = 0,1,\dots,n - 1$; 当 $k$ 继续增大时取值开始重复(因为辐角相差 $2\pi$ 给出同一个数).
- 这 $n$ 个根**均匀分布在以原点为心、半径为 $\sqrt[n]{|z|}$ 的圆周上**, 相邻两根的张角为 $\dfrac{2\pi}{n}$.
- 开方是**多值**运算, 这是复数与实数的重要差别: 实数开偶次方在负数处无解, 而复数域内一定有 $n$ 个解.

## 三、例题

**例 1**(乘幂): 计算 $(1+\sqrt3 i)^6$.

解: 先化为指数形式. $|1+\sqrt3 i|=\sqrt{1 + 3} = 2$, 点在第一象限, $\arg z=\dfrac{\pi}{3}$. 故

$$1+\sqrt3 i = 2e^{\frac{\pi}{3}i}$$

$$(1+\sqrt3 i)^6 = 2^6e^{6\cdot\frac{\pi}{3}i} = 64e^{2\pi i} = 64$$

**说明**: 结果为实数. 若直接用二项式展开, 需计算 7 个组合数并反复用 $i^2=-1$, 相当繁琐.

**例 2**(方根): 求 $\sqrt[3]{1}$ 的全部值, 并说明其几何分布.

解: $1$ 的模为 1, 一个辐角取 $0$. 由公式

$$w_k = e^{i\frac{0 + 2k\pi}{3}},\qquad k = 0,1,2$$

依次得

$$w_0 = e^{0} = 1$$
$$w_1 = e^{\frac{2\pi}{3}i}=-\frac12+\frac{\sqrt3}{2}i$$
$$w_2 = e^{\frac{4\pi}{3}i}=-\frac12-\frac{\sqrt3}{2}i$$

三个根分别是复平面上的三个点, 均匀分布在单位圆上, 相邻张角 $\frac{2\pi}{3}$. 它们恰好构成**内接于单位圆的等边三角形的三个顶点**.

**验算**: $w_1^3 = e^{2\pi i} = 1$, $w_2^3 = e^{4\pi i} = 1$, 成立.

**例 3**(一般方根): 求 $\sqrt[4]{-16}$ 的全部值.

解: $-16$ 的模为 16, 辐角可取 $\pi$. 于是

$$|w|=\sqrt[4]{16} = 2,\qquad \varphi=\frac{\pi + 2k\pi}{4},\quad k = 0,1,2,3$$

四个辐角依次为 $\frac{\pi}{4}$, $\frac{3\pi}{4}$, $\frac{5\pi}{4}$, $\frac{7\pi}{4}$, 故

$$w_k = 2e^{i\frac{(2k + 1)\pi}{4}},\qquad k = 0,1,2,3$$

展开为直角坐标: $\sqrt2+\sqrt2 i$, $-\sqrt2+\sqrt2 i$, $-\sqrt2-\sqrt2 i$, $\sqrt2-\sqrt2 i$.

**验算一个**: $(\sqrt2+\sqrt2 i)^2 = 2 + 4i + 2i^2 = 4i$, 再平方得 $(4i)^2=-16$, 正确.

**例 4**(解方程): 解方程 $z^3 + 8 = 0$.

解: 原方程即 $z^3=-8$. 由方根公式, $|z|=\sqrt[3]{8} = 2$, 辐角为 $\frac{\pi + 2k\pi}{3}$:

$$z_0 = 2e^{\frac{\pi}{3}i} = 1+\sqrt3 i$$
$$z_1 = 2e^{\pi i}=-2$$
$$z_2 = 2e^{\frac{5\pi}{3}i} = 1-\sqrt3 i$$

**三个根之和为 $0$**, 这是 $n$ 次方程缺二次项时的一般规律(韦达定理).

**例 5**(用乘幂证明三角恒等式): 用棣莫弗公式导出 $\cos3\theta$ 与 $\sin3\theta$ 的表达式.

解: 由 $(\cos\theta + i\sin\theta)^3=\cos3\theta + i\sin3\theta$, 左端按二项式展开:

$$(c + is)^3 = c^3 + 3c^2(is) + 3c(is)^2 + (is)^3 = c^3 - 3cs^2 + i(3c^2s - s^3)$$

其中记 $c=\cos\theta$, $s=\sin\theta$. 比较实虚部得

$$\cos3\theta = c^3 - 3cs^2 = 4\cos^3\theta - 3\cos\theta$$
$$\sin3\theta = 3c^2s - s^3 = 3\sin\theta - 4\sin^3\theta$$

**这是"倍角公式"的通用推导方式**: 把 $n$ 换成任意正整数, 都能用同样办法导出 $\cos n\theta$ 与 $\sin n\theta$.

## 四、易错点

- 开方只取一个值. $n$ 次方根有 $n$ 个, 漏掉会直接导致答案错误.
- 忘记 $\sqrt[n]{|z|}$ 中的模是先取模再开方, 而不是对整个 $z$ 开方.
- 用错辐角的初始值: 若取的 $\theta$ 不同(相差 $2\pi$), $k$ 的编号会平移, 但**根的集合不变**. 写答案时应以集合形式给出.
- 把乘幂也当成多值. 只有开方(以及后面的对数) 才多值.
- 混淆 $\sqrt[n]{z}$ 与 $(\sqrt[n]{|z|})e^{i\theta / n}$ 的单值写法: 后者只给出主值, 不是全部根.
