# 波动方程

波动方程是麦克斯韦方程组在无源区域的直接推论. 它说明**电磁场能以波的形式脱离场源独立传播**, 这是麦克斯韦理论最伟大的预言.

## 一、时域波动方程的来源推导

在**无源区域**($\rho = 0$, $\boldsymbol J=\boldsymbol 0$)、均匀理想介质中, 麦克斯韦方程组化为

$$\nabla\times\boldsymbol E=-\mu\frac{\partial\boldsymbol H}{\partial t}\qquad(1)$$
$$\nabla\times\boldsymbol H=\varepsilon\frac{\partial\boldsymbol E}{\partial t}\qquad(2)$$

对式 (1) 取旋度:

$$\nabla\times(\nabla\times\boldsymbol E)=-\mu\frac{\partial}{\partial t}(\nabla\times\boldsymbol H)$$

右端代入式 (2):

$$\nabla\times(\nabla\times\boldsymbol E)=-\mu\varepsilon\frac{\partial^2\boldsymbol E}{\partial t^2}$$

左端用矢量恒等式 $\nabla\times(\nabla\times\boldsymbol E)=\nabla(\nabla\cdot\boldsymbol E)-\nabla^2\boldsymbol E$. 无源区 $\nabla\cdot\boldsymbol E = 0$, 故左端为 $-\nabla^2\boldsymbol E$. 于是

$$\nabla^2\boldsymbol E=\mu\varepsilon\frac{\partial^2\boldsymbol E}{\partial t^2}$$

同理对磁场

$$\nabla^2\boldsymbol H=\mu\varepsilon\frac{\partial^2\boldsymbol H}{\partial t^2}$$

**这两个方程就是齐次波动方程**. 对比标准形式 $\nabla^2u=\dfrac{1}{v^2}\dfrac{\partial^2u}{\partial t^2}$ 可得波速

$$v=\frac{1}{\sqrt{\mu\varepsilon}}$$

**真空中** $v=\dfrac{1}{\sqrt{\mu_0\varepsilon_0}}\approx3\times10^8\ \text{m/s} = c$——与光速一致, 这便是"光是电磁波"的论断依据.

## 二、相量形式: 亥姆霍兹方程

用相量替换 $\partial/\partial t\to j\omega$, 波动方程退化为**亥姆霍兹方程**:

$$\nabla^2\dot{\boldsymbol E} + k^2\dot{\boldsymbol E}=\boldsymbol 0,\qquad \nabla^2\dot{\boldsymbol H} + k^2\dot{\boldsymbol H}=\boldsymbol 0$$

其中

$$k=\omega\sqrt{\mu\varepsilon}=\frac{\omega}{v}$$

称为**波数**. 亥姆霍兹方程是**空间上的**方程, 已不含时间导数.

## 三、平面波解的来源

设平面波沿 $+z$ 传播, $\dot{\boldsymbol E}$ 只依赖 $z$, 则亥姆霍兹方程化为常微分方程

$$\frac{d^2\dot E_x}{dz^2} + k^2\dot E_x = 0$$

其通解为

$$\dot E_x = E_0^+e^{-jkz} + E_0^-e^{+jkz}$$

其中 $e^{-jkz}$ 代表沿 $+z$ 传播的波, $e^{+jkz}$ 代表沿 $-z$ 传播的波. 取前者并还原为瞬时值:

$$\boldsymbol E(z,t)=\boldsymbol e_xE_0\cos(\omega t - kz)$$

这正是[平面电磁波](./平面电磁波.md)中采用的解.**可见波动方程是平面波理论的出发点**.

## 四、无源区域方程组的完整结论

| 方程     | 形式                                                                                             |
| -------- | ------------------------------------------------------------------------------------------------ |
| 波动方程 | $\nabla^2\boldsymbol E=\mu\varepsilon\dfrac{\partial^2\boldsymbol E}{\partial t^2}$              |
| 相量形式 | $\nabla^2\dot{\boldsymbol E} + k^2\dot{\boldsymbol E} = 0$                                       |
| 波速     | $v = 1/\sqrt{\mu\varepsilon}$                                                                    |
| 波数     | $k=\omega\sqrt{\mu\varepsilon} = 2\pi/\lambda$                                                   |
| 场量关系 | $\boldsymbol H=\dfrac{1}{\eta}\boldsymbol e_z\times\boldsymbol E$, $\eta=\sqrt{\mu/\varepsilon}$ |

## 五、例题

**例 1**: 求电磁波在 $\varepsilon_r = 4$、$\mu_r = 1$ 的理想介质中的传播速度与波长(频率 $f = 100\ \text{MHz}$).

解:

$$v=\frac{c}{\sqrt{\varepsilon_r\mu_r}}=\frac{3\times10^8}{2} = 1.5\times10^8\ \text{m/s}$$
$$\lambda=\frac vf=\frac{1.5\times10^8}{10^8} = 1.5\ \text{m}$$

**例 2**(验证解): 验证 $\boldsymbol E=\boldsymbol e_xE_0\cos(\omega t - kz)$ 满足波动方程, 并求 $k$ 与 $\omega$ 的关系.

解: 逐项求导

$$\frac{\partial^2\boldsymbol E}{\partial z^2}=-\boldsymbol e_xk^2E_0\cos(\omega t - kz),\qquad \frac{\partial^2\boldsymbol E}{\partial t^2}=-\boldsymbol e_x\omega^2E_0\cos(\omega t - kz)$$

代入波动方程 $\dfrac{\partial^2\boldsymbol E}{\partial z^2}=\mu\varepsilon\dfrac{\partial^2\boldsymbol E}{\partial t^2}$:

$$-k^2=\mu\varepsilon(-\omega^2)\ \Longrightarrow\ k=\omega\sqrt{\mu\varepsilon}$$

**结论**: 只有当 $k$ 与 $\omega$ 满足此**色散关系**时, 正弦解才成立. 这也说明理想介质中 $k$ 与 $\omega$ 成正比, 即**无色散**.

**例 3**: 说明为什么无源区域的波动方程中可以用 $\nabla\cdot\boldsymbol E = 0$.

解: 在无源区 $\rho = 0$, 由 $\nabla\cdot\boldsymbol D=\rho$ 且均匀介质 $\boldsymbol D=\varepsilon\boldsymbol E$, 得 $\nabla\cdot\boldsymbol E = 0$. 这也是能直接用恒等式 $\nabla\times(\nabla\times\boldsymbol E)=-\nabla^2\boldsymbol E$ 的前提.**有源区域的推导要复杂得多**, 会得到非齐次波动方程(右端出现源项).

## 六、易错点

- 忘记推导中用到的两个前提: **无源** ($\rho = 0,\boldsymbol J=\boldsymbol 0$) 与**均匀介质**.
- 把波速写成 $v=\sqrt{\mu\varepsilon}$: 正确的是 $1/\sqrt{\mu\varepsilon}$.
- 混淆波数 $k$ 与角频率 $\omega$: 前者描述空间变化, 后者描述时间变化, 由色散关系 $k=\omega / v$ 联系.
- 在无源区域之外仍使用 $\nabla^2\boldsymbol E=\mu\varepsilon\partial^2\boldsymbol E/\partial t^2$.
