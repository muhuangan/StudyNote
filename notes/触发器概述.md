# 触发器概述

## 核心结论

触发器是能够存储 1 位二值信号的基本单元电路. 它的本质是**带反馈的组合电路**: 把输出反馈回输入, 使电路具有两个自保持的稳定状态, 从而实现记忆功能.

## 一、触发器的三个基本特点

1. **有两个稳定状态**: 分别称为 0 态($Q = 0$,$\overline{Q} = 1$) 和 1 态($Q = 1$,$\overline{Q} = 0$).
2. **能长期保持**: 在没有外界触发信号时, 状态可以无限期保持(只要不断电).
3. **状态可改变**: 在输入信号作用下, 可以从一个稳态翻转到另一个稳态, 且翻转后新状态被保持.

**注意**: 0 态和 1 态的命名是约定的, 与 $Q$ 端的电平对应关系不可混淆. 通常以 $Q$ 端的电平作为触发器状态的标识.

## 二、为什么反馈能产生记忆

把两个反相器交叉耦合(首尾相接), 就构成最简单的双稳电路:

$$Q = \overline{\overline{Q}} = Q$$

这个等式对 $Q = 0$ 和 $Q = 1$ 都成立, 因此电路有两个**自洽的稳定状态**. 外界施加足够的驱动可以把它从一个稳态推到另一个稳态, 撤去驱动后新状态自行保持. 这就是全部触发器(以及 SRAM 存储单元) 的物理基础.

## 三、锁存器与触发器的区别

| 对比项       | 锁存器(Latch)                | 触发器(Flip-Flop)                |
| ------------ | ---------------------------- | -------------------------------- |
| 敏感对象     | **电平**敏感                 | **边沿**敏感                     |
| 透明性       | 使能期间输出随输入变化(透明) | 只在时钟沿瞬间采样, 其余时间封闭 |
| 状态更新次数 | 使能期间可多次翻转           | 每个时钟沿最多翻转一次           |
| 抗干扰能力   | 弱                           | 强                               |
| 典型器件     | SR 锁存器, 透明 D 锁存器     | 边沿 D 触发器, 边沿 JK 触发器    |

**术语说明**: 不同教材对这两个词的界定不完全一致. 本书(阎石) 的用法是: 由电平信号控制的基本存储单元称作**锁存器**; 在时钟信号控制下工作的存储单元统称**触发器**, 并按触发方式进一步分为电平触发, 脉冲触发, 边沿触发三类. 阅读资料时需注意这一术语差异.

## 四、触发器的分类

**按逻辑功能**:

| 类型 | 特性方程                                 | 特点                           |
| ---- | ---------------------------------------- | ------------------------------ |
| SR   | $Q^* = S + \overline{R}Q$, 约束 $SR = 0$ | 最基础, 有约束条件             |
| JK   | $Q^* = J\overline{Q} + \overline{K}Q$    | 功能最全, 无约束               |
| D    | $Q^* = D$                                | 最常用, 用于数据存储与移位     |
| T    | $Q^* = T \oplus Q$                       | 用于计数, 分频                 |
| T'   | $Q^* = \overline{Q}$                     | T 恒为 1, 每来一个脉冲翻转一次 |

**按触发方式**:

| 方式           | 更新时刻                     | 问题             |
| -------------- | ---------------------------- | ---------------- |
| 电平触发       | 时钟为有效电平的**整个期间** | 存在空翻         |
| 脉冲触发(主从) | 时钟的**下降沿**(或上升沿)   | 有一次翻转现象   |
| 边沿触发       | 时钟的**上升沿或下降沿瞬间** | 最可靠, 现代主流 |

**按器件工艺**: TTL 触发器, CMOS 触发器.

## 五、现态与次态

**现态** $Q^n$(或记作 $Q$): 触发器在触发信号**到来之前**的状态.

**次态** $Q^{n+1}$(或记作 $Q^*$): 触发器在触发信号**作用之后**的新状态.

**特性方程**就是描述二者与输入之间关系的方程:

$$Q^* = f(\text{输入},\ Q)$$

这一记号在时序电路的分析和设计中贯穿始终.

## 六、时序电路中的地位

触发器是**时序逻辑电路的核心存储元件**:

- 寄存器 = 多个 D 触发器并联.
- 计数器 = 触发器 + 组合反馈逻辑.
- 状态机 = 触发器组(状态寄存器)+ 组合逻辑(次态逻辑与输出逻辑).

## 七、选用的一般原则

1. 数据存储, 移位, 同步 → **边沿 D 触发器**.
2. 计数, 分频 → **T 或 T' 触发器**(通常由 D 或 JK 转换而来).
3. 需要完整状态控制能力 → **JK 触发器**.
4. 高速系统一律选**边沿触发**, 避免电平敏感带来的空翻与毛刺传播.

## 易错点

- 认为触发器"输出就是输入": 实际上触发器输出的是**上一次时钟沿采样到的输入**, 二者相差一个时钟周期.
- 混淆 $Q$ 与 $\overline{Q}$: 状态指的是 $Q$ 端的电平.
