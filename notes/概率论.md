# 概率论

## 阅读约定

1. 随机变量用大写字母 $X,Y,Z$ 表示, 其取值用相应的 $x,y,z$ 表示; 事件用 $A,B,C$ 表示.
2. $E(X)$ 表示数学期望, $D(X)$ 表示方差, $\operatorname{Cov}(X,Y)$ 表示协方差, $\rho_{XY}$ 表示相关系数.
3. $F(x)$ 表示分布函数, $f(x)$ 表示概率密度, $\varphi(x)$ 与 $\Phi(x)$ 分别表示标准正态分布的密度与分布函数.
4. 每篇笔记均含定义, 公式, 性质与例题, 例题给出完整步骤与数值, 便于独立重算.
