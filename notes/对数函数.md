# 对数函数

对数函数在复数域中**必然是多值的**, 根源是指数函数的周期性. 这不是技术上的缺点, 而是复分析的基本事实: 多值性引出了分支、割线与黎曼面这些概念. 处理办法是先接受多值, 再通过限制辐角范围取出单值分支.

## 一、定义

称满足

$$e^w = z\qquad(z\neq0)$$

的 $w$ 为 $z$ 的**对数**, 记作 $w = \operatorname{Ln}z$.

设 $z=|z|e^{i\theta}$, $w = u + iv$. 由 $e^{u + iv}=|z|e^{i\theta}$ 得 $e^u=|z|$, $v=\theta + 2k\pi$. 故

$$\operatorname{Ln}z=\ln|z|+i(\arg z + 2k\pi)=\ln|z|+i\operatorname{Arg}z,\qquad k = 0,\pm1,\pm2,\dots$$

其中 $\ln|z|$ 是通常的实对数.

**要点**: $\operatorname{Ln}z$ 是**多值函数**, 每支相差 $2\pi i$.

## 二、主值分支与单值化

把辐角限制在 $(-\pi,\pi]$ 内, 得到**主值分支**

$$\ln z=\ln|z|+i\arg z$$

于是

$$\operatorname{Ln}z=\ln z + 2k\pi i$$

**单值化与割线**: 取定主值后, $\ln z$ 在**去掉原点与负实轴**的区域 $D=\mathbb{C}\setminus\{(-\infty,0]\cup\{0\}\}$ 内是单值解析的. 负实轴称为**割线**, $z = 0$ 与 $z=\infty$ 是**分支点**.

**为什么必须割开负实轴**: 若绕过原点一周, 辐角由 $\pi$ 变为 $-\pi$, $\ln z$ 的虚部突然跳变 $2\pi$, 函数不连续. 必须沿某条射线"剪开"才能得到单值连续分支.

## 三、性质

**(1) 解析性**: 主值分支 $\ln z$ 在去掉原点与负实轴的区域上解析, 且

$$\frac{d}{dz}\ln z=\frac1z$$

**(2) 运算性质**(仅在某些分支下成立):

$$\operatorname{Ln}(z_1z_2) = \operatorname{Ln}z_1 + \operatorname{Ln}z_2\qquad\text{(作为集合等式)}$$

**注意**: 对主值一般**不**成立 $\ln(z_1z_2)=\ln z_1+\ln z_2$, 两边可能相差 $2\pi i$.

**(3) 与实对数的一致性**: 当 $z = x>0$ 时, $\ln z=\ln x$, 与实对数吻合.

**(4) 特殊值**:

$$\ln1 = 0,\qquad \operatorname{Ln}1 = 2k\pi i$$
$$\ln(-1) = i\pi,\qquad \operatorname{Ln}(-1) = i\pi + 2k\pi i = (2k + 1)\pi i$$
$$\ln i=\frac{\pi i}{2},\qquad \operatorname{Ln}i = i\left(\frac{\pi}{2} + 2k\pi\right)$$

## 四、例题

**例 1**: 求 $\operatorname{Ln}(-1+\sqrt3 i)$ 与主值 $\ln(-1+\sqrt3 i)$.

解: 由[复数的模与辐角](./复数的模与辐角.md) 例 1, $|-1+\sqrt3 i|=2$, 辐角主值为 $\frac{2\pi}{3}$. 故

$$\ln(-1+\sqrt3 i)=\ln2+\frac{2\pi}{3}i$$
$$\operatorname{Ln}(-1+\sqrt3 i)=\ln2 + i\left(\frac{2\pi}{3} + 2k\pi\right),\qquad k\in\mathbb{Z}$$

**例 2**: 求 $\operatorname{Ln}(1 - i)$.

解: $|1 - i|=\sqrt2$, $\arg(1 - i)=-\frac{\pi}{4}$. 故

$$\operatorname{Ln}(1 - i)=\frac12\ln2 + i\left(-\frac{\pi}{4} + 2k\pi\right),\qquad k\in\mathbb{Z}$$

**例 3**(不等式陷阱): 验证 $\operatorname{Ln}(z_1z_2)$ 与 $\operatorname{Ln}z_1 + \operatorname{Ln}z_2$ 的关系. 取 $z_1 = z_2=-1$.

解: 左端

$$\operatorname{Ln}\big((-1)(-1)\big) = \operatorname{Ln}1 = 2k\pi i$$

右端

$$\operatorname{Ln}(-1) + \operatorname{Ln}(-1) = i\pi(2m + 1) + i\pi(2n + 1) = 2(m + n + 1)\pi i$$

两者都等于"$2\pi i$ 的整数倍", 作为**集合**相等.

但取主值:

$$\ln(1) = 0,\qquad \ln(-1)+\ln(-1) = 2\pi i\neq0$$

**主值不满足加性**. 若写 $\ln(z_1z_2)=\ln z_1+\ln z_2$, 结果可能相差 $2\pi i$ 的整数倍.

**例 4**(解方程): 解方程 $\ln z=\dfrac{\pi}{2}i$.

解: 由定义

$$\ln z=\ln|z|+i\arg z=\frac{\pi}{2}i$$

比较实虚部: $\ln|z|=0$ 得 $|z|=1$; $\arg z=\frac{\pi}{2}$ 得辐角主值为 $\frac{\pi}{2}$. 故

$$z = e^{\frac{\pi}{2}i} = i$$

**例 5**(求导): 求 $\dfrac{d}{dz}\ln(z + 1)$ 并指出解析区域.

解: 由链式法则

$$\frac{d}{dz}\ln(z + 1)=\frac{1}{z + 1}$$

解析区域为去掉 $z + 1$ 的零点与割线的区域. 主值分支的割线取 $\operatorname{Re}(z + 1)\le0,\ \operatorname{Im}(z + 1) = 0$, 即 $z\le - 1$ 的实轴部分. 因此 $\ln(z + 1)$ 在**去掉射线 $z\le - 1$** 的区域上解析.

## 五、易错点

- 忘记 $\operatorname{Ln}$ 的多值性, 只写一个值.
- 对主值套用 $\ln(z_1z_2)=\ln z_1+\ln z_2$, 导致结果差 $2\pi i$.
- 忘记说明解析区域包含"去掉割线", 只写"去掉原点".
- 把 $\operatorname{Ln}0$ 当作有定义. $0$ 没有对数.
- 写 $\ln z$ 的导数为 $\frac1z$ 时不声明分支.
