# 脉冲触发触发器

## 核心结论

脉冲触发触发器采用**主-从两级结构**: 主触发器在 $CLK = 1$ 期间接收输入, 从触发器在 $CLK$ 下降沿把主触发器的状态送到输出. 它解决了空翻, 但引入了**一次翻转现象**—在 $CLK = 1$ 期间主触发器只能翻转一次, 因此要求输入信号在此期间保持稳定.

## 一、主从结构的工作原理

**两级结构**:

1. **主触发器**: 由 $CLK$ 直接控制(高电平有效).
2. **从触发器**: 由 $\overline{CLK}$ 控制, 即 $CLK$ 的低电平期间工作.
3. 两级之间通过一个受反相时钟控制的传输门(或门控锁存器) 连接.

**一个完整时钟周期的动作**:

| 阶段           | 主触发器       | 从触发器               | 输出               |
| -------------- | -------------- | ---------------------- | ------------------ |
| $CLK = 0$      | 保持(封锁输入) | 工作(接收主触发器状态) | 保持上一周期的结果 |
| $CLK$ 上升沿   | 开始接收输入   | 被封锁                 | 不变               |
| $CLK = 1$ 期间 | 按输入信号动作 | 被封锁                 | 不变               |
| $CLK$ 下降沿   | 被封锁         | 接收主触发器状态       | **更新为新状态**   |

**关键结论**: 输出只在 $CLK$ 的**下降沿**改变(也有上升沿更新的产品, 取决于内部反相的位置), 因此每个时钟周期最多翻转一次, 空翻被消除.

## 二、主从 SR 触发器

**特性表**(输出在下降沿更新):

| S   | R   | Q        | $Q^*$      |
| --- | --- | -------- | ---------- |
| 0   | 0   | $\times$ | $Q$(保持)  |
| 0   | 1   | $\times$ | 0(置 0)    |
| 1   | 0   | $\times$ | 1(置 1)    |
| 1   | 1   | $\times$ | 不定(禁止) |

**特性方程**:

$$Q^* = S + \overline{R}Q,\quad SR = 0$$

仍然保留 SR 的约束条件.

## 三、主从 JK 触发器

**结构改进**: 把主从 SR 触发器的输出反馈回主触发器的输入门:

$$S = J\overline{Q},\quad R = KQ$$

**关键效果**:

$$SR = J\overline{Q} \cdot KQ = JK \cdot Q\overline{Q} = 0$$

约束条件**自动满足**, 因此 $J = K = 1$ 是允许的, 此时触发器处于**翻转(计数)**状态.

**特性表**:

| J   | K   | Q   | $Q^*$ | 功能     |
| --- | --- | --- | ----- | -------- |
| 0   | 0   | 0   | 0     | 保持     |
| 0   | 0   | 1   | 1     | 保持     |
| 0   | 1   | 0   | 0     | 置 0     |
| 0   | 1   | 1   | 0     | 置 0     |
| 1   | 0   | 0   | 1     | 置 1     |
| 1   | 0   | 1   | 1     | 置 1     |
| 1   | 1   | 0   | 1     | **翻转** |
| 1   | 1   | 1   | 0     | **翻转** |

**特性方程**:

$$Q^* = J\overline{Q} + \overline{K}Q$$

JK 触发器是功能最完整的触发器: 只需改变 $J$,$K$ 的接法即可实现保持, 置 0, 置 1, 翻转四种功能.

## 四、一次翻转现象(主从 JK 的特有问题)

**现象**: 在 $CLK = 1$ 期间, 主触发器的状态**只能翻转一次**; 一旦翻转, 即使 $J$,$K$ 随后再变化, 主触发器也不会再翻转.

**原因**: 主触发器的输入 $S = J\overline{Q}_{主}$,$R = KQ_{主}$ 取自**主触发器自身的状态**. 当主触发器翻转后, 反馈信号随之改变, 使原来的驱动条件消失, 因此无法再次翻转.

**两种典型情形**:

1. 若 $Q = 0$, 则在 $CLK = 1$ 期间只要 $J$ 出现过 1(哪怕只是一个窄脉冲), 主触发器就翻转为 1, 之后 $J$ 再变化也无效.
2. 若 $Q = 1$, 则在 $CLK = 1$ 期间只要 $K$ 出现过 1, 主触发器就翻转为 0, 之后 $K$ 再变化也无效.

**工程后果**: 主从 JK 触发器要求**$J$,$K$ 在 $CLK = 1$ 的整个期间保持稳定**. 若在 $CLK = 1$ 期间 $J$,$K$ 上有干扰脉冲, 即使干扰很窄, 也会被"记住"并导致错误的翻转. 这使主从 JK 的抗干扰能力弱于边沿触发器.

## 五、主从结构与边沿触发的区别

| 对比项         | 脉冲触发(主从)           | 边沿触发         |
| -------------- | ------------------------ | ---------------- |
| 输入采样窗口   | $CLK = 1$ 的**整个期间** | 跳变沿**瞬间**   |
| 对输入毛刺     | 敏感(一次翻转现象)       | 不敏感(窗口极窄) |
| 输出更新时刻   | $CLK$ 下降沿             | 上升沿或下降沿   |
| 是否有一次翻转 | 有                       | 无               |

**重要**: 主从结构虽然输出在边沿更新, 但它**不是**边沿触发器, 因为它的输入采样是一个区间而非一个瞬间. 这是概念上最容易混淆的地方.

## 六、波形分析方法

分析主从 JK 触发器的输出波形时:

1. 先看 $CLK = 1$ 期间 $J$,$K$ 的取值(注意取的是**主触发器当前状态**下的有效值).
2. 判定主触发器在该期间的最终状态.
3. 在 $CLK$ 下降沿把主触发器状态送到输出.
4. $CLK = 0$ 期间输出保持不变, 无论 $J$,$K$ 如何变化.

## 七、主从 JK 的历史地位

主从 JK 触发器(如 74LS76,74LS107) 是早期时序电路的主力器件. 随着 CMOS 工艺成熟,**边沿触发 D 触发器**因抗干扰能力强, 时序分析简单而成为主流, JK 触发器在现代设计中已较少直接使用, 但在教材中仍是理解触发器功能演进的关键环节.

## 易错点

- 认为"输出在下降沿更新 = 边沿触发器": 判断标准是**输入采样窗口**, 不是输出更新时刻. 主从结构的采样窗口是整个 $CLK = 1$ 期间, 因此属于脉冲触发.
- 分析波形时用下降沿时刻的 $J$,$K$ 值来判断, 忽略了 $CLK = 1$ 期间早先出现过的脉冲, 会得出错误结果.
