# 电介质的极化与电位移矢量

真空中只有 $\rho$ 作为源; 引入电介质后, 极化电荷也会产生附加场. 为回避极化电荷, 引入**电位移矢量** $\vec D$.

## 一、电介质的极化

电介质(绝缘体)内部没有自由电荷, 但在外场作用下**束缚电荷**会发生微观位移或取向, 形成**电偶极子**, 这叫**极化**.

极化程度用**极化强度**描述:

$$\vec P=\lim_{\Delta V\to0}\frac{\sum\vec p_i}{\Delta V}$$

其中 $\vec p_i = q_i\vec d_i$ 是每个电偶极子的电偶极矩. 单位: $\text{C/m}^2$.

**极化电荷(束缚电荷)密度**:

$$\rho_P=-\nabla\cdot\vec P,\qquad \rho_{SP}=\vec P\cdot\vec e_n$$

## 二、电位移矢量

把真空中高斯定理的源改为"自由电荷 + 极化电荷":

$$\nabla\cdot\vec E=\frac{\rho+\rho_P}{\varepsilon_0}=\frac{\rho-\nabla\cdot\vec P}{\varepsilon_0}$$

整理得

$$\nabla\cdot(\varepsilon_0\vec E+\vec P)=\rho$$

于是**定义电位移矢量**:

$$\vec D=\varepsilon_0\vec E+\vec P$$

它的意义是: **$\vec D$ 的源只有自由电荷, 与极化电荷无关**. 这就是引入 $\vec D$ 的全部动机.

## 三、本构关系

对各向同性线性电介质, 极化与场强成正比:

$$\vec P=\chi_e\varepsilon_0\vec E$$

其中 $\chi_e$ 为**电极化率**. 代入定义得

$$\vec D=\varepsilon_0(1+\chi_e)\vec E=\varepsilon_0\varepsilon_r\vec E=\varepsilon\vec E$$

- $\varepsilon_r = 1+\chi_e$: **相对介电常数**(无量纲, 真空为 1);
- $\varepsilon=\varepsilon_0\varepsilon_r$: **介电常数**, 单位 $\text{F/m}$.

**常见介质**: 空气 $\varepsilon_r\approx1$, 纸 $2\sim3$, 云母 $5\sim7$, 钛酸钡可达 $10^3$ 以上.

## 四、有介质时的高斯定理

**积分形式**:

$$\oint_S\vec D\cdot d\vec S=\sum_{\text{自由}}q_i=\int_V\rho\,dV$$

**微分形式**:

$$\nabla\cdot\vec D=\rho$$

**优点**: 右端只含自由电荷, 计算时不必考虑复杂的束缚电荷分布.

## 五、例题

**例 1**: 平行板电容器极板间充满 $\varepsilon_r = 4$ 的电介质, 极板面电荷密度为 $\rho_S$. 求介质中的 $\vec D$ 与 $\vec E$.

解: 由对称性取垂直极板的柱形高斯面, 只有自由电荷:

$$D=\rho_S$$

再由本构关系:

$$E=\frac{D}{\varepsilon}=\frac{\rho_S}{\varepsilon_0\varepsilon_r}$$

**对比真空情形**: 填充介质后电场降为原来的 $1/\varepsilon_r$, 这正是介质"削弱电场"的作用.

**例 2**: 某介质中 $\vec P = (3\vec e_x-\vec e_y + 2\vec e_z)\times10^{-9}\ \text{C/m}^2$, 求极化电荷体密度.

解:

$$\rho_P=-\nabla\cdot\vec P=-\left(\frac{\partial P_x}{\partial x}+\frac{\partial P_y}{\partial y}+\frac{\partial P_z}{\partial z}\right) = 0$$

因为 $\vec P$ 是常矢量. 说明均匀极化不产生体束缚电荷(只在表面产生面束缚电荷).

**例 3**: 承例 2, 若介质占据 $x>0$ 的半空间, 且表面法向为 $-\vec e_x$, 求表面极化电荷密度.

解:

$$\rho_{SP}=\vec P\cdot\vec e_n = (3\vec e_x)\cdot(-\vec e_x)\times10^{-9}=-3\times10^{-9}\ \text{C/m}^2$$

## 六、易错点

- 把 $\vec D$ 与 $\vec E$ 混为一谈: 二者相差介电常数, 且真空中 $\vec D=\varepsilon_0\vec E$.
- 认为 $\vec D$ 与极化无关: $\vec D$ 的定义式中含有 $\vec P$, 只是其**散度**不含极化电荷.
- 忘记 $\varepsilon_r$ 是无量纲的相对值, $\varepsilon$ 才有单位.
- 把"束缚电荷"当作"自由电荷"代入高斯定理右侧.
