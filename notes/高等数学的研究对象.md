# 高等数学的研究对象

高等数学的核心不是"更难的算术", 而是研究:

1. **变化**: 函数怎样变化? 变化多快?  
   → 导数, 偏导数, 方向导数, 梯度.
2. **累积**: 许多微小量加起来是什么?  
   → 定积分, 重积分, 曲线积分, 曲面积分.
3. **逼近**: 复杂函数能否用简单函数逼近?  
   → 极限, 泰勒展开, 幂级数, 傅里叶级数.
4. **规律**: 已知变化规律, 如何求未知函数?  
   → 微分方程.
5. **空间**: 多元函数, 向量场, 曲面, 曲线如何描述?  
   → 向量代数, 空间解析几何, 多元微积分.

几个贯穿始终的思想:

- **极限思想**: 无限接近, 但不必到达.
- **局部线性化**: 复杂曲线在一点附近近似为直线.
- **以直代曲**: 用直线, 平面, 多项式近似复杂对象.
- **无穷分割求和**: 先微元, 再积分.
- **边界与内部转化**: 格林, 高斯, 斯托克斯公式.
