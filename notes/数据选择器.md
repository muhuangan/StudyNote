# 数据选择器

## 核心结论

数据选择器(MUX, 多路开关) 的功能是**在 $2^n$ 路数据中按地址选出 1 路送到输出**. 它的输出表达式是"地址最小项与数据的乘积之和", 因此天然可以用来实现任意逻辑函数—这是它最重要的用途.

## 一、基本结构

以 4 选 1 数据选择器为例:

- 数据输入端:$D_0$,$D_1$,$D_2$,$D_3$.
- 地址输入端:$A_1$,$A_0$(2 位地址选 4 路).
- 使能端:$\overline{EN}$(低电平有效).
- 输出:$Y$.

**输出表达式**:

$$Y = \overline{A_1}\,\overline{A_0} D_0 + \overline{A_1} A_0 D_1 + A_1 \overline{A_0} D_2 + A_1 A_0 D_3 = \sum_{i = 0}^{3} m_i D_i$$

**核心结构式**:$Y = \sum m_i D_i$, 即"地址选中哪一路的最小项为 1, 就把哪一路的数据送到输出".

## 二、8 选 1 与 16 选 1

| 类型    | 地址位数 | 数据输入端数 | 输出表达式                      |
| ------- | -------- | ------------ | ------------------------------- |
| 4 选 1  | 2        | 4            | $Y = \sum_{i = 0}^{3} m_i D_i$  |
| 8 选 1  | 3        | 8            | $Y = \sum_{i = 0}^{7} m_i D_i$  |
| 16 选 1 | 4        | 16           | $Y = \sum_{i = 0}^{15} m_i D_i$ |

## 三、典型芯片

**74LS151**: 8 选 1 数据选择器.

- 数据端 $D_0$ 至 $D_7$.
- 地址端 $A_2$,$A_1$,$A_0$.
- 使能端 $\overline{EN}$(低电平有效).
- **互补输出**: 同时提供 $Y$(原码) 与 $\overline{Y}$(反码), 使用非常方便.

**74LS153**: 双 4 选 1 数据选择器, 一片内含两个独立的 4 选 1 MUX, 共用地址端, 各有独立使能端. 适合需要两路输出的场合(如实现全加器).

**74LS157**: 四 2 选 1 数据选择器, 常用于总线数据切换.

## 四、级联扩展

**用两片 74LS151 构成 16 选 1**:

1. 低 3 位地址 $A_2 A_1 A_0$ 同时接两片.
2. 最高位地址 $A_3$ 接片 1 的 $\overline{EN}$, 经反相接片 2 的 $\overline{EN}$.
3. 两片输出经或门合并(未选中的那片输出为 0).

**用 4 选 1 构成 8 选 1** 同理, 用高位地址控制两片的使能.

## 五、用数据选择器实现逻辑函数(重点)

### 情况一: 函数变量数 = 地址位数

直接把变量接到地址端, 把函数真值表的输出值接到数据端.

**示例**: 用 8 选 1 MUX 实现 $F(A,B,C) = \sum m(1, 2, 4, 7)$.

令 $A_2 A_1 A_0 = A B C$, 则

$$D_0 = D_3 = D_5 = D_6 = 0,\quad D_1 = D_2 = D_4 = D_7 = 1$$

### 情况二: 函数变量数 = 地址位数 + 1(降维法)

当函数比地址多一个变量时, 把**低 $n$ 位变量接地址端, 剩余的那个变量(及其反变量, 0,1) 接到数据端**.

**降维法步骤**:

1. 画出函数的卡诺图.
2. 选定一个变量(通常是最高位或最低位) 作为"数据端变量", 其余变量作地址.
3. 对卡诺图中地址变量的每一组取值, 观察在该列(或行) 中被保留变量取 0 和取 1 时的函数值:

| 行内 $F$ 的取值情况          | 对应数据端应接    |
| ---------------------------- | ----------------- |
| 两格均为 0                   | 接 0(地)          |
| 两格均为 1                   | 接 1(电源)        |
| 两格为 $X$ 与 $\overline{X}$ | 接 $X$            |
| 两格为 $\overline{X}$ 与 $X$ | 接 $\overline{X}$ |

**示例**: 用 4 选 1 MUX(地址 $A_1 A_0$) 实现 $F(A,B,C) = \sum m(1, 2, 3, 4, 5)$.

令 $A_1 A_0 = A B$,$C$ 作数据端变量. 按 $AB$ 分组:

| $AB$           | $C = 0$ 时 $F$ | $C = 1$ 时 $F$ | $D$ 应接 |
| -------------- | -------------- | -------------- | -------- |
| 00($m_0, m_1$) | 0              | 1              | $C$      |
| 01($m_2, m_3$) | 1              | 1              | 1        |
| 10($m_4, m_5$) | 1              | 1              | 1        |
| 11($m_6, m_7$) | 0              | 0              | 0        |

所以 $D_0 = C$,$D_1 = 1$,$D_2 = 1$,$D_3 = 0$.

### 情况三: 函数变量数 > 地址位数 + 1

需要先级联扩展 MUX, 或配合少量逻辑门对剩余变量做预处理.

## 六、数据选择器的其他应用

1. **并行数据转串行**: 把并行数据的各位接到数据端, 用计数器产生地址循环变化, 输出即为串行数据流.
2. **总线多路切换**: 在多路数据源之间切换.
3. **波形发生器**: 数据端接固定电平, 地址端接计数器, 即可产生任意周期序列.
4. **函数发生器**: 如上所述.

## 七、与译码器的对比

| 对比项         | 数据选择器                     | 译码器               |
| -------------- | ------------------------------ | -------------------- |
| 实现函数的方式 | 用数据端"配置"函数值           | 用与非门"收集"最小项 |
| 所需外接器件   | 通常不需要额外门               | 需要与非门/或门      |
| 变量数限制     | 可处理"地址数 + 1"个变量       | 等于地址位数         |
| 适合场景       | 单输出函数, 变量数略多于地址位 | 多输出函数组         |

## 易错点

- 地址位与变量的对应关系必须明确写在图上,$A_2$ 必须对应函数的最高位变量, 接反会导致结果错误.
- 降维法中要按"地址变量的一行两格"来判断数据端接什么, 不能只看单个方格.
