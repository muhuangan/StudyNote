# 协方差

期望与方差各自刻画一个变量, 而**协方差**刻画两个变量"同起同落"的程度, 是把方差概念推广到两变量的自然结果.

## 一、定义

设 $X,Y$ 是两个随机变量, 若 $E\bigl\{[X - E(X)][Y - E(Y)]\bigr\}$ 存在, 则称其为 $X$ 与 $Y$ 的**协方差**, 记作

$$\operatorname{Cov}(X,Y) = E\bigl\{[X - E(X)]\,[Y - E(Y)]\bigr\}$$

**直观含义**: 若 $X$ 与 $Y$ 常同时高于(或同时低于)各自的均值, 则乘积为正, 协方差为正, 表示**正相关**; 反之若一个高于均值时另一个常低于均值, 协方差为负, 表示**负相关**.

## 二、计算公式

$$\operatorname{Cov}(X,Y) = E(XY) - E(X)\,E(Y)$$

**证明**: 展开乘积:

$$E\bigl[(X-\mu_X)(Y-\mu_Y)\bigr] = E\bigl(XY-\mu_YX-\mu_XY+\mu_X\mu_Y\bigr) = E(XY)-\mu_X\mu_Y$$

**实践**: 先算 $E(XY)$, $E(X)$, $E(Y)$ 三个量再代入, 比直接用定义省事得多.

## 三、基本性质

**(1)** $\operatorname{Cov}(X,X) = D(X)$(协方差是方差对两变量的推广);

**(2) 对称性** $\operatorname{Cov}(X,Y) = \operatorname{Cov}(Y,X)$;

**(3) 常数不影响**:
$$\operatorname{Cov}(aX + b,\ cY + d) = ac\,\operatorname{Cov}(X,Y)$$

**(4) 双线性**:
$$\operatorname{Cov}(X_1 + X_2,\ Y) = \operatorname{Cov}(X_1,Y) + \operatorname{Cov}(X_2,Y)$$

**(5) 与常数协方差为 0**: $\operatorname{Cov}(X,C) = 0$;

**(6) 方差公式的推广**:

$$D(X\pm Y) = D(X) + D(Y)\pm2\operatorname{Cov}(X,Y)$$

**(7) 独立 $\Rightarrow$ 协方差为 0**: 若 $X,Y$ 独立, 则 $E(XY) = E(X)E(Y)$, 故 $\operatorname{Cov}(X,Y) = 0$. **反之不成立**(见[不相关与独立性](./不相关与独立性.md)).

## 四、例题

**例 1**: 设 $(X,Y)$ 的联合分布律为

| $X\backslash Y$ | 0   | 1   | $p_{i\cdot}$ |
| --------------- | --- | --- | ------------ |
| 0               | 0.2 | 0.3 | 0.5          |
| 1               | 0.1 | 0.4 | 0.5          |
| $p_{\cdot j}$   | 0.3 | 0.7 | 1            |

求 $\operatorname{Cov}(X,Y)$.

解: 先求各阶矩:

$$E(X) = 0\times0.5 + 1\times0.5 = 0.5$$
$$E(Y) = 0\times0.3 + 1\times0.7 = 0.7$$
$$E(XY) = 1\times1\times0.4 = 0.4$$

故

$$\operatorname{Cov}(X,Y) = 0.4 - 0.5\times0.7 = 0.4 - 0.35 = 0.05>0$$

协方差为正, 说明两个变量有**正相关**趋势.

**例 2**(独立情形): 承例 1, 若改为"$X,Y$ 独立且 $P(X = 1) = 0.5$, $P(Y = 1) = 0.7$", 求协方差.

解: 由独立性

$$E(XY) = E(X)E(Y) = 0.5\times0.7 = 0.35\ \Rightarrow\ \operatorname{Cov}(X,Y) = 0$$

**例 3**(连续): 设 $(X,Y)$ 在三角形 $D=\{0<y<x<1\}$ 上均匀分布(密度 $f = 2$). 求 $\operatorname{Cov}(X,Y)$.

解: 依次计算

$$E(X)=\int_0^1\!\!\int_0^x2x\,dy\,dx=\int_0^12x^2dx=\frac23$$
$$E(Y)=\int_0^1\!\!\int_0^x2y\,dy\,dx=\int_0^1x^2dx=\frac13$$
$$E(XY)=\int_0^1\!\!\int_0^x2xy\,dy\,dx=\int_0^1x\cdot x^2dx=\int_0^1x^3dx=\frac14$$

故

$$\operatorname{Cov}(X,Y)=\frac14-\frac23\times\frac13=\frac14-\frac29=\frac{9 - 8}{36}=\frac{1}{36}>0$$

(与"$X$ 越大则 $y$ 的容许上限越大"的直觉一致.)

## 五、协方差的局限

协方差**带量纲**(是 $X$ 与 $Y$ 单位的乘积), 因此它的数值大小不能直接用来比较"相关强弱". 解决方法是把它标准化为**相关系数**(下一篇).

## 六、易错点

- 把 $\operatorname{Cov}(X,Y)$ 写成 $E(XY)$: 漏掉了 $E(X)E(Y)$.
- 认为"协方差小"就"独立性好": 协方差只反映**线性**关联.
- 忘记 $\operatorname{Cov}(X,X) = D(X)$ 这一特例.
- 对 $\operatorname{Cov}(aX + b,cY + d)$ 漏乘 $a c$.
