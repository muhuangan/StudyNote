# 用留数计算有理函数的无穷积分

形如 $\displaystyle\int_{-\infty}^{+\infty}\frac{P(x)}{Q(x)}dx$ 的反常积分, 用实分析的办法求原函数常常做不到(因为原函数可能不是初等函数, 或形式极繁). 留数法把它化为上半平面内有限个奇点的留数之和, 只要分母次数足够高, 计算量很小.

## 一、标准方法

**适用条件**:

1. $R(z)=\dfrac{P(z)}{Q(z)}$ 是**有理函数**, 且分母 $Q$ 在实轴上无零点;
2. 分母的次数至少比分子高 **2** 次, 即

$$\deg Q\ge\deg P + 2$$

(这条保证当 $|z|\to\infty$ 时 $|R(z)|\sim\frac{1}{|z|^2}$, 从而沿大圆弧的积分趋于 0.)

**公式**:

$$\int_{-\infty}^{+\infty}R(x)\,dx = 2\pi i\sum_{\operatorname{Im}z_k>0}\operatorname{Res}[R(z),z_k]$$

**即只取上半平面内的奇点.**

**为什么取上半平面**: 用上半平面内以 $[-R,R]$ 为直径的大半圆弧补成闭路(逆时针方向绕上半平面), 沿实轴的一段趋向所求积分, 沿大圆弧的一段由次数条件趋于 0. 于是积分等于 $2\pi i$ 乘上半平面内留数之和.

**若取下半平面**: 需把半圆弧取为顺时针(绕下半平面), 结果为

$$\int_{-\infty}^{+\infty}R(x)\,dx=-2\pi i\sum_{\operatorname{Im}z_k<0}\operatorname{Res}[R(z),z_k]$$

两者等价.

## 二、例题

**例 1**(最基本): 计算 $\displaystyle I=\int_{-\infty}^{+\infty}\frac{dx}{x^2 + 1}$.

解: $\deg Q = 2$, $\deg P = 0$, 差为 2, 条件满足. 分母零点 $z=\pm i$, 上半平面内只有 $z = i$.

$$\operatorname{Res}\left[\frac{1}{z^2 + 1},i\right]=\frac{1}{2z}\Big|_{z = i}=\frac{1}{2i}$$

故

$$I = 2\pi i\cdot\frac{1}{2i}=\pi$$

**验算**: 直接用原函数 $\arctan x$ 得 $[\arctan x]_{-\infty}^{+\infty}=\frac\pi2 - (-\frac\pi2)=\pi$, 一致.

**例 2**: 计算 $\displaystyle I=\int_{-\infty}^{+\infty}\frac{dx}{(x^2 + 1)(x^2 + 4)}$.

解: 分母次数 4, 分子次数 0, 差为 4, 条件满足.

**奇点**: $z=\pm i$, $z=\pm2i$. 上半平面内: $z = i$, $z = 2i$.

**求留数**(均为一阶极点, 用 $P / Q'$ 公式). 这里 $P = 1$, $Q = (z^2 + 1)(z^2 + 4) = z^4 + 5z^2 + 4$, $Q'=4z^3 + 10z = 2z(2z^2 + 5)$.

在 $z = i$: $Q'(i) = 2i(2(-1) + 5) = 2i\cdot3 = 6i$:

$$\operatorname{Res}=\frac{1}{6i}$$

在 $z = 2i$: $Q'(2i) = 2(2i)(2(-4) + 5) = 4i(-3)=-12i$:

$$\operatorname{Res}=\frac{1}{-12i}=-\frac{1}{12i}$$

于是

$$I = 2\pi i\left(\frac{1}{6i}-\frac{1}{12i}\right) = 2\pi i\cdot\frac{1}{12i}\left(2 - 1\right)=\frac{2\pi}{12}=\frac{\pi}{6}$$

**验算(部分分式)**: 由 $\frac{1}{(x^2 + 1)(x^2 + 4)}=\frac13\left(\frac{1}{x^2 + 1}-\frac{1}{x^2 + 4}\right)$, 积分得 $\frac13(\pi-\frac\pi2)=\frac{\pi}{6}$, 一致.

**例 3**(分子次数 2): 计算 $\displaystyle I=\int_{-\infty}^{+\infty}\frac{x^2\,dx}{x^4 + 1}$.

解: 分母次数 4, 分子次数 2, 差为 2, 条件刚好满足.

**奇点**: $x^4 + 1 = 0\Rightarrow z^4=-1 = e^{i\pi}$, 故

$$z_k = e^{i\frac{\pi + 2k\pi}{4}},\qquad k = 0,1,2,3$$

即

$$z_0 = e^{i\pi / 4},\quad z_1 = e^{i3\pi / 4},\quad z_2 = e^{i5\pi / 4},\quad z_3 = e^{i7\pi / 4}$$

上半平面内: $z_0 = e^{i\pi / 4}=\frac{\sqrt2}{2}(1 + i)$, $z_1 = e^{i3\pi / 4}=\frac{\sqrt2}{2}(-1 + i)$.

**求留数**: $R=\dfrac{z^2}{z^4 + 1}$, $Q'=4z^3$:

$$\operatorname{Res}[R,z_k]=\frac{z_k^2}{4z_k^3}=\frac{1}{4z_k}$$

于是两个留数之和为

$$\frac14\left(\frac{1}{z_0}+\frac{1}{z_1}\right)=\frac14\left(e^{-i\pi / 4} + e^{-i3\pi / 4}\right)$$

计算: $e^{-i\pi / 4}=\frac{\sqrt2}{2}(1 - i)$, $e^{-i3\pi / 4}=\frac{\sqrt2}{2}(-1 - i)$. 相加得 $\frac{\sqrt2}{2}(0 - 2i)=-\sqrt2 i$.

故

$$I = 2\pi i\cdot\frac14(-\sqrt2 i) = 2\pi i\cdot\left(-\frac{\sqrt2 i}{4}\right)=\frac{2\pi\sqrt2}{4}=\frac{\sqrt2\pi}{2}$$

**验算**: 由对称性 $x\to - x$ 与 $x\to\frac1x$ 可化为已知积分, 结果 $\frac{\sqrt2\pi}{2}\approx2.221$ 与数值积分一致.

**例 4**(偶数函数可化到半轴): 计算 $\displaystyle\int_0^{+\infty}\frac{dx}{x^4 + 1}$.

解: 被积函数为偶函数, 故

$$\int_0^{+\infty}\frac{dx}{x^4 + 1}=\frac12\int_{-\infty}^{+\infty}\frac{dx}{x^4 + 1}$$

对右端用留数法. $R=\frac{1}{z^4 + 1}$, $Q'=4z^3$:

$$\operatorname{Res}[R,z_k]=\frac{1}{4z_k^3}=-\frac{z_k}{4}$$

(用了 $z_k^4=-1$, 故 $\frac{1}{z_k^3}=\frac{z_k}{z_k^4}=-z_k$.) 上半平面内 $z_0 = e^{i\pi / 4}$, $z_1 = e^{i3\pi / 4}$:

$$\operatorname{Res}\text{ 之和}=-\frac14\left(e^{i\pi / 4} + e^{i3\pi / 4}\right)=-\frac14\left(\frac{\sqrt2}{2}(1 + i)+\frac{\sqrt2}{2}(-1 + i)\right)=-\frac14\left(\sqrt2 i\right)=-\frac{\sqrt2 i}{4}$$

故

$$\int_{-\infty}^{+\infty}\frac{dx}{x^4 + 1} = 2\pi i\cdot\left(-\frac{\sqrt2 i}{4}\right)=\frac{\sqrt2\pi}{2}$$

于是

$$\int_0^{+\infty}\frac{dx}{x^4 + 1}=\frac{\sqrt2\pi}{4}$$

**例 5**(条件不足的反例): 说明为什么不能用留数法直接算 $\displaystyle\int_{-\infty}^{+\infty}\frac{x\,dx}{x^2 + 1}$.

解: 这里 $\deg Q = 2$, $\deg P = 1$, 差为 **1**, 不满足"至少差 2"的条件. 沿大圆弧的积分不趋于 0.

事实上该积分本身**发散**(被积函数在无穷远处 $\sim\frac1x$, 两侧各自发散). 留数法给出的值会依赖于取极限的方式, 因此不适用.

**要点**: 使用公式前必须检查次数条件, 否则结论无意义.

## 三、易错点

- 忘记检查 $\deg Q\ge\deg P + 2$.
- 把下半平面的奇点也算进来, 或符号弄错.
- $x^4 + 1 = 0$ 这类方程的根写错(应为 $e^{i(\pi + 2k\pi) / 4}$).
- 未检查分母在实轴上无零点(否则积分是广义积分, 需另行处理).
- 求留数时忘记 $Q'$ 需要代入奇点求值, 而非求导后就此停手.
