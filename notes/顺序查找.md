# 顺序查找(线性表)

**查找表**: 有一组具有相同数据类型的数据元素组成的集合, 这些元素保存在一张结构化的数据表中, 用于支持对其中元素的查找操作

**关键字**: 数据元素中能唯一标识改元素的属性值, 查找时就是通过关键字来定位对应的数据元素的

**查找**: 在查找表中根据给定的"关键字"找出对应数据元素的过程

**平均查找长度**: 在一种查找方法中, 查找一个元素所需要比较的关键字的平均次数, 是衡量查找算法效率的重要指标. 通常分两种情况讨论: 查找成功和查找失败.

$$
ASL_{\text{success}} = \sum_{i = 1}^{n} P_i C_i
$$

如果表中有n个元素, 第i个元素被查到的概率为 $P_i$ , 查找它需要比较 $C_i$ 次关键字

按照表的顺序一个一个遍历并和关键字比较

```C
#include <stdio.h>
int search(int* data, int len, int value){
    for(int i = 0; i < len; i++){
        if(data[i] == value){
            return i;
        }
    }
    return -1;
}

int main(){
    int arr[] = {15, 54, 76, 6, 9, 45, 12};
    int len = sizeof(arr) / sizeof(arr[0]);
    int pos = search(arr, len, 45);
    printf("%d\n", pos);
    return 0;
}
```
