# 复数项级数

复数项级数的收敛性判定, 本质上可以化归为两个实数项级数------因为收敛要求实部与虚部同时收敛. 这一篇把基本概念与几个常用判据理清, 为幂级数与洛朗级数做准备.

## 一、复数序列的极限

设 $\{z_n\}$ 是复数序列, $z_0$ 为复数. 若对任意 $\varepsilon>0$, 存在正整数 $N$, 当 $n>N$ 时

$$|z_n - z_0|<\varepsilon$$

则称 $\{z_n\}$ **收敛**于 $z_0$, 记作 $\lim_{n\to\infty}z_n = z_0$.

设 $z_n = x_n + iy_n$, $z_0 = x_0 + iy_0$, 则

$$\lim z_n = z_0\ \Longleftrightarrow\ \lim x_n = x_0\ \text{且}\ \lim y_n = y_0$$

**与实序列的关系**: 复数序列收敛等价于两个实序列同时收敛. 因此实序列的许多结论可以直接搬运.

**柯西收敛准则**: $\{z_n\}$ 收敛当且仅当对任意 $\varepsilon>0$ 存在 $N$, 当 $m,n>N$ 时 $|z_m - z_n|<\varepsilon$.

## 二、复数项级数

设 $\{z_n\}$ 为复数序列, 称

$$\sum_{n = 1}^{\infty}z_n = z_1 + z_2+\dots + z_n+\dots$$

为**复数项级数**. 记部分和

$$S_n = z_1 + z_2+\dots + z_n$$

若 $\{S_n\}$ 收敛于有限值 $S$, 则称级数**收敛**, $S$ 为级数的和; 否则称**发散**.

**实虚部分解**: 设 $z_n = x_n + iy_n$, 则

$$\sum_{n = 1}^\infty z_n\ \text{收敛}\ \Longleftrightarrow\ \sum_{n = 1}^\infty x_n\ \text{与}\ \sum_{n = 1}^\infty y_n\ \text{都收敛}$$

且此时

$$\sum_{n = 1}^\infty z_n=\sum_{n = 1}^\infty x_n + i\sum_{n = 1}^\infty y_n$$

**实用价值**: 判断复数项级数的收敛性时, 可以分别判断实部与虚部, 从而使用实数的判据.

## 三、收敛的必要条件

**定理**: 若 $\sum z_n$ 收敛, 则

$$\lim_{n\to\infty}z_n = 0$$

**注意它是必要而非充分条件**: 与实情形一样, $z_n\to0$ 并不能保证 $\sum z_n$ 收敛.

**用法**: 若某一项的极限不为 0, 级数立刻发散. 这是最快的发散判别法.

## 四、绝对收敛

**定义**: 若 $\sum|z_n|$ 收敛, 则称 $\sum z_n$ **绝对收敛**.

**定理**:

- 绝对收敛的级数必收敛(**绝对收敛蕴含收敛**);
- 收敛但不绝对收敛的级数称为**条件收敛**;
- $\sum|z_n|$ 的每一项是非负实数, 因此可以套用一切正项级数判据(比值判据、根值判据、比较判据等).

**常用判据(比值法)**: 若

$$\lim_{n\to\infty}\left|\frac{z_{n + 1}}{z_n}\right|=\rho$$

则 $\rho<1$ 时级数绝对收敛, $\rho>1$ 时发散, $\rho = 1$ 时需另作判断.

**常用判据(根值法)**: 若 $\lim_{n\to\infty}\sqrt[n]{|z_n|}=\rho$, 结论同上.

## 五、级数的运算性质

若 $\sum z_n$ 与 $\sum w_n$ 都收敛, 则

$$\sum(\alpha z_n+\beta w_n)=\alpha\sum z_n+\beta\sum w_n$$

**要点**: 收敛级数可以逐项线性组合; 但两个发散级数相加未必发散, 需具体分析.

## 六、例题

**例 1**: 判断 $\displaystyle\sum_{n = 1}^{\infty}\frac{i^n}{n}$ 的收敛性.

解: 由 $|i^n|=1$ 得

$$\left|\frac{i^n}{n}\right|=\frac1n$$

而 $\sum\frac1n$ 是调和级数, **发散**. 故该级数不绝对收敛.

再看是否条件收敛. 分离实虚部: $i^n$ 按 $i,-1,-i,1$ 循环, 故实部为

$$0-\frac12 + 0+\frac14 + 0-\frac16 + 0+\frac18+\dots=-\frac12+\frac14-\frac16+\frac18-\dots$$

即 $\sum_{k = 1}^\infty\frac{(-1)^k}{2k}=-\frac12\sum_{k = 1}^\infty\frac{(-1)^{k + 1}}{k}$, 这是**交错调和级数**, 收敛.

虚部类似地给出 $\sum_{k = 0}^\infty\frac{(-1)^k}{2k + 1}$, 也收敛(莱布尼茨级数).

**结论**: 级数**条件收敛**.

**例 2**: 判断 $\displaystyle\sum_{n = 1}^{\infty}\frac{z^n}{n!}$ 的收敛性($z$ 为任意复数).

解: 用比值法:

$$\left|\frac{z^{n + 1} / (n + 1)!}{z^n / n!}\right|=\frac{|z|}{n + 1}\ \xrightarrow{\ n\to\infty\ }\ 0<1$$

故对任何固定的 $z$ 级数都**绝对收敛**. 这个级数的和正是 $e^z$.

**例 3**: 判断 $\displaystyle\sum_{n = 1}^{\infty}\left(\frac{1 + 2i}{3}\right)^n$ 的收敛性.

解: 这是等比级数, 公比 $q=\frac{1 + 2i}{3}$. 由

$$|q|=\frac{\sqrt{1 + 4}}{3}=\frac{\sqrt5}{3}\approx0.745<1$$

故级数**绝对收敛**, 且和为

$$\frac{q}{1 - q}=\frac{\frac{1 + 2i}{3}}{1-\frac{1 + 2i}{3}}=\frac{\frac{1 + 2i}{3}}{\frac{2 - 2i}{3}}=\frac{1 + 2i}{2 - 2i}=\frac{(1 + 2i)(2 + 2i)}{8}=\frac{2 + 2i + 4i + 4i^2}{8}=\frac{-2 + 6i}{8}=-\frac14+\frac34i$$

**要点**: 复数等比级数的收敛条件同样是 $|q|<1$, 而 $|q|$ 是复数公比的**模**.

**例 4**: 判断 $\displaystyle\sum_{n = 1}^{\infty}\frac{n!}{i^n}$ 的收敛性.

解: 通项为 $\frac{n!}{i^n} = n!\,i^{-n}$, 其模为

$$\left|\frac{n!}{i^n}\right|=n!\ \xrightarrow{\ n\to\infty\ }\ \infty$$

通项不趋于 0, 故级数**发散**.

**例 5**(由收敛推结论): 已知 $\sum z_n$ 收敛, 判断 $\sum\frac{z_n}{n}$ 是否必收敛.

解: **不必然绝对收敛, 但必然收敛**------若 $\sum z_n$ 收敛且 $\frac1n$ 单调递减趋于 0, 由阿贝尔变换(分部求和) 可证 $\sum\frac{z_n}{n}$ 收敛.

**注意**: 若只知 $\sum|z_n|$ 收敛(绝对收敛), 则由 $\left|\frac{z_n}{n}\right|\le|z_n|$ 及比较判据, $\sum\frac{z_n}{n}$ **绝对收敛**. 结论更强.

## 七、易错点

- 用"通项趋于 0"作为收敛的充分条件.
- 判断绝对收敛时忘记 $|z^n|=|z|^n$(而不是 $z^n$).
- 复数等比级数的公比忘记取模, 直接比较复数大小.
- 把条件收敛与绝对收敛混淆, 特别是含 $i^n$ 的项.
- 分离实虚部时把 $i^n$ 的周期记错($i,-1,-i,1$ 循环).
