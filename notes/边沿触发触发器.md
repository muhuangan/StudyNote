# 边沿触发触发器

## 核心结论

边沿触发触发器只在时钟的**跳变沿瞬间**采样输入, 其余时间输入被完全封锁. 它同时解决了电平触发的空翻和主从结构的一次翻转问题, 是**现代数字系统的标准存储元件**.

## 一、为什么边沿触发最优

| 问题         | 电平触发     | 脉冲触发(主从)      | 边沿触发         |
| ------------ | ------------ | ------------------- | ---------------- |
| 空翻         | 有           | 无                  | 无               |
| 一次翻转     | —            | 有                  | 无               |
| 输入采样窗口 | 整个有效电平 | 整个 $CLK = 1$ 期间 | **仅跳变沿瞬间** |
| 抗干扰能力   | 弱           | 中                  | **强**           |
| 时序分析难度 | 高           | 中                  | 低               |

边沿触发把"何时采样"压缩到一个极窄的时间窗口, 使时序分析只需检查**建立时间**与**保持时间**两个约束, 这是现代同步设计方法学的基础.

## 二、CMOS 边沿 D 触发器的结构

**结构**: 由两个受互补时钟控制的**传输门**与两个反相器构成主-从两级.

| 时钟状态     | 主传输门 | 从传输门 | 行为                                           |
| ------------ | -------- | -------- | ---------------------------------------------- |
| $CLK = 0$    | 导通     | 截止     | 主级跟随输入 $D$, 从级保持输出                 |
| $CLK$ 上升沿 | **关断** | **导通** | 主级锁存跳变瞬间的 $D$, 从级接收主级状态并输出 |
| $CLK = 1$    | 截止     | 导通     | 输入被完全隔离, 输出稳定                       |

**关键**: 主传输门在上升沿关断的瞬间, 主级锁存的是**关断时刻**的 $D$ 值; 此后 $D$ 的任何变化都无法穿过关断的传输门. 这正是"边沿采样"的物理实现.

## 三、TTL 维持阻塞型边沿 D 触发器

**结构**: 74LS74 采用**维持-阻塞**结构, 用三条内部反馈线实现:

1. **置 0 维持线**: 在 $CLK$ 上升沿后封锁置 0 通路, 使 $D = 0$ 的效果被维持.
2. **置 1 维持线**: 同理维持 $D = 1$ 的效果.
3. **置 1 阻塞线**: 阻止后续输入变化再次触发翻转.

**效果**: 输入信号在时钟上升沿被"冻结", 之后即使 $D$ 变化, 输出也不受影响.

## 四、边沿 D 触发器的特性

**特性方程**:

$$Q^* = D$$

**特性表**:

| $CLK$    | D        | $Q^*$     |
| -------- | -------- | --------- |
| 上升沿   | 0        | 0         |
| 上升沿   | 1        | 1         |
| 非上升沿 | $\times$ | $Q$(保持) |

**符号识别**: 时钟端带**三角形**(动态输入标志) 表示边沿触发; 三角形外再加小圆圈表示**下降沿**触发.

## 五、边沿 JK 触发器

**特性方程**:

$$Q^* = J\overline{Q} + \overline{K}Q$$

**与主从 JK 的区别**: 同样是这个特性方程, 但边沿 JK 只在跳变沿瞬间读入 $J$,$K$, 因此**没有一次翻转现象**, 抗干扰能力更强.

**用边沿 D 触发器构造 JK**: 令

$$D = J\overline{Q} + \overline{K}Q$$

即在 $D$ 输入端加一级组合逻辑即可.

## 六、T 触发器与 T' 触发器

**T 触发器**(翻转触发器):

$$Q^* = T\overline{Q} + \overline{T}Q = T \oplus Q$$

- $T = 0$: 保持.
- $T = 1$: 翻转.

**T' 触发器**:$T$ 恒为 1, 则 $Q^* = \overline{Q}$, 每来一个时钟沿翻转一次, 实现**二分频**.

**由 D 触发器构成 T**:$D = T \oplus Q$(外部加一个异或门).
**由 JK 触发器构成 T**:$J = K = T$.

## 七、异步置位与复位端

集成触发器通常带有不受时钟控制的**异步置位端 $\overline{S_D}$** 与**异步复位端 $\overline{R_D}$**(低电平有效, 也有高电平有效的产品).

| $\overline{S_D}$ | $\overline{R_D}$ | 行为                 |
| ---------------- | ---------------- | -------------------- |
| 0                | 1                | 立即置 1(与时钟无关) |
| 1                | 0                | 立即置 0(与时钟无关) |
| 1                | 1                | 正常工作             |
| 0                | 0                | **禁止**(输出不互补) |

**使用约束**:

1. 两者不能同时有效.
2. 撤除异步信号的时刻不能离时钟沿太近, 必须满足**恢复时间**(recovery time) 要求, 否则触发器可能进入亚稳态.
3. 上电复位电路通常接在异步复位端.

## 八、不同功能触发器之间的转换

| 转换方向 | 做法                                             |
| -------- | ------------------------------------------------ |
| D → JK   | $D = J\overline{Q} + \overline{K}Q$              |
| D → T    | $D = T \oplus Q$                                 |
| D → T'   | $D = \overline{Q}$(把 $\overline{Q}$ 反馈到 $D$) |
| JK → D   | $J = D$,$K = \overline{D}$                       |
| JK → T   | $J = K = T$                                      |

**核心方法**: 令两个触发器的特性方程相等, 解出输入端的连接关系.

## 九、典型器件

| 型号    | 功能                               | 触发方式 |
| ------- | ---------------------------------- | -------- |
| 74LS74  | 双上升沿 D 触发器(带异步置位/复位) | 上升沿   |
| 74LS112 | 双下降沿 JK 触发器                 | 下降沿   |
| 74LS273 | 八 D 触发器(带公共清零)            | 上升沿   |
| 74LS374 | 八 D 触发器(三态输出)              | 上升沿   |
| CD4013  | 双 CMOS D 触发器                   | 上升沿   |

## 易错点

- 时钟端的三角形符号是判断边沿触发的唯一依据, 没有三角形就是电平触发, 不能只看器件名称.
- 异步置位/复位端不受时钟控制, 若误当作同步端使用(以为要等时钟沿才生效), 会导致时序错误.
- $Q^*$ 是**沿之后**的状态,$Q$ 是**沿之前**的状态, 画波形时不要把两者错位一个周期.
