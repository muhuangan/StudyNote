# 半导体二极管门电路

## 核心结论

二极管门电路利用二极管的**单向导电性**实现与, 或逻辑, 结构最简单, 成本最低, 但存在**电平偏移**且**没有放大能力**, 无法级联成复杂系统, 因此已被 CMOS 与 TTL 完全取代, 仅作为理解原理的入门模型.

## 一、二极管的开关特性

| 工作状态 | 条件                       | 等效模型                       |
| -------- | -------------------------- | ------------------------------ |
| 导通     | 正向偏置且正向压降达到阈值 | 硅管压降约 0.7 V, 锗管约 0.3 V |
| 截止     | 反向偏置或正向压降低于阈值 | 相当于开路                     |

理想化分析时常把二极管视为**理想开关**: 导通时压降为 0, 截止时电流为 0. 实际分析必须计入 0.7 V 的导通压降, 这正是电平偏移的来源.

**开通时间**与**反向恢复时间**: 二极管由导通转为截止时, 需要一段时间消散 stored charge, 这段时间称为反向恢复时间 $t_{re}$(约几纳秒), 它限制了二极管电路的最高工作速度.

## 二、二极管与门

**结构**: 三个二极管的阳极通过电阻 $R$ 上拉到 $V_{CC}$, 阴极分别接输入 $A$,$B$,$C$, 输出从阴极公共点取出.

| 输入情况         | 二极管状态     | 输出                                 |
| ---------------- | -------------- | ------------------------------------ |
| 全为高电平       | 全部截止       | 输出被 $R$ 上拉到 $V_{CC}$, 为高电平 |
| 至少一个为低电平 | 对应二极管导通 | 输出被钳位在该输入电平加导通压降     |

**逻辑**: 有 0 出 0, 全 1 出 1, 即与逻辑.

## 三、二极管或门

**结构**: 三个二极管的阴极通过电阻 $R$ 下拉到地, 阳极分别接输入 $A$,$B$,$C$, 输出从阳极公共点取出.

| 输入情况         | 二极管状态     | 输出                             |
| ---------------- | -------------- | -------------------------------- |
| 全为低电平       | 全部截止       | 输出被 $R$ 下拉到地, 为低电平    |
| 至少一个为高电平 | 对应二极管导通 | 输出被钳位在该输入电平减导通压降 |

**逻辑**: 有 1 出 1, 全 0 出 0, 即或逻辑.

## 四、电平偏移问题(致命缺点)

设 $V_{CC} = 5\ \text{V}$, 硅管导通压降 $V_D = 0.7\ \text{V}$, 输入高电平 5 V, 低电平 0 V.

**与门的情况**:

- 输入全为 5 V 时, 二极管截止, 输出为 5 V(无偏移).
- 若某输入为 0 V, 输出为 $0 + 0.7 = 0.7\ \text{V}$(低电平被抬高 0.7 V).

**或门的情况**:

- 输入全为 0 V 时, 输出为 0 V(无偏移).
- 若某输入为 5 V, 输出为 $5 - 0.7 = 4.3\ \text{V}$(高电平被拉低 0.7 V).

**级联后果**: 把多级二极管门串联时, 每一级都会使信号摆幅缩小 0.7 V. 若高电平为 3 V, 经两级或门后变为 $3 - 1.4 = 1.6\ \text{V}$, 已经进入不确定区, 电路彻底失效.

这就是二极管门电路**不能级联**的根本原因, 也是必须引入带放大能力的三极管(TTL) 或 MOS 管(CMOS) 的动机.

## 五、另一个缺点: 负载能力差

二极管门的输出电平依赖上拉(或下拉) 电阻. 一旦接上负载, 负载电流会在电阻上产生额外压降, 进一步恶化电平. 因此二极管门的扇出系数很低.

## 六、与现代门电路的对比

| 对比项         | 二极管门     | CMOS / TTL |
| -------------- | ------------ | ---------- |
| 是否有电平偏移 | 有(0.7 V/级) | 无         |
| 是否有放大能力 | 无           | 有         |
| 能否多级级联   | 不能         | 能         |
| 扇出系数       | 很小         | 10 至 50   |
| 现状           | 仅作教学模型 | 实际使用   |

## 七、残余价值

1. **输入保护**: CMOS 输入端并联的钳位二极管本质上就是二极管电路.
2. **线与/线或的简易实现**: 多个开漏输出通过二极管隔离后合并.
3. **教学意义**: 它是理解"逻辑功能"与"电气特性"分离的第一个例子—逻辑上正确, 电气上不可用.

## 易错点

- 二极管与门输出低电平时是"输入低电平 + 0.7 V", 而不是 0 V; 分析时容易漏掉这个压降.
- 二极管门电路本身没有非运算能力, 无法构成完备逻辑, 这也是它无法实用的原因之一.
