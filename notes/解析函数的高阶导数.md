# 解析函数的高阶导数

解析函数最出人意料的性质是: **只要可导一次, 就自动无穷次可导**. 这一点与实函数截然不同(实函数可能一次可导而二次不可导). 高阶导数公式给出了各阶导数的积分表示, 它同时也是计算"分母含高阶奇点"的积分的标准工具.

## 一、高阶导数公式

**定理**: 设 $f$ 在简单闭曲线 $C$ 所围区域 $D$ 内解析, 在 $\overline D$ 上连续, $z_0\in D$, 则 $f$ 在 $z_0$ 处有任意阶导数, 且

$$f^{(n)}(z_0)=\frac{n!}{2\pi i}\oint_C\frac{f(z)}{(z - z_0)^{n + 1}}dz,\qquad n = 1,2,3,\dots$$

**等价的计算形式**(更常用):

$$\oint_C\frac{f(z)}{(z - z_0)^{n + 1}}dz=\frac{2\pi i}{n!}f^{(n)}(z_0)$$

**与柯西积分公式的关系**: $n = 0$ 时即为柯西积分公式 $f(z_0)=\frac{1}{2\pi i}\oint\frac{f(z)}{z - z_0}dz$. 可见高阶导数公式是它的自然推广.

## 二、为什么解析函数无穷次可导

柯西积分公式把 $f(z_0)$ 表示成含参数 $z_0$ 的积分

$$f(z_0)=\frac{1}{2\pi i}\oint_C\frac{f(z)}{z - z_0}dz$$

被积函数对 $z_0$ 是解析的, 因此在积分号下可以对 $z_0$ 逐次求导(这一步的严格性由积分的一致收敛性保证). 每次求导使分母的幂次增加 1, 并产生因子 $n!$:

$$\frac{\partial^n}{\partial z_0^n}\frac{1}{z - z_0}=\frac{n!}{(z - z_0)^{n + 1}}$$

于是得到高阶导数公式.

**要点**:"无穷次可导"不是额外假设, 而是柯西积分公式的直接推论. 这也解释了为什么解析条件如此强.

## 三、与实分析的对比

在实数域, $f(x) = x^2\sin\frac1x\ (x\neq0)$, $f(0) = 0$ 处处可导, 但 $f'$ 在 $0$ 处不连续, 因而不可导两次.

在复数域, 这种情况不可能出现: 只要 $f$ 在某点解析(即在某邻域内可导), 它在该点就有任意阶导数, 且各阶导数都解析.

**代价**: 复可导的条件更强(要求差商极限与方向无关), 因此满足条件的函数更少. **条件是入场费, 结论是奖品.**

## 四、例题

**例 1**: 计算 $\oint_{|z|=2}\dfrac{e^z}{(z - 1)^2}dz$.

解: 奇点 $z = 1$ 在圆内, 阶数为 2(即分母幂次 $n + 1 = 2$, 故 $n = 1$). $f(z) = e^z$. 由公式

$$\oint_{|z|=2}\frac{e^z}{(z - 1)^2}dz=\frac{2\pi i}{1!}f'(1) = 2\pi i\,e^1 = 2\pi ie$$

**要点**: 分母幂次是 $k$ 时, 用 $n = k - 1$, 需要求 $f$ 的 $(k - 1)$ 阶导数.

**例 2**: 计算 $\oint_{|z|=1}\dfrac{\sin z}{z^4}dz$.

解: 奇点 $z = 0$, 分母幂次 4, 故 $n = 3$. $f(z)=\sin z$, 其各阶导数:

$$f'(z)=\cos z,\quad f''(z)=-\sin z,\quad f'''(z)=-\cos z$$

故 $f'''(0)=-\cos0=-1$. 于是

$$\oint_{|z|=1}\frac{\sin z}{z^4}dz=\frac{2\pi i}{3!}(-1)=-\frac{2\pi i}{6}=-\frac{\pi i}{3}$$

**例 3**: 计算 $\oint_{|z - 1|=1}\dfrac{dz}{(z - 1)^3}$.

解: 这里 $f(z)\equiv1$, 分母幂次 3, $n = 2$. $f''(z) = 0$. 故

$$\oint_{|z - 1|=1}\frac{dz}{(z - 1)^3}=\frac{2\pi i}{2!}\cdot0 = 0$$

**规律**: 形如 $\oint\dfrac{dz}{(z - z_0)^n}$ 的积分, 当 $n\ge2$ 时为 0, 当 $n = 1$ 时为 $2\pi i$. 这与[复积分的定义与性质](./复积分的定义与性质.md) 例 2 的结论一致.

**例 4**: 计算 $\oint_{|z|=3}\dfrac{2z^2 + 1}{(z - 2)^3}dz$.

解: 奇点 $z = 2$($|2|=2<3$, 在圆内), 分母幂次 3, $n = 2$. $f(z) = 2z^2 + 1$, 故

$$f'(z) = 4z,\qquad f''(z) = 4$$

于是

$$\oint_{|z|=3}\frac{2z^2 + 1}{(z - 2)^3}dz=\frac{2\pi i}{2!}\cdot4 = 4\pi i$$

**例 5**(含多个奇点与不同阶): 计算 $\oint_{|z|=2}\dfrac{dz}{z^2(z - 1)}$.

解: 奇点 $z = 0$(二阶) 与 $z = 1$(一阶), 都在圆内. 部分分式:

$$\frac{1}{z^2(z - 1)}=-\frac1z-\frac{1}{z^2}+\frac{1}{z - 1}$$

**验算**: 右端通分,

$$\frac{-z(z - 1) - (z - 1) + z^2}{z^2(z - 1)}=\frac{-z^2 + z - z + 1 + z^2}{z^2(z - 1)}=\frac{1}{z^2(z - 1)}\quad\checkmark$$

逐项积分:

- $\oint\dfrac{-dz}{z}=-2\pi i$;
- $\oint\dfrac{-dz}{z^2} = 0$;
- $\oint\dfrac{dz}{z - 1} = 2\pi i$.

合计

$$\oint_{|z|=2}\frac{dz}{z^2(z - 1)}=-2\pi i + 0 + 2\pi i = 0$$

**对比例 2 的思路**: 处理混合阶奇点时, 先做部分分式把每一项化成"只含单个奇点的纯幂", 再用 $\oint\frac{dz}{(z - z_0)^n}$ 的规律, **无需套用高阶导数公式**, 计算更快.

## 五、易错点

- 混淆分母幂次与求导阶数: 分母是 $(z - z_0)^{n + 1}$ 时求 $n$ 阶导, 即"幂次减 1".
- 忘记 $n!$ 因子或 $2\pi i$ 因子.
- 求高阶导数时算错(如 $\sin$ 的四阶导应回到 $\sin$).
- 处理多个奇点时未做部分分式, 直接把分母当成 $(z - z_0)^{n + 1}$.
- 认为解析函数只能求有限阶导数(与实情形的直觉混淆).
