# 电偶极子

两个等量异号点电荷构成的**电偶极子**是物质极化的微观模型, 也是远区场按 $1 / r^3$ 衰减这一规律的来源.

## 一、定义

两个等量异号点电荷 $+q$ 与 $-q$, 相距 $d$, 当考察点距离 $r\gg d$ 时, 称为**电偶极子**. 定义**电偶极矩**:

$$\boldsymbol p = q\boldsymbol d$$

方向由 $-q$ 指向 $+q$. 单位 $\text{C}\cdot\text{m}$.

## 二、电位的来源推导

取偶极子中心为原点, $\boldsymbol p$ 沿 $+z$ 方向. 场点 $P(r,\theta)$ 到 $+q$ 与 $-q$ 的距离分别为

$$r_\pm=\sqrt{r^2\mp rd\cos\theta+\frac{d^2}{4}}$$

由叠加原理

$$\varphi=\frac{q}{4\pi\varepsilon_0}\left(\frac{1}{r_+}-\frac{1}{r_-}\right)$$

**远区近似**($r\gg d$): 对 $r_\pm$ 作泰勒展开

$$\frac{1}{r_\pm}\approx\frac{1}{r}\left(1\pm\frac{d\cos\theta}{2r}\right)\ \Rightarrow\ \frac{1}{r_+}-\frac{1}{r_-}\approx-\frac{d\cos\theta}{r^2}$$

故

$$\varphi=\frac{qd\cos\theta}{4\pi\varepsilon_0r^2}=\frac{\boldsymbol p\cdot\boldsymbol e_r}{4\pi\varepsilon_0r^2}$$

**关键**: 两个 $1 / r$ 项在相减时**部分抵消**, 剩下的最低阶是 $1 / r^2$——这就是偶极子电位衰减更快的原因.

## 三、电场的来源推导

用球坐标的梯度公式 $\boldsymbol E=-\nabla\varphi$, 先算两个分量:

$$E_r=-\frac{\partial\varphi}{\partial r}=\frac{2p\cos\theta}{4\pi\varepsilon_0r^3}$$
$$E_\theta=-\frac1r\frac{\partial\varphi}{\partial\theta}=\frac{p\sin\theta}{4\pi\varepsilon_0r^3}$$

合并为矢量形式:

$$\boldsymbol E=\frac{1}{4\pi\varepsilon_0r^3}\left[3(\boldsymbol p\cdot\boldsymbol e_r)\boldsymbol e_r-\boldsymbol p\right]$$

**特点**:

- 场强按 $1 / r^3$ 衰减(点电荷是 $1 / r^2$);
- 在 $\theta = 0$ 与 $\pi$ 方向(沿 $\boldsymbol p$)场与 $\boldsymbol p$ 同向或反向;
- 在 $\theta=\pi / 2$ 方向(赤道面上)场与 $\boldsymbol p$ **反向**.

## 四、偶极子在外场中的受力与力矩

**均匀外场**: 合力为零, 但有力矩

$$\boldsymbol M=\boldsymbol p\times\boldsymbol E$$

**非均匀外场**: 除力矩外还有合力

$$\boldsymbol F = (\boldsymbol p\cdot\nabla)\boldsymbol E$$

**结论**: 偶极子总是倾向于**转向与外场同向**(力矩使 $\boldsymbol p$ 与 $\boldsymbol E$ 平行), 这是电介质极化取向的微观机制.

## 五、例题

**例 1**: 电偶极子 $p = 2\times10^{-30}\ \text{C}\cdot\text{m}$(近似水分子的量级), 求沿线轴方向距离 $r = 1\ \text{nm}$ 处的电场大小.

解: 线轴上 $\theta = 0$, $\boldsymbol E=\dfrac{2p}{4\pi\varepsilon_0r^3}$:

$$E=\frac{2\times2\times10^{-30}}{4\pi\times8.854\times10^{-12}\times(10^{-9})^3}=\frac{4\times10^{-30}}{1.113\times10^{-37}}\approx3.6\times10^{7}\ \text{V/m}$$

**对比**: 同等距离处一个点电荷 $q$ 的场为 $\dfrac{q}{4\pi\varepsilon_0r^2}$, 若 $q = 1.6\times10^{-19}\ \text{C}$ 则约 $1.4\times10^{9}\ \text{V/m}$. 可见偶极子场弱得多.

**例 2**: 已知 $\varphi=\dfrac{3\cos\theta}{r^2}$(V), 求 $\boldsymbol E$.

解: 与标准式 $\varphi=\dfrac{p\cos\theta}{4\pi\varepsilon_0r^2}$ 对照, 得 $\dfrac{p}{4\pi\varepsilon_0} = 3$. 由 $E_r=\dfrac{2p\cos\theta}{4\pi\varepsilon_0r^3}=\dfrac{6\cos\theta}{r^3}$, $E_\theta=\dfrac{p\sin\theta}{4\pi\varepsilon_0r^3}=\dfrac{3\sin\theta}{r^3}$:

$$\boldsymbol E=\frac{6\cos\theta}{r^3}\boldsymbol e_r+\frac{3\sin\theta}{r^3}\boldsymbol e_\theta$$

**例 3**: 偶极子 $\boldsymbol p$ 置于均匀场 $\boldsymbol E$ 中, 初始夹角 $90^\circ$, 求使其转到与场同向时电场做的功.

解: 势能 $W=-\boldsymbol p\cdot\boldsymbol E=-pE\cos\theta$. 初始 $\theta = 90^\circ$: $W_1 = 0$; 终态 $\theta = 0$: $W_2=-pE$. 电场做功等于势能减少:

$$A = W_1 - W_2 = pE$$

## 六、易错点

- 计算电位时未做远区近似, 直接相减导致表达式复杂且失去 $1 / r^2$ 的简洁形式.
- 把偶极子场写成 $1 / r^2$: 正确的是 $1 / r^3$.
- 忘记力矩公式是**叉乘**, 其方向垂直于 $\boldsymbol p$ 与 $\boldsymbol E$ 所在平面.
- 混淆电偶极矩与电荷量: $\boldsymbol p = q\boldsymbol d$ 是电荷量乘以间距.
