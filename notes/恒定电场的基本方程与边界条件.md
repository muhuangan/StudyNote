# 恒定电场的基本方程与边界条件

导电媒质中由恒定电流建立的电场称为**恒定电场**. 它的方程结构与静电场**高度相似**, 因而可以借用静电场的一切求解方法.

## 一、基本方程

| 形式 | 方程                                         | 来源                   |
| ---- | -------------------------------------------- | ---------------------- |
| 积分 | $\oint_C\boldsymbol E\cdot d\boldsymbol l=0$ | 恒定电场仍是无旋场     |
| 积分 | $\oint_S\boldsymbol J\cdot d\boldsymbol S=0$ | 电流连续性(电荷不堆积) |
| 微分 | $\nabla\times\boldsymbol E=\boldsymbol 0$    | 由上式的斯托克斯定理   |
| 微分 | $\nabla\cdot\boldsymbol J=0$                 | 由恒定电流的连续性方程 |

配合本构关系 $\boldsymbol J=\sigma\boldsymbol E$ 构成完整方程组.

**为什么仍然无旋?** 恒定电场由**恒定分布的电荷**产生, 这些电荷不随时间变化, 因此与静电场一样满足 $\nabla\times\boldsymbol E=\boldsymbol 0$, 仍可引入电位 $\boldsymbol E=-\nabla\varphi$. 区别在于: **静电场的电荷静止不动, 恒定电场的电荷在流动**.

## 二、电位方程的来源推导

由 $\nabla\cdot\boldsymbol J=0$ 与 $\boldsymbol J=\sigma\boldsymbol E$, 再代入 $\boldsymbol E=-\nabla\varphi$:

$$\nabla\cdot(\sigma\boldsymbol E)=\nabla\cdot(-\sigma\nabla\varphi)=0$$

即

$$\nabla\cdot(\sigma\nabla\varphi)=0$$

若媒质均匀($\sigma$ 为常数), 可提出:

$$\sigma\nabla^2\varphi=0\ \Longrightarrow\ \nabla^2\varphi=0$$

**结论**: **均匀导电媒质中的恒定电场, 其电位满足拉普拉斯方程**——这与无源区域静电场的电位方程**完全相同**.

## 三、边界条件

设 $\boldsymbol e_n$ 从媒质 1 指向媒质 2:

**(1) 电流法向分量连续**: 由 $\nabla\cdot\boldsymbol J=0$(取扁柱面)

$$J_{1n}=J_{2n}\qquad\text{或}\qquad \boldsymbol e_n\cdot(\boldsymbol J_1-\boldsymbol J_2)=0$$

**(2) 电场切向分量连续**: 由 $\nabla\times\boldsymbol E=\boldsymbol 0$(取扁环)

$$E_{1t}=E_{2t}\qquad\text{或}\qquad \boldsymbol e_n\times(\boldsymbol E_1-\boldsymbol E_2)=\boldsymbol 0$$

**用电位表示**(代入 $\boldsymbol J=\sigma\boldsymbol E=-\sigma\nabla\varphi$):

$$\varphi_1=\varphi_2,\qquad \sigma_1\frac{\partial\varphi_1}{\partial n}=\sigma_2\frac{\partial\varphi_2}{\partial n}$$

**两种重要特例**:

| 情形                                   | 结论                                                                 |
| -------------------------------------- | -------------------------------------------------------------------- |
| 媒质 2 为理想导体($\sigma_2\to\infty$) | 导体内 $\boldsymbol E=\boldsymbol 0$, 是等位体; 表面 $\varphi=$ 常数 |
| 媒质 2 为理想绝缘体($\sigma_2=0$)      | $J_{2n}=0$, 故 $J_{1n}=0$, **电流不能流出**, 电流线沿表面切向流动    |

## 四、静电比拟(重要技巧)

对比"无源区静电场"与"均匀媒质中的恒定电场":

| 项目     | 静电场                                    | 恒定电场                                  |
| -------- | ----------------------------------------- | ----------------------------------------- |
| 无旋方程 | $\nabla\times\boldsymbol E=0$             | $\nabla\times\boldsymbol E=0$             |
| 无散方程 | $\nabla\cdot\boldsymbol D=0$              | $\nabla\cdot\boldsymbol J=0$              |
| 本构关系 | $\boldsymbol D=\varepsilon\boldsymbol E$  | $\boldsymbol J=\sigma\boldsymbol E$       |
| 位方程   | $\nabla^2\varphi=0$                       | $\nabla^2\varphi=0$                       |
| 通量     | $Q=\int\boldsymbol D\cdot d\boldsymbol S$ | $I=\int\boldsymbol J\cdot d\boldsymbol S$ |

**结论**: 两者数学同构, 只需作替换 $\varepsilon\leftrightarrow\sigma$, $\boldsymbol D\leftrightarrow\boldsymbol J$, $Q\leftrightarrow I$.

由此得到极实用的关系(**同一几何、同一边界形状**):

$$\frac{G}{C}=\frac{\sigma}{\varepsilon}\quad\text{或}\quad G=\frac{\sigma}{\varepsilon}C$$

即: **已知某电极结构的电容 $C$, 立刻可写出其电导 $G$**(反之亦然), 无需重新求解拉普拉斯方程.

## 五、例题

**例 1**(静电比拟): 已知同轴电缆单位长度的电容为 $C=\dfrac{2\pi\varepsilon}{\ln(b/a)}$. 若填充媒质电导率为 $\sigma$, 求单位长度的漏电阻.

解: 由静电比拟

$$G=\frac{\sigma}{\varepsilon}C=\frac{\sigma}{\varepsilon}\cdot\frac{2\pi\varepsilon}{\ln(b/a)}=\frac{2\pi\sigma}{\ln(b/a)}$$

漏电阻

$$R=\frac1G=\frac{\ln(b/a)}{2\pi\sigma}$$

**例 2**(分层媒质): 两层导电媒质串联, $\sigma_1=10^{-3}\ \text{S/m}$, $\sigma_2=10^{-2}\ \text{S/m}$, 厚度分别为 $d_1=d_2=1\ \text{cm}$. 若总电流密度 $J=1\ \text{A/m}^2$, 求各层电场.

解: 由法向连续 $J_{1n}=J_{2n}=J$:

$$E_1=\frac{J}{\sigma_1}=\frac{1}{10^{-3}}=1000\ \text{V/m},\qquad E_2=\frac{J}{\sigma_2}=\frac{1}{10^{-2}}=100\ \text{V/m}$$

**结论**: 电导率小的媒质中电场更强, 电压降主要落在低电导率层上.

**例 3**(接地电阻): 半径 $a$ 的球形接地体埋于电导率为 $\sigma$ 的大地中, 求接地电阻.

解: 利用静电比拟. 孤立球的电容 $C=4\pi\varepsilon a$, 故

$$G=\frac{\sigma}{\varepsilon}\cdot4\pi\varepsilon a=4\pi\sigma a\ \Rightarrow\ R=\frac{1}{4\pi\sigma a}$$

## 六、易错点

- 把恒定电场与静电场完全等同: 前者 $\nabla\cdot\boldsymbol J=0$, 导体**内部无体电荷**, 电荷只分布在电极表面与分界面.
- 忘记边界条件用 $\sigma$ 而非 $\varepsilon$: 电流连续对应 $\sigma_1\partial_n\varphi_1=\sigma_2\partial_n\varphi_2$.
- 静电比拟时把 $G/C=\sigma/\varepsilon$ 记成反比.
- 认为恒定电场中导体内部电场为零: 那是**静电平衡**的结论, 恒定电流时导体内 $E=J/\sigma\ne0$.
