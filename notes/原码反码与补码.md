# 原码反码与补码

## 核心结论

带符号二进制数有四种表示法: 原码, 反码, 补码和移码. 其中**补码**最重要, 因为它把减法统一为加法, 把 0 的表示唯一化, 是计算机中整数运算的实际编码方式.

## 一、机器数与真值

- **真值**: 带正负号的真实数值, 如 $+5$,$-5$.
- **机器数**: 把符号数码化后的二进制表示, 最高位作为符号位(0 表示正, 1 表示负).

设机器字长为 $n$ 位, 则 1 位符号位加 $n - 1$ 位数值位.

## 二、原码

**定义**: 符号位加真值的绝对值.

- 正数原码: 符号位为 0, 数值位为绝对值本身.
- 负数原码: 符号位为 1, 数值位为绝对值本身.

例($n = 8$):

$$[+5]_\text{原} = 00000101,\quad [-5]_\text{原} = 10000101$$

**缺点**: 0 有两种表示($00000000$ 与 $10000000$); 减法不能直接当作加法做, 需要先比较绝对值大小再决定结果符号, 电路复杂.

## 三、反码

**定义**: 正数的反码与原码相同; 负数的反码是符号位保持为 1, 数值位逐位取反.

$$[-5]_\text{反} = 11111010$$

**缺点**: 0 仍有两种表示($00000000$ 与 $11111111$); 运算时若最高位产生进位, 需要把进位**循环进位**(加到最低位) 才能得到正确结果, 硬件不够简洁.

## 四、补码

**定义**: 正数的补码与原码相同; 负数的补码等于其反码加 1, 也等于 $2^n$ 减去该数的绝对值.

$$[X]_\text{补} = \begin{cases} X, & 0 \le X < 2^{n - 1} \\ 2^n + X = 2^n - |X|, & -2^{n - 1} \le X < 0 \end{cases}$$

例($n = 8$):$[-5]_\text{补} = 2^8 - 5 = 251 = 11111011$.

**快速求法(负数)**: 从原码出发, 符号位不变, 数值位**从右往左找到第一个 1, 该 1 及其右边保持不变, 其左边全部取反**. 这一技巧比"取反加一"更快且不易出错.

**补码的优点**:

1. 0 的表示唯一:$[0]_\text{补} = 00000000$.
2. 减法可以化为加法:$A - B = A + [-B]_\text{补}$.
3. 符号位可以直接参与运算, 不需要单独处理.
4. 表示范围比原码, 反码多一个数:$n$ 位补码可表示 $-2^{n - 1}$ 至 $2^{n - 1} - 1$. 以 8 位为例是 $-128$ 至 $+127$, 其中 $10000000$ 被定义为 $-128$.

## 五、移码

**定义**: 在补码基础上把符号位取反, 即

$$[X]_\text{移} = 2^{n - 1} + X$$

移码保持了真值从小到大的**无符号大小顺序**, 因此专门用于浮点数的阶码比较.

## 六、四种表示法对照($n = 4$)

| 真值 | 原码 | 反码 | 补码 | 移码 |
| ---- | ---- | ---- | ---- | ---- |
| +7   | 0111 | 0111 | 0111 | 1111 |
| +1   | 0001 | 0001 | 0001 | 1001 |
| +0   | 0000 | 0000 | 0000 | 1000 |
| -0   | 1000 | 1111 | —    | —    |
| -1   | 1001 | 1110 | 1111 | 0111 |
| -7   | 1111 | 1000 | 1001 | 0001 |
| -8   | 无   | 无   | 1000 | 0000 |

## 易错点

- $-128$ 在 8 位补码中存在($10000000$), 但它的相反数 $+128$ 无法表示, 对 $-128$ 求补会得到它自身.
- 补码的符号位是数值的一部分, 扩展位数时要做**符号扩展**: 正数高位补 0, 负数高位补 1.
