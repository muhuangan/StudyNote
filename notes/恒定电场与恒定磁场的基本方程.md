# 恒定电场与恒定磁场的基本方程

恒定电场(导电媒质中的稳定电流场)与恒定磁场是一对平行理论: 前者的方程与静电场**结构相同**, 后者的方程与静电场**对偶**.

## 一、电流与电流密度

**电流强度**: 单位时间穿过某截面的电荷量, $I=\dfrac{dq}{dt}$, 单位 $\text{A}$.

**电流密度矢量** $\boldsymbol J$: 方向为该点正电荷运动方向, 大小为垂直于运动方向单位面积上的电流:

$$I=\int_S\boldsymbol J\cdot d\boldsymbol S$$

**三种电流密度**:

| 类型   | 表达式                                | 说明                |
| ------ | ------------------------------------- | ------------------- |
| 体电流 | $\boldsymbol J=\rho\boldsymbol v$     | $\rho$ 为体电荷密度 |
| 面电流 | $\boldsymbol J_S=\rho_S\boldsymbol v$ | 表面流动            |
| 线电流 | $I=\rho_l v$                          | 细导线              |

**电流连续性方程**(电荷守恒的数学表述):

$$\oint_S\boldsymbol J\cdot d\boldsymbol S=-\frac{dq}{dt}\qquad\Longleftrightarrow\qquad \nabla\cdot\boldsymbol J=-\frac{\partial\rho}{\partial t}$$

**恒定电流**时 $\dfrac{\partial\rho}{\partial t} = 0$, 故

$$\nabla\cdot\boldsymbol J = 0$$

即恒定电流场是**无散场**, 电流线处处闭合.

## 二、恒定电场的基本方程

导电媒质中, 恒定电场满足:

$$\oint_C\boldsymbol E\cdot d\boldsymbol l = 0\qquad\Longleftrightarrow\qquad\nabla\times\boldsymbol E=\boldsymbol 0$$
$$\oint_S\boldsymbol J\cdot d\boldsymbol S = 0\qquad\Longleftrightarrow\qquad\nabla\cdot\boldsymbol J = 0$$

配合**欧姆定律的微分形式**

$$\boldsymbol J=\sigma\boldsymbol E$$

($\sigma$ 为电导率, 单位 $\text{S/m}$)即构成完整方程组.

**与静电场的对照**:

|          | 静电场(介质中)                           | 恒定电场(导电媒质中)                |
| -------- | ---------------------------------------- | ----------------------------------- |
| 无旋方程 | $\nabla\times\boldsymbol E = 0$          | $\nabla\times\boldsymbol E = 0$     |
| 有散方程 | $\nabla\cdot\boldsymbol D=\rho$          | $\nabla\cdot\boldsymbol J = 0$      |
| 本构关系 | $\boldsymbol D=\varepsilon\boldsymbol E$ | $\boldsymbol J=\sigma\boldsymbol E$ |
| 可引入   | 电位 $\boldsymbol E=-\nabla\varphi$      | 电位 $\boldsymbol E=-\nabla\varphi$ |
| 电位方程 | $\nabla^2\varphi=-\rho/\varepsilon$      | $\nabla^2\varphi = 0$               |

**结论: 恒定电场的电位满足拉普拉斯方程**(因为导电媒质内部无自由电荷堆积).

## 三、恒定磁场的基本方程

$$\oint_S\boldsymbol B\cdot d\boldsymbol S = 0\qquad\Longleftrightarrow\qquad\nabla\cdot\boldsymbol B = 0$$
$$\oint_C\boldsymbol B\cdot d\boldsymbol l=\mu_0I\qquad\Longleftrightarrow\qquad\nabla\times\boldsymbol B=\mu_0\boldsymbol J$$

前者是**磁通连续性定理**(磁场无散, 磁感线闭合), 后者是**安培环路定律**.

**与静电场的对偶关系**:

| 静电场                                    | 恒定磁场                                       |
| ----------------------------------------- | ---------------------------------------------- |
| $\nabla\cdot\boldsymbol D=\rho$           | $\nabla\times\boldsymbol B=\mu_0\boldsymbol J$ |
| $\nabla\times\boldsymbol E=\boldsymbol 0$ | $\nabla\cdot\boldsymbol B = 0$                 |
| 电偶极子 $\boldsymbol p$                  | 磁偶极子 $\boldsymbol m$                       |

## 四、例题

**例 1**(安培环路定律求磁场): 求无限长直导线(电流 $I$)在距离 $\rho$ 处的磁感应强度.

解: 取半径 $\rho$ 的圆形回路, 由对称性 $\boldsymbol B\parallel d\boldsymbol l$ 且 $B$ 恒定:

$$B\cdot2\pi\rho=\mu_0I\ \Rightarrow\ \boldsymbol B=\frac{\mu_0I}{2\pi\rho}\boldsymbol e_\phi$$

**例 2**(磁通连续性): 说明为什么不存在"磁荷".

解: 由 $\oint_S\boldsymbol B\cdot d\boldsymbol S = 0$, 穿过任意闭合面的磁通恒为零, 即**磁感线无起点无终点**(总是闭合曲线). 这与电场线起于正电荷、止于负电荷形成对照; 若存在磁荷(磁单极子), 则右端应改为 $q_m$, 而实验至今未发现.

**例 3**(恒定电场中的电阻): 均匀导电媒质中, 已知两点间电位差 $U$ 与电场分布, 求电流与该段电阻.

解: 由 $\boldsymbol E=-\nabla\varphi$ 求得 $\boldsymbol E$, 再由 $\boldsymbol J=\sigma\boldsymbol E$ 积分得 $I$, 最后由 $R = U / I$ 求电阻. 由于 $\nabla^2\varphi = 0$, 恒定电场问题与"相同几何、相同边界"的静电场问题**数学同构**, 这一对应称为**静电比拟**, 可用于互相借用电容公式求电导($G\leftrightarrow C$, $\sigma\leftrightarrow\varepsilon$).

## 五、易错点

- 把恒定电场与静电场完全等同: 前者内部无体电荷($\nabla\cdot\boldsymbol J = 0$), 电荷只出现在**电极表面与分界面**.
- 混淆 $\boldsymbol J=\sigma\boldsymbol E$ 与 $\boldsymbol D=\varepsilon\boldsymbol E$ 的适用对象.
- 误认为"磁场有源": $\nabla\cdot\boldsymbol B = 0$ 表明磁场**无散**.
- 安培环路定律只对恒定电流成立, 时变情形需加位移电流项.
