# 相关系数

协方差带量纲, 无法直接比较相关强弱. 除以两个标准差把它标准化, 就得到取值恒在 $[-1,1]$ 内的**相关系数**.

## 一、定义

设 $D(X)>0$, $D(Y)>0$, 称

$$\rho_{XY}=\frac{\operatorname{Cov}(X,Y)}{\sqrt{D(X)}\sqrt{D(Y)}}$$

为 $X$ 与 $Y$ 的**相关系数**.

**要点**: $\rho_{XY}$ 是**无量纲**的纯数, 因此可以在不同问题之间比较.

## 二、基本性质

**(1) 取值范围**

$$|\rho_{XY}|\le1$$

**证明思路**: 对任意实数 $t$, 有 $D(Y - tX)\ge0$, 即

$$t^2D(X) - 2t\operatorname{Cov}(X,Y) + D(Y)\ge0\quad\text{对一切 }t$$

作为 $t$ 的二次式恒非负, 判别式必须 $\le0$:

$$4\operatorname{Cov}^2(X,Y) - 4D(X)D(Y)\le0\ \Rightarrow\ \rho_{XY}^2\le1$$

**(2) 取到 ±1 的充要条件**: $|\rho_{XY}|=1$ $\iff$ 存在常数 $a\ne0,b$ 使

$$P(Y = aX + b) = 1$$

即 $X,Y$ 之间是**严格的线性关系**(概率 1 成立). $\rho = 1$ 时 $a>0$, 正相关; $\rho=-1$ 时 $a<0$, 负相关.

**(3) 在标准化下等于协方差**: 令 $X^*=\dfrac{X - E(X)}{\sqrt{D(X)}}$, $Y^*=\dfrac{Y - E(Y)}{\sqrt{D(Y)}}$, 则

$$\rho_{XY} = \operatorname{Cov}(X^*,Y^*)$$

## 三、怎样解读 $\rho$

| $\rho$ 的取值 | 含义                             |
| ------------- | -------------------------------- |
| $\rho>0$      | 正相关: 一个偏大时另一个倾向偏大 |
| $\rho<0$      | 负相关: 一个偏大时另一个倾向偏小 |
| $\rho = 0$    | 不相关(无**线性**关联)           |
| $\rho=\pm1$   | 完全线性关系                     |

**$\rho$ 的准确含义**: 它是**线性**关联强度的度量. $\rho$ 接近 0 只说明"没有线性关系", 并**不排除**存在明显的非线性关系(如 $Y = X^2$).

## 四、例题

**例 1**: 承[协方差](./协方差.md)例 1: $\operatorname{Cov}(X,Y) = 0.05$, 且 $D(X) = 0.25$, $D(Y) = 0.21$. 求 $\rho_{XY}$.

解:

$$\rho_{XY}=\frac{0.05}{\sqrt{0.25}\times\sqrt{0.21}}=\frac{0.05}{0.5\times0.4583}=\frac{0.05}{0.2291}\approx0.218$$

属于弱正相关.

**例 2**(二维正态): 设 $(X,Y)\sim N(\mu_1,\mu_2,\sigma_1^2,\sigma_2^2,\rho)$, 则其相关系数恰好等于参数 $\rho$. 因此在二维正态族里,"$\rho = 0$"就是"独立", 二者等价.

**例 3**(线性关系的极端情形): 设 $Y = 3X + 2$ 且 $D(X) = 1$. 求 $\rho_{XY}$.

解: $\operatorname{Cov}(X,Y) = \operatorname{Cov}(X,3X + 2) = 3D(X) = 3$, $\sqrt{D(Y)}=\sqrt{9D(X)} = 3$, $\sqrt{D(X)} = 1$, 故

$$\rho_{XY}=\frac{3}{1\times3} = 1$$

符合"存在正线性关系时 $\rho = 1$".

**例 4**(反例: $\rho = 0$ 但有强关系): 设 $X\sim U(-1,1)$, $Y = X^2$. 求 $\rho_{XY}$.

解: $E(X) = 0$, $E(XY) = E(X^3) = 0$(奇函数在对称区间上积分为 0), 故

$$\operatorname{Cov}(X,Y) = E(XY) - E(X)E(Y) = 0\ \Rightarrow\ \rho_{XY} = 0$$

但 $Y$ 完全由 $X$ 决定($Y = X^2$), 二者显然**不独立**且存在强(非线性)关系. 这清楚说明 $\rho$ 只衡量线性关联.

## 五、易错点

- 认为 $\rho = 0$ 就是"两个变量没有关系": 只是没有**线性**关系.
- 忘记 $\rho$ 的符号意义: 负号表示负相关, 不能丢掉.
- 把 $\rho$ 与协方差混为一谈: 前者无量纲, 后者带量纲.
- 认为相关一定意味着因果: 统计相关不等于因果关系.
- 忘记 $\rho$ 存在的前提是 $D(X),D(Y)>0$.
