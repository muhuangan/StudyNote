# 电磁场与波

## 阅读约定

1. 矢量用粗斜体表示(如 $\boldsymbol E$), 单位矢量用 $\boldsymbol e_x,\boldsymbol e_\rho,\boldsymbol e_r$ 表示.
2. 基本场量: 电场强度 $\boldsymbol E$, 电位移矢量 $\boldsymbol D$, 磁感应强度 $\boldsymbol B$, 磁场强度 $\boldsymbol H$, 电流密度 $\boldsymbol J$; 辅助函数: 电位 $\varphi$, 矢量磁位 $\boldsymbol A$.
3. 采用 $e^{j\omega t}$ 时间约定(相量法的取实部约定为 $\cos$).
4. 本系列按"矢量分析 → 静电场 → 恒定电场与恒定磁场 → 时变电磁场 → 平面电磁波 → 反射与折射"组织. 每篇含定义, 公式, **来源推导**, 性质与例题; 例题给出完整步骤与数值, 便于独立重算.
