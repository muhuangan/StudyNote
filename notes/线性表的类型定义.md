# 线性表的类型定义

**线性表**: 具有相同特性的数据元素的一个有限序列  
基本要素: 线性起点, 直接前趋, 直接后继, 线性终点  
**表长**: 数据元素个数

**空表**: n = 0

顺序存储结构问题:

1. 存储空间分配不灵活
2. 空间复杂度高
