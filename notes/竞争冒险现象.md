# 竞争冒险现象

## 核心结论

**竞争**是指同一信号经不同路径到达某点的时间差; **冒险**是指竞争导致输出出现不应有的窄脉冲(毛刺). 判断方法有代数法和卡诺图法, 消除方法有加冗余项, 加滤波电容, 加选通脉冲三种.

## 一、概念辨析

**竞争(Race)**: 一个输入信号经过两条(或多条) 不同路径传输到同一个门电路的输入端, 由于各路径的门数量和延迟不同, 到达时间有先后.

**冒险(Hazard)**: 由于竞争, 输出在短时间内出现违背真值表的尖峰脉冲(毛刺, glitch).

**关键区别**: 竞争是**原因**, 冒险是**可能的结果**. 有竞争不一定有冒险, 只有当电路结构对时间差敏感时才会产生毛刺.

## 二、两种冒险类型

### 静态 1 型冒险("0"型冒险的对称情况)

输出本应**恒为 1**, 但在输入变化时出现了一个短暂的 0 脉冲.

**典型电路**:$F = A + \overline{A}$. 理论上恒为 1, 但当 $A$ 由 1 变 0 时, 由于反相器有延迟,$\overline{A}$ 尚未变高, 瞬间出现 $A = 0$ 且 $\overline{A} = 0$, 输出短暂为 0.

### 静态 0 型冒险

输出本应**恒为 0**, 但出现了一个短暂的 1 脉冲.

**典型电路**:$F = A \cdot \overline{A}$. 当 $A$ 由 0 变 1 时,$\overline{A}$ 尚未变低, 瞬间两输入都为 1, 输出短暂为 1.

### 动态冒险

输出本应变化一次, 却变化了多次(如 0→1→0→1). 多发生在多级电路中, 通常由多个静态冒险叠加产生.

## 三、判断方法一: 代数法

**判据**: 把除一个变量外的其余变量固定为某些取值后, 若表达式能化为

$$F = A + \overline{A} \quad \text{或} \quad F = A \cdot \overline{A}$$

则存在冒险. 前者产生静态 1 型冒险(毛刺为 0), 后者产生静态 0 型冒险(毛刺为 1).

**检查步骤**:

1. 逐个变量检查.
2. 对某变量 $A$, 找出使其他变量固定后 $F$ 中出现 $A$ 与 $\overline{A}$ 的取值组合.
3. 若存在, 则在该组合下 $A$ 变化时会产生冒险.

**示例**:$F = AB + \overline{A}C$.

令 $B = C = 1$, 则 $F = A + \overline{A}$, 因此当 $B = C = 1$ 且 $A$ 发生变化时, 输出会出现 0 毛刺, 存在静态 1 型冒险.

## 四、判断方法二: 卡诺图法

**判据**: 若卡诺图中**两个圈相切**(即两个圈有公共边但没有重叠的方格), 且切点处没有被第三个圈覆盖, 则存在冒险.

**原因**: 相切处的输入变化会使输出从一个圈"跳到"另一个圈, 而两个圈对应的乘积项在切换瞬间可能同时为 0(或同时为 1), 产生毛刺.

**示例**:$F = AB + \overline{A}C$ 的卡诺图中,$AB$ 圈与 $\overline{A}C$ 圈在 $m_3$,$m_7$ 附近相切, 切点处无第三个圈覆盖, 因此存在冒险.

## 五、消除方法一: 加冗余项(最常用)

**做法**: 在卡诺图上把相切处再圈一个圈, 即添加一个冗余的乘积项, 把两个相切的圈"连"起来.

**示例**:$F = AB + \overline{A}C$ 在 $B = C = 1$ 时冒险, 添加冗余项 $BC$:

$$F = AB + \overline{A}C + BC$$

由冗余律,$BC$ 不改变函数的逻辑值; 但当 $B = C = 1$ 时,$BC = 1$ 使输出稳定为 1, 毛刺消失.

**优点**: 从逻辑上彻底消除, 不依赖元件参数.
**缺点**: 增加器件.

## 六、消除方法二: 加滤波电容

**做法**: 在输出端与地之间并联一个小电容(几十至几百皮法).

**原理**: 利用电容两端电压不能突变的特性, 把窄毛刺平滑掉.

**优点**: 最简单, 成本最低.
**缺点**:

1. 会使输出波形的上升/下降沿变缓, 增加传输延迟.
2. 对宽度较大的毛刺无效.
3. 不适用于对边沿要求严格的信号(如时钟).

## 七、消除方法三: 加选通脉冲(最彻底)

**做法**: 引入一个**选通脉冲** $P$, 只在电路输出已经稳定后才允许输出通过; 在未稳定期间(输入变化后的一段时间内) 把输出封锁.

**实现**:

$$F_{out} = F \cdot P$$

其中 $P$ 的上升沿必须晚于输入信号变化的时刻, 且晚于电路的最大传输延迟.

**优点**: 完全消除毛刺, 且不改变逻辑功能.
**缺点**: 需要额外的时序控制信号, 输出变成脉冲形式(只在选通期间有效), 对时序要求严格.

## 八、三种方法的对比

| 方法       | 原理     | 代价       | 适用场景                   |
| ---------- | -------- | ---------- | -------------------------- |
| 加冗余项   | 逻辑消除 | 增加器件   | 组合电路, 可修改设计时首选 |
| 加滤波电容 | 平滑波形 | 边沿变缓   | 输出对边沿不敏感的场合     |
| 加选通脉冲 | 时间避开 | 需额外时序 | 时序系统, 同步电路首选     |

**工程首选**: 在同步时序系统中, 毛刺通常出现在时钟之间, 只要在时钟有效沿时刻采样, 毛刺自然被忽略, 这是最经济的方法. 因此"加选通脉冲"的思想实际上体现在同步设计方法中.

## 九、冒险与格雷码的关系

多位信号同时变化最容易产生冒险. 若把编码改为**格雷码**, 使状态变化时只有 1 位翻转, 则从根本上避免了多位竞争. 这是格雷码计数器, 异步 FIFO 跨时钟域设计的理论依据.

## 易错点

- 认为"有竞争就一定有冒险": 竞争是普遍存在的, 只有当表达式满足 $A + \overline{A}$ 或 $A \cdot \overline{A}$ 形式时才会产生毛刺.
- 认为加滤波电容是万能的: 它会劣化边沿, 在高速电路中不可接受.
- 忽略 MSI 器件内部的冒险: 使用译码器, 数据选择器实现的函数同样可能产生毛刺.
