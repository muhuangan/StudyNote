# 电位与电位差

静电场是无旋场, 因此可以引入标量位函数——**电位**. 引入电位之后, 矢量问题简化为标量问题, 计算量大幅下降.

## 一、静电场的环路定理

静电场做功与路径无关, 即

$$\oint_C\boldsymbol E\cdot d\boldsymbol l = 0$$

由斯托克斯定理得**微分形式**:

$$\nabla\times\boldsymbol E=\boldsymbol 0$$

这是静电场**无旋性**的体现, 也是引入电位的依据.

## 二、电位的定义

静电场中某点 $P$ 的**电位**定义为把单位正电荷从 $P$ 点移到**参考点** $Q$ 时电场力所做的功:

$$\varphi_P=\int_P^{Q}\boldsymbol E\cdot d\boldsymbol l$$

**参考点的选取**:

- 有限区域问题: 常取无穷远点为参考, 即 $\varphi_\infty = 0$;
- 工程问题: 常取大地或机壳为参考(接地).

**电场强度是电位的负梯度**:

$$\boldsymbol E=-\nabla\varphi$$

负号的含义: 电场指向电位**降低**最快的方向.

## 三、电位差与两点间的关系

$$U_{PQ}=\varphi_P-\varphi_Q=\int_P^{Q}\boldsymbol E\cdot d\boldsymbol l$$

**电位是相对的, 电位差是绝对的**: 改变参考点只会使各点电位同时加上同一个常数, 不影响电场强度.

## 四、电位的计算

**点电荷**: 取无穷远为参考,

$$\varphi=\frac{q}{4\pi\varepsilon_0r}$$

**叠加原理**: 电位是**标量**, 直接代数相加:

$$\varphi=\sum_i\frac{q_i}{4\pi\varepsilon_0r_i}$$

**结论**: 求电场时优先算电位, 再由 $\boldsymbol E=-\nabla\varphi$ 求场(标量求和比矢量求和容易, 这是电位法的最大优势).

## 五、三种坐标系中的电位方程

由 $\boldsymbol E=-\nabla\varphi$ 与 $\nabla\cdot\boldsymbol E=\dfrac{\rho}{\varepsilon_0}$ 得**泊松方程**:

$$\nabla^2\varphi=-\frac{\rho}{\varepsilon_0}$$

无源区域($\rho = 0$)退化为**拉普拉斯方程**:

$$\nabla^2\varphi = 0$$

拉普拉斯算子在直角坐标中为 $\nabla^2=\dfrac{\partial^2}{\partial x^2}+\dfrac{\partial^2}{\partial y^2}+\dfrac{\partial^2}{\partial z^2}$.

## 六、例题

**例 1**: 求点电荷 $q$ 在距离 $r$ 处的电位, 并由此求电场.

解:

$$\varphi=\frac{q}{4\pi\varepsilon_0r}$$

由球对称性, 用球坐标梯度公式:

$$\boldsymbol E=-\nabla\varphi=-\frac{\partial\varphi}{\partial r}\boldsymbol e_r=\frac{q}{4\pi\varepsilon_0r^2}\boldsymbol e_r$$

与库仑定律一致.

**例 2**(电偶极子的电位): 两个等量异号点电荷 $+q$ 与 $-q$ 相距 $d$, 求远区电位.

解: 由叠加原理(取 $r\gg d$)

$$\varphi=\frac{q}{4\pi\varepsilon_0}\left(\frac{1}{r_1}-\frac{1}{r_2}\right)\approx\frac{qd\cos\theta}{4\pi\varepsilon_0r^2}=\frac{\boldsymbol p\cdot\boldsymbol e_r}{4\pi\varepsilon_0r^2}$$

其中 $\boldsymbol p = q\boldsymbol d$ 为电偶极矩, $\theta$ 为位矢与 $\boldsymbol p$ 的夹角.

**注意**: 偶极子电位按 $1 / r^2$ 衰减, 比点电荷的 $1 / r$ 更快; 这是"两电荷的 $1 / r$ 项互相抵消"的结果.

**例 3**: 已知电位 $\varphi = 3x^2y$(V), 求点 $(1,2,3)$ 处的电场.

解:

$$\boldsymbol E=-\nabla\varphi=-\left(6xy\boldsymbol e_x + 3x^2\boldsymbol e_y\right)$$

代入 $(1,2,3)$:

$$\boldsymbol E=-(12\boldsymbol e_x + 3\boldsymbol e_y)=-12\boldsymbol e_x - 3\boldsymbol e_y\ \text{V/m}$$

## 七、易错点

- 忘记 $\boldsymbol E=-\nabla\varphi$ 中的**负号**.
- 把电位当矢量: 电位是**标量**, 求和时直接代数相加.
- 忘记参考点的选取: 不同参考点下同一点电位不同, 题目未说明时默认取无穷远.
- 混淆电位与电位能: 电位能 $W = q\varphi$ 与电荷量有关, 电位与试探电荷无关.
