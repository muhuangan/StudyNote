# 事件的运算律

事件的运算满足一整套代数律, 其中最常用的是**分配律**与**德摩根律**. 熟练之后可以像化简代数式一样化简事件表达式.

## 一、基本运算律

设 $A,B,C$ 为事件, 则:

**幂等律**

$$A\cup A = A,\qquad AA = A$$

**交换律**

$$A\cup B = B\cup A,\qquad AB = BA$$

**结合律**

$$(A\cup B)\cup C = A\cup(B\cup C),\qquad (AB)C = A(BC)$$

**吸收律**

$$A\cup(AB) = A,\qquad A(A\cup B) = A$$

**分配律**(两条都要会)

$$A(B\cup C) = AB\cup AC$$
$$A\cup(BC) = (A\cup B)(A\cup C)$$

第一条与代数中的分配律完全一致; 第二条是集合特有的, 代数中没有对应物, 最容易漏掉.

**与全集、空集的关系**

$$A\cup\Omega=\Omega,\quad A\Omega = A,\quad A\cup\varnothing = A,\quad A\varnothing=\varnothing,\quad A\cup\bar A=\Omega,\quad A\bar A=\varnothing$$

**双重否定律**

$$\overline{(\bar A)} = A$$

## 二、德摩根律(对偶律)

这是全篇最重要的一条:

$$\overline{A\cup B}=\bar A\,\bar B,\qquad \overline{AB}=\bar A\cup\bar B$$

口决: **长杠变短杠, 并且"并变交, 交变并"**.

推广到 $n$ 个事件:

$$\overline{\bigcup_{i = 1}^{n}A_i}=\bigcap_{i = 1}^{n}\bar A_i,\qquad \overline{\bigcap_{i = 1}^{n}A_i}=\bigcup_{i = 1}^{n}\bar A_i$$

它的实用价值在于把"至少一个发生"与"全都不发生"来回转换:

$$\overline{A_1\cup A_2\cup\cdots\cup A_n}=\bar A_1\bar A_2\cdots\bar A_n$$

即"**至少有一个发生**"的逆事件是"**一个都没发生**". 这是**正难则反**解法的理论依据.

## 三、例题

**例 1**: 化简 $(A\cup B)(A\cup\bar B)$.

解: 用第二条分配律

$$(A\cup B)(A\cup\bar B) = A\cup(B\bar B) = A\cup\varnothing = A$$

**例 2**: 已知 $\overline{A\cup B\cup C}$ 表示"三人都没击中", 用 $\bar A,\bar B,\bar C$ 表示它.

解: 由德摩根律

$$\overline{A\cup B\cup C}=\bar A\,\bar B\,\bar C$$

**例 3**: 若 $A\subset B$, 化简 $A\cup B$, $AB$, $A - B$.

解:

- $A\cup B = B$;
- $AB = A$;
- $A - B = A\bar B=\varnothing$(因为 $A$ 全在 $B$ 里面, $A$ 发生必有 $B$ 发生, 不存在"$A$ 发生而 $B$ 不发生").

**例 4**: 证明 $(A - B)\cup(B - A) = (A\cup B) - AB$.

解:

$$(A - B)\cup(B - A) = A\bar B\cup \bar A B$$

右端:

$$(A\cup B) - AB = (A\cup B)\overline{AB} = (A\cup B)(\bar A\cup\bar B)$$
$$=A\bar A\cup A\bar B\cup B\bar A\cup B\bar B=\varnothing\cup A\bar B\cup \bar AB\cup\varnothing = A\bar B\cup\bar AB$$

两端相等, 得证. 该式的实际意义是"**恰有一个发生**".

**例 5**(正难则反): 甲, 乙, 丙三人独立破译密码, 各自能译出的概率分别为 $0.4,0.5,0.6$, 求密码被译出的概率.

解: 记 $A_1,A_2,A_3$ 为三人各自译出. 直接求"至少一个成功"要分 7 种情况, 改用对立事件:

$$P(A_1\cup A_2\cup A_3) = 1 - P(\bar A_1\bar A_2\bar A_3) = 1 - 0.6\times0.4\times0.4 = 1 - 0.096 = 0.904$$

## 四、易错点

- 德摩根律方向搞反: $\overline{A\cup B}$ 是 $\bar A\bar B$, 不是 $\bar A\cup\bar B$;
- 忘记第二条分配律 $A\cup(BC) = (A\cup B)(A\cup C)$;
- 认为 $A - B = B - A$: 差运算**不可交换**, 只有在 $A = B$ 时相等;
- 把事件的"减"当成数值相减, 例如认为 $P(A\cup B) - P(A) = P(B)$, 这只有在 $A\subset B$ 或类似条件下才对.
