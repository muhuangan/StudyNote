# 随机变量函数的期望

计算 $E\bigl(g(X)\bigr)$ 时**不必先求出 $g(X)$ 的分布**: 直接拿 $g$ 作用在每个取值上再按原分布加权即可. 这条结论极大简化了运算.

## 一、一维情形

设 $X$ 的分布已知, $g$ 为连续函数.

**离散型**: 若 $P(X = x_k) = p_k$, 则

$$E\bigl[g(X)\bigr]=\sum_{k}g(x_k)\,p_k$$

**连续型**: 若 $X$ 的密度为 $f(x)$, 则

$$E\bigl[g(X)\bigr]=\int_{-\infty}^{+\infty}g(x)f(x)\,dx$$

**与直接法的对比**: 直接法要先求出 $Y = g(X)$ 的分布律或密度, 再按定义算期望, 步骤繁琐; 本公式**用 $X$ 的分布就够了**.

(上述要求相应的级数或积分绝对收敛; 否则该期望不存在.)

## 二、二维情形

设 $(X,Y)$ 的联合分布已知, $g$ 为二元连续函数.

**离散型**:

$$E\bigl[g(X,Y)\bigr]=\sum_{i}\sum_{j}g(x_i,y_j)\,p_{ij}$$

**连续型**:

$$E\bigl[g(X,Y)\bigr]=\int_{-\infty}^{+\infty}\int_{-\infty}^{+\infty}g(x,y)f(x,y)\,dx\,dy$$

**特别有用的特例**: 取 $g(x,y) = xy$ 得 $E(XY)$; 取 $g(x,y) = x + y$ 得 $E(X + Y)$.

## 三、例题

**例 1**(离散): 设 $X$ 的分布律为

| $X$ | $-1$ | $0$ | $1$ | $2$ |
| --- | ---- | --- | --- | --- |
| $P$ | 0.2  | 0.3 | 0.4 | 0.1 |

求 $E(X^2)$ 与 $E(2X + 1)$.

解: 不必先求 $X^2$ 的分布, 直接作用:

$$E(X^2) = (-1)^2(0.2) + 0^2(0.3) + 1^2(0.4) + 2^2(0.1) = 0.2 + 0.4 + 0.4 = 1.0$$
$$E(2X + 1) = 2E(X) + 1 = 2\times0.6 + 1 = 2.2$$

其中 $E(X) = (-1)(0.2) + 0(0.3) + 1(0.4) + 2(0.1) = 0.6$.

**例 2**(连续): 设 $X\sim U(0,1)$, 求 $E(X^2)$ 与 $E(e^X)$.

解:

$$E(X^2)=\int_0^1x^2dx=\frac13$$
$$E(e^X)=\int_0^1e^xdx = e - 1\approx1.7183$$

**例 3**(正态): 设 $X\sim N(0,1)$, 求 $E(e^X)$.

解: 用高斯积分:

$$E(e^X)=\int_{-\infty}^{+\infty}e^x\cdot\frac{1}{\sqrt{2\pi}}e^{-x^2 / 2}dx=\frac{1}{\sqrt{2\pi}}\int_{-\infty}^{+\infty}e^{-(x - 1)^2 / 2+\frac12}dx = e^{1 / 2}\approx1.6487$$

即 $E(e^X) = e^{\sigma^2 / 2+\mu}$ 在 $\mu = 0,\sigma = 1$ 时的取值. 这条常用来求对数正态分布的期望.

**例 4**(二维): 设 $(X,Y)$ 的联合分布律为 $P(X = i,Y = j)=\frac{1}{9}\ (i,j\in\{1,2,3\})$, 求 $E(XY)$.

解:

$$E(XY)=\sum_{i = 1}^{3}\sum_{j = 1}^{3}ij\cdot\frac19=\frac19\left(\sum_{i = 1}^3i\right)\left(\sum_{j = 1}^3j\right)=\frac19\times6\times6 = 4$$

(这里 $X,Y$ 独立, 所以结果也等于 $E(X)E(Y) = 2\times2 = 4$.)

## 四、为什么这条公式成立(离散情形的证明思路)

设 $Y = g(X)$, 把 $X$ 的取值按 $g$ 的取值**分组**, 则

$$E(Y)=\sum_{y}y\,P(Y = y)=\sum_{y}y\sum_{k:\,g(x_k) = y}P(X = x_k)=\sum_{y}\sum_{k:\,g(x_k) = y}g(x_k)P(X = x_k)=\sum_{k}g(x_k)p_k$$

即"按 $Y$ 的值分组求和"等价于"按 $X$ 的值直接求和". 连续情形的证明思路相同.

## 五、易错点

- 误以为 $E[g(X)] = g\bigl(E(X)\bigr)$: 一般**不成立**! 例如 $E(X^2)\ne[E(X)]^2$(差值正是方差). 只有当 $g$ 为线性函数时才恒成立.
- 先求了 $g(X)$ 的分布再算期望, 白白增加工作量.
- 二维情形漏掉交叉项或漏掉联合密度的定义域限制.
- 忘记绝对收敛条件.
